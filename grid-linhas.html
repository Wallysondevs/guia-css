CSS Linhas (grid-template-rows)

Até aqui, a Ana só desenhou as colunas das grades, e o navegador criou as linhas sozinho, cada uma com a altura do conteúdo. Muitas vezes isso basta. Mas a galeria de fotos fica mais bonita com todas as linhas da mesma altura, e no layout do blog ela quer o rodapé sempre no pé da página, mesmo quando o texto é curto. Nesta aula você vai controlar as linhas com grid-template-rows e grid-auto-rows.

Você vai aprender
  • Qual altura as linhas têm quando você não diz nada, e por que todos os itens de uma linha ficam da mesma altura.
  • grid-template-rows: linhas com altura definida.
  • As linhas que o navegador cria sozinho (a grade implícita) e o grid-auto-rows, que dá altura a elas.
  • minmax() para uma altura mínima que pode crescer.
  • fr nas linhas: por que precisa de uma altura no pai, e o layout com o rodapé no pé.
  • O texto que vaza de uma linha baixa demais, e as mensagens reais do validador W3C.

Antes, é bom ter visto Introdução ao Grid e Colunas (grid-template-columns e fr): quase tudo das colunas vale para as linhas. Os exemplos com resultado são desenhados agora pelo seu navegador; os números em pixels do texto foram medidos no Chromium. As mensagens do validador saíram do validador W3C (vnu), na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: as prateleiras de uma estante

As colunas de uma grade são como as divisórias em pé de uma estante. As linhas são as prateleiras. Numa estante montada sob medida, cada prateleira tem a altura do objeto mais alto que vai nela: se um livro grande entra, a prateleira inteira fica alta, e os livros pequenos ao lado ganham um espaço sobrando em cima. Numa estante comprada pronta, as prateleiras têm alturas fixas: ou o objeto cabe, ou fica para fora.

No Grid, as linhas são "sob medida" por padrão. Com grid-template-rows e grid-auto-rows, você escolhe as alturas.

1. Sem dizer nada: linhas sob medida

Uma grade de três colunas e cinco itens. O item 2 tem um texto mais comprido:

<link rel="stylesheet" href="style.css">
<div class="grade">
  <div class="item">1</div>
  <div class="item">2. Um texto maior, que quebra em várias linhas</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
</div>

.grade {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 8px;
  width: 400px;
  border: 2px dashed gray;
}

.item {
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}

A primeira linha ficou da altura do item 2, e os itens 1 e 3 esticaram até essa altura, com espaço vazio embaixo do número. A segunda linha, só com textos curtos, ficou baixinha. Cada linha tem a altura do seu item mais alto (o valor auto), e os itens esticam para preencher a casa (o alinhamento padrão, stretch, que você controla na aula Alinhando no Grid).

2. grid-template-rows: alturas definidas

O grid-template-rows ("modelo das linhas") funciona igual ao grid-template-columns: um tamanho para cada linha, separados por espaço, de cima para baixo.

<link rel="stylesheet" href="style.css">
<div class="grade">
  <div class="item">1</div><div class="item">2</div><div class="item">3</div>
  <div class="item">4</div><div class="item">5</div><div class="item">6</div>
  <div class="item">7</div>
</div>

.grade {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 60px 100px;
  gap: 8px;
  width: 400px;
  border: 2px dashed gray;
}

.item {
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}
grid-template-rows
Desenha as linhas da grade. Vai no pai, junto do display: grid.
60px
A altura da primeira linha (itens 1, 2 e 3).
100px
A altura da segunda linha (itens 4, 5 e 6).

E o item 7? A Ana desenhou só duas linhas, mas há sete itens em três colunas. O navegador não joga o item fora: ele cria uma terceira linha por conta própria, com altura auto (o tamanho do conteúdo). Repare que ela é a mais baixa das três.

3. As linhas que o navegador cria: grid-auto-rows

A grade que você desenha com grid-template-rows e grid-template-columns se chama grade explícita (escrita por você). As linhas que o navegador acrescenta quando sobram itens formam a grade implícita (subentendida). Numa galeria ou numa lista de produtos, você nem sabe quantas linhas vão existir: depende de quantos itens há. Por isso, o mais comum é não escrever grid-template-rows e dizer a altura de todas as linhas criadas com grid-auto-rows:

<link rel="stylesheet" href="style.css">
<div class="grade">
  <div class="item">1</div><div class="item">2</div><div class="item">3</div>
  <div class="item">4</div><div class="item">5</div>
</div>

.grade {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-auto-rows: 80px;
  gap: 8px;
  width: 400px;
  border: 2px dashed gray;
}

.item {
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}
grid-auto-rows
"Linhas automáticas": a altura de cada linha que o navegador criar por conta própria.
80px
Todas as linhas criadas terão 80 pixels. Acrescente mais itens no HTML: cada linha nova também terá 80.

Com grid-template-rows e grid-auto-rows juntos, o primeiro vale para as linhas que você desenhou, e o segundo para as que vierem depois. Volte ao exemplo da seção 2, acrescente grid-auto-rows: 100px e veja o item 7 ganhar uma linha de 100 pixels.

Experimente: a galeria com linhas iguais

Missão: sem altura nas linhas, cada linha ficou da altura da foto mais alta, e a galeria ficou enorme. Faça todas as linhas terem 100px de altura, com grid-auto-rows. (O object-fit: cover recorta cada foto para preencher a casa sem deformar: aula Imagens que se Adaptam.)

<link rel="stylesheet" href="style.css">
<div class="galeria">
  <img src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura com cobertura de chocolate">
  <img src="assets/midia/bolo-quadrado-400.jpg" alt="O mesmo bolo, visto mais de perto">
  <img src="assets/midia/mapa-400.png" alt="Mapa do bairro com a Lojinha da Ana">
  <img src="assets/midia/avatar-ana-192.png" alt="Avatar da Ana">
  <img src="assets/midia/bolo-800.jpg" alt="Bolo de cenoura em tamanho grande">
</div>

.galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 8px;
}

.galeria img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-auto-rows: 100px;
  gap: 8px;
}

.galeria img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

4. Altura mínima que cresce: minmax()

Uma altura fixa tem um risco: se o conteúdo for maior, ele vaza da linha (veja Quando dá errado). Muitas vezes você quer outra coisa: "todas as linhas com pelo menos 60 pixels, mas, se o texto precisar, a linha cresce". Isso se escreve com a função minmax(mínimo, máximo):

<link rel="stylesheet" href="style.css">
<div class="grade">
  <div class="item">1</div>
  <div class="item">Bolo de cenoura com cobertura de chocolate e granulado</div>
  <div class="item">3</div>
  <div class="item">4</div>
</div>

.grade {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-auto-rows: minmax(60px, auto);
  gap: 8px;
  width: 400px;
  border: 2px dashed gray;
}

.item {
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}
minmax(
Uma função: um tamanho "entre um mínimo e um máximo".
60px,
O mínimo: a linha nunca fica mais baixa que 60 pixels. A vírgula separa os dois valores (dentro de funções, a vírgula é permitida).
auto)
O máximo: auto, o tamanho do conteúdo. Se o texto precisar de mais que 60, a linha cresce.

A primeira linha cresceu para caber o texto comprido; a segunda, só com o item 4, ficou com os 60 pixels mínimos (sem minmax, ela teria só a altura de uma linha de texto). O minmax() também funciona nas colunas; a aula repeat, minmax e auto-fit vai mais fundo.

5. fr nas linhas e o rodapé no pé

O fr funciona nas linhas, mas com uma condição: ele divide o espaço que sobra, e só sobra altura se o pai tiver uma altura. Um pai sem height tem só a altura do conteúdo: não sobra nada, e as linhas 1fr ficam com a altura do conteúdo, como auto.

O uso clássico é o layout da página: cabeçalho, conteúdo e rodapé. Com grid-template-rows: auto 1fr auto, o cabeçalho e o rodapé ficam com a altura deles, e o conteúdo estica para ocupar o resto. Assim, o rodapé fica no pé mesmo com pouco texto:

<link rel="stylesheet" href="style.css">
<div class="pagina">
  <header class="topo">Receitas da Ana</header>
  <main class="conteudo">Só uma receita por enquanto.</main>
  <footer class="rodape">© Ana, 2026</footer>
</div>

.pagina {
  display: grid;
  grid-template-rows: auto 1fr auto;
  height: 250px;
  gap: 8px;
  font-family: sans-serif;
}

.topo,
.rodape {
  padding: 8px;
  background-color: navy;
  color: white;
}

.conteudo {
  padding: 8px;
  background-color: lightyellow;
}

O cabeçalho e o rodapé têm a altura de uma linha de texto (mais o padding), e o conteúdo ficou com todo o meio. Apague o height: 250px: a página encolhe para o tamanho do conteúdo e o 1fr não tem mais o que dividir. Numa página de verdade, em vez de height: 250px, use min-height: 100dvh no pai: "no mínimo a altura da tela, mas cresça se o texto for longo" (aula Unidades da Tela).

Quando dá errado

CSS quase nunca mostra mensagem: o navegador ignora em silêncio o que não entende.

O texto vazou da linha

O que aconteceu: grid-auto-rows: 40px, e um dos itens tem um texto que precisa de mais de 40 pixels:

<link rel="stylesheet" href="style.css">
<div class="grade">
  <div class="item">1</div>
  <div class="item">Bolo de cenoura com cobertura de chocolate e granulado</div>
  <div class="item">3</div>
  <div class="item">4</div>
</div>

.grade {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-auto-rows: 40px;
  gap: 8px;
  width: 400px;
  border: 2px dashed gray;
}

.item {
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}

O que você vê: o fundo vermelho do item 2 acaba nos 40 pixels, e o resto do texto continua para baixo, por cima do vão e da linha seguinte. Como a letra é branca, a parte que saiu do fundo vermelho quase some na página. A linha não cresce: você disse "40 pixels", e o navegador obedece. O validador não reclama: está tudo escrito certo.

Como consertar: troque por grid-auto-rows: minmax(40px, auto) (seção 4), ou apague o grid-auto-rows e deixe o conteúdo decidir.

O 1fr nas linhas não fez nada

O que aconteceu: grid-template-rows: auto 1fr auto, mas o pai não tem height nem min-height.

O que você vê: o rodapé logo abaixo do conteúdo, e não no pé. As linhas ficam com a altura do conteúdo, como se fossem auto. Não sobra altura para dividir.

Como consertar: dê altura ao pai (min-height: 100dvh numa página, ou uma altura fixa num componente).

error: CSS: “grid-template-row”: Property “grid-template-row” doesn't exist.

O que aconteceu: o nome sem o s do fim.

$ vnu --css rowsing.css
"file:/home/ana/grade/rowsing.css":3.28-3.32: error: CSS: “grid-template-row”: Property “grid-template-row” doesn't exist.

"A propriedade não existe." O navegador ignora a linha: as linhas voltam a ser automáticas. No F12, a declaração aparece riscada, com um ícone de aviso.

Como consertar: grid-template-rows, no plural (e grid-auto-rows, também no plural).

error: CSS: “grid-template-rows”: “,” is an incorrect operator.

O que aconteceu: as alturas separadas por vírgula: grid-template-rows: 100px, 100px;.

$ vnu --css rowsvirg.css
"file:/home/ana/grade/rowsvirg.css":3.30-3.34: error: CSS: “grid-template-rows”: “,” is an incorrect operator.

Como nas colunas, os tamanhos são separados por espaço. A vírgula só aparece dentro de funções, como o minmax(60px, auto). A declaração errada é ignorada inteira.

Como consertar: grid-template-rows: 100px 100px;.

error: CSS: “grid-auto-rows”: “x” is not a “grid-auto-rows” value.

O que aconteceu: um valor que não é tamanho no meio da lista (aqui, um x que sobrou de uma edição).

$ vnu --css autox.css
"file:/home/ana/grade/autox.css":3.35-3.35: error: CSS: “grid-auto-rows”: “x” is not a “grid-auto-rows” value.

"x não é um valor de grid-auto-rows." Basta um valor errado para a declaração inteira ser ignorada.

Como consertar: só tamanhos (80px, 1fr, auto, minmax(…)), separados por espaço.

Missão final: o blog com rodapé no pé

Missão: monte a página do blog em três linhas. (1) Transforme a .pagina numa grade. (2) Use grid-template-rows: auto 1fr auto. (3) Dê à página min-height: 300px, para o rodapé ir para o pé.

<link rel="stylesheet" href="style.css">
<div class="pagina">
  <header class="topo">Blog da Ana</header>
  <main class="conteudo">
    <h1>Bolo de cenoura</h1>
    <p>A receita sai amanhã!</p>
  </main>
  <footer class="rodape">Feito com carinho pela Ana</footer>
</div>

.pagina {
  font-family: sans-serif;
}

.topo,
.rodape {
  padding: 8px;
  background-color: darkgreen;
  color: white;
}

.conteudo {
  padding: 0 8px;
}

.pagina {
  display: grid;
  grid-template-rows: auto 1fr auto;
  min-height: 300px;
  font-family: sans-serif;
}

.topo,
.rodape {
  padding: 8px;
  background-color: darkgreen;
  color: white;
}

.conteudo {
  padding: 0 8px;
}

Acrescente vários parágrafos no main: quando o texto passa dos 300 pixels, a página cresce e o rodapé desce junto. É a vantagem do min-height sobre o height.

Resumo

  • Sem nada escrito, cada linha tem a altura do seu item mais alto, e os itens da linha esticam até ela.
  • grid-template-rows, no pai, dá uma altura a cada linha desenhada (grade explícita), de cima para baixo.
  • As linhas que o navegador cria quando sobram itens (grade implícita) seguem o grid-auto-rows (padrão: auto).
  • Altura fixa pode fazer o texto vazar; minmax(60px, auto) dá um mínimo e deixa crescer.
  • fr nas linhas só divide altura se o pai tiver altura: grid-template-rows: auto 1fr auto + min-height = rodapé no pé.
  • Nome sem o s (grid-template-row), vírgula entre os valores ou valor que não é tamanho: o validador reclama, e o navegador ignora a linha.
