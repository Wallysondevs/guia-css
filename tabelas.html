CSS Tabelas

A tabela de preços da lojinha da Ana está pronta no HTML, mas o navegador a desenha sem nenhuma linha: só texto em colunas, apertado. Nesta aula você vai dar a ela bordas, espaço, um cabeçalho colorido e listras, e vai entender o detalhe que confunde todo mundo na primeira vez: as bordas duplas.

Você vai aprender
  • Como o navegador desenha uma tabela sem CSS.
  • Bordas nas células e por que elas saem duplas.
  • border-collapse: collapse: as linhas simples.
  • padding, text-align e vertical-align nas células.
  • Cabeçalho colorido e linhas listradas (zebra).
  • A legenda (caption-side) e a tabela larga no celular.
  • Os erros: a borda no <tr> que não aparece, a borda só por fora e o validador W3C.

Os resultados são desenhados pelo seu navegador. O HTML das tabelas (<table>, <tr>, <th>, <td>, <thead>, <caption>) está no Guia HTML.

A ideia: a grade de uma planilha

Abra uma planilha: cada valor fica numa célula, e as células são separadas por linhas finas, uma só entre duas células vizinhas. Uma tabela HTML sem CSS é como uma planilha com as linhas de grade desligadas. O CSS liga as linhas, escolhe a grossura e a cor, e dá espaço dentro de cada célula.

Primeiro, a tabela crua:

<table>
  <tr><th>Produto</th><th>Preço</th></tr>
  <tr><td>Bolo de cenoura</td><td>R$ 35,00</td></tr>
  <tr><td>Pão de queijo</td><td>R$ 2,50</td></tr>
</table>

O que o navegador põe sozinho (é o que o F12 mostra na aba Computed):

  • nenhuma borda;
  • o <th> (célula de cabeçalho) em negrito (font-weight: 700) e centralizado (text-align: center);
  • só 1px de padding dentro de cada célula, e 2px de espaço entre as células (border-spacing: 2px);
  • o texto no meio da altura da célula (vertical-align: middle).

1. Bordas nas células, e as linhas duplas

A borda vem da propriedade border (aula Bordas). O primeiro instinto é pôr a borda na tabela, nas células de cabeçalho e nas células comuns:

Experimente: tire o table, do seletor e veja a moldura de fora sumir. Depois tire o th,.

<link rel="stylesheet" href="style.css">
<table>
  <tr><th>Produto</th><th>Preço</th></tr>
  <tr><td>Bolo de cenoura</td><td>R$ 35,00</td></tr>
  <tr><td>Pão de queijo</td><td>R$ 2,50</td></tr>
</table>

table, th, td {
  border: 1px solid navy;
}

O resultado parece um monte de caixinhas: cada célula tem a sua borda, a tabela tem a dela, e entre elas sobram os 2px do border-spacing. Por isso as linhas saem duplas. É o jeito "separado" de desenhar tabelas, o padrão do navegador (border-collapse: separate).

2. Linhas simples: border-collapse: collapse

A propriedade border-collapse ("juntar as bordas") faz as bordas vizinhas virarem uma só, como na planilha:

<style>
  table { margin-bottom: 12px; }
  th, td { border: 1px solid navy; }
  .separada { border-collapse: separate; }
  .junta    { border-collapse: collapse; }
</style>
<table class="separada">
  <tr><th>separate</th><th>(o padrão)</th></tr>
  <tr><td>Bolo de cenoura</td><td>R$ 35,00</td></tr>
</table>
<table class="junta">
  <tr><th>collapse</th><th>(linhas simples)</th></tr>
  <tr><td>Bolo de cenoura</td><td>R$ 35,00</td></tr>
</table>
table
O border-collapse vai na tabela, não nas células.
border-collapse
Como juntar as bordas das células.
collapse
"Juntar": duas bordas vizinhas viram uma, e o border-spacing deixa de valer.
separate
"Separar" (o padrão): cada célula com a sua borda, afastadas pelo border-spacing.
QueroEscreva
Grade de linhas simples (o mais comum)table { border-collapse: collapse; } + th, td { border: … }
Só linhas horizontais, visual mais leveborder-collapse: collapse + border-bottom nas células
Células como "azulejos" separadosborder-collapse: separate; border-spacing: 6px;

3. Espaço e alinhamento dentro da célula

Com as linhas no lugar, o texto fica grudado nelas. O espaço de dentro é o padding (aula Espaço Interno), escrito nas células:

<style>
  table { border-collapse: collapse; }
  th, td {
    border: 1px solid navy;
    padding: 8px 12px;
  }
  th { text-align: left; }
  .preco { text-align: right; }
  td { height: 48px; }
  .topo { vertical-align: top; }
</style>
<table>
  <tr><th>Produto</th><th>Preço</th></tr>
  <tr><td class="topo">Bolo (vertical-align: top)</td><td class="preco">R$ 35,00</td></tr>
  <tr><td>Pão de queijo (middle, o padrão)</td><td class="preco">R$ 2,50</td></tr>
</table>
padding: 8px 12px
8px em cima e embaixo, 12px nas laterais.
text-align
Alinhamento na horizontal: left, center, right (aula Alinhamento). Na tabela, textos ficam melhor à esquerda e números à direita, para as casas decimais se alinharem.
vertical-align
Alinhamento na vertical, dentro da altura da célula: top, middle (o padrão) ou bottom.

4. Cabeçalho colorido e listras (zebra)

Numa tabela comprida, o olho se perde ao seguir uma linha da esquerda para a direita. Duas ajudas clássicas: um cabeçalho que se destaca e listras, uma linha sim, outra não, com um fundo levemente diferente.

Experimente: troque even (pares) por odd (ímpares) e veja as listras mudarem de linha. Depois troque o #eeeeee por #fde8e1.

<link rel="stylesheet" href="style.css">
<table class="precos">
  <thead>
    <tr><th>Produto</th><th>Preço</th></tr>
  </thead>
  <tbody>
    <tr><td>Bolo de cenoura</td><td>R$ 35,00</td></tr>
    <tr><td>Bolo de fubá</td><td>R$ 30,00</td></tr>
    <tr><td>Pão de queijo</td><td>R$ 2,50</td></tr>
    <tr><td>Brigadeiro</td><td>R$ 3,00</td></tr>
  </tbody>
</table>

.precos {
  border-collapse: collapse;
}

.precos th,
.precos td {
  padding: 8px 12px;
  text-align: left;
}

.precos th {
  background-color: navy;
  color: white;
}

.precos tbody tr:nth-child(even) {
  background-color: #eeeeee;
}
.precos th
As células de cabeçalho: fundo azul-marinho (navy) e letra branca, com bom contraste.
tbody tr
As linhas do corpo da tabela. Usar o tbody no seletor deixa a linha do cabeçalho fora da contagem.
:nth-child(even)
"O filho de número par": a 2ª, a 4ª, a 6ª linha… odd são as ímpares. A aula :nth-child mostra todas as contas possíveis.
background-color
O fundo da linha inteira (aula Cor de Fundo). Um cinza bem claro basta: listra forte cansa a vista.
Destacar a linha sob o mouse

Com .precos tbody tr:hover { background-color: #fff3c4; }, a linha em que o mouse está fica amarelada. Ajuda a ler tabelas largas no computador (no celular não há mouse). Os estados :hover e companhia estão na aula Estados.

5. A legenda e a largura

O <caption>, o título da tabela, aparece em cima por padrão. Com caption-side: bottom ele vai para baixo. E width: 100% faz a tabela ocupar a largura toda do espaço disponível, em vez de só o tamanho do conteúdo:

<style>
  table {
    width: 100%;
    border-collapse: collapse;
  }
  caption {
    caption-side: bottom;
    font-style: italic;
    padding-top: 6px;
  }
  th, td {
    border-bottom: 1px solid #cccccc;
    padding: 8px;
    text-align: left;
  }
</style>
<table>
  <caption>Preços de outubro</caption>
  <tr><th>Produto</th><th>Preço</th></tr>
  <tr><td>Bolo de cenoura</td><td>R$ 35,00</td></tr>
</table>

Repare também no estilo "só linhas horizontais": um border-bottom em cada célula, sem bordas verticais. É o visual mais comum em sites hoje.

Tabela larga no celular

Uma tabela com muitas colunas não cabe numa tela estreita. O navegador primeiro aperta as colunas e quebra o texto; quando não dá mais, a tabela passa da borda e a página inteira ganha rolagem para o lado. A saída é pôr a tabela dentro de uma <div> que rola sozinha:

<style>
  .tabela-rolagem {
    max-width: 260px;
    overflow-x: auto;
    border: 1px dashed gray;
  }
  td { white-space: nowrap; padding: 4px 8px; }
</style>
<div class="tabela-rolagem">
  <table>
    <tr><td>Bolo de cenoura</td><td>R$ 35,00</td><td>Encomenda com 2 dias</td><td>Serve 12</td></tr>
  </table>
</div>

O max-width: 260px faz o papel da tela estreita do celular. A tabela continua inteira, e só a caixa tracejada rola para o lado (arraste ou use a barra). O overflow-x: auto é o assunto da aula O que Transborda.

Quando dá errado

Borda só na tabela: aparece só a moldura 
<style>
  table {
    border: 1px solid navy;
  }
</style>
<table>
  <tr><th>Produto</th><th>Preço</th></tr>
  <tr><td>Bolo de cenoura</td><td>R$ 35,00</td></tr>
</table>

O que você vê: uma moldura em volta da tabela inteira, sem nenhuma linha entre as células.

Por quê: a border não é herdada: a borda do <table> é só da caixa da tabela. As células têm as suas próprias bordas, que continuam sem nada.

Como consertar: ponha a borda em th, td.

Borda no <tr>: não aparece nada 
<style>
  tr {
    border-bottom: 2px solid tomato;
  }
</style>
<table>
  <tr><td>Bolo de cenoura</td><td>R$ 35,00</td></tr>
  <tr><td>Pão de queijo</td><td>R$ 2,50</td></tr>
</table>

O que você vê: nenhuma linha vermelha.

Por quê: no modo padrão (separate), as linhas da tabela (<tr>) não desenham borda: só a tabela e as células desenham. O validador não reclama, porque a declaração é válida; ela só não tem efeito ali.

Como consertar: ponha border-collapse: collapse na tabela (aí a borda do <tr> aparece), ou ponha o border-bottom nas células (td), que funciona nos dois modos.

collapsed em vez de collapse: as linhas continuam duplas 
table {
  border-collapse: collapsed;
}

O que você vê: nada muda; as bordas continuam duplas. No F12, no painel Styles (Estilos), a declaração aparece riscada, com um ícone de aviso.

$ vnu --css style.css
"file:/home/ana/site/style.css":2.20-2.28: error: CSS: “border-collapse”: “collapsed” is not a “border-collapse” value.

O que significa: "collapsed não é um valor de border-collapse". O valor é o verbo, collapse, sem o d. O navegador ignorou a declaração inteira e ficou com o padrão, separate.

Resumo

  • Sem CSS, a tabela não tem bordas, o th é negrito e centralizado, as células têm 1px de padding e ficam separadas por 2px (border-spacing).
  • A borda vai nas células (th, td); na tabela, ela é só a moldura de fora.
  • No modo padrão (separate) as bordas saem duplas; border-collapse: collapse, na tabela, junta numa linha só.
  • padding dá espaço dentro da célula; text-align alinha na horizontal (números à direita) e vertical-align na vertical.
  • Listras: tbody tr:nth-child(even) com um fundo claro. Cabeçalho: fundo escuro e letra clara, com contraste.
  • Tabela larga: dentro de uma <div> com overflow-x: auto.
  • Erros: borda no <tr> só aparece com collapse; collapsed não existe (o validador avisa e o navegador ignora).
