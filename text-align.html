CSS text-align

Todo texto começa encostado na margem esquerda da página. Para centralizar o título do site da Ana, pôr o preço no canto direito de um cartão ou deixar um parágrafo com as duas bordas retas, como num jornal, existe uma única propriedade: text-align, "alinhamento do texto". Nesta aula você vai conhecer os valores dela lado a lado, entender dentro de que o texto é alinhado e evitar os três tropeços mais comuns.

Você vai aprender
  • A regra text-align: center; e cada parte dela.
  • Os valores left, center, right, justify, start e end, um ao lado do outro.
  • Por que o text-align alinha o conteúdo de uma caixa, e não a caixa.
  • Como centralizar uma imagem com ele, e como a herança espalha o alinhamento pelos filhos.
  • Quando o texto justificado e o centralizado atrapalham a leitura.
  • O que acontece com um valor inventado (e a mensagem do validador W3C), com o text-align num <span> e na tentativa de centralizar uma caixa.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: livros numa prateleira

Pense numa prateleira com alguns livros. Você pode encostá-los todos na ponta esquerda, juntá-los no meio, empurrá-los para a ponta direita ou espaçá-los até que encostem nas duas pontas. A prateleira não sai do lugar: só os livros se movem dentro dela.

No CSS, a prateleira é a caixa de um elemento, como um parágrafo ou um título, e os livros são as palavras de cada linha. O text-align diz para que lado as palavras se arrumam.

Na prateleiraNo CSS
A prateleira, que não se moveA caixa do elemento (o <p>, o <h1>)
Os livrosAs palavras de cada linha (e as imagens que estão no meio do texto)
Encostar à esquerda, no meio, à direita, nas duas pontasleft, center, right, justify

1. A primeira regra: centralizar o título

<style>
  h1 {
    text-align: center;
  }
</style>
<h1>Receitas da Ana</h1>
<p>Bolo de cenoura com cobertura de chocolate.</p>
h1
O seletor: a regra vale para todo <h1> da página.
text-align
A propriedade: "alinhamento do texto". Ela diz como as linhas se arrumam dentro da caixa do elemento.
center
O valor: "centro". Cada linha fica no meio da caixa, com o mesmo espaço sobrando dos dois lados.
;
Fecha a declaração. Ponha sempre, até na última.

Repare no resultado: o título foi para o meio, e o parágrafo continuou encostado à esquerda. A regra só vale para o <h1>.

2. Os valores, lado a lado

Cada parágrafo abaixo tem uma borda fina, para você ver o tamanho da caixa (a "prateleira"), e o nome do valor escrito dentro:

<style>
  p {
    border: 1px solid gray;
    padding: 4px;
  }
  .esquerda { text-align: left; }
  .centro { text-align: center; }
  .direita { text-align: right; }
  .justificado { text-align: justify; }
</style>
<p class="esquerda">left: encostado à esquerda</p>
<p class="centro">center: no meio</p>
<p class="direita">right: encostado à direita</p>
<p class="justificado">justify: o bolo de cenoura da Ana leva três cenouras médias, quatro ovos, uma xícara de óleo, duas de açúcar e duas e meia de farinha de trigo. As linhas cheias encostam nas duas bordas; a última fica à esquerda.</p>
ValorO que fazQuando usar
leftEncosta as linhas à esquerda; a borda direita fica "recortada"O padrão para ler em português. Você quase nunca precisa escrever
centerPõe cada linha no meio da caixaTítulos curtos, botões, rodapés, uma frase de destaque
rightEncosta as linhas à direitaPreços e números numa coluna, uma data no canto de um cartão
justifyEstica os espaços entre as palavras para cada linha cheia encostar nas duas bordas; a última linha não é esticadaColunas largas de texto corrido, como num livro. Com cuidado (veja a seção 6)
startEncosta no começo da linha, que depende da línguaÉ o valor inicial. Bom para sites em mais de uma língua
endEncosta no fim da linhaO "à direita" que vira "à esquerda" sozinho em árabe ou hebraico

Experimente: troque o valor do text-align no style.css por left, right e justify, e veja o parágrafo mudar ao vivo.

<link rel="stylesheet" href="style.css">
<h1>Bolo de cenoura</h1>
<p>Bata no liquidificador as cenouras, os ovos e o óleo. Despeje numa tigela, junte o açúcar e a farinha e misture bem. Asse por 40 minutos em forno médio.</p>

p {
  text-align: center;
}

3. Ele alinha o conteúdo, não a caixa

Esta é a ideia mais importante da aula. Um parágrafo ou um título é uma caixa que ocupa toda a largura disponível (são elementos de bloco). O text-align não move essa caixa: ele move as linhas dentro dela. Veja com uma caixa colorida de 300 pixels de largura:

<style>
  .caixa {
    width: 300px;
    background-color: lightblue;
    text-align: center;
  }
</style>
<div class="caixa">Bolo de fubá</div>

O texto "Bolo de fubá" ficou no meio da caixa azul, mas a caixa continuou encostada à esquerda da página. Para mover a caixa em si, o caminho é outro: margens automáticas (margin-inline: auto, aula Margem) ou o Flexbox (aula Centralizando Qualquer Coisa).

Imagens também são "livros"

Uma <img> fica no meio do texto, como uma palavra grande (ela é um elemento em linha). Por isso o text-align do pai a move. Para centralizar uma foto, ponha o alinhamento no parágrafo que a contém, e não na imagem:

<style>
  .foto {
    text-align: center;
  }
</style>
<p class="foto">
  <img src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura com cobertura de chocolate" width="200" height="150">
</p>

4. A herança: um alinhamento para vários filhos

O text-align é herdado: o que você põe num elemento vale também para tudo o que está dentro dele, até alguém dizer outra coisa (aula Herança). Um único text-align no <article> centraliza o título e o parágrafo do cartão:

<style>
  .cartao {
    text-align: center;
  }
</style>
<article class="cartao">
  <h2>Bolo de fubá</h2>
  <p>Fofinho, com erva-doce.</p>
</article>

No F12, na aba Computed (Calculado) do <p>, o text-align aparece como center, embora nenhuma regra fale do p: o valor veio do pai. Isso também vale para as metas das missões deste guia, que leem o valor calculado.

Para um filho voltar ao normal, dê a ele o próprio text-align: a regra do filho vence o valor herdado.

Missão: no cartão da lojinha, centralize o título e encoste o preço à direita. Dica: o título pode herdar do .cartao, e o .preco precisa de uma regra própria.

<link rel="stylesheet" href="style.css">
<article class="cartao">
  <h2>Bolo de cenoura</h2>
  <p>Com cobertura de chocolate. Serve 12 fatias.</p>
  <p class="preco">R$ 45,00</p>
</article>

.cartao {
  width: 260px;
  border: 1px solid gray;
  padding: 8px;
}

.cartao {
  width: 260px;
  border: 1px solid gray;
  padding: 8px;
  text-align: center;
}

.preco {
  text-align: right;
}

5. start e end: o começo e o fim da linha

Em português, a gente lê da esquerda para a direita. Em árabe e em hebraico, da direita para a esquerda. O valor inicial do text-align não é left: é start, "o começo da linha", seja ele de que lado for. O atributo dir="rtl" do HTML (right to left, "da direita para a esquerda") troca o lado:

<style>
  p {
    border: 1px solid gray;
  }
</style>
<p>Receitas da Ana</p>
<p dir="rtl">Receitas da Ana</p>

Os dois parágrafos têm text-align: start (ninguém escreveu nada), mas o segundo encostou à direita: lá, o começo da linha é a direita. Se você escrever left, o texto fica à esquerda nas duas línguas; com start e end, o alinhamento acompanha a língua. Num site só em português, left/right e start/end dão o mesmo resultado; a aula Propriedades Lógicas aprofunda essa ideia.

6. Justificado e centralizado: com moderação

O justify deixa a página com cara de livro, mas numa coluna estreita ele abre buracos entre as palavras, porque o navegador estica só os espaços (por padrão, ele não divide palavras com hífen). Os buracos que se alinham de uma linha para outra formam "rios" brancos que atrapalham a leitura, principalmente para quem tem dislexia:

<style>
  p {
    width: 220px;
    border: 1px solid gray;
    text-align: justify;
  }
</style>
<p>Misture os ovos, o açúcar e o óleo no liquidificador. Junte a cenoura ralada e bata até virar um creme liso e alaranjado.</p>

Já o center num texto longo faz cada linha começar num ponto diferente, e o olho perde tempo procurando o início da próxima. A recomendação de acessibilidade (WCAG) é não justificar blocos de texto. Na prática:

SituaçãoQual usar
Parágrafos de texto corridoO padrão (start): não escreva nada
Título curto, chamada, botão, rodapécenter
Preço, número, data no cantoright (ou end)
Coluna larga que precisa parecer impressajustify, e confira se não abriu buracos
Centralizar a caixa (um cartão, um bloco com largura)Não é text-align: margin-inline: auto ou Flexbox

Quando dá errado

Um valor que não existe: text-align: middle 
<style>
  h1 {
    text-align: middle;
  }
</style>
<h1>Receitas da Ana</h1>

O que o leitor vê: o título continua encostado à esquerda, como se a regra não existisse. Nenhuma mensagem aparece na página.

Por quê: middle ("meio") não é um valor do text-align (ele existe em outra propriedade, a vertical-align). O navegador ignora a declaração inteira e fica com o valor que já valia, start. No F12, no painel Styles (Estilos), a declaração aparece riscada, com um ícone de aviso ao lado. O mesmo acontece com centre (a grafia britânica) e centro.

O que o validador diz, num style.css com os dois erros:

$ cat style.css
h1 {
  text-align: middle;
}
p {
  text-align: centre;
}
$ vnu --css style.css
"file:/home/ana/site/style.css":2.15-2.20: error: CSS: “text-align”: “middle” is not a “text-align” value.
"file:/home/ana/site/style.css":5.15-5.20: error: CSS: “text-align”: “centre” is not a “text-align” value.

"middle não é um valor de text-align", na linha 2, coluna 15, e o mesmo para centre na linha 5.

Como consertar: text-align: center;, com a grafia americana.

text-align num <span>: nada acontece 
<style>
  .aviso {
    text-align: center;
    background-color: lightyellow;
  }
</style>
<p><span class="aviso">Promoção de hoje</span></p>

O que o leitor vê: o fundo amarelo aparece (a regra funciona), mas "Promoção de hoje" continua à esquerda.

Por quê: o <span> é um elemento em linha: a caixa dele tem só o tamanho das palavras, então não sobra espaço para elas se moverem lá dentro. O text-align só tem efeito numa caixa de bloco, que tem largura própria. O F12 até mostra center na aba Computed do span, mas não há para onde mover. O validador não reclama: a declaração é válida.

Como consertar: ponha o text-align no pai, o <p>, que é a "prateleira" de verdade.

Queria centralizar a caixa, e só o texto foi

A Ana quer um cartão de 300 pixels no meio da página e escreve text-align: center no cartão. Como você viu na seção 3, o texto vai para o meio do cartão, mas o cartão fica à esquerda. O validador não reclama, porque não há erro: é a propriedade errada para o que ela quer.

Como consertar: para mover a caixa, margin-inline: auto; no próprio cartão (aula Margem), ou display: flex; justify-content: center; no pai (aula Centralizando Qualquer Coisa).

Esperava que o texto fosse para o meio na vertical

O text-align só trabalha na horizontal, ao longo da linha. Numa caixa alta, text-align: center põe o texto no meio da largura, mas ele continua lá em cima. Centralizar na vertical é trabalho do Flexbox ou do Grid (aula Centralizando Qualquer Coisa).

Missão: o rodapé da Ana deveria estar centralizado, mas continua à esquerda. Descubra o erro no style.css e conserte.

<link rel="stylesheet" href="style.css">
<footer>
  <p>Receitas da Ana · desde 2024</p>
</footer>

footer {
  text-align: middle;
}

footer {
  text-align: center;
}

Resumo

  • text-align arruma as linhas dentro da caixa de um elemento de bloco: left, center, right, justify, start (o valor inicial) e end.
  • Ele move o texto e as imagens do conteúdo, nunca a própria caixa. Para centralizar a caixa, use margin-inline: auto ou Flexbox; para a vertical, Flexbox ou Grid.
  • É herdado: um text-align no pai vale para todos os filhos, até um deles ter a própria regra.
  • Para centralizar uma imagem, ponha text-align: center no pai dela.
  • start/end acompanham a direção da língua; left/right, não.
  • Texto corrido: deixe no padrão. center para trechos curtos; justify com cuidado, porque abre buracos em colunas estreitas.
  • Valor inventado (middle, centre) é ignorado em silêncio; o validador avisa: “middle” is not a “text-align” value.
