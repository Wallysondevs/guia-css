CSS Unidades

Quase todo tamanho no CSS é um número colado numa unidade: 16px, 1.5rem, 50%, 100vw. A unidade diz "16 de quê": pixels, o tamanho da letra, a largura da tela, a largura do pai. Esta página junta todas as unidades em tabelas, com as conversões medidas no Chromium e a aula que explica cada grupo.

Como usar esta página
  • Procure a unidade com Ctrl+F (dvh, ch).
  • Os valores em px foram medidos com getComputedStyle (o mesmo que a aba Computed do F12 mostra), numa tela de 800 × 600 pixels, com a fonte padrão de 16px. No seu navegador, as unidades da tela e as que dependem da fonte darão outros números.
  • Na dúvida, o guia recomenda: rem para letras, rem/em para espaços, % ou fr para larguras, px para bordas finas.

Como se escreve

h1 {
  font-size: 2.5rem;
  margin: 0;
}
2.5
O número. A parte decimal vai com ponto, como no inglês: 2.5, nunca 2,5 (a vírgula separa valores no CSS). .5rem é o mesmo que 0.5rem. Pode ser negativo onde faz sentido (margin-top: -1rem).
rem
A unidade, colada no número, sem espaço. 2.5 rem, com espaço, é inválido.
0
Zero é zero em qualquer unidade: pode ficar sem unidade (margin: 0). É o único número de tamanho que dispensa a unidade.

Unidades absolutas

Têm um tamanho fixo, que não depende de nada na página. Na tela, todas são convertidas para px: o CSS define 1in = 96px, e as outras saem daí. Um "pixel do CSS" não é um ponto físico da tela: num celular com tela densa, 1px ocupa 2 ou 3 pontos de verdade.

Relativas à tela (viewport)

A viewport é a área da janela onde a página aparece. 1vw é 1% da largura dela; 100vw, a largura inteira. Medido numa janela de 800 × 600:

No computador, dvh, svh e lvh dão o mesmo número que vh (as barras do navegador não mudam). A diferença aparece no celular. Também existem dvmin, svmax e companhia. Aula: Unidades da Tela (vw, vh, dvh).

Suporte: dvh, svh, lvh, vi e vb funcionam no Chrome 108, Firefox 101 e Safari 15.4 em diante. vw, vh, vmin e vmax, em todos.
width: 100vw pode criar rolagem para o lado. O 100vw inclui a largura da barra de rolagem vertical. Num computador com barra visível, a caixa fica uns pixels mais larga que a página. Para "a largura toda", use width: 100%.

Experimente

Cinco caixas com a mesma conta, em unidades diferentes. Mude a largura do quadro (botões 375 e 768 da barra), ou o font-size do .grupo, e veja quem acompanha o quê:

<link rel="stylesheet" href="style.css">
<div class="grupo">
  <p class="px">width: 200px</p>
  <p class="rem">width: 12.5rem</p>
  <p class="em">width: 12.5em</p>
  <p class="pct">width: 50%</p>
  <p class="vw">width: 30vw</p>
</div>

.grupo {
  font-size: 20px;
}

.grupo p {
  margin: 0 0 0.5rem;
  padding: 0.25rem;
  background-color: lightsteelblue;
  font-size: 1rem;
}

.px  { width: 200px; }
.rem { width: 12.5rem; }
.em  { width: 12.5em; }
.pct { width: 50%; }
.vw  { width: 30vw; }

Com a fonte padrão de 16px, 12.5rem e 12.5em dão os mesmos 200px que 200px: o em de cada parágrafo usa o font-size dele (1rem), e não os 20px do .grupo. Troque o font-size: 1rem do .grupo p por 1.5rem: a letra cresce nas cinco, mas só a caixa em fica mais larga.

Quando dá errado

Número sem unidade, espaço no meio, unidade inventada 
.caixa {
  width: 300;
}
h1 {
  font-size: 2 rem;
}

O que a Ana vê: a caixa continua com a largura de antes e o título continua do tamanho padrão. Nenhuma mensagem na tela.

Por quê: 300 sem unidade não é um tamanho (só o 0 pode ficar sem), e 2 rem são dois valores separados, não "2rem". O navegador descarta as duas declarações. No F12, aba Elements (Elementos), painel Styles (Estilos), elas aparecem riscadas, com um ícone de aviso amarelo ao lado.

O validador W3C:

$ vnu --css semunidade.css
"file:/home/ana/ref/unidades/semunidade.css":2.10-2.12: error: CSS: “width”: only “0” can be a “unit”. You must put a unit after your number.
$ vnu --css espaco.css
"file:/home/ana/ref/unidades/espaco.css":2.16-2.18: error: CSS: “font-size”: Too many values or values are not recognized.
$ vnu --css pxx.css
"file:/home/ana/ref/unidades/pxx.css":2.10-2.14: error: CSS: “width”: Unknown dimension.
  • only “0” can be a “unit”. You must put a unit after your number. = "só o 0 dispensa a unidade. Você precisa pôr uma unidade depois do número."
  • Too many values or values are not recognized. = "valores demais, ou valores não reconhecidos": o validador viu 2 e rem como duas coisas.
  • Unknown dimension. = "dimensão desconhecida": a unidade não existe (aqui, 10pxx). Lembre que as unidades cq… também dão esse erro no vnu 26.10.12, mas por falha do validador.

Como resolver: número e unidade colados (300px, 2rem), ponto como separador decimal.

O em que vira uma bola de neve

Uma lista dentro de outra, com li { font-size: 1.2em; }: cada nível fica 1,2 vez maior que o de fora (1,2 × 1,2 × 1,2…), porque o em do font-size é medido na letra do pai. Com 1.2rem, todos os níveis ficam iguais. Na letra, prefira rem.

Missão

Missão: deixe o CSS da Ana em unidades relativas. (1) O título: troque os 32px por 2rem (o mesmo tamanho, mas respeitando a letra que a pessoa escolheu). (2) O aviso: troque o padding: 10px por 1em, para o espaço acompanhar a letra dele (que é de 1.25rem = 20px). Confira o padding-top calculado no F12, se quiser.

<link rel="stylesheet" href="style.css">
<h1>Padaria da Ana</h1>
<p class="aviso">Hoje tem pão de queijo quentinho!</p>

h1 {
  font-size: 32px;
}

.aviso {
  font-size: 1.25rem;
  padding: 10px;
  background-color: lightyellow;
  border: 1px solid goldenrod;
}

h1 {
  font-size: 2rem;
}

.aviso {
  font-size: 1.25rem;
  padding: 1em;
  background-color: lightyellow;
  border: 1px solid goldenrod;
}

Resumo

  • Número e unidade colados, decimal com ponto: 1.5rem. Só o 0 dispensa a unidade.
  • Absolutas: px (1in = 96px), cm, mm, pt; fora o px, ficam para a impressão.
  • Da fonte: rem (raiz), em (o próprio elemento), ch, ex, lh.
  • Da tela: vw, vh, vmin, vmax e, para o celular, dvh, svh, lvh. Do contêiner: cqw, cqi…
  • % depende da propriedade: padding e margin usam a largura do pai, até em cima e embaixo.
  • Sem unidade: line-height: 1.5, opacity, z-index, flex-grow.
  • fr no Grid, deg/turn nos giros, s/ms no tempo, x/dppx na resolução.
  • Unidade errada ou faltando: a declaração é ignorada (riscada no F12).
