CSS Seletor Universal (*)

Até aqui, cada seletor escolhia alguém: todos os parágrafos (p), os elementos com uma etiqueta (.destaque), um elemento só (#topo). O seletor universal, o asterisco *, não escolhe: ele pega todos os elementos da página, sem exceção. É uma ferramenta poderosa e, por isso mesmo, usada em poucos lugares bem conhecidos.

Você vai aprender
  • O que o * pega (inclusive o <html> e o <body>).
  • Os três usos clássicos: box-sizing para todos, zerar margens e enxergar as caixas da página.
  • O * junto de outros seletores: .cartao *.
  • Por que o * perde para qualquer outra regra.
  • A diferença entre * { color: … } e body { color: … }, e o que dá errado quando se exagera.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código.

A ideia: "atenção, todo mundo"

Na escola, a diretora pode chamar um aluno pelo nome (o ID), uma turma inteira pela camiseta (a classe), ou pegar o microfone e dizer: "atenção, todo mundo". Esse aviso chega a todos: alunos, professores, a cantina. O * é o "todo mundo" do CSS.

1. O primeiro *

<style>
  * {
    color: darkslateblue;
  }
</style>
<h1>Receitas da Ana</h1>
<p>Bolo de cenoura com <strong>cobertura de chocolate</strong>.</p>
<ul>
  <li>Farinha</li>
  <li>Cenoura</li>
</ul>
*
O asterisco: "qualquer elemento". Não precisa de nada no HTML: nenhum class, nenhum id.
{ color: darkslateblue; }
A declaração vai para cada elemento da página, um por um: o <h1>, o <p>, o <strong>, o <ul>, cada <li>, e também o <html>, o <body> e até os elementos invisíveis do <head>.

Todo o texto ficou azul-ardósia, inclusive as bolinhas da lista. Para trocar a cor do texto do site inteiro, porém, existe um jeito melhor (veja a seção 4).

2. Enxergando as caixas: * { outline: … }

Todo elemento da página é uma caixa retangular (aula O Modelo de Caixa). Normalmente você não vê essas caixas. Um truque muito usado para estudar ou consertar um layout é desenhar um contorno em todas elas de uma vez:

Missão: no style.css, escreva uma regra com o seletor * e a declaração outline: 1px solid crimson;. Repare em quantas caixas aparecem, até em volta do <strong> no meio da frase.

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p>Bolo de cenoura com <strong>cobertura de chocolate</strong>.</p>
<ul>
  <li>Farinha</li>
  <li>Cenoura</li>
</ul>

/* escreva a regra aqui */

* {
  outline: 1px solid crimson;
}

Aparece uma caixa para cada elemento: a do <h1>, a do <p>, a do <strong> dentro dele, a do <ul> e uma para cada <li>. Em volta de tudo, o contorno do <body>. O <html> também ganha o seu, mas ele ocupa o quadro inteiro e o contorno fica por fora, onde não se vê. Os espaços entre as caixas são as margens. O outline (contorno) é usado aqui, em vez de border, porque ele não ocupa espaço: as caixas não mudam de tamanho nem de lugar (aula Contorno). Quando terminar de investigar, apague a regra.

3. O uso mais comum: box-sizing para todos

Quase todo site moderno começa o CSS com esta regra:

*,
*::before,
*::after {
  box-sizing: border-box;
}

Ela muda a forma como o navegador calcula a largura das caixas, para todos os elementos (e para os pseudo-elementos ::before e ::after, que o * sozinho não pega). O porquê está na aula box-sizing: border-box. Por enquanto, repare na forma: três seletores separados por vírgula (aula Agrupando Seletores), o primeiro deles o *.

Outro uso comum é zerar as margens que o navegador põe por conta própria:

* {
  margin: 0;
}

Isso faz parte dos resets (aula Reset e Normalize). Mas cuidado: depois dele, você tem de devolver o espaço que quiser, elemento por elemento (veja Quando dá errado).

4. * { color } × body { color }

Para mudar a cor do texto do site inteiro, as duas regras parecem iguais. Não são:

Experimente: com body, o texto ficou azul-ardósia, mas o link continua com a cor de link, azul e sublinhado. Troque body por * e veja o link ficar da mesma cor do texto, sem parecer link.

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p>Veja também o <a href="bolo.html">bolo de fubá</a>.</p>

body {
  color: darkslateblue;
}
body { color: … }* { color: … }
Como a cor chega nos filhosPor herança: o filho só herda se ninguém der outra cor a eleDireto em cada elemento, como se cada um tivesse a regra
LinksContinuam com a cor de link do navegadorFicam com a mesma cor do texto
Qual usarEste, para o estilo geral do textoEvite para cores e fontes

Por que o link muda? O navegador tem o seu próprio CSS, que diz "links são azuis". Com body, a sua cor só chega no link por herança, e uma cor herdada perde para qualquer regra que fale do elemento diretamente, inclusive a do navegador. Com *, a sua regra fala diretamente do <a>, e uma regra sua vence a do navegador. Os detalhes estão nas aulas A Cascata e Herança.

5. O * dentro de outros seletores

O * também aparece como parte de seletores maiores, sempre com o sentido de "qualquer elemento":

SeletorQuer dizer
.cartao *Qualquer elemento dentro de um .cartao, em qualquer nível
.cartao > *Só os filhos diretos do .cartao (aula Combinadores)
*.destaqueQualquer elemento com a classe destaque: o mesmo que .destaque. O * fica subentendido quando você não escreve o elemento

Experimente: .cartao * pintou de verde todos os elementos dentro do cartão: o título, o parágrafo e o <em> dentro do parágrafo. O parágrafo de fora não mudou. Troque por .cartao > *: o resultado parece igual, porque o <em> herda a cor do pai. Agora acrescente font-style: normal; e compare as duas versões.

<link rel="stylesheet" href="style.css">
<div class="cartao">
  <h2>Bolo de fubá</h2>
  <p>Fofinho, com <em>erva-doce</em>.</p>
</div>
<p>Parágrafo fora do cartão.</p>

.cartao * {
  color: darkgreen;
}

Com .cartao * { font-style: normal; }, o <em> perde o itálico, porque a regra fala dele. Com .cartao > *, só o <h2> e o <p> recebem a regra; o <em>, neto do cartão, continua em itálico.

6. O * perde para todo mundo

O * é o seletor mais fraco que existe: a força dele é zero (aula Especificidade). Qualquer outra regra que fale do mesmo elemento, até um simples p, ganha dele, não importa a ordem:

<style>
  p {
    color: darkred;
  }
  * {
    color: darkslateblue;
  }
</style>
<h2>Novidades</h2>
<p>Receita nova toda sexta-feira!</p>

O título ficou azul-ardósia (só o * fala dele), e o parágrafo ficou vermelho-escuro: p venceu, mesmo com o * vindo depois. É por isso que o * é bom para "valores de base": ele põe um padrão, e qualquer regra mais específica muda o que quiser.

Quando dá errado

* { padding: 0; }: as bolinhas da lista saem da caixa 
<style>
  * {
    margin: 0;
    padding: 0;
  }
</style>
<h1>Receitas da Ana</h1>
<p>Ingredientes:</p>
<ul>
  <li>Farinha</li>
  <li>Cenoura</li>
</ul>

O que você vê: tudo grudado no canto, sem espaço entre o título, o parágrafo e a lista. E as bolinhas da lista sumiram.

Por quê: o navegador põe margens no <h1>, no <p> e no <ul>, e um recuo (padding) à esquerda da lista, onde ficam as bolinhas. Com margin: 0 e padding: 0 para todos, as margens somem, o corpo da página encosta na borda e as bolinhas, que ficam fora do <li>, vão parar fora da área visível.

Como consertar: se zerar, devolva o que precisa: ul { padding-left: 1.5rem; }, p { margin-bottom: 1rem; }. Ou não zere o padding de todos: a maioria dos resets modernos zera só a margin (aula Reset e Normalize).

* { color } apagou a cara de link

O que você vê: com * { color: darkslateblue; }, os links ficam da mesma cor do texto. Só o sublinhado denuncia que são links (e, se outra regra tirar o sublinhado, nada mais).

Por quê: o * fala diretamente do <a> e vence a cor de link do navegador (seção 4).

Como consertar: cor geral no body, e uma regra própria para os links, se quiser outra cor (aula Estilizando Links).

Escreveu all ou todos no lugar do * 
<style>
  all {
    color: darkslateblue;
  }
</style>
<p>Receita nova toda sexta-feira!</p>

O que você vê: nada muda. all não é uma palavra especial nesse lugar: é um seletor de elemento, que procura um <all> na página. O validador de CSS não reclama, porque o seletor é válido. O "todos" do CSS é só o *.

Missão final: o começo do CSS da Ana

Missão: monte o começo do CSS que quase todo site usa. (1) Uma regra para *, *::before, *::after com box-sizing: border-box;. (2) Uma regra * com margin: 0;. (3) Devolva o espaço embaixo dos parágrafos: p { margin-bottom: 16px; }. Ligue o contorno da seção 2 se quiser ver as caixas.

<p>Doces e salgados de fim de semana.</p>

  <p>Bolo de fubá</p>
</div>
<ul>
  <li>Pão de queijo</li>
  <li>Brigadeiro</li>
</ul>

.cartao {
  border: 2px solid gray;
  padding: 8px;
}

*,
*::before,
*::after {
  box-sizing: border-box;
}

* {
  margin: 0;
}

p {
  margin-bottom: 16px;
}

.cartao {
  border: 2px solid gray;
  padding: 8px;
}

Resumo

  • * pega todos os elementos da página, do <html> ao último <li>. Não pega os pseudo-elementos: por isso *, *::before, *::after.
  • Usos clássicos: box-sizing: border-box para todos, margin: 0 nos resets e outline temporário para enxergar as caixas.
  • Dentro de outros seletores: .cartao * (tudo dentro), .cartao > * (filhos diretos). *.destaque é o mesmo que .destaque.
  • A força do * é zero: qualquer outra regra ganha dele.
  • Para cor e fonte do site, use body, e não *: com *, os links perdem a cor de link.
  • Zerou tudo? Devolva o espaço que precisa, principalmente o recuo das listas.
