CSS Nomes de Cores

O CSS conhece 148 cores pelo nome, de aliceblue a yellowgreen. Esta página traz todas, a lista completa do padrão CSS Color 4 (conferida no MDN), cada uma com o código hexadecimal, o rgb() e uma amostra desenhada agora pelo seu navegador a partir do próprio nome: cada quadradinho é um background-color: nome de verdade, não uma imagem.

Como usar esta página
  • Procure com Ctrl+F pelo nome em inglês (salmon, navy) ou pelo código (#ff6347).
  • Os nomes estão em inglês e são escritos juntos, sem espaço nem hífen: lightblue, não light-blue.
  • Os 148 nomes foram conferidos no Chromium: cada um deu exatamente o rgb() da tabela.
  • Para entender como as cores funcionam, comece pela aula Cores por Nome. Para escolher qualquer cor (são mais de 16 milhões), veja Hexadecimais, rgb() e hsl().

Como usar um nome de cor

<style>
  h1 {
    color: black;
    background-color: tomato;
  }
  p {
    color: darkslategray;
    border-left: 4px solid gold;
    padding-left: 0.5rem;
  }
</style>
<h1>Padaria da Ana</h1>
<p>Pão quentinho às 7h.</p>
tomato
O nome vai direto como valor, sem aspas e sem #. Serve em qualquer propriedade que aceite cor: color (a cor da letra), background-color (o fundo), border-color, outline-color, text-decoration-color, nos degradês…
darkslategray
Nomes compostos ficam grudados. Maiúsculas não importam: Tomato e TOMATO deram o mesmo rgb(255, 99, 71) no Chromium. O costume é escrever tudo em minúsculas.
solid gold
Dentro de um atalho como border, o nome da cor entra como mais um valor.

Cada nome é só um apelido para um código. Para o navegador, tomato, #ff6347 e rgb(255, 99, 71) são a mesma cor; no F12, na aba Computed (Calculado), ela aparece como rgb(255, 99, 71).

Por família

As 148 cores, separadas pelo matiz (a posição no círculo das cores, o "h" do hsl()) e, dentro de cada família, da mais clara para a mais escura. A separação foi feita pela conta, não "a olho": por isso o brown (marrom) caiu nos vermelhos e o pink (rosa), também. As cores quase brancas e as sem cor (cinzas) ficaram em grupos à parte. Os sinônimos (gray e grey) aparecem os dois.

Curiosidades (que confundem)

O quêPor quê
darkgray é mais clara que gray #a9a9a9 × #808080. Os nomes vieram de listas diferentes: gray é a das 16 básicas, darkgray veio da lista de cores do sistema X11 (Unix), onde "gray" era mais claro.
gray e greyAs duas grafias (americana e britânica) funcionam, em todos os cinzas: darkgrey, lightslategrey, dimgrey…
aqua = cyan, fuchsia = magentaMesma cor, dois nomes: um veio das 16 básicas, o outro do X11.
green é escuro; o verde "puro" é lime green = #008000; lime = #00ff00.
rebeccapurpleA mais nova da lista: entrou no CSS Color 4, em 2014, em homenagem a Rebecca Meyer, filha de Eric Meyer, um dos pioneiros do CSS. Funciona no Chrome 38, Firefox 33 e Safari 9 em diante.
Não existem darkyellow nem lightredOs nomes não seguem um padrão: nem todo "dark…" ou "light…" existe. Na dúvida, procure nesta página; se não estiver aqui, use um hexadecimal ou hsl().

As cores do sistema mudam conforme o computador, o tema e o modo de alto contraste: servem para fazer algo "parecer do sistema", não para a identidade do seu site.

Suporte: transparent e currentcolor funcionam em todos os navegadores. Entre as cores do sistema, AccentColor é recente no Chrome (149; Firefox 103, Safari 16.5), e ButtonBorder, Mark e MarkText ainda não funcionam no Safari.

Contraste: nem toda cor serve para texto

Um nome bonito não garante leitura. A regra de acessibilidade (WCAG) pede contraste de pelo menos 4,5 para 1 entre o texto comum e o fundo. Algumas cores com nome sobre fundo branco (a conta é a da WCAG; a amostra, o seu navegador desenha):

  • navy · 16:1
  • maroon · 10,9:1
  • darkslategray · 8,9:1
  • rebeccapurple · 8,4:1
  • darkgreen · 7,4:1
  • firebrick · 6,7:1
  • dimgray · 5,5:1
  • crimson · 5:1
  • teal · 4,8:1
  • seagreen · 4,3:1 ✗
  • steelblue · 4,1:1 ✗
  • gray · 3,9:1 ✗
  • tomato · 3:1 ✗
  • orange · 2:1 ✗
  • yellow · 1,1:1 ✗

As marcadas com ✗ ficam abaixo de 4,5:1: use-as como fundo, borda ou detalhe, e não como cor de texto sobre branco. Mais na aula CSS e Acessibilidade.

Quando dá errado

Nome escrito errado, com hífen ou com aspas 
h1 {
  color: tomatoe;
}
h2 {
  color: light-blue;
}
p {
  color: "tomato";
}

O que a Ana vê: os títulos e o parágrafo continuam pretos, a cor que eles herdam. Conferido no Chromium: com color: tomatoe, o calculado ficou rgb(0, 0, 0).

Por quê: o navegador só conhece os nomes desta página, escritos do jeito certo. Um nome que não existe, um hífen no meio ou aspas em volta tornam o valor inválido, e a declaração inteira é ignorada. No F12, painel Styles (Estilos), a linha aparece riscada, com um ícone de aviso.

O validador W3C:

$ vnu --css tomatoe.css
"file:/home/ana/ref/cores/tomatoe.css":2.10-2.16: error: CSS: “color”: “tomatoe” is not a “color” value.
$ vnu --css hifen.css
"file:/home/ana/ref/cores/hifen.css":2.10-2.19: error: CSS: “color”: “light-blue” is not a “color” value.
$ vnu --css aspas.css
"file:/home/ana/ref/cores/aspas.css":2.10-2.17: error: CSS: “color”: “"tomato"” is not a “color” value.

“tomatoe” is not a “color” value = "tomatoe não é um valor de cor". Nomes certos com maiúsculas (Tomato), grey, rebeccapurple, currentcolor e as cores do sistema (CanvasText) passaram sem nenhuma mensagem.

Como resolver: copie o nome desta página. Se a cor que você quer não tem nome, use o código: #ff6347 ou rgb(255 99 71).

Resumo

  • O CSS tem 148 nomes de cores (CSS Color 4), em inglês, escritos juntos e sem aspas: lightseagreen.
  • Maiúsculas não importam, mas o costume é minúsculas.
  • Cada nome é um apelido de um código: tomato = #ff6347 = rgb(255, 99, 71).
  • Sinônimos: gray/grey, aqua/cyan, fuchsia/magenta. E darkgray é mais clara que gray.
  • Especiais: transparent, currentcolor (a cor da letra) e as cores do sistema (Canvas, CanvasText…).
  • Texto precisa de contraste de 4,5:1: yellow, orange e tomato sobre branco não passam.
  • Nome errado = declaração ignorada; o validador diz is not a “color” value.
