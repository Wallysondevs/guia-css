CSS box-shadow

Uma sombra discreta embaixo de um cartão faz ele parecer "levantado" da página, como uma folha de papel sobre a mesa. É assim que muitos sites mostram o que é clicável ou o que está por cima (um menu aberto, uma janela de aviso). No CSS, a sombra vem do box-shadow ("sombra da caixa"). Nesta aula você vai montar uma sombra peça por peça, ver cada valor lado a lado e chegar às sombras suaves que os sites de hoje usam.

Você vai aprender
  • As partes de uma sombra: deslocamento horizontal e vertical, desfoque, espalhamento e cor.
  • Cada valor lado a lado, para ver o que ele muda.
  • Como fazer uma sombra suave e realista, com cor transparente.
  • A sombra interna (inset) e várias sombras na mesma caixa.
  • A sombra que cresce quando o mouse passa por cima.
  • Os erros reais do validador W3C.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a lanterna e o cartão

Ponha um cartão sobre a mesa e acenda uma lanterna em cima dele, um pouco à esquerda. A sombra aparece do lado oposto à luz: um pouco para a direita e para baixo. Se você levantar o cartão, a sombra fica mais espalhada e borrada. Se a luz for fraca, a sombra é clarinha.

O box-shadow descreve essa sombra com números: para onde ela vai, quanto ela borra, quanto ela cresce e de que cor ela é.

1. A primeira sombra

<style>
  .cartao {
    max-width: 260px;
    padding: 16px;
    margin: 12px;
    background-color: white;
    box-shadow: 6px 6px 12px gray;
  }
</style>
<div class="cartao">Bolo de cenoura: R$ 35</div>
box-shadow:
A propriedade da sombra. Box shadow = "sombra da caixa".
6px
1º número: o deslocamento horizontal. Positivo vai para a direita; negativo, para a esquerda.
6px
2º número: o deslocamento vertical. Positivo vai para baixo; negativo, para cima.
12px
3º número (opcional): o desfoque (blur). 0 é uma sombra de contorno duro; quanto maior, mais borrada.
gray
A cor. Sem ela, a sombra usa a cor do texto.

A sombra cinza aparece à direita e embaixo do cartão, borrada nas pontas. O cartão parece ter uma lanterna em cima, à esquerda.

2. Cada valor lado a lado

O deslocamento: para onde vai

<style>
  .s {
    display: inline-block;
    width: 110px;
    padding: 18px 4px;
    margin: 18px;
    text-align: center;
    font-family: monospace;
    background-color: lightyellow;
    border: 1px solid khaki;
  }
</style>
<div class="s" style="box-shadow: 8px 8px 0 gray">8px 8px</div>
<div class="s" style="box-shadow: -8px 8px 0 gray">-8px 8px</div>
<div class="s" style="box-shadow: 8px -8px 0 gray">8px -8px</div>
<div class="s" style="box-shadow: 0 0 0 gray">0 0</div>

Sem desfoque (o terceiro número é 0), a sombra é uma cópia cinza da caixa, deslocada. Com 0 0, ela fica exatamente atrás da caixa e não aparece.

O desfoque: quanto borra

<style>
  .s {
    display: inline-block;
    width: 110px;
    padding: 18px 4px;
    margin: 18px;
    text-align: center;
    font-family: monospace;
    background-color: lightyellow;
    border: 1px solid khaki;
  }
</style>
<div class="s" style="box-shadow: 6px 6px 0 gray">blur 0</div>
<div class="s" style="box-shadow: 6px 6px 6px gray">blur 6px</div>
<div class="s" style="box-shadow: 6px 6px 20px gray">blur 20px</div>

Quanto maior o desfoque, mais a sombra se espalha e mais fraca fica nas pontas. O desfoque não pode ser negativo.

O espalhamento: quanto cresce

Um 4º número, opcional, é o espalhamento (spread): aumenta (positivo) ou diminui (negativo) o tamanho da sombra antes do desfoque.

<style>
  .s {
    display: inline-block;
    width: 110px;
    padding: 18px 4px;
    margin: 22px;
    text-align: center;
    font-family: monospace;
    background-color: lightyellow;
    border: 1px solid khaki;
  }
</style>
<div class="s" style="box-shadow: 0 0 10px 0 gray">spread 0</div>
<div class="s" style="box-shadow: 0 0 10px 8px gray">spread 8px</div>
<div class="s" style="box-shadow: 0 10px 10px -6px gray">spread -6px</div>
<div class="s" style="box-shadow: 0 0 0 4px darkorange">0 0 0 4px</div>
  • spread 8px: uma "aura" em volta da caixa toda.
  • spread -6px com deslocamento para baixo: a sombra só aparece embaixo, como a de um objeto pousado.
  • 0 0 0 4px: sem deslocamento e sem desfoque, só espalhamento. Vira uma "borda" de 4px que não ocupa espaço, parecida com um outline, e é muito usada como anel de foco.

A cor: sombras de verdade são transparentes

Sombras de verdade não são cinza: são o fundo um pouco mais escuro. Por isso as sombras bonitas usam preto transparente, que escurece qualquer fundo:

<style>
  .fundo {
    background-color: gold;
    padding: 8px;
  }
  .s {
    display: inline-block;
    width: 130px;
    padding: 18px 4px;
    margin: 16px;
    text-align: center;
    font-family: monospace;
    background-color: white;
  }
</style>
<div class="fundo">
  <div class="s" style="box-shadow: 0 4px 12px gray">gray</div>
  <div class="s" style="box-shadow: 0 4px 12px rgb(0 0 0 / 0.25)">preto 25%</div>
</div>

Sobre o fundo amarelo, a sombra gray fica acinzentada, com cara de "suja"; a de preto com 25% de opacidade (rgb(0 0 0 / 0.25), aula Transparência) vira um amarelo mais escuro, como uma sombra de verdade. No F12, na aba Computed, ela aparece como rgba(0, 0, 0, 0.25) 0px 4px 12px 0px: o navegador põe a cor na frente e completa o espalhamento com 0px.

3. A sombra de cartão de hoje

As sombras dos sites atuais são sutis: pouco deslocamento, bastante desfoque, cor bem transparente. Compare uma sombra "anos 2000" com uma moderna:

<style>
  body {
    background-color: whitesmoke;
  }
  .cartao {
    display: inline-block;
    vertical-align: top;
    width: 180px;
    padding: 16px;
    margin: 12px;
    background-color: white;
    border-radius: 12px;
  }
  .antiga  { box-shadow: 5px 5px 5px black; }
  .moderna { box-shadow: 0 2px 8px rgb(0 0 0 / 0.15); }
</style>
<div class="cartao antiga">5px 5px 5px black</div>
<div class="cartao moderna">0 2px 8px rgb(0 0 0 / 0.15)</div>

A sombra antiga é pesada e chama mais atenção que o próprio cartão. A moderna mal se nota, mas separa o cartão do fundo. Repare também que as duas acompanham o border-radius: a sombra tem a forma da caixa.

Missão: dê ao cartão a sombra moderna: deslocamento horizontal 0, vertical 2px, desfoque 8px, na cor rgb(0 0 0 / 0.15).

4. A sombra interna: inset

A palavra inset ("embutido"), no começo ou no fim, joga a sombra para dentro da caixa. Ela parece afundada, como um campo de formulário ou um botão apertado:

<style>
  .s {
    display: inline-block;
    width: 150px;
    padding: 18px 4px;
    margin: 12px;
    text-align: center;
    font-family: monospace;
    background-color: whitesmoke;
    border-radius: 8px;
  }
</style>
<div class="s" style="box-shadow: 0 2px 6px gray">por fora</div>
<div class="s" style="box-shadow: inset 0 2px 6px gray">inset</div>

Na interna, o deslocamento para baixo (2px) escurece a parte de cima, por dentro: é como se a borda de cima fizesse sombra no "buraco".

5. Várias sombras: a vírgula

Separadas por vírgula, várias sombras se empilham na mesma caixa. A primeira da lista fica por cima:

<style>
  body {
    background-color: whitesmoke;
  }
  .cartao {
    max-width: 240px;
    padding: 16px;
    margin: 16px;
    background-color: white;
    border-radius: 12px;
    box-shadow:
      0 1px 2px rgb(0 0 0 / 0.2),
      0 8px 24px rgb(0 0 0 / 0.12);
  }
</style>
<div class="cartao">Duas sombras: uma curta e nítida, outra longa e suave.</div>

A sombra curta marca a borda do cartão; a longa dá a sensação de altura. É a receita das "elevações" de muitos sistemas de design. Quebrar a lista em linhas, com uma sombra por linha, deixa o código fácil de ler.

Vírgula separa sombras, não números

Dentro de uma sombra, os números vão separados por espaço. A vírgula só aparece entre sombras inteiras. box-shadow: 5px, 5px, 10px, gray; é inválido (veja Quando dá errado).

6. A sombra não ocupa espaço

Como o outline, a sombra é desenhada por cima do que está em volta e não empurra nada. Isso tem duas consequências:

  • Pode aparecer e crescer sem mexer no layout. Ótimo para o efeito de "levantar" um cartão no :hover.
  • Pode ser cortada. Se o pai tem overflow: hidden, a sombra que passa da borda dele some. E uma sombra grande precisa de espaço em volta (uma margin), senão encosta nos vizinhos.
<style>
  body {
    background-color: whitesmoke;
  }
  .cartao {
    max-width: 240px;
    padding: 16px;
    margin: 16px;
    background-color: white;
    border-radius: 12px;
    box-shadow: 0 2px 8px rgb(0 0 0 / 0.15);
    transition: box-shadow 0.2s;
  }
  .cartao:hover {
    box-shadow: 0 8px 20px rgb(0 0 0 / 0.25);
  }
</style>
<div class="cartao">Passe o mouse aqui.</div>
<p>Este parágrafo não se mexe.</p>

Ao passar o mouse, a sombra cresce e escurece, e o cartão parece subir; o parágrafo embaixo fica parado. O transition faz a troca ser suave em vez de instantânea (aula Transições). Num celular, sem mouse, o :hover não acontece, então nada importante pode depender dele.

E a sombra do texto?

O box-shadow é a sombra da caixa. Para a sombra das letras, existe o text-shadow, com valores parecidos (aula Sombra no Texto).

Quando dá errado

A declaração inválida é ignorada inteira: a caixa fica sem sombra nenhuma, e o F12 mostra a linha riscada no painel de estilos (aula DevTools).

Um número só: Too many values or values are not recognized 
<style>
  .cartao {
    max-width: 240px;
    padding: 16px;
    margin: 12px;
    box-shadow: 5px red;
  }
</style>
<div class="cartao">Cadê a sombra vermelha?</div>

$ vnu --css s1.css
"file:/home/ana/site/s1.css":2.19-2.21: error: CSS: “box-shadow”: Too many values or values are not recognized.

O que você vê: o cartão sem sombra. No F12, aba Computed: box-shadow: none.

Por quê: uma sombra precisa de pelo menos dois números, o horizontal e o vertical. Com um só, o navegador não entende a declaração ("valores não reconhecidos").

Como consertar: box-shadow: 5px 5px red;.

Vírgulas entre os números 
$ cat s3.css
.cartao {
  box-shadow: 5px, 5px, 10px, gray;
}
$ vnu --css s3.css
"file:/home/ana/site/s3.css":2.31-2.34: error: CSS: “box-shadow”: Too many values or values are not recognized.

Com as vírgulas, o navegador lê quatro sombras: 5px, 5px, 10px e gray, cada uma inválida sozinha. A declaração toda é ignorada. Conserto: box-shadow: 5px 5px 10px gray;.

$ vnu --css s4.css

  • box-shadow: 5px 5px 10px 4px 2px red;: o máximo são quatro números; o quinto, 2px, "não é um valor de box-shadow".
  • box-shadow: 5px 5px -10px gray;: o desfoque (o 3º número) "não pode ser negativo". Os deslocamentos e o espalhamento podem.
  • box-shadow: 5 5 10 gray;: só o 0 fica sem unidade.
  • box-shaddow: com dois d, a propriedade "não existe".
A sombra está lá, mas cortada

O que você vê: a sombra aparece só de um lado, ou some na borda de uma caixa maior.

Por quê: um pai com overflow: hidden corta tudo o que passa da borda dele, sombras incluídas (aula O que Transborda). Não é erro de CSS: o validador não avisa.

Como consertar: dê espaço (padding no pai, margin no filho) ou tire o overflow: hidden do pai.

Resumo

  • box-shadow: X Y desfoque espalhamento cor; X e Y são obrigatórios; desfoque e espalhamento são opcionais; a cor, se faltar, é a do texto.
  • X positivo vai para a direita; Y positivo, para baixo. O desfoque borra e nunca é negativo; o espalhamento faz a sombra crescer ou encolher.
  • Sombras bonitas são sutis e de preto transparente: 0 2px 8px rgb(0 0 0 / 0.15).
  • inset joga a sombra para dentro; a vírgula empilha várias sombras; 0 0 0 3px cor vira um anel.
  • A sombra não ocupa espaço (pode crescer no :hover sem mexer na página), acompanha o border-radius e é cortada por overflow: hidden.
  • Erros: um número só, vírgula entre números, cinco números, desfoque negativo, número sem unidade, box-shaddow. A caixa fica sem sombra.
