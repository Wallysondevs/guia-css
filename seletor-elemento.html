CSS Seletor de Elemento

O seletor mais simples do CSS é o nome de um elemento HTML: p, h1, li, a. Ele escolhe todos os elementos daquele tipo, em qualquer lugar da página. É com ele que se monta a base do visual de um site: a letra do body, a cor dos títulos, o jeito dos links. Nesta aula você vai usá-lo, ver até onde ele alcança (às vezes, mais longe do que você queria) e saber quando trocar por uma classe.

Você vai aprender
  • A escrever um seletor de elemento: o nome da tag, sem < e >.
  • Que ele pega todos os elementos do tipo, no cabeçalho, no meio e no rodapé.
  • A montar os estilos de base de um site com body, títulos, parágrafos e links.
  • Quando usar o seletor de elemento e quando preferir uma classe.
  • Os erros reais: a tag escrita com < >, o link que não fica da cor do li e a regra que pega elementos demais.

A ideia: "todos os cozinheiros"

Na padaria da Ana, um aviso diz: "todos os cozinheiros usam touca". Não importa se o cozinheiro está na cozinha, no balcão ou no estoque, nem se chegou ontem: se é cozinheiro, usa touca.

O seletor de elemento é esse aviso. p { … } quer dizer "todo parágrafo", onde quer que ele esteja, inclusive os que você ainda vai escrever.

1. A forma: o nome da tag

h2 {
  color: darkgreen;
}
h2
O seletor de elemento (também chamado seletor de tipo; em inglês, type selector): o nome da tag <h2>, sem os sinais < e >. Escolhe todos os <h2> da página.
{ color: darkgreen; }
O que acontece com todos eles: texto verde-escuro.

Qualquer elemento do HTML pode ser seletor: body, header, nav, ul, li, a, img, table, button… Os nomes são os mesmos do HTML (em inglês). Escreva-os em minúsculas, como no HTML.

2. Todos, em qualquer lugar

A página da Ana tem parágrafos no cabeçalho, na receita e no rodapé. Uma regra para p pega os três:

Experimente: os três parágrafos ficaram verde-azulados e em itálico, cada um num lugar diferente da página. Acrescente um quarto parágrafo em qualquer lugar do index.html: ele já nasce com o mesmo visual. Depois troque o seletor p por h2.

<link rel="stylesheet" href="style.css">
<header>
  <h1>Receitas da Ana</h1>
  <p>Receitas simples, testadas na minha cozinha.</p>
</header>
<main>
  <h2>Bolo de cenoura</h2>
  <p>Fofinho, com cobertura de chocolate.</p>
</main>
<footer>
  <p>Feito pela Ana em 2026.</p>
</footer>

p {
  color: teal;
  font-style: italic;
}

O navegador não quer saber se o <p> está dentro do <header>, do <main> ou do <footer>: é um <p>, então recebe o estilo. Para escolher só os parágrafos do rodapé, existe outro seletor, que vem nas próximas aulas (footer p, em Descendente, Filho e Irmãos), ou uma classe (Seletor de Classe).

3. Estilos de base

Como o seletor de elemento pega tudo de um tipo, ele é perfeito para o "visual padrão" do seu site, por cima do padrão do navegador: a letra de todo o texto, a cor de todos os títulos, o jeito de todos os links. Quase toda folha de estilo começa assim:

/* ========== Base ========== */

body {
  font-family: sans-serif;
  background-color: linen;
}

h1 {
  color: firebrick;
}

h2 {
  color: darkgreen;
}

a {
  color: firebrick;
}
body
O corpo da página. A cor de fundo dele pinta a janela inteira, e a fonte passa para todos os elementos de dentro (aula Herança).
h1, h2
Todos os títulos de cada nível, cada nível com a sua regra.
a
Todos os links da página.

Depois da base, os detalhes ("este parágrafo é um aviso", "este botão é o principal") ficam com as classes. É a divisão que você vai ver em quase todo site: elementos para o geral, classes para o específico.

E o elemento html?

O seletor html também existe e pega o elemento raiz da página. Na prática, o visual geral vai no body. O html aparece em casos especiais, como o tamanho de letra de base para a unidade rem (aula Unidades).

Um sinal de que o seletor de elemento não é a ferramenta certa: você escreve p { … } e logo depois precisa "desfazer" o estilo em vários parágrafos. Aí é melhor uma classe só nos parágrafos que precisam.

Quando dá errado

A tag com < > no seletor: Style sheets should not include HTML syntax 
<p> {
  color: teal;
}

O que você vê: os parágrafos continuam pretos (conferido no Chromium). O seletor <p> não é CSS válido, e o navegador descarta a regra inteira. As regras depois dela funcionam normalmente.

$ vnu --css tag.css
"file:/home/ana/site/tag.css":1.1-1.3: error: CSS: Parse Error. Style sheets should not include HTML syntax.
"file:/home/ana/site/tag.css":3.2-4.1: error: CSS: Parse Error.

O que significa: "erro de leitura: folhas de estilo não devem ter sintaxe de HTML" (na linha 1, o <p>), e um segundo erro de leitura no fim da regra descartada.

Como consertar: só o nome: p { … }.

O li ficou verde, mas o link dentro dele, não 
<style>
  li {
    color: teal;
  }
</style>
<ul>
  <li><a href="bolo.html">Bolo de cenoura</a></li>
  <li>Pão de queijo</li>
</ul>

O que você vê: o "Pão de queijo" e as bolinhas ficam verde-azulados, mas o link "Bolo de cenoura" continua azul.

Por quê: a regra li pinta o <li>. O texto do link, porém, pertence ao <a>, e o <a> tem uma cor própria, que vem da folha padrão do navegador. Uma regra que fala diretamente do elemento (a do navegador, para o a) vence a cor que viria do pai (o li). No F12, o painel Computed do link mostra rgb(0, 0, 238), o azul padrão. Aula Herança.

Como consertar: uma regra para o próprio link, com o seletor a. É a missão abaixo.

Missão: deixe o link "Bolo de cenoura" da mesma cor dos itens da lista (teal), com uma regra nova para o elemento a.

<link rel="stylesheet" href="style.css">
<ul>
  <li><a href="bolo.html">Bolo de cenoura</a></li>
  <li>Pão de queijo</li>
</ul>

li {
  color: teal;
}

li {
  color: teal;
}

a {
  color: teal;
}
A regra pegou elementos demais 
p {
  text-align: center;
  font-size: 24px;
}

O que acontece: a Ana queria centralizar e aumentar a frase de boas-vindas do cabeçalho. Mas todos os parágrafos do site ficaram centralizados e grandes: o modo de preparo das receitas, o rodapé, tudo. Não é um erro de sintaxe (o validador não diz nada), é o seletor fazendo exatamente o que diz.

Como consertar: deixe no seletor de elemento só o que vale para todos, e use uma classe para o caso especial: <p class="boas-vindas"> e .boas-vindas { … } (aula Seletor de Classe).

O seletor está certo, mas o HTML usa outro elemento

O que acontece: o CSS tem h2 { color: darkgreen; }, mas os títulos das receitas não mudam. Abrindo o HTML (ou o painel Elements do F12), a Ana descobre que eles são <h3>. Ou a regra é paragrafo, titulo, lista: nomes em português, que não são elementos do HTML.

O que o validador diz: nada. Ele não compara o CSS com o HTML.

Como consertar: o seletor tem de ser o nome exato da tag usada no HTML.

Resumo

  • O seletor de elemento (ou de tipo) é o nome da tag, sem < >: p, h1, a, body.
  • Ele pega todos os elementos do tipo, em qualquer lugar da página, inclusive os que você acrescentar depois.
  • É o seletor dos estilos de base: elementos para o geral, classes para o específico.
  • O a tem cor própria (do navegador): a cor do li ou do p não chega no link. Dê a ele a sua regra.
  • Seletor com <p> derruba a regra (Style sheets should not include HTML syntax). Nome de tag que não está no HTML não dá erro: só não pega ninguém.
