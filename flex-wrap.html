CSS flex-wrap

A Ana pôs os produtos da lojinha numa fila com display: flex. Com três produtos, ficou lindo. Com cinco, os cartões ficaram espremidos, o texto quebrou em pedacinhos e o último cartão saiu para fora da caixa. É que o Flexbox, sozinho, põe tudo numa linha só, custe o que custar. Nesta aula você vai conhecer a propriedade flex-wrap (wrap = "embrulhar", "quebrar a linha"), que deixa os itens descerem para a linha de baixo quando não cabem mais.

Você vai aprender
  • Por que, sem flex-wrap, os itens encolhem e chegam a vazar da caixa.
  • Como escrever flex-wrap: wrap, parte por parte, e onde ele vai (no pai, não nos itens).
  • Os três valores, nowrap, wrap e wrap-reverse, desenhados lado a lado.
  • O atalho flex-flow, que junta a direção e a quebra numa linha.
  • O que o align-content faz com as várias linhas que aparecem.
  • Por que às vezes o wrap "não faz nada", e as mensagens reais do validador W3C.

Antes, é bom ter visto Introdução ao Flexbox (o que é o "pai flex" e os "itens") e Direção (flex-direction). Os exemplos com resultado são desenhados agora pelo seu navegador. As mensagens do validador saíram do validador W3C (vnu, o mesmo do validator.w3.org), na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: a prateleira que enche

Pense numa prateleira de padaria. A Ana vai colocando os potes de doce lado a lado. Uma hora a prateleira acaba. Ela tem duas escolhas:

  1. Apertar tudo na mesma prateleira, encostando um pote no outro, até que algum fique pendurado para fora. É o que o Flexbox faz por padrão (nowrap, "não quebrar").
  2. Começar a prateleira de baixo com os potes que não couberam. É o flex-wrap: wrap.

No Flexbox, cada "prateleira" se chama linha flex (flex line). Sem flex-wrap, só existe uma. Com wrap, o navegador abre quantas linhas precisar.

1. O problema: tudo numa linha só

Cinco produtos, cada um com width: 120px (largura de 120 pixels), numa vitrine de 320 pixels. A conta não fecha: só os cartões somam mais de 600 pixels. Veja o que o navegador faz:

<link rel="stylesheet" href="style.css">
<div class="vitrine">
  <div class="produto">Bolo de cenoura</div>
  <div class="produto">Brigadeiro</div>
  <div class="produto">Pão de mel</div>
  <div class="produto">Torta de limão</div>
  <div class="produto">Cookies</div>
</div>

.vitrine {
  display: flex;
  width: 320px;
  border: 2px dashed gray;
}

.produto {
  width: 120px;
  margin: 4px;
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}

Duas coisas aconteceram, e as duas são o Flexbox tentando caber numa linha só:

  • Os cartões encolheram: nenhum ficou com 120 pixels. Os itens flex podem encolher para caber (aula Crescer e Encolher), e o texto quebra em várias linhas: "Pão / de / mel".
  • Mesmo assim, não coube: um item não encolhe menos que a sua palavra mais comprida ("Brigadeiro", "Cookies"). O último cartão ficou com um pedaço para fora da borda tracejada. (Se a largura da sua tela for pequena, o vazamento é ainda maior.)

Esse é o comportamento padrão: flex-wrap: nowrap. Você não escreveu nada, e mesmo assim ele está lá.

2. A solução: flex-wrap: wrap

Uma linha a mais no pai (a .vitrine) resolve:

.vitrine {
  display: flex;
  flex-wrap: wrap;
}
.vitrine
O seletor: o pai flex, o elemento que tem o display: flex. O flex-wrap é uma propriedade do pai, porque é ele que decide quantas linhas existem. Escrito num item, não faz nada.
flex-wrap
A propriedade. Wrap é "quebrar a linha", como o "quebra automática de texto" de um editor de texto.
:
Separa a propriedade do valor.
wrap
O valor: "pode quebrar". Quando o próximo item não cabe, ele desce para uma nova linha.
;
Fecha a declaração. Esquecer o ; estraga esta linha e a de baixo (veja Quando dá errado).

Com o wrap, cada cartão volta a ter os seus 120 pixels (mais o padding), e os que não cabem descem:

<link rel="stylesheet" href="style.css">
<div class="vitrine">
  <div class="produto">Bolo de cenoura</div>
  <div class="produto">Brigadeiro</div>
  <div class="produto">Pão de mel</div>
  <div class="produto">Torta de limão</div>
  <div class="produto">Cookies</div>
</div>

.vitrine {
  display: flex;
  flex-wrap: wrap;
  width: 320px;
  border: 2px dashed gray;
}

.produto {
  width: 120px;
  margin: 4px;
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}

Agora são três linhas: dois cartões, dois cartões e o "Cookies" sozinho na última. Nada vaza. Mude o width: 320px da vitrine para 480px e veja os cartões subirem: cabem três por linha. Quem decide quantos cabem é a largura que sobra, e não um número que você escreve.

A última linha fica "manca"

Repare que o "Cookies" ficou sozinho à esquerda, com um buraco ao lado. É normal: cada linha é arrumada separadamente, e o item não sabe o tamanho dos de cima. Se você quer que ele cresça e ocupe a sobra, isso é o flex-grow (aula Crescer e Encolher). Se quer colunas certinhas, alinhadas nas duas direções, isso é Grid (aula Introdução ao Grid).

ValorO que fazNo exemplo
nowrapPadrão. Uma linha só: os itens encolhem e, se mesmo assim não couberem, vazam.Os cinco espremidos numa linha
wrapQuebra: os itens que não cabem descem para uma nova linha, embaixo.1 e 2 em cima, 3 e 4 no meio, 5 embaixo
wrap-reverseQuebra também, mas as linhas novas vão para cima: a primeira linha fica no pé da caixa.1 e 2 embaixo, 3 e 4 no meio, 5 em cima

O wrap-reverse é raro. A ordem dos itens dentro de cada linha não muda (1 continua à esquerda do 2); só a ordem das linhas é que se inverte. No dia a dia, você vai usar wrap quase sempre, e nowrap quando quiser garantir uma linha só (um menu que deve rolar para o lado, por exemplo).

4. O atalho flex-flow

A direção (flex-direction) e a quebra (flex-wrap) andam tanto juntas que existe um atalho para as duas: flex-flow (flow = "fluxo"). Estas duas regras fazem exatamente a mesma coisa:

/* jeito longo */
.vitrine {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
}

/* atalho */
.vitrine {
  display: flex;
  flex-flow: row wrap;
}
flex-flow
O atalho: aceita uma direção, uma quebra, ou as duas, separadas por espaço (sem vírgula).
row
A direção: row, column, row-reverse ou column-reverse.
wrap
A quebra: nowrap, wrap ou wrap-reverse.

Quem fica de fora volta ao padrão: flex-flow: wrap é o mesmo que row wrap. Como todo atalho, ele apaga o que veio antes: um flex-wrap: wrap escrito acima de um flex-flow: column volta para nowrap. Na aba Computed do F12 e no getComputedStyle, o que aparece é a propriedade longa: flex-wrap vale wrap, e flex-direction vale row.

5. Várias linhas: o align-content

Com o wrap, aparece algo que não existia: várias linhas. E se a vitrine for mais alta do que as linhas precisam? Quem decide o que fazer com a altura que sobra é o align-content ("alinhar o conteúdo"), que arruma as linhas dentro do pai. Veja a mesma vitrine com 200 pixels de altura, sem e com align-content: flex-start:

<link rel="stylesheet" href="style.css">
<p>sem align-content</p>
<div class="vitrine">
  <div class="produto">Bolo</div>
  <div class="produto">Brigadeiro</div>
  <div class="produto">Pão de mel</div>
</div>

<p>align-content: flex-start</p>
<div class="vitrine no-topo">
  <div class="produto">Bolo</div>
  <div class="produto">Brigadeiro</div>
  <div class="produto">Pão de mel</div>
</div>

p {
  font-family: monospace;
}

.vitrine {
  display: flex;
  flex-wrap: wrap;
  width: 320px;
  height: 200px;
  border: 2px dashed gray;
}

.no-topo {
  align-content: flex-start;
}

.produto {
  width: 120px;
  margin: 4px;
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}

Na primeira vitrine, as duas linhas dividiram a altura que sobrava, e os cartões esticaram até ficarem altos e vazios por baixo do texto. Na segunda, as linhas ficaram juntas no topo, cada uma com a altura do seu conteúdo, e a sobra ficou embaixo. O align-content aceita os mesmos valores que você conhece do justify-content (flex-start, center, flex-end, space-between…), mas só funciona quando há quebra de linha: com nowrap, só existe uma linha, e não há o que arrumar.

align-items × align-content

Os nomes confundem. O align-items (aula Alinhando na Coluna) alinha cada item dentro da sua linha. O align-content arruma as linhas dentro do pai. Pense nas prateleiras: um arruma os potes em cada prateleira; o outro decide onde ficam as prateleiras no armário.

6. Quebrando em coluna

O wrap também funciona com flex-direction: column: os itens descem um embaixo do outro e, quando a altura acaba, começam uma nova coluna ao lado. Mas para isso o pai precisa de uma altura definida. Sem altura, a caixa simplesmente cresce para baixo e nunca "acaba":

<link rel="stylesheet" href="style.css">
<div class="vitrine">
  <div class="produto">Bolo</div>
  <div class="produto">Brigadeiro</div>
  <div class="produto">Pão de mel</div>
  <div class="produto">Cookies</div>
</div>

.vitrine {
  display: flex;
  flex-flow: column wrap;
  width: 320px;
  height: 130px;
  border: 2px dashed gray;
}

.produto {
  width: 120px;
  margin: 4px;
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}

Bolo, Brigadeiro e Pão de mel enchem a primeira coluna; o Cookies começa a segunda. Apague a linha do height e veja: os quatro ficam numa coluna só. Na prática, quebrar em colunas é bem menos comum do que em linhas; para colunas de verdade, o Grid costuma ser melhor.

7. Formas de fazer a mesma coisa

"Cartões que se ajeitam conforme a largura da tela" tem mais de uma solução. O flex-wrap é uma delas:

FormaComo ficaQuando usar
display: flex (sem wrap)Uma linha só; os itens encolhemPoucos itens que sempre cabem: o menu com 3 links, o cabeçalho com logo e botão
display: flex + flex-wrap: wrapQuantos couberem por linha; cada linha é independenteEtiquetas, botões, fotos de tamanhos diferentes, uma lista de "tags" que pode crescer
display: grid com repeat(auto-fit, …)Colunas iguais, alinhadas de cima a baixoGalerias e grades de produtos, quando a última linha também deve ficar alinhada (aula repeat, minmax e auto-fit)
flex + @mediaVocê escolhe o layout para cada largura de telaQuando a mudança é grande (de coluna para linha, por exemplo): aula Media Queries
float ou display: inline-blockItens lado a lado que quebram como textoO jeito antigo: você vai encontrar em sites velhos, mas hoje o flex-wrap faz melhor (aula float)

Quando dá errado

CSS quase nunca mostra mensagem de erro: o navegador ignora em silêncio o que não entende, e a página fica como estava. Os casos abaixo são os mais comuns com flex-wrap.

O flex-wrap foi parar no item

O que aconteceu: a Ana escreveu o flex-wrap na regra dos cartões, e não na da vitrine:

.vitrine {
  display: flex;
}

.produto {
  flex-wrap: wrap;
}

O que você vê: nada muda; os cartões continuam espremidos numa linha. A declaração é válida (o validador não reclama), mas o flex-wrap só tem efeito num elemento com display: flex, e o cartão não é um pai flex. No F12, na aba Elements (Elementos), clique num cartão: o painel Styles (Estilos) mostra o flex-wrap: wrap ali, aplicado ao lugar errado.

Como consertar: mova a linha para a regra do pai (.vitrine). A regra para lembrar: flex-wrap, flex-direction, justify-content e align-items vão no pai.

Sem display: flex, o flex-wrap não faz nada

O que aconteceu: a regra tem flex-wrap: wrap, mas o display: flex foi apagado (ou está escrito errado, como display: flexbox).

O que você vê: os cartões voltam a ficar um embaixo do outro, cada um na sua linha, como qualquer div. Parece que o wrap "quebrou demais", mas na verdade não há Flexbox nenhum: os div são blocos, e blocos sempre começam numa linha nova.

Como consertar: confira o display: flex no mesmo elemento.

"O wrap não quebra"

O que aconteceu: a Ana pôs flex-wrap: wrap, mas os cartões continuam numa linha só. Nesse caso, os cartões não têm width: cada um tem só a largura do seu texto curto ("Bolo", "Brigadeiro", "Pão de mel").

O que você vê: os três numa linha, com espaço de sobra à direita. Não é erro: eles cabem. O wrap só quebra quando o próximo item não cabe. Diminua a largura da vitrine (ou ponha mais itens) e a quebra aparece.

Como consertar: se você quer um número certo de itens por linha, dê uma largura aos itens (width ou flex-basis, aula Crescer e Encolher), ou use Grid.

error: CSS: “flex-wrap”: “true” is not a “flex-wrap” value.

O que aconteceu: a Ana pensou em "ligar" a quebra, como um interruptor: flex-wrap: true;. Ou inventou um valor parecido, como wrapped.

$ vnu --css quebra.css
"file:/home/ana/flex/quebra.css":3.14-3.17: error: CSS: “flex-wrap”: “true” is not a “flex-wrap” value.
$ vnu --css quebra2.css
"file:/home/ana/flex/quebra2.css":3.14-3.20: error: CSS: “flex-wrap”: “wrapped” is not a “flex-wrap” value.

"true não é um valor de flex-wrap." O 3.14-3.17 é a linha 3, da coluna 14 à 17. No navegador, a declaração é ignorada: vale o padrão, nowrap, e os cartões continuam espremidos. No F12, ela aparece riscada, com um ícone de aviso.

Como consertar: os valores são só nowrap, wrap e wrap-reverse.

Quebra em coluna que não quebra

O que aconteceu: flex-flow: column wrap, mas a vitrine não tem height.

O que você vê: todos os itens numa coluna só, e a caixa cada vez mais comprida. Sem uma altura, a coluna nunca "acaba", então nunca há motivo para começar outra.

Como consertar: dê uma altura ao pai (height ou max-height), como no exemplo da seção 6.

Resumo

  • Por padrão (flex-wrap: nowrap), o Flexbox põe tudo numa linha só: os itens encolhem e, se não couberem, vazam.
  • flex-wrap: wrap, escrito no pai, deixa os itens que não cabem descerem para uma nova linha. wrap-reverse empilha as linhas para cima.
  • Cada linha é arrumada sozinha: a última pode ficar "manca". Para colunas alinhadas, use Grid.
  • flex-flow: row wrap é o atalho para flex-direction + flex-wrap.
  • Com várias linhas, align-content decide onde elas ficam no pai.
  • O wrap só quebra quando o item não cabe; em coluna, o pai precisa de altura. Valores inventados (true, wrapped) são ignorados, e o validador avisa.
