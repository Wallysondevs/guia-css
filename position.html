CSS position

Até aqui, cada elemento foi parar onde o navegador quis: um bloco embaixo do outro, as palavras uma depois da outra. A propriedade position ("posição") deixa você tirar um elemento desse lugar: empurrá-lo alguns pixels, prendê-lo no canto de um cartão, deixá-lo parado na tela enquanto a página rola. Esta aula é o mapa do assunto: o que é o "fluxo normal", os cinco valores de position e as propriedades que dizem para onde o elemento vai. As próximas aulas detalham cada valor.

Você vai aprender
  • O que é o fluxo normal da página.
  • Os cinco valores: static, relative, absolute, fixed e sticky.
  • top, right, bottom, left e o atalho inset: para onde o elemento vai.
  • A ideia de elemento de referência: "10px do topo… de quem?"
  • Qual valor usar em cada situação.
  • Os erros: o top que não faz nada e as mensagens do validador W3C.

Os resultados são desenhados pelo seu navegador, logo abaixo de cada código.

A ideia: a fila e quem sai dela

Pense numa fila de banco. Cada pessoa fica atrás da anterior, e ninguém escolhe o próprio lugar: é a ordem de chegada. Esse é o fluxo normal da página: os elementos se arrumam na ordem do HTML, os blocos um embaixo do outro, as palavras uma depois da outra.

Agora imagine:

  • Alguém dá um passo para o lado, mas o lugar dele na fila continua guardado. É o relative.
  • Alguém sai da fila e vai se encostar numa parede; a fila anda e fecha o buraco. É o absolute.
  • Alguém fica parado na porta, não importa quanto a fila ande. É o fixed.
  • Alguém anda com a fila até chegar à porta e ali fica preso, até a fila acabar. É o sticky.

1. O padrão: position: static

Todo elemento começa com position: static ("estático"): ele fica no fluxo normal, onde o navegador o pôs. Você quase nunca escreve static; ele é o que já está lá. A única vez em que ele aparece no código é para desfazer outro valor, por exemplo dentro de uma @media.

Num elemento static, as propriedades top, right, bottom e left não fazem nada. Para que elas funcionem, o elemento precisa de outro valor de position: é aí que ele passa a ser um elemento posicionado.

2. Os três primeiros, lado a lado

Três fileiras com as mesmas caixas 1, 2 e 3. A caixa 2 de cada fileira tem top: 20px e left: 20px; só o position dela muda:

<style>
  .caixa {
    width: 110px;
    height: 36px;
    margin: 4px;
    background-color: #e8ecff;
    border: 2px solid navy;
  }
  .mexe {
    top: 20px;
    left: 20px;
    background-color: #fde8e1;
    border-color: tomato;
  }
  .estatica { position: static; }
  .relativa { position: relative; }
  .absoluta { position: absolute; }
  .fileira {
    position: relative;
    margin-bottom: 16px;
    border: 2px dashed gray;
  }
</style>
<div class="fileira">
  <div class="caixa">1</div>
  <div class="caixa mexe estatica">2 static</div>
  <div class="caixa">3</div>
</div>
<div class="fileira">
  <div class="caixa">1</div>
  <div class="caixa mexe relativa">2 relative</div>
  <div class="caixa">3</div>
</div>
<div class="fileira">
  <div class="caixa">1</div>
  <div class="caixa mexe absoluta">2 absolute</div>
  <div class="caixa">3</div>
</div>

Repare em cada fileira:

  • static: a caixa 2 nem se mexeu. O top e o left foram ignorados.
  • relative: a caixa 2 desceu 20px e foi 20px para a direita, a partir de onde estava, e ficou por cima da caixa 3. O lugar dela na fileira continua reservado: a caixa 3 não subiu.
  • absolute: a caixa 2 saiu da fileira. A caixa 3 subiu e encostou na 1, e a caixa 2 foi parar a 20px do topo e 20px da esquerda da fileira tracejada, por cima das caixas 1 e 3. A fileira encolheu: ela só mede o que ficou no fluxo.

Por que "da fileira tracejada"? Porque a fileira tem position: relative. Esse é o próximo assunto.

3. top, right, bottom e left

Essas quatro propriedades, as propriedades de deslocamento, dizem a que distância o elemento fica de cada lado. O detalhe que confunde: top: 20px não quer dizer "suba 20px", e sim "fique a 20px do topo", o que, na prática, empurra para baixo.

Os valores podem ser em px, rem, % e as outras unidades da aula Unidades. O padrão é auto, "o navegador decide".

O atalho inset

A propriedade inset ("encaixe") junta as quatro, na mesma ordem do margin: em cima, direita, embaixo, esquerda.

Escrita curtaÉ o mesmo que
inset: 0;top: 0; right: 0; bottom: 0; left: 0;
inset: 10px 20px;top: 10px; bottom: 10px; e right: 20px; left: 20px;
inset: 0 0 auto auto;top: 0; right: 0; (o canto de cima, à direita)

O inset funciona em todos os navegadores atuais (Chrome e Edge desde a versão 87, Firefox desde a 66, Safari desde a 14.1).

Missão: o selo "Novo!" está colado no título. Faça-o subir 10px e ir 8px para a direita, a partir de onde está, sem mexer no resto da página.

}

4. O elemento de referência: "10px do topo de quem?"

Quando você diz top: 10px, sempre há uma pergunta escondida: 10px do topo de quê? A resposta muda com o valor de position. Esse "de quê" é o elemento de referência (na especificação do CSS, o containing block, "bloco que contém").

ValorOs deslocamentos contam a partir de…Sai do fluxo?Aula
static(não usa deslocamento)Nãoesta
relativeDo lugar onde o próprio elemento estariaNão: o lugar fica guardadoposition: relative
absoluteDo ancestral posicionado mais próximo (o primeiro "pai", "avô"… com position diferente de static); se não houver, da páginaSimposition: absolute
fixedDa janela do navegador (a parte visível da página)Simposition: fixed
stickyDa área que rola: o elemento anda com a página até "grudar" na distância pedidaNãoposition: sticky

Por isso, no exemplo da seção 2, a caixa absolute foi parar dentro da fileira: a fileira tinha position: relative e virou a referência. Essa dupla, pai relative + filho absolute, é a receita mais usada do posicionamento, e é o centro da aula position: absolute.

Quem fica por cima?

Quando um elemento posicionado cai em cima de outro, ele é desenhado por cima dos elementos do fluxo normal. Entre dois posicionados, vence o que vem depois no HTML. Para mudar essa ordem existe o z-index, aula Camadas.

5. Qual usar

QueroUse
Ajustar um elemento uns poucos pixels, sem mexer no restorelative + top/left
Servir de referência para um filho absoluterelative, sem deslocamento
Um selo no canto de um cartão, um "×" para fechar, um texto sobre a fotoabsolute dentro de um pai relative
Um botão "voltar ao topo" ou um aviso de cookies sempre na telafixed
Um cabeçalho que gruda no topo quando a página rolasticky + top: 0
Arrumar colunas, cartões lado a lado, o layout da páginaNenhum: use Flexbox ou Grid (aulas Flexbox e Grid)
Position não é para montar o layout

Dá para posicionar tudo com absolute e números exatos, e a página fica perfeita… na sua tela. Numa tela menor, com uma fonte maior ou com um texto mais comprido, tudo se sobrepõe, porque elementos fora do fluxo não empurram uns aos outros. Use position para detalhes; o layout é com Flexbox e Grid.

Quando dá errado

O top não faz nada: o elemento é static 
<style>
  .selo {
    top: -10px;
    left: 8px;
    background-color: gold;
  }
</style>
<h1>Bolo de cenoura <span class="selo">Novo!</span></h1>

O que você vê: o selo fica onde estava, colado ao título.

Por quê: sem position, o selo é static, e um elemento static ignora os deslocamentos. O validador não reclama: tudo ali é CSS válido. O F12 confunde mais: na aba Computed, o top aparece com -10px, como se valesse; quem diz que ele não tem efeito é o position: static, logo ao lado.

Como consertar: acrescente position: relative; (ou outro valor que não seja static).

Número sem unidade: top: 10 
.selo {
  position: relative;
  top: 10;
}

O que você vê: o selo não se move. No F12, a declaração top: 10 aparece riscada, com um ícone de aviso.

$ vnu --css style.css
"file:/home/ana/site/style.css":3.8-3.9: error: CSS: “top”: only “0” can be a “unit”. You must put a unit after your number.

O que significa: "só o 0 pode ficar sem unidade. Você precisa pôr uma unidade depois do número." Escreva top: 10px. O 0 é a exceção porque zero é zero em qualquer unidade: top: 0 está certo.

Valor com erro de digitação: absolut 
.selo {
  position: absolut;
  top: 0;
  right: 0;
}

O que você vê: o selo continua no fluxo normal, e o top e o right não fazem nada, porque o elemento continua static.

$ vnu --css style.css
"file:/home/ana/site/style.css":2.13-2.19: error: CSS: “position”: “absolut” is not a “position” value.

O que significa: "absolut não é um valor de position". Faltou o e: absolute. Os cinco valores são static, relative, absolute, fixed e sticky.

Missão final: o selo no canto do cartão

Missão: o selo "Novo!" deve ficar no canto de cima, à direita, do cartão. (1) Faça o cartão virar a referência; (2) tire o selo do fluxo com absolute; (3) cole-o no canto com top e right iguais a 0.

  padding: 12px;
  border: 2px solid tomato;
}

.selo {
  padding: 4px 8px;
  background-color: gold;
}

.cartao {

  width: 260px;

  position: absolute;
  top: 0;
  right: 0;

Tire o position: relative do cartão e veja o selo fugir para o canto do quadro inteiro: sem ancestral posicionado, a referência passa a ser a página.

Resumo

  • Sem position, todo elemento é static: fica no fluxo normal e ignora top, right, bottom e left.
  • relative: desloca a partir do próprio lugar, que continua guardado. Também serve de referência para filhos absolute.
  • absolute: sai do fluxo e conta a partir do ancestral posicionado mais próximo.
  • fixed: preso à janela. sticky: anda com a página e gruda.
  • top: 20px é "a 20px do topo", ou seja, empurra para baixo. inset é o atalho dos quatro.
  • Position é para detalhes; o layout da página é com Flexbox e Grid.
  • Erros: deslocamento num elemento static não faz nada (e o validador não avisa); número sem unidade (top: 10) e absolut são ignorados, e o validador avisa.
