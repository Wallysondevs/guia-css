CSS Unidades: px, em, rem e %

Todo tamanho no CSS é um número com uma unidade: 16px, 1.5em, 2rem, 50%. A unidade diz "16 de quê?". Algumas são fixas, outras dependem de outro tamanho, e é aí que mora a confusão: por que o mesmo 1.2em deu 19px num lugar e 27px no outro? Nesta aula você vai conhecer as quatro unidades mais usadas, fazer a conta de cada uma e conferir o resultado no valor calculado do navegador.

Você vai aprender
  • px: a medida fixa.
  • em: relativa à letra do próprio elemento (ou do pai, no font-size), e o efeito "bola de neve" nas listas.
  • rem: relativa à letra do <html>, igual em toda a página.
  • %: relativa a um tamanho do pai.
  • Por que fontes em rem respeitam quem aumenta a letra do navegador.
  • Qual unidade usar em cada propriedade.
  • Os erros comuns: número sem unidade e espaço antes da unidade, com as mensagens do validador W3C.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. Os valores calculados das tabelas foram conferidos no Chromium, com o tamanho de letra padrão do navegador (16px); as mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: centímetro, palmo e "metade da mesa"

Para dizer o tamanho de alguma coisa, você pode usar uma régua (10 centímetros, sempre iguais), o seu palmo ("dois palmos", que muda com o tamanho da mão de quem mede) ou uma fração de outra coisa ("metade da mesa", que muda com a mesa).

O navegador sempre termina a conta em pixels: na aba Computed (Calculado) do F12, 1.5em, 1.5rem e 150% aparecem como 24px. As metas das missões leem esse valor calculado.

1. px: a medida fixa

<style>
  h2 {
    font-size: 24px;
  }
  .caixa {
    width: 200px;
    border: 2px solid navy;
    padding: 8px;
  }
</style>
<h2>Receitas da Ana</h2>
<div class="caixa">Uma caixa de 200px de largura.</div>
24
O número.
px
A unidade: "pixel". No CSS, 1px não é exatamente um pontinho da tela: é uma medida padrão que o navegador ajusta para telas de alta definição (num celular moderno, 1px do CSS pode usar 3 ou 4 pontinhos de verdade). Para você, basta saber que 24px é sempre o mesmo tamanho, onde quer que esteja.

O px é fácil de entender e previsível. O defeito dele: não acompanha nada. Se o leitor aumentar a letra padrão do navegador porque enxerga pouco, um font-size em px não cresce (veja a seção 3).

2. em: o tamanho da letra

Um em é o tamanho da letra (font-size). De quem, depende da propriedade:

  • No font-size, é a letra do pai (a do próprio elemento ainda está sendo decidida).
  • Em qualquer outra propriedade (padding, margin, width…), é a letra do próprio elemento.
<style>
  .caixa {
    font-size: 20px;
  }
  .caixa p {
    font-size: 1.5em;
  }
</style>
<div class="caixa">
  <p>Pão de queijo</p>
</div>

A conta: o pai (.caixa) tem letra de 20px, então 1.5em = 20 × 1,5 = 30px. É o valor calculado do p.

O melhor uso: espaçamento que acompanha a letra

Um botão com padding em em fica proporcional em qualquer tamanho. Os três botões abaixo têm a mesma regra de padding; só a letra muda:

<style>
  .botao {
    display: inline-block;
    padding: 0.5em 1em;
    border: 2px solid navy;
    background-color: aliceblue;
  }
  .pequeno { font-size: 12px; }
  .medio { font-size: 16px; }
  .grande { font-size: 24px; }
</style>
<a class="botao pequeno" href="#">Comprar</a>
<a class="botao medio" href="#">Comprar</a>
<a class="botao grande" href="#">Comprar</a>

O cuidado: a bola de neve

Como o em do font-size parte do pai, elementos dentro de elementos iguais multiplicam de novo a cada nível. Uma lista com li { font-size: 1.2em; }, com sublistas:

    font-size: 1.2em;
  }
</style>

        </ul>
      </li>
    </ul>
  </li>
</ul>

Cada nível ficou 20% maior que o anterior. Às vezes é isso que você quer; quase sempre não é. A solução é a próxima unidade.

3. rem: a letra da raiz

O rem (root em, "em da raiz") é sempre o tamanho da letra do <html>, o elemento raiz da página. Não importa onde o elemento está: a conta é a mesma. A mesma lista, com rem:

<style>
  li {
    font-size: 1.2rem;
  }
</style>
<ul>
  <li>Doces
    <ul>
      <li>Bolos
        <ul>
          <li>Bolo de cenoura</li>
        </ul>
      </li>
    </ul>
  </li>
</ul>

A conta: 16 × 1,2 = 19.2px nos três níveis (o valor calculado dos três li, no Chromium). Sem bola de neve.

Por que o guia recomenda rem para a letra

O <html> começa com a letra padrão do navegador, normalmente 16px. Quem enxerga pouco pode aumentar esse padrão nas configurações do navegador (por exemplo, para 20px). Aí:

  • um título com font-size: 2rem vai de 32px para 40px: respeita a escolha do leitor;
  • um título com font-size: 32px continua com 32px: ignora a escolha.

Por isso: tamanho de letra em rem. E não ponha html { font-size: 10px; } "para facilitar a conta": isso também passa por cima do padrão que o leitor escolheu.

4. %: uma parte do pai

A porcentagem é sempre "tantos por cento de alguma coisa do pai". O quê, depende da propriedade:

Propriedade% de quêExemplo (pai com 400px de largura e letra de 16px)
widthDa largura do conteúdo do paiwidth: 50% → 400 × 50 ÷ 100 = 200px
font-sizeDa letra do pai (igual ao em)font-size: 150% → 16 × 1,5 = 24px
padding e marginDa largura do pai, até em cima e embaixopadding: 10% → 40px nos quatro lados
line-heightDa letra do próprio elemento150% → 24px (aula Espaçamento)
<style>
  .pai {
    width: 400px;
    border: 2px solid gray;
  }
  .filho {
    width: 50%;
    background-color: aliceblue;
  }
</style>
<div class="pai">
  <div class="filho">50% do pai: 200px</div>
</div>

A caixa azul ocupa a metade esquerda do pai. Se o pai mudar de largura, o filho muda junto: é por isso que % é a base de layouts que se adaptam à tela (aula O que é Design Responsivo). O padding em % calculado pela largura, mesmo em cima e embaixo, surpreende muita gente: no exemplo da tabela, padding: 10% dá 40px também no padding-top (conferido no Chromium).

Quando dá errado

Número sem unidade, e espaço antes da unidade 
<style>
  p {
    font-size: 30;
  }
  h2 {
    font-size: 3 rem;
  }
</style>
<h2>Receitas da Ana</h2>
<p>Bolo de cenoura</p>

O que o leitor vê: o título e o parágrafo com os tamanhos padrão do navegador, como se as regras não existissem. No Chromium, o valor calculado do p continua 16px, e o do h2, 24px (o padrão de um h2).

Por quê: 30 sozinho não diz "30 de quê", e só o 0 pode ficar sem unidade (zero é zero em qualquer unidade). E o número e a unidade são uma coisa só: com espaço, 3 rem vira dois valores, 3 e rem, e nenhum dos dois faz sentido. O navegador ignora as duas declarações; no F12, no painel Styles (Estilos), elas aparecem riscadas, com um ícone de aviso.

O que o validador diz:

$ cat style.css
p {
  font-size: 30;
}
h2 {
  font-size: 3 rem;
}
$ vnu --css style.css
"file:/home/ana/site/style.css":2.14-2.15: error: CSS: “font-size”: only “0” can be a “unit”. You must put a unit after your number.
"file:/home/ana/site/style.css":5.16-5.18: error: CSS: “font-size”: Too many values or values are not recognized.

"Só o 0 pode ficar sem unidade. Você precisa pôr uma unidade depois do número" e "valores demais, ou valores não reconhecidos".

Como consertar: font-size: 1.875rem; (ou 30px) e font-size: 3rem;, colado.

O em que virou bola de neve

A Ana escreveu .cartao { font-size: 1.25em; } e pôs um cartão dentro de outro. O de dentro ficou com a letra maior que o de fora: 16 × 1,25 = 20px no primeiro, 20 × 1,25 = 25px no segundo. O validador não reclama, porque tudo é válido. A pista está na aba Computed: o mesmo 1.25em, dois valores calculados diferentes.

Como consertar: font-size: 1.25rem;, que dá 20px nos dois.

O botão que não acompanhou o em

Num <button> de verdade, o em parece não obedecer o tamanho da página: um botão com padding: 0.5em 1em ficou com o padding de 6,67px em cima, e não 8px. É que o navegador dá aos botões e campos de formulário uma letra própria, menor (13,33px no Chromium), em vez de herdar a da página.

Como consertar: button { font-size: 1rem; } (ou font: inherit;), e o em volta a funcionar como esperado. Mais na aula Estilizando Botões.

Resumo

  • Todo número no CSS precisa de unidade, menos o 0. Número e unidade vão colados: 2rem, nunca 2 rem.
  • px é fixo. em é a letra do pai (no font-size) ou do próprio elemento (no resto). rem é a letra do <html>. % é uma parte de um tamanho do pai.
  • O navegador termina toda conta em pixels: é o que mostra a aba Computed e o que as metas conferem.
  • em no font-size faz bola de neve em elementos aninhados (19,2 → 23,04 → 27,648px); rem não.
  • Letra em rem (respeita o leitor), padding de botão em em, larguras em %, bordas em px.
  • Erros: only “0” can be a “unit” (faltou a unidade) e Too many values or values are not recognized (espaço antes da unidade).
