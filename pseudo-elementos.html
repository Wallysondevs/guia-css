CSS Pseudo-elementos

Algumas partes da página não têm tag nenhuma no HTML: a primeira letra de um parágrafo, a primeira linha, a bolinha de uma lista, o texto cinza de exemplo dentro de um campo, o pedaço de texto que o leitor selecionou com o mouse. Mesmo assim, o CSS consegue pintar cada uma delas, com os pseudo-elementos. Na aula anterior você viu os dois mais famosos, ::before e ::after, que criam conteúdo. Nesta aula ficam os outros: os que escolhem um pedaço que já existe.

Você vai aprender
  • O que é um pseudo-elemento e por que ele usa dois dois-pontos (::).
  • ::first-letter: a primeira letra, para fazer uma letra capitular de revista.
  • ::first-line: a primeira linha, que muda conforme a largura da caixa.
  • ::marker: a bolinha (ou o número) de cada item de lista.
  • ::placeholder: o texto de exemplo dentro de um campo de formulário.
  • ::selection: o texto que o leitor seleciona com o mouse.
  • ::file-selector-button: o botão "Escolher arquivo".
  • Quais propriedades cada um aceita, e os erros reais do validador W3C.

Os resultados são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: o marca-texto

Pense num livro impresso. Você não pode pôr uma etiqueta em cada letra, mas pode dizer a quem vai diagramar: "a primeira letra de cada capítulo fica grande e vermelha" ou "a primeira linha fica em versalete". Você não sabe que letra ou que palavras serão; a regra vale para o que estiver naquele lugar.

O pseudo-elemento é isso: um pedaço de um elemento que o navegador encontra sozinho. Não existe <primeira-letra> no HTML; quem decide qual é a primeira letra (ou onde a primeira linha acaba) é o navegador, na hora de desenhar.

TipoEscreve comEscolheExemplo

Pseudo-elementodois ::um pedaço do elemento (ou algo que o CSS cria)p::first-letter, li::marker

1. A primeira letra: ::first-letter

A letra capitular, aquela letra grande que abre um texto de revista, é o uso clássico:

Experimente: troque a cor, o tamanho e a fonte da primeira letra. Depois apague o float: left; e veja a letra grande empurrar a primeira linha para baixo.

<link rel="stylesheet" href="style.css">
<h1>Bolo de cenoura</h1>
<p class="abertura">Era domingo e a cozinha da Ana já cheirava a chocolate. O bolo de cenoura da avó tem só sete ingredientes, uma batedeira velha e quarenta minutos de forno.</p>

.abertura::first-letter {
  font-size: 3.5rem;
  font-weight: bold;
  color: tomato;
  float: left;
  line-height: 1;
  margin-right: 0.5rem;
}
.abertura
O elemento dono do pedaço: o parágrafo com a classe abertura.
::first-letter
O pedaço: a primeira letra (first letter) do texto. Os dois dois-pontos dizem "isto é um pseudo-elemento". Não há espaço entre .abertura e ::.
font-size: 3.5rem;
A letra fica três vezes e meia o tamanho da letra padrão da página (veja Unidades).
float: left;
A letra "flutua" à esquerda e o texto contorna, ocupando duas ou três linhas ao lado dela (o float tem aula própria, float: o Jeito Antigo; aqui é um dos poucos usos em que ele ainda é a ferramenta certa).
line-height: 1;
Tira a sobra de altura de cima e de baixo da letra grande, para ela encostar no texto.

Repare no resultado: o "E" de "Era" fica grande, em negrito e da cor tomato; o texto contorna a letra pela direita. Só o E mudou: o resto da palavra continua normal.

O que conta como "primeira letra"

  • Se o texto começa com uma pontuação, como as aspas de uma citação, o navegador leva a pontuação junto: em "Era…, o pedaço é "E.
  • Só funciona em elementos de bloco, como p, div, h1, li (veja display). Num span, que é em linha, nada acontece (veja Quando dá errado).
  • Aceita as propriedades de fonte, cor, fundo, margem, preenchimento (padding), borda, float e line-height. Uma propriedade fora da lista, como width, é ignorada.

Missão: na página de receitas da Ana, faça uma capitular em cada parágrafo de dentro de .receita: escreva a regra .receita p::first-letter com font-size: 2rem; e color: darkgreen;.

<link rel="stylesheet" href="style.css">
<div class="receita">
  <h2>Pão de queijo</h2>
  <p>Ferva o leite, a água e o óleo e despeje sobre o polvilho.</p>
  <p>Quando amornar, junte os ovos e o queijo e sove bem.</p>
</div>

.receita p {
  line-height: 1.5;
}

.receita p {
  line-height: 1.5;
}

.receita p::first-letter {
  font-size: 2rem;
  color: darkgreen;
}

2. A primeira linha: ::first-line

::first-line pinta a primeira linha como ela aparece na tela, e não a primeira frase. Onde a linha quebra depende da largura da caixa: numa caixa estreita, a primeira linha tem poucas palavras; numa larga, muitas. Os dois parágrafos abaixo têm o mesmo texto e a mesma regra, só a largura muda:

Experimente: mude o width do .estreito para 320px e veja mais palavras entrarem na primeira linha.

<link rel="stylesheet" href="style.css">
<p class="estreito">Na lojinha da Ana, todo sábado tem pão de queijo saindo do forno às oito.</p>
<p class="largo">Na lojinha da Ana, todo sábado tem pão de queijo saindo do forno às oito.</p>

p::first-line {
  font-weight: bold;
  color: navy;
  text-transform: uppercase;
}

.estreito {
  width: 180px;
}

.largo {
  width: 420px;
}

Repare: no parágrafo estreito, só "NA LOJINHA DA ANA," ficou em maiúsculas azuis e em negrito (pode variar uma palavra, conforme a fonte do seu computador); no largo, a primeira linha vai até "PÃO DE". O resto do texto continua normal. O navegador refaz a conta sempre que a largura muda, por exemplo quando o leitor gira o celular.

::first-line aceita menos propriedades que ::first-letter: fonte, cor, fundo, text-transform, letter-spacing, word-spacing, text-decoration e line-height. Nada de margem, borda ou float: a linha não é uma caixa.

3. A bolinha da lista: ::marker

Cada <li> tem um marcador: a bolinha de <ul> ou o número de <ol>. O ::marker pinta só ele, sem mexer no texto do item:

Experimente: troque as cores e o tamanho. Na aba index.html, troque ul por ol (nas duas tags) e veja os números ganharem o mesmo estilo.

<link rel="stylesheet" href="style.css">
<h2>Ingredientes</h2>
<ul>
  <li>3 cenouras</li>
  <li>4 ovos</li>
  <li>2 xícaras de açúcar</li>
</ul>

li::marker {
  color: tomato;
  font-size: 1.5rem;
}

Antes do ::marker, para ter uma bolinha de outra cor, era preciso esconder a bolinha (list-style: none) e desenhar outra com ::before. Hoje, para mudar só a cor e o tamanho, o ::marker resolve em duas linhas. O resto das listas (o tipo de marcador, a posição, imagem no lugar da bolinha) está em Estilizando Listas.

Trocar o símbolo: content

O ::marker também aceita content, que troca a bolinha por um texto qualquer:

Experimente: troque o "✔ " por outro símbolo. Repare no espaço dentro das aspas: sem ele, o símbolo encosta no texto.

<link rel="stylesheet" href="style.css">
<h2>Já comprei</h2>
<ul class="feito">
  <li>Cenouras</li>
  <li>Ovos</li>
</ul>

.feito li::marker {
  content: "✔ ";
  color: green;
}
Suporte do ::marker

Chrome e Edge (desde a versão 86) e Firefox (68) aceitam tudo o que está nesta aula. O Safari aceita o ::marker há anos, mas só com color e font-size (dados do MDN, outubro de 2026): no iPhone, o content: "✔ " acima é ignorado e a bolinha normal continua. Se o símbolo é importante, use o jeito de Estilizando Listas (list-style-type: "✔ "), que funciona nos três.

O ::marker aceita poucas propriedades: color, as de fonte (font-size, font-weight…), content e as de animação. background-color, padding e margin são ignorados em silêncio (veja Quando dá errado).

4. O texto de exemplo dos campos: ::placeholder

O atributo placeholder do HTML mostra um texto de exemplo dentro do campo vazio, que some quando o leitor começa a digitar (no Guia HTML: formulários). O ::placeholder estiliza esse texto:

Experimente: digite no segundo campo: o texto de exemplo some, e o que você digita tem a cor normal. O ::placeholder só vale para o texto de exemplo.

<link rel="stylesheet" href="style.css">
<p><label>Sem estilo <input type="email" placeholder="ana@exemplo.com"></label></p>
<p><label>Com estilo <input class="contato" type="email" placeholder="ana@exemplo.com"></label></p>

.contato::placeholder {
  color: #6b6b6b;
  font-style: italic;
}
Contraste e o placeholder

A tentação é deixar o texto de exemplo bem clarinho. Mas um cinza fraco sobre branco fica ilegível para muita gente. A regra de acessibilidade (WCAG) pede contraste de pelo menos 4,5 para 1 no texto: #6b6b6b sobre branco dá cerca de 5,3 para 1 e passa; #bbbbbb dá menos de 2 para 1 e não passa. E o placeholder não substitui o <label>: ele some quando o leitor digita, e aí ninguém lembra o que o campo pedia.

5. O texto selecionado: ::selection

Quando o leitor arrasta o mouse sobre um texto, o navegador pinta a seleção de azul (a cor exata depende do sistema). O ::selection troca essa cor:

Experimente: selecione com o mouse um pedaço dos dois parágrafos. O de cima usa a cor do sistema; o de baixo, a da Ana.

<link rel="stylesheet" href="style.css">
<p>Parágrafo comum: selecione este texto.</p>
<p class="marca">Parágrafo da Ana: selecione este também.</p>

.marca::selection {
  background-color: gold;
  color: black;
}
  • Sem nada na frente (::selection { … }), a regra vale para a página toda.
  • Aceita, na prática, color e background-color (e text-shadow). Margem, borda e tamanho de letra são ignorados: a seleção não pode mudar o desenho do texto.
  • Escolha cores com bom contraste entre si: o leitor precisa continuar lendo o que selecionou.

6. O botão do campo de arquivo: ::file-selector-button

O <input type="file"> desenha um botão ("Escolher arquivo", "Procurar…", o texto muda com o navegador e o idioma) e o nome do arquivo ao lado. Não há tag para o botão, mas há pseudo-elemento:

Experimente: mude a cor de fundo do botão. O texto do botão não muda: quem escreve é o navegador.

<link rel="stylesheet" href="style.css">
<p><label>Foto do bolo: <input type="file" accept="image/*"></label></p>

input::file-selector-button {
  background-color: navy;
  color: white;
  border: none;
  border-radius: 6px;
  padding: 0.5rem 1rem;
  cursor: pointer;
}

Diferente dos outros desta aula, este pseudo-elemento é quase uma caixa normal: aceita fundo, borda, cantos arredondados, preenchimento. Funciona em todos os navegadores atuais (Chrome e Edge 89, Firefox 82, Safari 14.1).

7. Um : ou dois ::?

No CSS antigo (CSS2, de 1998), os quatro primeiros pseudo-elementos eram escritos com um dois-pontos: :first-letter, :first-line, :before e :after. Depois, o CSS3 criou o :: para separar pseudo-elementos de pseudo-classes. Os navegadores continuam aceitando o jeito antigo só para esses quatro, para não quebrar sites velhos.

EscritaFunciona?Qual usar
p::first-letterSimEsta. O :: deixa claro que é um pedaço.
p:first-letterSim (só por compatibilidade)Só para reconhecer em código antigo.
input::placeholderSimEsta.
input:placeholderNão: a regra inteira é ignoradaNunca. Os pseudo-elementos novos só existem com ::.

Regra simples: sempre :: para pseudo-elementos. Assim você nunca precisa lembrar quais são os quatro antigos.

No F12

No painel de estilos (aba Elements/Elementos), as regras de pseudo-elementos aparecem em blocos separados, com o nome do pseudo-elemento no título do bloco (no Chrome, "Pseudo ::first-letter element" ou parecido; o texto muda de navegador para navegador). O ::marker e o ::placeholder aparecem como "filhos" na árvore de elementos, em cinza.

Quando dá errado

Um dois-pontos só: Unknown pseudo-element or pseudo-class “:placeholder”

Erro de propósito: o texto de exemplo deveria ficar verde e não fica. Ponha o segundo : e veja a cor aparecer.

<link rel="stylesheet" href="style.css">
<input type="text" placeholder="Seu nome">

input:placeholder {
  color: green;
}

O que você vê: o texto de exemplo continua com a cor padrão do navegador, cinza. Nenhuma mensagem aparece na página.

Por quê: :placeholder, com um dois-pontos, seria uma pseudo-classe, e ela não existe. Quando o navegador não entende o seletor, ele joga fora a regra inteira, com todas as declarações dentro das chaves. No F12, a regra nem aparece no painel de estilos do input. O validador avisa:

$ vnu --css dois-pontos.css
"file:/home/ana/site/dois-pontos.css":1.7-1.17: error: CSS: Unknown pseudo-element or pseudo-class “:placeholder”

O que significa: "pseudo-elemento ou pseudo-classe desconhecido: :placeholder", na linha 1, colunas 7 a 17. O mesmo erro aparece com uma letra errada: p::first-leter dá Unknown pseudo-element or pseudo-class “::first-leter”.

Como consertar: input::placeholder, com dois ::.

::first-letter num span: nada muda, e o validador não avisa 
<style>
  span::first-letter {
    color: tomato;
    font-size: 2rem;
  }
</style>
<p><span>Bolo de fubá</span> com erva-doce.</p>

O que você vê: o "B" de "Bolo" continua do tamanho e da cor do resto do texto.

Por quê: o ::first-letter só existe em elementos de bloco (ou inline-block, list-item, células de tabela). O span é em linha, então não tem "primeira letra" para o CSS. O seletor é válido, por isso o validador fica quieto.

Como consertar: ponha a regra no bloco (p::first-letter), ou transforme o span em display: inline-block.

Propriedade que o pseudo-elemento não aceita: ignorada em silêncio 
<style>
  li::marker {
    background-color: yellow;
    color: tomato;
  }
</style>
<ul>
  <li>Cenouras</li>
  <li>Ovos</li>
</ul>

O que você vê: as bolinhas ficam cor de tomate, mas sem fundo amarelo. A cor funcionou; o fundo, não.

Por quê: cada pseudo-elemento tem uma lista curta de propriedades permitidas, e background-color não está na lista do ::marker. O navegador ignora só essa declaração; a regra continua valendo. O validador não reclama (vnu --css não mostra nada para este arquivo): para ele, o seletor e a declaração estão bem escritos.

Como consertar: confira a tabela de Referência abaixo. Para uma bolinha com fundo, esconda o marcador (list-style: none) e desenhe outro com ::before, que aceita tudo.

Espaço antes dos ::

O que acontece: p ::first-letter, com espaço, quer dizer "a primeira letra de qualquer elemento dentro de um p" (o espaço é o combinador descendente, de Combinadores). Num <p> só com texto, não há elemento dentro, e nada muda. O validador não reclama: o seletor é válido.

Como consertar: cole o pseudo-elemento no seletor: p::first-letter.

Resumo

  • Um pseudo-elemento escolhe um pedaço de um elemento que não tem tag própria. Escreve-se com ::, colado no seletor: p::first-letter.
  • ::first-letter: a primeira letra de um bloco (capitular, com float: left). ::first-line: a primeira linha como aparece na tela, que muda com a largura.
  • ::marker: a bolinha ou o número da lista (color e font-size funcionam em todos; content não funciona no Safari).
  • ::placeholder: o texto de exemplo dos campos (contraste de 4,5 para 1; não substitui o label). ::selection: a cor do texto selecionado. ::file-selector-button: o botão do campo de arquivo.
  • Cada pseudo-elemento aceita uma lista curta de propriedades; o resto é ignorado em silêncio, sem aviso do validador.
  • Um dois-pontos só (input:placeholder) ou um nome errado derruba a regra inteira; o validador avisa: Unknown pseudo-element or pseudo-class.
