CSS z-index

Com position, os elementos podem ficar um em cima do outro: um selo sobre a foto, uma barra fixa sobre o texto, um menu que se abre sobre o banner. Quando dois se sobrepõem, alguém tem de ficar por cima. Quem decide é o navegador, com uma regra simples, e você pode mudar a decisão com a propriedade z-index ("índice z", a ordem das camadas). Nesta aula você vai empilhar cartões, trazer um para a frente, mandar outro para trás e entender a armadilha mais famosa do CSS: o z-index: 9999 que não funciona.

Você vai aprender
  • A ordem natural das camadas: quem vem depois no HTML fica por cima.
  • Como o z-index muda essa ordem, com números maiores na frente.
  • Por que o z-index não faz nada num elemento sem position.
  • O que um z-index negativo faz.
  • O contexto de empilhamento: por que um número enorme às vezes não traz o elemento para a frente.
  • As mensagens reais do validador.

Os resultados são desenhados pelo seu navegador. Esta aula usa position: relative e position: absolute para sobrepor os elementos; se precisar, reveja position: relative e position: absolute.

A ideia: folhas de papel na mesa

Espalhe três folhas de papel na mesa, uma por cima da outra. A última que você pôs fica por cima de todas. Se quiser outra folha na frente, você a puxa para o topo da pilha.

A tela do computador tem largura (o eixo x, da esquerda para a direita) e altura (o eixo y, de cima para baixo). O z-index trabalha num terceiro eixo, o z, que sai da tela em direção aos seus olhos. Um número maior é uma folha mais perto de você.

Experimente: o cartão C, o último no HTML, está por cima de todos, e o A, o primeiro, por baixo. Mude a ordem das linhas no index.html (ponha o A por último) e veja o A passar para a frente.

.c { top: 80px; left: 120px; background-color: navy; }
z-index
A propriedade da camada. O nome vem do eixo z, o que sai da tela.
1
Um número inteiro: 1, 10, -1. Não tem unidade (nada de px) e não pode ter vírgula. Quanto maior, mais perto de você.
auto
O valor padrão: "sem camada própria". O elemento fica na ordem natural, como se fosse z-index: 0 na hora de comparar.

As regras de comparação, entre irmãos posicionados:

SituaçãoQuem fica por cima
Números diferentesO de z-index maior
Números iguais (ou os dois sem z-index)O que vem depois no HTML
z-index: 1 contra sem z-indexO de z-index: 1: qualquer número positivo vence o auto

3. Só vale em elemento posicionado

O z-index só funciona em elementos com position relative, absolute, fixed ou sticky. Num elemento com a posição normal (static), ele é ignorado, sem nenhum aviso. A exceção são os itens de um Flexbox ou de um Grid (aulas Introdução ao Flexbox e Introdução ao Grid), que aceitam z-index mesmo sem position.

Experimente: o selo tem z-index: 10, mas está escondido atrás da foto (só aparecem as beiradas que sobram, em cima e à esquerda). Ponha position: relative; no .selo e veja-o passar para a frente.

<link rel="stylesheet" href="style.css">
<p class="selo">Novo!</p>
<img class="foto" src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura com cobertura de chocolate" width="240" height="180">

.selo {
  z-index: 10;
  width: 60px;
  margin: 0;
  padding: 6px;
  background-color: gold;
  font-weight: bold;
}

.foto {
  position: relative;
  top: -20px;
  left: 20px;
}

Conferimos no Chromium: o valor calculado do z-index do selo continua sendo 10. O navegador aceita a declaração (ela é válida), só não tem o que fazer com ela num elemento static. Por isso o F12 não risca a linha, como faria com um erro de digitação. Alguns navegadores (o Firefox, por exemplo) mostram ao lado dela uma dica de que a propriedade não tem efeito ali.

4. O contexto de empilhamento: as pastas

Agora a armadilha. A Ana tem uma barra de topo com um menu que se abre para baixo, e logo depois um banner. O menu fica atrás do banner, e nem z-index: 9999 resolve:

Experimente: o menu (fundo branco, com borda) está cortado pelo banner laranja, apesar do z-index: 9999. Mude o z-index do .topo de 1 para 3 e veja o menu inteiro aparecer.

<link rel="stylesheet" href="style.css">
<header class="topo">
  Receitas da Ana
  <ul class="menu">
    <li>Bolos</li>
    <li>Doces</li>
    <li>Salgados</li>
  </ul>
</header>
<div class="banner">Semana do bolo: 20% de desconto</div>

.topo {
  position: relative;
  z-index: 1;
  background-color: navy;
  color: white;
  padding: 12px;
}

.menu {
  position: absolute;
  z-index: 9999;
  top: 30px;
  left: 12px;
  margin: 0;
  padding: 8px 24px;
  background-color: white;
  color: black;
  border: 1px solid gray;
}

.banner {
  position: relative;
  z-index: 2;
  height: 120px;
  padding: 12px;
  background-color: darkorange;
}

Por que o 9999 perde para o 2? Volte às folhas na mesa, agora com pastas:

  • Um elemento posicionado com um z-index (qualquer número, até 0) vira uma pasta: um contexto de empilhamento. Tudo o que está dentro dele é empilhado dentro da pasta.
  • O .topo (z-index: 1) é uma pasta; o .banner (z-index: 2) é outra pasta, por cima dela.
  • O menu está dentro da pasta do .topo. O 9999 dele só vale lá dentro: ele fica na frente do texto do .topo, mas a pasta inteira continua embaixo da pasta do banner. Uma folha não sai da pasta, por maior que seja o número.
Elementoz-indexComparado com quem
.topo1Com o .banner (os dois estão no body): perde para o 2
.menu (dentro do .topo)9999Só com o que está dentro do .topo
.banner2Com o .topo: vence o 1, e cobre tudo o que está dentro dele

Como resolver: compare as pastas, e não as folhas. Dê ao pai do menu (o .topo) um z-index maior que o do banner, ou tire o z-index do .topo (sem ele, o .topo deixa de ser pasta e o 9999 do menu passa a ser comparado direto com o 2 do banner).

O que mais cria uma pasta

Não é só o z-index. Algumas propriedades, mesmo sem position, também criam um contexto de empilhamento, e por isso aparecem em tantas perguntas de "meu z-index não funciona":

PropriedadeCria uma pasta quando
position + z-indexrelative/absolute com um z-index que não seja auto
position: fixed ou stickySempre, mesmo sem z-index
opacityMenor que 1 (aula Transparência)
transform, filterQualquer valor diferente de none
Item de Flexbox ou GridCom um z-index que não seja auto
isolation: isolateSempre: serve justamente para criar uma pasta de propósito

5. z-index negativo: para trás

Um número negativo manda o elemento para trás dos elementos normais (não posicionados) do mesmo contexto. Serve, por exemplo, para uma forma decorativa atrás de um título:

Experimente: o círculo amarelo fica atrás do texto do título, apesar de vir depois dele no HTML. Troque -1 por 1: o círculo cobre as letras. Depois volte para -1 e troque a linha isolation: isolate; por background-color: wheat;: sem a pasta, o círculo vai para trás do fundo do título e quase some.

<link rel="stylesheet" href="style.css">
<h1 class="titulo">Receitas da Ana <span class="bola"></span></h1>

.titulo {
  position: relative;
  isolation: isolate;
  padding: 24px;
}

.bola {
  position: absolute;
  z-index: -1;
  top: 8px;
  left: 8px;
  width: 80px;
  height: 80px;
  border-radius: 50%;
  background-color: gold;
}
z-index: -1;
Põe o círculo atrás do conteúdo normal da pasta em que ele está: o texto do título.
isolation: isolate;
Faz do título uma pasta. Sem isso, o -1 mandaria o círculo para trás de tudo, até do fundo de um pai com cor de fundo, e ele poderia sumir. Com a pasta, o círculo vai para trás só do texto do título.

Boas práticas: uma escala de camadas

Num site de verdade, os números se acumulam: alguém põe z-index: 100, outra pessoa precisa passar por cima e põe 999, depois 9999… Em vez dessa corrida, combine poucos degraus e use sempre os mesmos:

Camadaz-index
Conteúdo normal, selos sobre fotos1
Menus que se abrem10
Barra de topo fixa ou grudada100
Janela de aviso por cima de tudo1000

Com as variáveis do CSS (aula Variáveis), dá para dar nomes a esses degraus. E, quando um número enorme "não funciona", o problema quase nunca é o número: é uma pasta (seção 4).

Quando dá errado

z-index sem position: nada muda 
.selo {
  z-index: 10;
}

O que o leitor vê: o selo continua atrás da foto (seção 3). O validador não reclama: o código é válido.

Por quê: num elemento static, o z-index não tem efeito.

Como consertar: position: relative; no mesmo elemento (ele continua no mesmo lugar, mas passa a aceitar o z-index).

z-index: 9999 e o elemento continua atrás

O que o leitor vê: o menu cortado pelo banner (seção 4).

Por quê: um ancestral do elemento é uma pasta (tem position + z-index, opacity menor que 1, transform, filter…), e essa pasta inteira está abaixo da outra.

Como achar: no F12, suba pelos ancestrais do elemento procurando essas propriedades. O primeiro que tiver uma delas é a pasta; compare o z-index dela com o do elemento que cobre.

Como consertar: aumente o z-index do ancestral (a pasta), ou tire dele o que cria a pasta.

Número com vírgula: This number should be an integer 
.selo {
  position: relative;
  z-index: 1.5;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":3.12-3.14: error: CSS: “z-index”: This number should be an integer.

O que significa: "este número deveria ser um inteiro". O navegador ignora a declaração e o elemento fica com auto, na ordem natural.

Como consertar: use inteiros: z-index: 2;.

Com unidade: “10px” is not a “z-index” value 
.selo {
  position: relative;
  z-index: 10px;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":3.12-3.15: error: CSS: “z-index”: “10px” is not a “z-index” value.

O que significa: "10px não é um valor de z-index". O z-index é uma posição na pilha, e não uma medida: não leva px. A declaração é ignorada.

Como consertar: z-index: 10;.

Resumo

  • Quando elementos se sobrepõem, a ordem natural é: os posicionados por cima dos normais, e, entre eles, quem vem depois no HTML fica por cima.
  • z-index muda essa ordem: inteiro, sem unidade, maior = mais à frente. O padrão é auto.
  • Só vale em elemento posicionado (relative, absolute, fixed, sticky) ou em item de Flexbox/Grid. Num static, é ignorado sem aviso.
  • Negativo manda para trás do conteúdo normal; com isolation: isolate no pai, só para trás do pai.
  • Contexto de empilhamento = pasta: os filhos só disputam lugar dentro dela. Um 9999 não sai de uma pasta que está embaixo; compare o z-index dos pais.
  • Validador: This number should be an integer para 1.5. Use uma escala de poucos degraus em vez de uma corrida de números.
