CSS Grid

O Grid desenha uma grade de linhas e colunas e deixa você pôr cada item na célula que quiser, ou espalhar um item por várias células. É o jeito de montar o esqueleto de uma página (cabeçalho, menu, conteúdo, rodapé) e galerias. Esta página junta todas as propriedades, valores e funções do Grid, com os valores calculados medidos no Chromium e a aula de cada assunto.

Como usar esta página
  • Como no Flexbox, há as propriedades do contêiner (o pai, com display: grid) e as dos itens (os filhos diretos).
  • O Grid conta linhas (as divisórias), não células: uma grade de 3 colunas tem 4 linhas verticais, numeradas de 1 a 4 (e de -1 a -4, de trás para a frente).
  • Para aprender do começo, vá à aula Introdução ao Grid. Flexbox ou Grid? Veja a comparação.

A ideia em uma tela

Pense numa forma de gelo, ou na vitrine de doces da padaria, com divisórias. Você decide quantas colunas e linhas a forma tem e de que tamanho. Cada doce vai numa casinha; um bolo grande pode ocupar duas casinhas. As divisórias são as linhas do Grid; cada fileira ou coluna de casinhas é uma trilha (track).

<style>
  .grade {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 6px;
  }
  .grade div {
    padding: 0.5rem;
    background-color: lightsteelblue;
    font-family: monospace;
  }
  .grade .bolo {
    grid-column: 1 / 3;
    background-color: royalblue;
    color: white;
  }
  .grade .torta {
    grid-row: span 2;
    background-color: navy;
    color: white;
  }
</style>
<div class="grade">
  <div class="bolo">bolo: grid-column: 1 / 3</div>
  <div class="torta">torta: grid-row: span 2</div>
  <div>sonho</div>
  <div>broa</div>
  <div>pão</div>
</div>

O bolo vai da linha vertical 1 à 3 (duas colunas); a torta ocupa duas linhas de altura; os outros entram sozinhos nas casinhas livres, na ordem do HTML.

auto-fill × auto-fit ao vivo

<style>
  .g { display: grid; gap: 4px; margin-bottom: 0.5rem; padding: 4px; border: 1px dashed gray; }
  .fill { grid-template-columns: repeat(auto-fill, minmax(6rem, 1fr)); }
  .fit  { grid-template-columns: repeat(auto-fit, minmax(6rem, 1fr)); }
  .g div { padding: 0.5rem; background-color: lightsteelblue; }
  p { margin: 0.5rem 0 0.25rem; font: bold 0.9rem monospace; }
</style>
<p>auto-fill: as colunas vazias continuam lá</p>
<div class="g fill"><div>pão</div><div>bolo</div></div>
<p>auto-fit: as colunas vazias somem e os itens esticam</p>
<div class="g fit"><div>pão</div><div>bolo</div></div>

Com muitos itens (mais do que cabem numa linha), os dois ficam iguais. A diferença só aparece quando sobra lugar, e numa tela estreita (menos de quatro colunas de 6rem) pode nem aparecer.

Áreas com nome (grid-template-areas)

.pagina {
  display: grid;
  grid-template-columns: 12rem 1fr;
  grid-template-areas:
    "topo   topo"
    "menu   conteudo"
    "rodape rodape";
}
.pagina header { grid-area: topo; }
"topo topo"
Uma linha da grade, com um nome por coluna. Repetir o nome (topo topo) faz a área ocupar as duas colunas.
"menu conteudo"
Todas as linhas precisam ter o mesmo número de colunas, e cada área tem de formar um retângulo.
.
Um ponto ("topo .") é uma casinha vazia, sem nome.
grid-area: topo
No item: "vá para a área topo". O nome vai sem aspas aqui. Medido: grid-area: topo → grid-row-start e grid-column-start calculados como topo.

Quando dá errado

As áreas que não formam um retângulo (e o validador não avisa) 
.pagina {
  display: grid;
  grid-template-areas:
    "topo topo"
    "menu";
}

O que a Ana vê (os quatro itens têm grid-area: topo, menu, conteudo e rodape): o layout desmonta de um jeito estranho. No Chromium, os quatro itens foram parar na mesma casinha, um em cima do outro, e só o último (o rodapé) aparece; o cabeçalho, o menu e o conteúdo ficaram escondidos embaixo dele.

Por quê: a segunda linha tem uma coluna e a primeira, duas. Todas as linhas precisam ter o mesmo número de nomes, e cada área tem de ser um retângulo ("a b a" também é inválido). O navegador descarta a declaração inteira: medido, o grid-template-areas calculado ficou none. Sem as áreas, os nomes topo, menu… não apontam para lugar nenhum, e o navegador cria linhas extras com esses nomes, todas no mesmo ponto: os itens se empilham ali.

O validador W3C (vnu 26.10.12) não deu nenhuma mensagem para esse arquivo. Aqui, quem mostra o problema é o F12: no painel Styles, a declaração aparece riscada, com o ícone de aviso. O Chrome também tem uma camada de "grid" que desenha as linhas e os nomes das áreas sobre a página: clique no selo grid ao lado do elemento, na aba Elements.

Como resolver: complete a linha ("menu conteudo") ou use um ponto para a casinha vazia ("menu .").

Em todos os casos, o navegador ignora a declaração: sem colunas definidas, a grade fica com uma coluna só. Medido: com repeat(3 1fr), o grid-template-columns calculado ficou none.

Outras armadilhas
  • Neto não é item: só os filhos diretos do contêiner se encaixam na grade. Um <ul> dentro do grid é um item; os <li> dele, não (a não ser com subgrid).
  • Aspas no grid-area: nos itens, o nome vai sem aspas (grid-area: topo); as aspas são só no grid-template-areas.
  • 1fr que estoura: uma coluna 1fr não fica menor que o conteúdo (uma imagem larga, uma palavra enorme). Use minmax(0, 1fr).
  • auto-fit sem minmax(): repeat(auto-fit, 1fr) é inválido; o navegador precisa de um tamanho mínimo para saber quantas colunas cabem.

Missão

Missão: transforme a vitrine numa grade de 3 colunas iguais (use repeat() e fr) e faça o bolo em destaque ocupar duas colunas com span.

  <div>Sonho</div>

}

  font-weight: bold;

Resumo

  • Contêiner: display: grid, grid-template-columns, grid-template-rows, grid-template-areas, gap, grid-auto-rows, grid-auto-flow.
  • Trilhas: fr (fração do que sobra), repeat(), minmax(), auto-fill (mantém colunas vazias) × auto-fit (as vazias somem).
  • Itens: grid-column e grid-row (linha-início / linha-fim, span N, 1 / -1), grid-area.
  • Alinhar: -items no pai, -self no item, -content a grade toda; justify na horizontal, align na vertical.
  • Áreas: mesmo número de colunas em cada linha e áreas retangulares. O vnu não avisa: confira no F12.
  • Trilhas separadas por espaço; posições separadas por /; repeat(3, 1fr) com vírgula.
