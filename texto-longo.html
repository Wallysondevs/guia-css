CSS Texto que Não Cabe

O navegador quebra as linhas nos espaços, e quase sempre isso basta. Mas um endereço de site comprido, um e-mail ou uma palavra enorme não têm espaço no meio, e saem pela borda da caixa, atropelando o resto da página. No outro extremo, às vezes você quer uma linha só, cortada com "…" quando não couber. Nesta aula você vai resolver os dois casos: quebrar o que é comprido demais (overflow-wrap) e cortar com reticências (text-overflow).

Você vai aprender
  • Por que uma palavra sem espaços vaza da caixa.
  • overflow-wrap: break-word e anywhere: quebrar só quando precisa.
  • word-break: break-all e hyphens: auto, e quando usar cada um.
  • white-space: nowrap: proibir a quebra de linha.
  • As reticências do text-overflow: ellipsis, e as três regras que ele precisa.
  • Cortar um resumo em duas linhas com -webkit-line-clamp.
  • Os erros comuns: overflow-wrap: break-all, text-overflow sozinho (com as mensagens do validador W3C).

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. Os valores calculados foram conferidos no Chromium; as mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a fita métrica na gaveta

Você guarda objetos numa gaveta estreita. Os pequenos cabem, um ao lado do outro, e quando a fileira enche você começa outra fileira. Mas uma fita métrica esticada, mais comprida que a gaveta, não cabe de jeito nenhum: ou ela fica para fora, ou você a dobra. Outra opção é cortar o que sobra e deixar um aviso de que tem mais.

No CSS, a gaveta é a caixa, as fileiras são as linhas e a fita é uma palavra sem espaços. overflow-wrap dobra a fita; text-overflow corta e põe o aviso "…".

1. O problema: a palavra que vaza

<style>
  .cartao {
    width: 160px;
    border: 2px solid navy;
    padding: 4px;
    background-color: aliceblue;
  }
</style>
<div class="cartao">Site: https://receitasdaana.example/bolo-de-cenoura-com-cobertura</div>

O endereço saiu pela borda direita do cartão. O navegador só quebra a linha em lugares "permitidos": espaços e alguns sinais, como o hífen. No Chromium, ele quebrou depois de "bolo-" e de "com-", mas o pedaço https://receitasdaana.example/bolo- não tem nenhum lugar permitido e é mais largo que o cartão. Por padrão, o navegador prefere deixar vazar a cortar uma palavra.

2. overflow-wrap: quebre só quando precisar

<style>
  .cartao {
    width: 160px;
    border: 2px solid navy;
    padding: 4px;
    background-color: aliceblue;
    overflow-wrap: break-word;
  }
</style>
<div class="cartao">Site: https://receitasdaana.example/bolo-de-cenoura-com-cobertura</div>
overflow-wrap
A propriedade: "quebra quando transborda". Ela diz o que fazer com uma palavra que não cabe sozinha numa linha.
break-word
O valor: "quebre a palavra". O navegador primeiro tenta os lugares normais; só quando um pedaço ainda não cabe, ele o corta onde for preciso, no fim da linha.

Agora o endereço ficou dentro do cartão, cortado em "receitasdaana.exa" / "mple/…". As palavras normais da frase continuam inteiras: só o que não cabia foi quebrado. O valor inicial é normal (deixa vazar).

Valor de overflow-wrapO que faz
normalNunca corta uma palavra; ela vaza (o valor inicial)
break-wordCorta só a palavra que não cabe numa linha inteira
anywhereIgual na caixa comum. A diferença aparece quando a caixa pode encolher até o tamanho do conteúdo (células de tabela, itens do Flexbox): com anywhere, ela pode encolher cortando as palavras; com break-word, a palavra mais longa decide a largura mínima
Uma regra para o site todo

Muita gente põe body { overflow-wrap: break-word; } no começo do CSS. Como a propriedade é herdada, todo texto do site fica protegido contra endereços e e-mails compridos, e as palavras normais não mudam.

Missão: o e-mail da lojinha vaza do cartão. Faça a .contato quebrar só o que não cabe, com overflow-wrap.

<link rel="stylesheet" href="style.css">
<div class="contato">
  <h2>Fale com a Ana</h2>
  <p>encomendas.bolos.da.ana@lojinha-da-ana.example</p>
</div>

.contato {
  width: 180px;
  border: 2px solid tomato;
  padding: 8px;
}

.contato {
  width: 180px;
  border: 2px solid tomato;
  padding: 8px;
  overflow-wrap: break-word;
}

3. Outros jeitos de quebrar: word-break e hyphens

word-break: break-all: corta em qualquer letra

O word-break ("quebra de palavra") com break-all não espera a palavra não caber: ele corta qualquer palavra onde a linha acabar, para encher cada linha até o fim.

<style>
  .cartao {
    width: 160px;
    border: 2px solid navy;
    padding: 4px;
    background-color: aliceblue;
    word-break: break-all;
  }
</style>
<div class="cartao">Bolo de cenoura com cobertura de chocolate</div>

Repare: "cobertura" virou "co" / "bertura", embora coubesse inteira na linha de baixo. Para texto em português, isso atrapalha a leitura. O break-all serve para trechos que não são palavras, como um código ou um número de pedido muito longo.

hyphens: auto: quebra com hífen, nas sílabas

O hyphens: auto pede ao navegador para dividir palavras longas nas sílabas, com hífen, como num livro. Ele precisa saber a língua do texto: o lang="pt-BR" da página (ou do elemento) é obrigatório.

<style>
  .cartao {
    width: 160px;
    border: 2px solid navy;
    padding: 4px;
    background-color: aliceblue;
    hyphens: auto;
  }
</style>
<div class="cartao" lang="pt-BR">Pneumoultramicroscopicossilicovulcanoconiótico é uma palavra extraordinariamente comprida</div>
O hífen depende do navegador

Pelos dados do MDN, Chrome (desde a versão 87), Firefox e Safari sabem hifenizar português. Mas a divisão usa um dicionário de sílabas do navegador, e nem toda instalação o tem: no Chromium do laboratório do guia, sem esse dicionário, o exemplo acima não ganhou hífen nenhum, e a palavra gigante vazou do cartão. Se o seu navegador tiver o dicionário, você vê a palavra dividida com hífens. Por isso, não conte só com o hyphens: junte-o com overflow-wrap: break-word, que funciona sempre.

SituaçãoQual usar
Endereços, e-mails, palavras gigantes no meio do textooverflow-wrap: break-word (de preferência no body)
Células de tabela ou itens de Flexbox que não encolhemoverflow-wrap: anywhere
Código, número de pedido, sequência sem sentidoword-break: break-all
Colunas estreitas de texto corrido, com cara de livrohyphens: auto + lang, com overflow-wrap de reserva

4. O contrário: uma linha só, com reticências

Num cartão de produto, a Ana quer o nome numa linha só, cortado com "…" se for comprido. São quatro ingredientes, e todos são necessários:

<style>
  .nome {
    width: 160px;
    border: 2px solid navy;
    padding: 4px;
    background-color: aliceblue;
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
  }
</style>
<div class="nome">Bolo de cenoura com cobertura de chocolate</div>
width: 160px
Uma largura limitada. Num elemento de bloco, a largura já vem do pai; o que não pode é uma caixa que cresce junto com o texto.
white-space: nowrap
"Espaço em branco: sem quebra". O texto fica numa linha só, mesmo que não caiba.
overflow: hidden
"Transbordamento: escondido". O que sai da caixa não aparece (aula O que Transborda).
text-overflow: ellipsis
"Transbordamento do texto: reticências". No lugar do corte seco, o navegador mostra "…".

O resultado: "Bolo de cenoura com …". Tire qualquer um dos ingredientes e as reticências somem (veja Quando dá errado).

O que fica escondido

O texto cortado continua no HTML (leitores de tela e buscadores leem tudo), mas quem enxerga não tem como ver o resto. Não corte informação importante, como o preço. Se o nome completo for útil, mostre-o na página do produto, ou no atributo title (a dica que aparece ao parar o mouse).

Cortar em duas ou três linhas: -webkit-line-clamp

Para um resumo de receita com no máximo duas linhas, e "…" no fim da segunda, existe o line-clamp ("grampo de linhas"). Hoje ele funciona em todos os navegadores atuais, mas só com o prefixo -webkit- e mais duas declarações antigas que vêm junto:

<style>
  .resumo {
    width: 200px;
    border: 2px solid navy;
    background-color: aliceblue;
    display: -webkit-box;
    -webkit-box-orient: vertical;
    -webkit-line-clamp: 2;
    overflow: hidden;
  }
</style>
<p class="resumo">Bata no liquidificador as cenouras, os ovos e o óleo. Despeje numa tigela e junte o açúcar.</p>
Por que com -webkit-?

Este é um dos raros casos em que o prefixo é o jeito certo hoje. A versão sem prefixo, line-clamp: 2, ainda está em teste nos navegadores (dados do MDN); no Chromium 155 do laboratório, ela não funciona. As quatro linhas acima, juntas, funcionam no Chrome, Edge, Firefox e Safari. Evite pôr padding em cima e embaixo nesta caixa: ele deixa aparecer um pedaço da terceira linha.

Quando dá errado

Valores trocados: overflow-wrap: break-all, text-overflow: dots 
$ cat style.css
.link {
  overflow-wrap: break-all;
}
.titulo {
  text-overflow: dots;
}
.resumo {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;
  overflow: hidden;
}
$ vnu --css style.css
"file:/home/ana/site/style.css":2.18-2.26: error: CSS: “overflow-wrap”: “break-all” is not a “overflow-wrap” value.
"file:/home/ana/site/style.css":5.18-5.21: error: CSS: “text-overflow”: “dots” is not a “text-overflow” value.

O que o leitor vê: o endereço continua vazando e o título continua sem reticências: as duas declarações foram ignoradas. No F12, no painel Styles (Estilos), elas aparecem riscadas, com um ícone de aviso.

Por quê: break-all existe, mas é valor de outra propriedade, a word-break; e as reticências se chamam ellipsis, não dots ("pontos"). O validador diz "break-all não é um valor de overflow-wrap" e "dots não é um valor de text-overflow". O bloco .resumo, com o prefixo -webkit-, passou sem erro.

Como consertar: overflow-wrap: break-word; (ou word-break: break-all;, se for mesmo para cortar em qualquer letra) e text-overflow: ellipsis;.

O text-overflow sem os outros ingredientes 
<style>
  div {
    width: 160px;
    border: 2px solid navy;
    padding: 4px;
    margin-bottom: 6px;
  }
  .sem-nowrap {
    overflow: hidden;
    text-overflow: ellipsis;
  }
  .sem-hidden {
    white-space: nowrap;
    text-overflow: ellipsis;
  }
</style>
<div class="sem-nowrap">Bolo de cenoura com cobertura de chocolate</div>
<div class="sem-hidden">Bolo de cenoura com cobertura de chocolate</div>

O que o leitor vê: nenhuma reticência. Na primeira caixa, o nome quebrou em duas linhas, normalmente. Na segunda, ficou numa linha só e vazou pela borda.

Por quê: o text-overflow só desenha o "…" quando o texto transborda (precisa do nowrap, senão ele simplesmente quebra a linha) e o transbordamento está escondido (precisa do overflow: hidden). O validador não reclama: cada declaração, sozinha, é válida. Na aba Computed, o text-overflow mostra ellipsis nas duas caixas, e mesmo assim nada aparece.

Como consertar: os quatro juntos: largura limitada, white-space: nowrap, overflow: hidden e text-overflow: ellipsis.

O break-all que estragou os parágrafos

A Ana pôs body { word-break: break-all; } para resolver um endereço comprido. O endereço coube, mas agora todo parágrafo do site tem palavras cortadas no meio ("co" / "bertura"). O validador não reclama, porque o código é válido.

Como consertar: no body, use overflow-wrap: break-word, que só corta o que não cabe. Guarde o break-all para o elemento que mostra códigos.

Referência rápida

EscritaO que faz
overflow-wrap: break-word;Corta só a palavra que não cabe (herdado; bom no body)
overflow-wrap: anywhere;Igual, e deixa a caixa encolher (tabelas, Flexbox)
word-break: break-all;Corta qualquer palavra onde a linha acabar
hyphens: auto;Divide nas sílabas, com hífen; precisa do lang e do dicionário do navegador
white-space: nowrap;Proíbe quebrar a linha
text-overflow: ellipsis;"…" no corte; exige nowrap, overflow: hidden e largura limitada
display: -webkit-box; -webkit-box-orient: vertical; -webkit-line-clamp: 2; overflow: hidden;Corta em 2 linhas, com "…"

Resumo

  • O navegador quebra linhas em espaços e hífens; uma palavra sem esses lugares, mais larga que a caixa, vaza.
  • overflow-wrap: break-word corta só o que não cabe: ótimo no body, contra endereços e e-mails. anywhere também deixa a caixa encolher.
  • word-break: break-all corta qualquer palavra: só para códigos. hyphens: auto divide nas sílabas, mas depende do lang e do dicionário do navegador.
  • Reticências numa linha: largura limitada + white-space: nowrap + overflow: hidden + text-overflow: ellipsis. Faltou um, não aparece.
  • Em várias linhas: display: -webkit-box; -webkit-box-orient: vertical; -webkit-line-clamp: N; overflow: hidden;.
  • Texto cortado continua no HTML, mas some da tela: não corte o que é importante.
  • Valores trocados são ignorados: “break-all” is not a “overflow-wrap” value, “dots” is not a “text-overflow” value.
