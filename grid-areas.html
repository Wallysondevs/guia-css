CSS grid-template-areas

Na aula anterior você posicionou itens pelos números dos riscos da grade: grid-column: 1 / 3. Funciona, mas quem lê o código precisa contar riscos de cabeça. Nesta aula você vai desenhar o layout da página do blog da Ana com palavras, como um mapa: "aqui fica o topo, aqui o menu, aqui o conteúdo". O CSS lê o desenho e monta a grade.

Você vai aprender
  • grid-template-areas: o mapa da grade, escrito no pai.
  • grid-area: o nome de cada parte, escrito no filho.
  • Como uma área ocupa várias células (repetindo o nome) e como deixar uma célula vazia (.).
  • Como mudar o layout inteiro mexendo só no mapa.
  • Os erros que o validador W3C não pega: área em forma de L, fileiras com números diferentes de células, nome que não está no mapa.

Os resultados desta aula são desenhados pelo seu navegador, dentro de cada caixa. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a planta da casa

Antes de construir uma casa, alguém desenha a planta: um retângulo escrito "sala", outro "cozinha", outro "quarto". Ninguém diz "a cozinha vai do metro 3 ao metro 7"; a planta mostra onde cada cômodo fica.

O grid-template-areas (em inglês, "modelo de áreas da grade") é a planta da sua página. Cada palavra é uma célula. Para um cômodo ocupar duas células, você escreve o nome duas vezes. Depois, cada elemento da página diz em que cômodo mora, com grid-area ("área da grade").

1. O primeiro mapa

O blog da Ana tem quatro partes: o topo (<header>), o menu (<nav>), o conteúdo (<main>) e o rodapé (<footer>), os elementos da aula HTML Semântico do Guia HTML. Ela quer o topo e o rodapé de ponta a ponta, e o menu ao lado do conteúdo:

Experimente: leia o mapa no style.css e compare com o resultado. Depois troque "menu conteudo" por "conteudo menu" e troque o grid-template-columns para 1fr 150px: o menu passa para a direita, sem mexer no HTML.

<link rel="stylesheet" href="style.css">
<div class="pagina">
  <header class="topo">Blog da Ana</header>
  <nav class="menu">Receitas · Sobre</nav>
  <main class="conteudo">Hoje: bolo de cenoura.</main>
  <footer class="rodape">Feito pela Ana</footer>
</div>

.pagina {
  display: grid;
  grid-template-columns: 150px 1fr;
  grid-template-areas:
    "topo   topo"
    "menu   conteudo"
    "rodape rodape";
  gap: 8px;
}

.topo {
  grid-area: topo;
}

.menu {
  grid-area: menu;
}

.conteudo {
  grid-area: conteudo;
}

.rodape {
  grid-area: rodape;
}

.pagina header,
.pagina nav,
.pagina main,
.pagina footer {
  background: #dbeafe;
  border: 2px solid #1d4ed8;
  padding: 12px;
}

No resultado, "Blog da Ana" ocupa a primeira fileira inteira; embaixo, o menu fica numa coluna estreita à esquerda e o conteúdo na coluna larga; o rodapé fecha a página de ponta a ponta.

grid-template-areas:
Vai no pai (o elemento com display: grid). É o mapa.
"topo topo"
Uma fileira da grade, entre aspas. Cada palavra é uma célula: aqui, duas células, as duas do topo. Repetir o nome faz a área ocupar as duas.
"menu conteudo"
A segunda fileira: a célula da esquerda é do menu, a da direita do conteudo.
"rodape rodape";
A terceira fileira. Só a última fileira leva o ;: as três strings juntas são um valor.
grid-area: topo;
Vai no filho. Diz "este elemento mora na área topo". O nome vai sem aspas.

Os espaços extras dentro das aspas ("menu conteudo") não mudam nada: servem para alinhar as palavras e deixar o mapa parecido com o resultado. É um costume que ajuda muito a ler.

O mapa e o tamanho das colunas são coisas separadas

O mapa diz quem fica onde. A largura das colunas continua vindo do grid-template-columns (aula Colunas), e a altura das fileiras, do grid-template-rows (aula Linhas). O número de palavras de cada fileira tem de bater com o número de colunas.

Os nomes

Os nomes são inventados por você: topo, cabecalho, a, lateral. Não precisam ser iguais à classe nem ao elemento. A regra do guia é a mesma das classes: minúsculas, sem acento, com hífen quando tiver mais de uma palavra (menu-lateral). Um nome com acento até funciona, mas é fácil escrever rodape num lugar e rodapé no outro (veja Quando dá errado).

2. Células vazias: o ponto

Para deixar uma célula sem ninguém, escreva um ponto (.) no lugar do nome:

<style>
  .pagina {
    display: grid;
    grid-template-columns: 150px 1fr;
    grid-template-areas:
      "topo topo"
      "menu conteudo"
      ".    rodape";
    gap: 8px;
  }
  .topo { grid-area: topo; }
  .menu { grid-area: menu; }
  .conteudo { grid-area: conteudo; }
  .rodape { grid-area: rodape; }
  .pagina > * {
    background: #dbeafe;
    border: 2px solid #1d4ed8;
    padding: 12px;
  }
</style>
<div class="pagina">
  <header class="topo">Blog da Ana</header>
  <nav class="menu">Receitas · Sobre</nav>
  <main class="conteudo">Hoje: bolo de cenoura.</main>
  <footer class="rodape">Feito pela Ana</footer>
</div>

Agora o rodapé fica só embaixo do conteúdo, e o canto de baixo, à esquerda, fica vazio. (Nos exemplos curtos, .pagina > * pinta todos os filhos de uma vez: o * é o seletor universal e o > o combinador filho.)

3. Outro layout, o mesmo HTML

A grande vantagem das áreas: para mudar o layout, você mexe só no mapa. No celular, por exemplo, a Ana quer tudo empilhado, numa coluna só:

<style>
  .pagina {
    display: grid;
    grid-template-columns: 1fr;
    grid-template-areas:
      "topo"
      "menu"
      "conteudo"
      "rodape";
    gap: 8px;
  }
  .topo { grid-area: topo; }
  .menu { grid-area: menu; }
  .conteudo { grid-area: conteudo; }
  .rodape { grid-area: rodape; }
  .pagina > * {
    background: #dbeafe;
    border: 2px solid #1d4ed8;
    padding: 12px;
  }
</style>
<div class="pagina">
  <header class="topo">Blog da Ana</header>
  <nav class="menu">Receitas · Sobre</nav>
  <main class="conteudo">Hoje: bolo de cenoura.</main>
  <footer class="rodape">Feito pela Ana</footer>
</div>

As quatro partes ficam uma embaixo da outra, cada uma com a largura toda. Os grid-area dos filhos são os mesmos: só o mapa mudou. Para usar um mapa no celular e outro na tela grande, junte isto com @media (aula Media Queries): dentro do @media, você troca só o grid-template-columns e o grid-template-areas.

4. As outras formas de usar grid-area

O grid-area também aceita números, como atalho de quatro propriedades. A ordem é: fileira de começo / coluna de começo / fileira de fim / coluna de fim.

EscritaÉ o mesmo queQuando usar
grid-area: topo;Mora na área topo do mapaLayout da página (topo, menu, conteúdo): o mapa se lê como o resultado
grid-column: 1 / 3; + grid-row: 1;Riscos numerados (aula Posicionando Itens)Um item especial numa grade de itens iguais (o destaque de um cardápio)
grid-area: 1 / 1 / 2 / 3;grid-row-start: 1, grid-column-start: 1, grid-row-end: 2, grid-column-end: 3Raramente: é curto, mas difícil de ler (qual número é qual?)

Por baixo dos panos, o nome vira riscos: no F12, aba Computed, o .topo do primeiro exemplo mostra grid-row-start: topo e grid-column-end: topo. O navegador cria riscos chamados topo-start e topo-end em volta da área e usa esses.

Quando dá errado

Nesta aula, os piores erros são os que o validador não vê. Em todos eles, o mapa inválido é ignorado inteiro (no F12, o grid-template-areas calculado fica none), e os filhos procuram áreas que não existem.

Área em forma de L: o mapa todo é ignorado 
<style>
  .pagina {
    display: grid;
    grid-template-columns: 150px 1fr;
    grid-template-areas:
      "topo topo"
      "menu conteudo"
      "menu rodape"
      "conteudo conteudo";
    gap: 8px;
  }
  .topo { grid-area: topo; }
  .menu { grid-area: menu; }
  .conteudo { grid-area: conteudo; }
  .rodape { grid-area: rodape; }
  .pagina > * {
    background: #dbeafe;
    border: 2px solid #1d4ed8;
    padding: 12px;
  }
</style>
<div class="pagina">
  <header class="topo">Blog da Ana</header>
  <nav class="menu">Receitas · Sobre</nav>
  <main class="conteudo">Hoje: bolo de cenoura.</main>
  <footer class="rodape">Feito pela Ana</footer>
</div>

O que você vê: só o "Feito pela Ana", num cartão pequeno à direita. O topo, o menu e o conteúdo sumiram.

Por quê: a área conteudo aparece em dois pedaços separados (na segunda fileira e na quarta). Cada área precisa ser um retângulo: nada de L, de T ou de pedaços soltos. Com uma área inválida, o navegador ignora o grid-template-areas inteiro. Aí os quatro filhos pedem áreas que não existem, e o Grid manda todos para a mesma célula extra, fora da grade: eles ficam empilhados um em cima do outro, e só o último, o rodapé, aparece.

$ vnu --css style.css
$

O validador não diz nada: para ele, as aspas e os nomes estão bem escritos. Só olhando o resultado (ou o none no F12) você descobre.

Como consertar: desenhe cada área como um retângulo. Se o conteúdo precisa de mais espaço, aumente o retângulo dele, sem pedaços separados.

Uma fileira com mais células que as outras 
.pagina {
  display: grid;
  grid-template-columns: 150px 1fr;
  grid-template-areas:
    "topo topo"
    "menu conteudo conteudo"
    "rodape rodape";
}

O que você vê: o mesmo desastre do L: só o rodapé aparece.

Por quê: todas as fileiras do mapa precisam ter o mesmo número de palavras. Aqui a do meio tem 3 e as outras 2, e o mapa inteiro é ignorado. O validador também fica quieto.

Como consertar: conte as palavras de cada fileira. Alinhar o mapa com espaços, como uma tabela, ajuda a ver o erro.

Esqueceu as aspas no mapa: is not a “grid-template-areas” value 
.pagina {
  display: grid;
  grid-template-areas: topo topo;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":3.29-3.32: error: CSS: “grid-template-areas”: “topo” is not a “grid-template-areas” value.

O que significa: "topo não é um valor de grid-template-areas". No mapa, cada fileira é um texto entre aspas: "topo topo". Sem as aspas, a declaração é ignorada e o mapa fica none.

Aspas no lugar errado: is not a “grid-area” value 
.topo {
  grid-area: "topo";
}

$ vnu --css style.css
"file:/home/ana/site/style.css":2.14-2.19: error: CSS: “grid-area”: “"topo"” is not a “grid-area” value.

O que você vê: o topo deixa de atravessar a página: ele cai na primeira célula livre, a da esquerda na primeira fileira, e a da direita fica vazia.

Por quê: é o contrário do erro anterior. No mapa vão aspas; no grid-area do filho, o nome vai sem aspas. Com aspas, a declaração é ignorada (no F12, riscada) e o item volta a ser posicionado automaticamente.

Nome diferente do mapa: rodape × rodapé 
<style>
  .pagina {
    display: grid;
    grid-template-columns: 150px 1fr;
    grid-template-areas:
      "topo   topo"
      "menu   conteudo"
      "rodape rodape";
    gap: 8px;
  }
  .topo { grid-area: topo; }
  .menu { grid-area: menu; }
  .conteudo { grid-area: conteudo; }
  .rodape { grid-area: rodapé; }
  .pagina > * {
    background: #dbeafe;
    border: 2px solid #1d4ed8;
    padding: 12px;
  }
</style>
<div class="pagina">
  <header class="topo">Blog da Ana</header>
  <nav class="menu">Receitas · Sobre</nav>
  <main class="conteudo">Hoje: bolo de cenoura.</main>
  <footer class="rodape">Feito pela Ana</footer>
</div>

O que você vê: o topo, o menu e o conteúdo estão no lugar, só um pouco mais estreitos; a última fileira do mapa ficou vazia, e o rodapé apareceu sozinho lá embaixo, num cartão estreito à direita, fora da grade.

Por quê: rodapé, com acento, é um nome válido, mas não é rodape. Como não existe área rodapé no mapa, o Grid cria uma coluna e uma fileira extras e põe o item lá. O validador não reclama: para ele, os dois nomes estão bem escritos.

Como consertar: o mesmo nome, letra por letra, no mapa e no grid-area. Nomes sem acento evitam o problema.

Antes da missão, os quatro elementos entram na grade em ordem, dois por fileira. Com a solução, o topo atravessa a página, o conteúdo fica na coluna larga com o menu à direita, e o rodapé fecha embaixo. Repare que, no HTML, o <nav> continua antes do <main>: só a tela mudou.

Resumo

  • grid-template-areas, no pai, é o mapa: uma string entre aspas por fileira, uma palavra por célula. Repetir o nome estica a área; . é uma célula vazia.
  • grid-area: nome, no filho, sem aspas, põe o elemento na área.
  • A largura das colunas continua no grid-template-columns; o número de palavras de cada fileira tem de bater com ele.
  • Para mudar o layout (por exemplo, no celular), troque só o mapa.
  • Cada área é um retângulo e todas as fileiras têm o mesmo número de células. Um mapa inválido é ignorado inteiro (none), e o validador não avisa. Aspas faltando no mapa ou sobrando no grid-area: o validador avisa.
