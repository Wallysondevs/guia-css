CSS position: absolute

Um selo "Novo!" no canto de cima de um cartão. Um "×" para fechar um aviso. O nome do bolo escrito por cima da foto. Tudo isso é position: absolute: o elemento sai da fila do fluxo normal e vai se prender a um ponto exato de outro elemento. Nesta aula você vai aprender a receita que resolve quase todos esses casos, pai relative + filho absolute, e os tropeços clássicos de quem começa.

Você vai aprender
  • O que muda quando um elemento sai do fluxo.
  • A quem o top e o left se referem: o ancestral posicionado.
  • A receita pai relative + filho absolute.
  • Os quatro cantos, esticar com inset: 0 e centralizar.
  • Texto sobre a foto e selo pendurado para fora do cartão.
  • Os erros: o selo que foge para o canto da página, o pai que encolhe e o selo cortado.

Os resultados são desenhados pelo seu navegador. Se ainda não viu, leia antes position: Como Funciona e position: relative.

A ideia: o ímã na geladeira

Os papéis presos na porta da geladeira não ficam numa fila: cada ímã vai exatamente onde você o põe, "no canto de cima, à direita", e não empurra os outros. Se você pregar um ímã num quadro de avisos, a posição dele passa a ser "no canto do quadro", e não mais da geladeira.

No CSS, o elemento absolute é o ímã, e o elemento onde ele "gruda" é o ancestral posicionado mais próximo: o primeiro pai, avô ou bisavô que tenha position diferente de static. Se nenhum tiver, ele gruda na própria página.

1. Sair do fluxo

<style>
  .cartao {
    position: relative;
    width: 260px;
    padding: 12px;
    border: 2px solid tomato;
  }
  .selo {
    position: absolute;
    top: 0;
    right: 0;
    padding: 4px 8px;
    background-color: gold;
  }
</style>
<div class="cartao">
  <span class="selo">Novo!</span>
  <h2>Bolo de cenoura</h2>
  <p>Fofinho, com cobertura de chocolate.</p>
</div>
.cartao { position: relative; }
O cartão vira um elemento posicionado: a referência dos filhos absolute. Ele não se move: não tem deslocamento.
.selo { position: absolute; }
O selo sai do fluxo: os outros elementos se arrumam como se ele não existisse.
top: 0; right: 0;
A 0 do topo e a 0 da direita do cartão: o canto de cima, à direita. As distâncias contam a partir da borda de dentro do cartão (depois da border, antes do padding): o selo encosta na borda vermelha, ignorando os 12px de padding.

Repare que o título começa no alto do cartão, como se o selo não estivesse ali: o selo, fora do fluxo, não ocupa lugar. É por isso que ele pode ficar por cima de outras coisas, e é por isso que você precisa deixar espaço para ele, se não quiser que cubra o texto.

Ele também encolhe

Um bloco absolute não ocupa mais a largura toda: ele fica do tamanho do conteúdo, como um inline-block. E, mesmo que seja um <span>, ele passa a aceitar width, height e todas as margens (aula display): o navegador o trata como um bloco.

2. Com e sem a referência

O que acontece se o pai não tiver position: relative? O absolute continua procurando um ancestral posicionado, subindo pelo HTML. Se não achar nenhum, usa a própria página. Compare:

Experimente: o selo está no canto do cartão. Apague a linha position: relative; do .cartao: o selo foge para o canto de cima, à direita, do quadro inteiro. Volte a linha e troque o right: 0 por left: 0.

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<div class="cartao">
  <span class="selo">Novo!</span>
  <h2>Bolo de cenoura</h2>
  <p>Fofinho, com cobertura de chocolate.</p>
</div>

.cartao {
  position: relative;
  width: 260px;
  padding: 12px;
  border: 2px solid tomato;
}

.selo {
  position: absolute;
  top: 0;
  right: 0;
  padding: 4px 8px;
  background-color: gold;
}
A receita

Sempre que escrever position: absolute, pergunte: "em relação a quem?". E ponha position: relative nesse elemento. Pai relative, filho absolute: é a regra que resolve 9 em cada 10 casos.

3. Os cantos, as bordas e o meio

Combinando um deslocamento vertical (top ou bottom) e um horizontal (left ou right), você alcança qualquer canto:

<style>
  .quadro {
    position: relative;
    height: 160px;
    border: 2px solid navy;
    background-color: #e8ecff;
  }
  .ima {
    position: absolute;
    padding: 4px 8px;
    background-color: gold;
  }
  .a { top: 0;    left: 0; }
  .b { top: 0;    right: 0; }
  .c { bottom: 0; left: 0; }
  .d { bottom: 0; right: 0; }
  .meio {
    inset: 0;
    margin: auto;
    width: 90px;
    height: 24px;
    background-color: #fde8e1;
  }
</style>
<div class="quadro">
  <span class="ima a">top left</span>
  <span class="ima b">top right</span>
  <span class="ima c">bottom left</span>
  <span class="ima d">bottom right</span>
  <span class="ima meio">no meio</span>
</div>

O "no meio" usa um truque: inset: 0 diz "a 0 de todos os lados", width e height dizem o tamanho e, com margin: auto, o navegador divide a sobra igualmente entre os quatro lados. O elemento fica centralizado nas duas direções. (Para centralizar no layout, Flexbox e Grid são mais simples: aula Centralizando Qualquer Coisa.)

Esticar: lados opostos ao mesmo tempo

Diferente do relative, no absolute os lados opostos não brigam: left: 0 e right: 0 juntos fazem o elemento esticar de uma borda à outra. Com inset: 0, ele cobre o pai inteiro, como uma película.

EscritaResultado
top: 0; right: 0;Canto de cima, à direita (o selo)
bottom: 0; left: 0; right: 0;Faixa na borda de baixo, de ponta a ponta (a legenda da foto)
inset: 0;Cobre o pai inteiro (uma película escura sobre a foto)
inset: 0; margin: auto; + width e heightCentralizado
top: -10px; right: -10px;Pendurado para fora do canto (o número de notificações)
top: 50%; left: 50%; transform: translate(-50%, -50%);Centralizado sem saber o tamanho (aula transform)

4. Texto sobre a foto

Um dos usos mais bonitos: a legenda numa faixa escura, por cima da parte de baixo da foto.

Missão: ponha a legenda por cima da foto, colada na borda de baixo e na da esquerda. (1) A .foto vira a referência; (2) a .legenda sai do fluxo; (3) bottom e left iguais a 0. Para a faixa ir de ponta a ponta, acrescente também right: 0.

<link rel="stylesheet" href="style.css">
<div class="foto">
  <img src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura com cobertura de chocolate" width="400" height="300">
  <p class="legenda">Bolo de cenoura, R$ 35,00</p>
</div>

.foto {
  width: 300px;
}

.foto img {
  display: block;
  width: 100%;
  height: auto;
}

.legenda {
  margin: 0;
  padding: 8px;
  background-color: rgba(0, 0, 0, 0.6);
  color: white;
}

.foto {
  position: relative;
  width: 300px;
}

.foto img {
  display: block;
  width: 100%;
  height: auto;
}

.legenda {
  position: absolute;
  bottom: 0;
  left: 0;
  right: 0;
  margin: 0;
  padding: 8px;
  background-color: rgba(0, 0, 0, 0.6);
  color: white;
}

Dois detalhes do código: o margin: 0 da legenda tira a margem padrão do <p>, senão ela ficaria 16px acima da borda; e o fundo rgba(0, 0, 0, 0.6) é um preto 60% opaco (aula Transparência), que garante o contraste da letra branca sobre qualquer parte da foto.

5. Pendurado para fora

Com valores negativos, o filho sai um pouco para fora do pai, como o numerozinho vermelho de notificações em cima de um ícone:

<style>
  .carrinho {
    position: relative;
    display: inline-block;
    margin: 16px;
    padding: 10px 14px;
    border: 2px solid navy;
    border-radius: 8px;
  }
  .contador {
    position: absolute;
    top: -10px;
    right: -10px;
    width: 22px;
    height: 22px;
    border-radius: 50%;
    background-color: crimson;
    color: white;
    font-size: 13px;
    text-align: center;
    line-height: 22px;
  }
</style>
<a class="carrinho" href="carrinho.html">
  Carrinho
  <span class="contador">3</span>
</a>

O círculo com o "3" fica metade dentro e metade fora do canto do botão. Em um site de verdade, o leitor de tela leria "Carrinho 3"; um texto escondido como "itens" (com a classe da aula Escondendo) deixa a leitura mais clara.

Quando dá errado

O selo fugiu para o canto da página 
<style>
  .cartao {
    width: 220px;
    margin-top: 40px;
    padding: 12px;
    border: 2px solid tomato;
  }
  .selo {
    position: absolute;
    top: 0;
    right: 0;
    background-color: gold;
  }
</style>
<div class="cartao">
  <span class="selo">Novo!</span>
  <h2>Bolo de cenoura</h2>
</div>

O que você vê: o "Novo!" aparece lá no canto de cima, à direita, do quadro, longe do cartão.

Por quê: o cartão não tem position, então não é a referência. Sem nenhum ancestral posicionado, o selo usa a página. O validador não reclama: o CSS é válido.

Como consertar: position: relative no .cartao. No F12, para saber qual é a referência de um elemento absolute, suba pelos pais na aba Elements e veja qual é o primeiro com position diferente de static.

O pai encolheu até sumir 
<style>
  .faixa {
    position: relative;
    border: 3px dashed crimson;
  }
  .faixa p {
    position: absolute;
    margin: 0;
  }
</style>
<div class="faixa">
  <p>Promoção de bolos!</p>
</div>
<p>Este parágrafo deveria vir embaixo da faixa.</p>

O que você vê: a borda tracejada da faixa virou uma linha só, sem altura. O texto "Promoção de bolos!" aparece por cima dessa linha, e o parágrafo seguinte subiu e ficou colado nele.

Por quê: o pai só mede o que está no fluxo. Com o único filho fora do fluxo, a faixa fica com altura 0 (o F12 mostra height: 0px na aba Computed), e o parágrafo de baixo sobe.

Como consertar: deixe no fluxo pelo menos o conteúdo principal e use absolute só para os enfeites; ou dê ao pai uma altura (min-height) que caiba o filho.

O selo pendurado foi cortado 
<style>
  .cartao {
    position: relative;
    overflow: hidden;
    width: 220px;
    margin: 20px;
    padding: 12px;
    border: 2px solid tomato;
    border-radius: 12px;
  }
  .selo {
    position: absolute;
    top: -10px;
    right: -10px;
    padding: 6px 10px;
    background-color: gold;
  }
</style>
<div class="cartao">
  <span class="selo">Novo!</span>
  <h2>Bolo de cenoura</h2>
</div>

O que você vê: só um pedaço do selo aparece, cortado na borda arredondada do cartão.

Por quê: o overflow: hidden do cartão (posto para arredondar os cantos de uma foto, por exemplo) corta tudo o que passa da borda, inclusive um filho absolute pendurado para fora (aula O que Transborda).

Como consertar: tire o overflow: hidden do cartão e ponha o corte só onde ele é preciso (na foto, com border-radius nela), ou deixe o selo inteiro dentro do cartão (top: 8px; right: 8px;).

Exercícios

1. A referência

2. Canto de baixo

3. Cobrir tudo

5. Num elemento absolute, o que fazem left: 0 e right: 0 juntos?

6. Um <div> tem só um filho, e esse filho é absolute. Qual a altura do <div> (sem height, padding nem borda)?

Missão final: o cartão completo

Missão: (1) faça o cartão virar a referência; (2) pendure o selo "Novo!" para fora do canto de cima, à direita, com top e right de -10px; (3) ponha o botão "×" no canto de cima, à esquerda, a 8px de cada borda.

  <span class="selo">Novo!</span>
  <h2>Bolo de cenoura</h2>
  <p>Fofinho, com cobertura de chocolate.</p>
</div>

  border-radius: 12px;
}

}

Resumo

  • position: absolute tira o elemento do fluxo: os vizinhos ocupam o lugar dele, e ele encolhe para o tamanho do conteúdo.
  • top, right, bottom e left contam a partir do ancestral posicionado mais próximo; sem nenhum, da página.
  • A receita: pai relative, filho absolute.
  • Lados opostos esticam (left: 0; right: 0); inset: 0 cobre tudo; com margin: auto e tamanho, centraliza; valores negativos penduram para fora.
  • Use para enfeites (selos, "×", legendas sobre fotos), não para o layout.
  • Erros: sem pai posicionado o filho foge para a página; um pai com todos os filhos absolute fica com altura 0; overflow: hidden no pai corta o que está pendurado.
