CSS Tema Escuro

Muita gente deixa o celular e o computador no modo escuro: fundo escuro, letras claras, menos luz nos olhos à noite. O navegador sabe qual modo a pessoa escolheu e conta isso ao CSS. Nesta aula, o site de receitas da Ana vai ganhar uma versão escura que liga sozinha, sem você reescrever as regras: só as cores mudam.

Você vai aprender
  • A media query @media (prefers-color-scheme: dark): "se a pessoa prefere o escuro…".
  • O jeito organizado: guardar as cores em variáveis e trocar só as variáveis.
  • A propriedade color-scheme, que avisa o navegador para escurecer as peças dele (campos, botões, barra de rolagem).
  • A função light-dark(claro, escuro): as duas cores numa linha só.
  • Um botão "trocar tema" para quem quer escolher diferente do sistema.
  • Como ver a versão escura no editor do guia, e os erros que deixam o texto invisível.

Antes, é bom ter visto Variáveis (o var(--nome)) e Media Queries (o @media). As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: a mesma casa, de dia e de noite

Pense na cozinha da Ana. De dia, a janela aberta ilumina tudo. À noite, ela acende uma luz mais fraca e amarelada. A cozinha é a mesma: os armários, a mesa e o fogão continuam no lugar. Só a luz muda.

No site é igual. O tema escuro não é outro site e nem outro arquivo CSS. As margens, as fontes, o layout continuam iguais. Só trocam as cores: o fundo, o texto, os links, as bordas. Por isso o segredo de um bom tema escuro é deixar as cores num lugar só, fácil de trocar.

  1. A pessoa escolhe o modo escuro nas configurações do sistema (Windows, macOS, Android, iPhone, Linux) ou do navegador.
  2. O navegador guarda essa preferência e a mostra ao CSS como uma característica da tela, igual à largura.
  3. O seu CSS pergunta, com @media: "a pessoa prefere escuro?". Se sim, as regras de dentro valem.

1. A pergunta: prefers-color-scheme

Na aula Media Queries, o @media perguntava a largura da tela. Aqui ele pergunta a preferência de cores:

body {
  background-color: #fffaf3;
  color: #2b2118;
}

@media (prefers-color-scheme: dark) {
  body {
    background-color: #1e1b18;
    color: #f3ead9;
  }
}
body { … }
As cores de sempre, do tema claro: fundo creme, letra marrom-escura. Valem para todo mundo.
@media
"Para o tipo de tela…". Abre uma pergunta.
(prefers-color-scheme: dark)
A pergunta, sempre entre parênteses. prefers-color-scheme = "prefere o esquema de cores"; dark = "escuro". A resposta é sim quando a pessoa escolheu o modo escuro.
{ body { … } }
As regras de dentro só valem quando a resposta é sim. Elas vêm depois das cores claras e têm o mesmo seletor: pela cascata, quem vem depois vence.
ValorQuando a resposta é sim
darka pessoa prefere o tema escuro
lighta pessoa prefere o tema claro, ou não escolheu nada

Na prática, quase todo mundo escreve só o bloco dark: o claro fica como as regras normais, fora do @media. Assim, um navegador muito antigo, que não entende a pergunta, mostra o tema claro, que funciona.

Como ver a versão escura aqui no guia

Experimente a caixa abaixo. Você provavelmente vai ver o tema claro, mesmo que o seu sistema esteja no modo escuro. Não é erro no seu CSS:

O quadro do editor é sempre "de dia"

O editor do guia desenha cada exemplo como uma folha branca, avisando ao navegador que o quadro é claro. Os navegadores atuais (Chrome, Edge e Firefox) respeitam esse aviso: dentro do quadro, a resposta de prefers-color-scheme: dark é "não", mesmo com o seu sistema no modo escuro (conferido no Chromium). O botão de tema do guia (o sol e a lua lá em cima) também não muda os quadros: ele troca as cores do guia, e não a preferência do seu sistema. Para ver a versão escura do seu código:

  • ↗ (abrir numa aba nova): a aba nova segue a preferência do seu sistema. Deixe o sistema no modo escuro e clique em ↗.
  • F12: as ferramentas do desenvolvedor sabem fingir a preferência, para a página inteira e todos os quadros. No Chrome e no Edge, abra o F12, aperte Ctrl+Shift+P, digite prefers-color-scheme e escolha a opção com dark. No Firefox, a aba Inspetor tem, no painel de regras, um botão de sol e um de lua. (Os nomes exatos dos menus mudam com a versão do navegador.)

As seções 3 e 4 mostram também um jeito de pôr o claro e o escuro lado a lado, sem fingir nada.

Experimente: esta página tem o tema claro e o escuro. Abra-a com ↗ com o seu sistema no modo escuro (ou finja o escuro no F12) e veja as cores trocarem. Depois, mude as cores do bloco @media e confira de novo.

2. O jeito organizado: variáveis que mudam de valor

Um site de verdade tem cor em muitos lugares: o fundo, o texto, os títulos, os links, as bordas dos cartões, os botões. Repetir cada regra dentro do @media dá trabalho e é fácil esquecer uma. A solução é guardar as cores em variáveis e, no tema escuro, trocar só as variáveis:

:root {
  --fundo: #fffaf3;
  --texto: #2b2118;
  --destaque: #c2410c;
}

@media (prefers-color-scheme: dark) {
  :root {
    --fundo: #1e1b18;
    --texto: #f3ead9;
    --destaque: #fb923c;
  }
}

body {
  background-color: var(--fundo);
  color: var(--texto);
}

h1,
a {
  color: var(--destaque);
}
:root { --fundo: …; }
As cores do tema claro, com nome. :root é a raiz da página (o <html>): dali, as variáveis valem para todos os elementos.
@media (…dark) { :root { … } }
No escuro, as mesmas variáveis ganham outros valores. Nenhuma regra do site é repetida.
color: var(--texto);
As regras do site usam só os nomes. Elas não sabem (nem precisam saber) qual tema está ligado.

Repare na cor de destaque: no claro, um laranja-escuro (#c2410c); no escuro, um laranja mais claro (#fb923c). O laranja-escuro em cima do fundo escuro ficaria apagado, difícil de ler. No tema escuro, as cores de destaque costumam ficar mais claras e menos "berrantes".

Missão: as cores já estão em variáveis. Acrescente, depois do :root, um bloco @media (prefers-color-scheme: dark) com um :root dentro que mude --fundo para #1e1b18 e --texto para #f3ead9 (nesta ordem). O quadro vai continuar claro: confira o escuro com ↗ ou com o F12.

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p>Hoje tem bolo de cenoura com cobertura de chocolate.</p>

:root {
  --fundo: #fffaf3;
  --texto: #2b2118;
}

body {
  background-color: var(--fundo);
  color: var(--texto);
}

:root {
  --fundo: #fffaf3;
  --texto: #2b2118;
}

@media (prefers-color-scheme: dark) {
  :root {
    --fundo: #1e1b18;
    --texto: #f3ead9;
  }
}

body {
  background-color: var(--fundo);
  color: var(--texto);
}

3. color-scheme: avisando o navegador

O seu CSS pinta o fundo e o texto. Mas uma página tem peças que o navegador desenha: o campo de texto, a caixa de seleção, o botão sem estilo, a barra de rolagem. Sem aviso, elas continuam claras, e o resultado é um campo branco brilhando no meio do site escuro.

A propriedade color-scheme ("esquema de cores") é esse aviso: ela diz em quais esquemas a página (ou um pedaço dela) sabe ser desenhada. Veja dois quadrados com o mesmo HTML, um com color-scheme: light e o outro com color-scheme: dark:

<style>
  .claro { color-scheme: light; }
  .escuro { color-scheme: dark; }
  div { padding: 12px; margin-bottom: 8px; border: 1px solid gray; }
</style>
<div class="claro">
  <p>color-scheme: light</p>
  <input type="text" value="Bolo de cenoura" aria-label="Receita">
  <select aria-label="Tamanho"><option>Forma média</option></select>
  <button>Salvar</button>
</div>
<div class="escuro">
  <p>color-scheme: dark</p>
  <input type="text" value="Bolo de cenoura" aria-label="Receita">
  <select aria-label="Tamanho"><option>Forma média</option></select>
  <button>Salvar</button>
</div>

No segundo quadrado, o navegador desenhou o campo, a lista e o botão com fundo escuro e letras claras. Mas repare: o fundo do próprio quadrado e o texto do parágrafo continuaram iguais aos do primeiro. O color-scheme num elemento muda as peças do navegador, e não as cores que são suas. (Na raiz da página, :root, ele muda também o fundo e o texto padrão da página toda.)

ValorO que diz ao navegador
normalo padrão: "não sei nada de esquemas" (desenha claro)
light"eu só sei ser claro"
dark"eu só sei ser escuro"
light dark"sei ser os dois; siga a preferência da pessoa". É o que você quer num site com tema escuro

Num site com os dois temas, escreva no :root:

:root {
  color-scheme: light dark;
}

Há também a versão em HTML, uma <meta> no <head>: <meta name="color-scheme" content="light dark">. Ela tem uma vantagem: o navegador a lê antes de baixar o CSS, e a página não "pisca" branca ao abrir no modo escuro. Pode usar as duas.

4. light-dark(): as duas cores numa linha

A função light-dark() recebe duas cores: a primeira para o esquema claro, a segunda para o escuro. O navegador escolhe uma delas conforme o color-scheme do elemento:

:root {
  color-scheme: light dark;
}

body {
  background-color: light-dark(#fffaf3, #1e1b18);
  color: light-dark(#2b2118, #f3ead9);
}
color-scheme: light dark;
Obrigatório. Sem ele, o esquema é sempre o claro e a função sempre escolhe a primeira cor.
light-dark(
"claro-escuro": a função.
#fffaf3,
A cor do esquema claro (vem primeiro).
#1e1b18)
A cor do esquema escuro.

Com color-scheme: light dark na raiz, a página segue a preferência da pessoa, sem nenhum @media. E como a função olha o color-scheme do próprio elemento, dá para forçar um pedaço da página a ficar escuro. É assim que o claro e o escuro aparecem lado a lado, aqui no quadro:

Experimente: o mesmo cartão duas vezes; o segundo tem color-scheme: dark. Troque as cores dentro do light-dark() e veja cada cartão pegar a sua. Depois apague a linha color-scheme: dark; do .noite: os dois ficam iguais.

<link rel="stylesheet" href="style.css">
<div class="cartao">
  <h2>Bolo de cenoura</h2>
  <p>Massa fofinha e <a href="#cobertura">cobertura de chocolate</a>.</p>
</div>
<div class="cartao noite">
  <h2>Bolo de cenoura</h2>
  <p>Massa fofinha e <a href="#cobertura">cobertura de chocolate</a>.</p>
</div>

.cartao {
  background-color: light-dark(#fffaf3, #1e1b18);
  color: light-dark(#2b2118, #f3ead9);
  padding: 12px 16px;
  margin-bottom: 12px;
  border-radius: 8px;
}

.cartao a {
  color: light-dark(#c2410c, #fb923c);
}

.noite {
  color-scheme: dark;
}
Suporte

light-dark() é recente: funciona no Chrome e no Edge desde a versão 123, no Firefox desde a 120 e no Safari desde a 17.5 (todos de 2024, segundo o MDN). Num navegador mais velho, a declaração inteira é ignorada. Se o seu público pode ter aparelhos antigos, escreva antes uma linha simples, que serve de reserva: color: #2b2118; e, embaixo, color: light-dark(#2b2118, #f3ead9);. Quem não entende a segunda fica com a primeira. A @media (prefers-color-scheme) e o color-scheme funcionam em todos os navegadores atuais.

Missão: o cartão de baixo devia ser a versão noturna, mas está igual ao de cima. Use light-dark() no .cartao: fundo #fffaf3 no claro e #1e1b18 no escuro; texto #2b2118 no claro e #f3ead9 no escuro. Depois, dê color-scheme: dark ao .noite.

<div class="cartao noite"><p>Pão de queijo: 40 minutos.</p></div>

  color-scheme: dark;

5. Um botão para trocar o tema

A preferência do sistema é um bom começo, mas há quem use o sistema escuro e queira ler um site claro (ou o contrário). Por isso muitos sites, inclusive este guia, têm um botão de tema. O CSS para isso é pequeno: uma classe na raiz que muda o color-scheme. Com as cores em light-dark(), só isso já troca tudo:

Experimente: clique no botão algumas vezes. O onclick põe e tira a classe escuro do <html> (o JavaScript é assunto de outro guia; aqui, só repare no CSS).

<link rel="stylesheet" href="style.css">
<button type="button" onclick="document.documentElement.classList.toggle('escuro')">Trocar tema</button>
<h1>Receitas da Ana</h1>
<p>Escolha uma receita e mãos à obra.</p>
<input type="search" placeholder="Buscar receita" aria-label="Buscar receita">

:root {
  color-scheme: light;
}

:root.escuro {
  color-scheme: dark;
}

body {
  background-color: light-dark(#fffaf3, #1e1b18);
  color: light-dark(#2b2118, #f3ead9);
}

  color: light-dark(#c2410c, #fb923c);
}

Repare que o campo de busca e o próprio botão também escurecem: é o color-scheme trabalhando. Num site de verdade, o botão começa no tema do sistema e guarda a escolha da pessoa para a próxima visita. Essa parte é JavaScript.

6. Cuidados com as cores do escuro

Tema escuro não é "inverter as cores". Algumas dicas que deixam a leitura confortável:

  • Fuja do preto puro com branco puro. #000 com #fff tem contraste tão forte que as letras parecem "vibrar". Um fundo quase preto (#1e1b18) e um texto quase branco (#f3ead9) cansam menos.
  • Cores de destaque mais claras. O laranja-escuro do tema claro some no fundo escuro. Use uma versão mais clara da mesma cor.
  • Confira o contraste nos dois temas. A aula CSS e Acessibilidade mostra como medir. No escuro é fácil errar para menos (um cinza-escuro sobre preto).
  • Sombras quase não aparecem num fundo escuro. Para separar um cartão do fundo, use um fundo um pouco mais claro ou uma borda.

Quando dá errado

error: CSS: “escuro” is not a “prefers-color-scheme” value

O que aconteceu: o valor foi escrito em português: @media (prefers-color-scheme: escuro).

$ vnu --css escuro.css
"file:/home/ana/tema/escuro.css":1.37-1.37: error: CSS: “escuro” is not a “prefers-color-scheme” value

"escuro não é um valor de prefers-color-scheme." O navegador não reclama: a pergunta nunca tem resposta "sim", e o tema escuro nunca liga.

Como consertar: os valores são em inglês: dark ou light.

error: CSS: unrecognized media “prefers-color-scheme”.

O que aconteceu: faltaram os parênteses: @media prefers-color-scheme: dark { … }.

$ vnu --css semparen.css
"file:/home/ana/tema/semparen.css":5.2-6.1: error: CSS: unrecognized media “prefers-color-scheme”.

"Mídia não reconhecida." Sem parênteses, o validador acha que prefers-color-scheme é um tipo de mídia, como screen ou print. O navegador descarta o bloco inteiro. Com = no lugar de : ((prefers-color-scheme = dark)), a mensagem é “=” is not a “prefers-color-scheme” value, seguida de um Parse Error.

Como consertar: @media (prefers-color-scheme: dark): parênteses e dois-pontos.

O tema escuro nunca aparece (e o validador não reclama)

O que aconteceu: o bloco escuro veio antes das cores claras:

@media (prefers-color-scheme: dark) {
  :root {
    --fundo: #1e1b18;
  }
}

:root {
  --fundo: #fffaf3;
}

Os dois blocos têm o mesmo seletor (:root) e a mesma especificidade. Pela cascata, vence o que vem por último: o claro. O @media não dá prioridade nenhuma; ele só liga ou desliga as regras de dentro. No F12, com o escuro fingido, a aba de estilos mostra o --fundo: #1e1b18 riscado.

Como consertar: o bloco @media sempre depois das cores claras.

O texto sumiu no tema escuro

O que aconteceu: o bloco escuro trocou o fundo e esqueceu o texto: body { background-color: #1e1b18; }. O texto continua com a cor do tema claro, marrom-escuro sobre quase preto. Veja (o cartão está forçado no escuro, como na seção 4):

<style>
  .cartao { color: #2b2118; padding: 8px 16px; }
  .noite { background-color: #1e1b18; }
</style>
<div class="cartao noite">
  <p>Torta de limão: 1 hora de geladeira.</p>
</div>

O texto está lá (selecione com o mouse e ele aparece), mas quase não se lê.

Como consertar: no tema escuro, troque sempre os pares: fundo e texto juntos. Com variáveis (seção 2) ou light-dark() (seção 4), fica difícil esquecer.

light-dark() sempre escolhe a primeira cor

O que aconteceu: a página usa light-dark(), mas ninguém escreveu color-scheme. Sem ele, o esquema é normal, que o navegador desenha como claro: a função escolhe a primeira cor até no modo escuro do sistema. O validador não percebe, porque o código está certo; falta uma linha.

Como consertar: :root { color-scheme: light dark; }.

color-scheme: escuro não faz nada (e o validador aceita)

O que aconteceu: o valor em português, de novo, agora na propriedade. Aqui o validador fica quieto:

$ vnu --css cs.css
$

Por uma regra curiosa: o color-scheme aceita nomes inventados, reservados para esquemas futuros. O navegador guarda escuro, não conhece esse esquema e desenha tudo claro. No F12, a aba Computed (Calculado) mostra color-scheme: escuro, sem risco nenhum, e mesmo assim nada escurece.

Como consertar: light, dark ou light dark.

Resumo

  • O tema escuro troca só as cores; o layout continua igual.
  • @media (prefers-color-scheme: dark) { … } liga regras quando a pessoa prefere o escuro. Escreva o claro como regra normal e o bloco escuro depois.
  • Guarde as cores em variáveis no :root e, no escuro, troque só as variáveis.
  • color-scheme: light dark no :root faz o navegador escurecer as peças dele (campos, botões, barra de rolagem) e o fundo padrão.
