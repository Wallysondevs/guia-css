CSS Cores Hexadecimais (#)

Os nomes de cor da aula anterior são só quase 150. O logo da Lojinha da Ana tem um laranja-tijolo que não está em nenhum nome. Para ele, o CSS tem o código hexadecimal: uma cerquilha (#) e seis letras e números, como #c7401f. É a forma de cor mais comum nos sites, e a que os programas de desenho entregam. Nesta aula você vai aprender a ler esse código, e não só a copiá-lo.

Você vai aprender
  • O que quer dizer cada parte de #ff6347: três pares, um para cada luz (vermelho, verde e azul).
  • Como contar de 00 a ff e por que ff é o máximo.
  • Por que vermelho + verde dá amarelo na tela.
  • A forma curta de três dígitos: #f60 = #ff6600.
  • Os oito dígitos, com transparência: #ff634780.
  • Onde achar o código de uma cor e os erros reais do validador W3C.

Antes, é bom ter feito Cores por Nome. Os quadros "Resultado" e as caixas "Experimente" são desenhados agora pelo seu navegador. As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: o código da tinta

Numa loja de tintas, você não precisa dizer "aquele laranja meio queimado". Você entrega o código da cor, e a máquina mistura a quantidade certa de cada pigmento. Qualquer loja, com o mesmo código, faz a mesma cor.

A tela faz o mesmo, com três luzes em vez de pigmentos: vermelho (red), verde (green) e azul (blue), o famoso RGB. Cada pontinho da tela acende essas três luzes, cada uma com uma força de 0 (apagada) a 255 (no máximo). O código hexadecimal é a receita: quanto de cada luz.

1. A anatomia de #ff6347

Lembra do tomato? O navegador guardava rgb(255, 99, 71). Em hexadecimal, ele é #ff6347:

#
A cerquilha avisa: "aqui vem um código de cor". Sem ela, ff6347 é só uma palavra que o CSS não conhece.
ff
O 1º par: a luz vermelha. ff é o máximo, 255.
63
O 2º par: a luz verde. 63 vale 99.
47
O 3º par: a luz azul. 47 vale 71.

Muito vermelho, pouco verde e menos azul ainda: um vermelho alaranjado. É o mesmo tomate:

<style>
  .nome { color: tomato; }
  .hex { color: #ff6347; }
</style>
<h2 class="nome">color: tomato</h2>
<h2 class="hex">color: #ff6347</h2>

Os dois títulos saíram da mesma cor. O navegador guarda os dois como rgb(255, 99, 71).

2. Contando de 00 a ff

"Hexadecimal" quer dizer "de base 16": cada algarismo vai de 0 a 15. Como só temos dez algarismos (0 a 9), as letras a a f fazem o papel do 10 ao 15:

Algarismo01…9abcdef
Vale01…9101112131415

Com dois algarismos, o primeiro vale 16 vezes mais (como, no nosso sistema, a dezena vale 10 vezes a unidade). A conta é 16 × o primeiro + o segundo:

ParContaForça da luz
0016 × 0 + 00 (apagada)
3316 × 3 + 351
4716 × 4 + 771
6316 × 6 + 399
8016 × 8 + 0128 (metade)
c716 × 12 + 7199
ff16 × 15 + 15255 (o máximo)

Você não precisa fazer essas contas no dia a dia. Basta o "olho": perto de 00 é pouca luz, perto de ff é muita. Em #c7401f, o vermelho (c7) está alto e os outros dois, baixos: é um vermelho, meio escuro.

3. Misturando as três luzes

Cada caixa abaixo tem o código escrito dentro, com a cor de fundo desse código:

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px; /* espaço em volta do texto (aula Espaço Interno) */
    font-family: monospace;
  }
  .vermelho { background-color: #ff0000; color: #000000; }
  .verde { background-color: #00ff00; color: #000000; }
  .azul { background-color: #0000ff; color: #ffffff; }
  .amarelo { background-color: #ffff00; color: #000000; }
  .ciano { background-color: #00ffff; color: #000000; }
  .magenta { background-color: #ff00ff; color: #000000; }
  .branco { background-color: #ffffff; color: #000000; }
  .cinza { background-color: #808080; color: #000000; }
  .preto { background-color: #000000; color: #ffffff; }
</style>
<p class="vermelho">#ff0000 só vermelho</p>
<p class="verde">#00ff00 só verde</p>
<p class="azul">#0000ff só azul</p>
<p class="amarelo">#ffff00 vermelho + verde = amarelo</p>
<p class="ciano">#00ffff verde + azul = ciano</p>
<p class="magenta">#ff00ff vermelho + azul = magenta</p>
<p class="branco">#ffffff as três no máximo = branco</p>
<p class="cinza">#808080 as três pela metade = cinza</p>
<p class="preto">#000000 tudo apagado = preto</p>

Na tinta, vermelho com verde dá um marrom sujo. Na tela é diferente, porque luz somada fica mais clara: vermelho e verde acesos juntos dão amarelo, e as três luzes no máximo dão branco. Repare também na regra dos cinzas: quando os três pares são iguais (#808080, #333333, #d3d3d3), a cor é um cinza; quanto maior o número, mais claro.

Experimente: mude um par de cada vez e veja a cor mudar. Comece trocando o 00 do meio por 80, depois por ff.

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>

h1 {
  color: #ff0000;
}

5. A forma curta: três dígitos

Quando os dois algarismos de cada par são iguais, dá para escrever um só de cada: o navegador repete cada um.

CurtaO navegador lê comoValor calculado
#f00#ff0000rgb(255, 0, 0)
#f60#ff6600rgb(255, 102, 0)
#fc0#ffcc00rgb(255, 204, 0)
#333#333333rgb(51, 51, 51)
#fff#ffffffrgb(255, 255, 255)
#000#000000rgb(0, 0, 0)
<style>
  .longa { color: #ff6600; }
  .curta { color: #f60; }
</style>
<h2 class="longa">#ff6600</h2>
<h2 class="curta">#f60</h2>

Os dois títulos têm a mesma cor. Mas atenção: #ff6347 não tem forma curta, porque 63 e 47 não são pares repetidos. E #f63 não é o tomate: é #ff6633, outra cor. Use a forma curta só quando ela é exata; o #333 (cinza bem escuro, ótimo para texto) e o #fff são os mais comuns.

6. Maiúsculas ou minúsculas?

#FF6347 e #ff6347 são a mesma cor, e o validador aceita os dois. Os programas de desenho costumam entregar em maiúsculas; o estilo do guia (e de muitos projetos) é minúsculas. O importante é escolher um jeito e usar no arquivo todo.

7. Oito dígitos: a cor com transparência

Um quarto par no fim diz quanto a cor é opaca (o "alfa"): ff é totalmente opaca, 00 é invisível, 80 é mais ou menos a metade.

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px;
    font-family: monospace;
  }
  .a { background-color: #ff6347ff; }
  .b { background-color: #ff6347b3; }
  .c { background-color: #ff634780; }
  .d { background-color: #ff634740; }
</style>
<p class="a">#ff6347ff (opaca)</p>
<p class="b">#ff6347b3</p>
<p class="c">#ff634780 (metade)</p>
<p class="d">#ff634740</p>

O tomate vai ficando mais fraco porque o fundo branco aparece através dele. O navegador guarda #ff634780 como rgba(255, 99, 71, 0.5). Também existe a forma curta de quatro dígitos (#f008). O assunto "cor meio transparente" é da aula Transparência, onde a forma com rgb() costuma ser mais fácil de ler.

Suporte

Os oito (e os quatro) dígitos funcionam em todos os navegadores atuais: Firefox desde a versão 49, Safari desde a 10, Chrome desde a 62 e Edge desde a 79 (de 2020, o último a chegar). Segundo o caniuse.com, isso cobre mais de 97% das pessoas. O velho Internet Explorer não entende.

8. Onde achar o código de uma cor

  • Programas de desenho (Figma, Inkscape, GIMP, Photoshop): o seletor de cor mostra o código com #. Copie e cole.
  • O F12 (aula Inspecionando com o F12): no painel de estilos, cada cor tem um quadradinho; clicando nele, abre um seletor de cor onde você escolhe com o mouse e o código muda junto. (Descrição ilustrativa: o desenho do seletor muda de navegador para navegador.)
  • O próprio HTML: o campo <input type="color"> abre o seletor de cor do seu sistema e devolve o código. Clique no quadrado colorido abaixo e escolha uma cor:
<label>Escolha uma cor: <input type="color" value="#c7401f"></label>

O valor de um <input type="color"> é sempre um código de seis dígitos em minúsculas, como #c7401f.

Quando dá errado

Como em toda cor errada, o navegador não mostra mensagem: ele ignora a declaração, e o texto fica com a cor que já tinha. Os quatro títulos abaixo queriam ser tomate:

<style>
  .a { color: ff6347; }
  .b { color: #ff634; }
  .c { color: #gg6347; }
  .d { color: # ff6347; }
</style>
<h2 class="a">color: ff6347</h2>
<h2 class="b">color: #ff634</h2>
<h2 class="c">color: #gg6347</h2>
<h2 class="d">color: # ff6347</h2>

Os quatro ficaram pretos. No F12, cada declaração aparece riscada no painel de estilos. O validador explica:

error: CSS: “color”: “ff6347” is not a “color” value.

O que aconteceu: faltou a cerquilha: color: ff6347;.

$ vnu --css sem-cerquilha.css
"file:/home/ana/hex/sem-cerquilha.css":2.10-2.15: error: CSS: “color”: “ff6347” is not a “color” value.

"ff6347 não é um valor de cor." Sem o #, o CSS procura uma cor com esse nome, e ela não existe.

Como consertar: color: #ff6347;.

error: CSS: “color”: “#ff634” is not a valid color 3 or 6 hexadecimals numbers.

O que aconteceu: sobrou um algarismo a menos (ou a mais): cinco dígitos.

$ vnu --css cinco.css
"file:/home/ana/hex/cinco.css":2.10-2.15: error: CSS: “color”: “#ff634” is not a valid color 3 or 6 hexadecimals numbers.

"#ff634 não é uma cor válida de 3 ou 6 números hexadecimais." O código tem de ter 3, 4, 6 ou 8 algarismos depois do #. (A mensagem do validador só cita 3 e 6, mas ele aceita também 4 e 8, como os navegadores.)

Como consertar: copie o código de novo, de onde você o pegou. Contar os algarismos ajuda: seis.

error: CSS: “color”: “#gg6347” is not a valid color 3 or 6 hexadecimals numbers.

O que aconteceu: uma letra que não existe em hexadecimal: só valem 0 a 9 e a a f.

$ vnu --css letra-g.css
"file:/home/ana/hex/letra-g.css":2.10-2.16: error: CSS: “color”: “#gg6347” is not a valid color 3 or 6 hexadecimals numbers.

Um engano parecido: a letra o no lugar do zero (#ff63o7) ou o l no lugar do um.

Como consertar: confira cada caractere; na dúvida, copie e cole em vez de digitar.

error: CSS: “color”: “ff6347” is not a “color” value. (com espaço depois do #)

O que aconteceu: color: # ff6347;, com um espaço entre a cerquilha e o código.

$ vnu --css espaco.css
"file:/home/ana/hex/espaco.css":2.12-2.17: error: CSS: “color”: “ff6347” is not a “color” value.

A mesma mensagem da falta de #: com o espaço, o # fica sozinho, e o ff6347 vira uma palavra separada.

Como consertar: tudo junto: #ff6347.

Resumo

  • O código hexadecimal #rrggbb diz quanto de cada luz acender: vermelho, verde e azul, cada uma de 00 (apagada) a ff (255, o máximo).
  • Os algarismos vão de 0 a 9 e de a (10) a f (15). Par = 16 × o primeiro + o segundo.
  • Luz somada clareia: vermelho + verde = amarelo; tudo no máximo = branco; pares iguais = cinza.
  • Forma curta #rgb só quando os pares se repetem: #f60 = #ff6600. Maiúsculas valem, mas use minúsculas.
  • Oito dígitos (#ff634780) acrescentam a transparência; o navegador guarda como rgba(…).
  • Sem #, com espaço, com letra fora de a–f ou com o número errado de algarismos: a cor é ignorada em silêncio, e o validador mostra o motivo.
