CSS flex-direction

Ao ligar o Flexbox, os itens ficam lado a lado, em linha. Mas e se você quiser os itens um embaixo do outro, arrumados pelo Flexbox? Ou de trás para frente? É o trabalho do flex-direction ("direção flex"): ele escolhe para onde vai a fila de itens. Nesta aula você vai ver os quatro valores lado a lado, montar o cartão de receita da Ana em coluna, fazer um menu que vira coluna no celular e entender por que o reverse pede cuidado.

Você vai aprender
  • Os quatro valores: row, row-reverse, column e column-reverse.
  • Como a direção principal e a cruzada trocam de lugar numa coluna.
  • Quando usar a coluna em vez de deixar os blocos empilhados sozinhos.
  • Como trocar de coluna para linha conforme a largura da tela.
  • Por que o reverse confunde quem usa o teclado.
  • As mensagens reais do validador.

Antes, é bom ter visto Introdução ao Flexbox (o pai flex, os itens, a direção principal e a cruzada). Os resultados são desenhados pelo seu navegador; os números em pixels do texto foram medidos no Chromium. As mensagens do validador saíram do validador W3C (vnu), na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: a fila e a pilha

Os mesmos três potes de doce podem ser arrumados de dois jeitos: em fila, numa prateleira, um ao lado do outro; ou em pilha, um em cima do outro. E, nos dois casos, você pode começar pela ponta de cá ou pela de lá. O flex-direction é essa escolha, feita no pai, valendo para todos os itens.

1. Os quatro valores

Cada caixa abaixo tem os mesmos três itens, na mesma ordem no HTML (1, 2, 3). Só muda o flex-direction do pai, escrito no alto de cada caixa:

<style>
  .caixa { margin-bottom: 12px; padding: 4px; border: 2px dashed gray; font-family: sans-serif; }
  .caixa p { margin: 0 0 4px; font-weight: bold; }
  .pai { display: flex; }
  .item { margin: 2px; padding: 8px 16px; background-color: firebrick; color: white; }
  .row { flex-direction: row; }
  .row-reverse { flex-direction: row-reverse; }
  .column { flex-direction: column; }
  .column-reverse { flex-direction: column-reverse; }
</style>

  <div class="pai row-reverse"><div class="item">1</div><div class="item">2</div><div class="item">3</div></div>
</div>

<div class="caixa">

Repare em duas coisas nas colunas: os itens ficam da largura toda da caixa (eles esticam na direção cruzada, que agora é a deitada), e o row-reverse não só inverte a ordem, como também empurra os itens para a outra ponta.

Experimente: troque o valor do flex-direction pelos outros três e veja o menu mudar.

2. Numa coluna, as direções giram

Na aula anterior, a direção principal era a deitada e a cruzada, a em pé. O flex-direction escolhe justamente qual é a principal. Numa coluna, elas trocam de lugar:

rowcolumn
Direção principal (onde os itens se enfileiram)Deitada ↔Em pé ↕
Direção cruzadaEm pé ↕Deitada ↔
justify-content alinhaNa horizontalNa vertical
align-items alinhaNa verticalNa horizontal
Os itens esticam (por padrão)Na alturaNa largura

Por isso os itens da coluna ocuparam a largura toda: o "esticar" acontece na direção cruzada, que virou a deitada. Veja o efeito no alinhamento, com um align-items: center (aula align-items), que alinha na cruzada:

Experimente: em coluna, o align-items: center centraliza os botões na horizontal. Troque column por row: o mesmo align-items: center passa a alinhar na vertical, e como a caixa não tem altura sobrando, nada parece mudar de altura.

<link rel="stylesheet" href="style.css">
<div class="painel">
  <a class="botao" href="bolos.html">Ver os bolos</a>
  <a class="botao" href="doces.html">Ver os doces</a>
  <a class="botao" href="contato.html">Encomendar</a>
</div>

.painel {
  display: flex;
  flex-direction: column;
  align-items: center;
  padding: 8px;
  background-color: linen;
}

.botao {
  margin: 4px;
  padding: 8px 16px;
  background-color: darkgreen;
  color: white;
}

3. Para que serve a coluna

Se blocos já ficam um embaixo do outro sem CSS nenhum, por que usar flex-direction: column? Porque, com ela, os itens empilhados ganham os poderes do Flexbox:

  • alinhar todos de uma vez (como os botões centralizados acima);
  • espaçar com gap (aula gap);
  • fazer um item crescer para ocupar a altura que sobra (aula Crescer e Encolher);
  • e trocar para linha com uma única declaração, na tela larga (próxima seção).

O cartão de receita da Ana é um caso típico: foto, título e texto empilhados.

Missão: o cartão já tem display: flex, então a foto, o título e o texto estão em linha, e o título e o texto, espremidos, vazam para fora do cartão. Faça a foto, o título e o texto ficarem um embaixo do outro, ainda com Flexbox.

<link rel="stylesheet" href="style.css">
<article class="cartao">
  <img src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura com cobertura de chocolate" width="200" height="150">
  <h2>Bolo de cenoura</h2>
  <p>Fofinho, com cobertura de chocolate. 50 minutos.</p>
</article>

.cartao {
  display: flex;
  width: 220px;
  padding: 10px;
  border: 2px solid peru;
  background-color: linen;
}

.cartao h2,
.cartao p {
  margin: 8px 0 0;
}

  flex-direction: column;
  width: 220px;
  padding: 10px;
  border: 2px solid peru;
  background-color: linen;
}

.cartao p {

4. Coluna no celular, linha no computador

Um uso muito comum: no celular, a tela é estreita e o menu fica melhor em coluna; numa tela larga, em linha. Com uma media query (aula Media Queries), basta trocar o flex-direction:

Experimente: use os botões de largura da barra do quadro (375, 768 e cheia). Em 375 pixels, o menu fica em coluna; a partir de 600 pixels, em linha.

<link rel="stylesheet" href="style.css">
<ul class="menu">
  <li>Início</li>
  <li>Bolos</li>
  <li>Doces</li>
  <li>Contato</li>
</ul>

.menu {
  display: flex;
  flex-direction: column;
  list-style: none;
  padding: 0;
  background-color: navy;
}

.menu li {
  padding: 12px 16px;
  color: white;
}

@media (min-width: 600px) {
  .menu {
    flex-direction: row;
  }
}
flex-direction: column;
O padrão deste menu, pensado para o celular (o jeito Mobile First: primeiro a tela pequena).
@media (min-width: 600px) { … }
"Se a janela tiver pelo menos 600 pixels de largura": aí o menu vira linha. Só o flex-direction muda; o resto continua valendo.

5. O reverse e a ordem do teclado

O row-reverse e o column-reverse mudam só a aparência. A ordem do HTML continua a mesma, e é ela que o teclado e os leitores de tela seguem.

Experimente: clique no resultado e aperte Tab várias vezes. Na tela, a ordem é 3, 2, 1, mas o contorno do foco vai no 1 primeiro, depois no 2 e no 3: da direita para a esquerda.

<link rel="stylesheet" href="style.css">
<nav class="passos">
  <a href="passo1.html">Passo 1</a>
  <a href="passo2.html">Passo 2</a>
  <a href="passo3.html">Passo 3</a>
</nav>

.passos {
  display: flex;
  flex-direction: row-reverse;
}

.passos a {
  margin: 4px;
  padding: 8px 16px;
  background-color: linen;
}
Use o reverse com cuidado

Quem enxerga a tela lê "Passo 3, Passo 2, Passo 1"; quem usa o teclado ou um leitor de tela percorre "Passo 1, Passo 2, Passo 3". Quando a ordem tem significado (passos, datas, um texto), mude a ordem no HTML, e não com reverse. O reverse serve bem quando a ordem não importa para entender a página, como inverter a posição de uma foto e um texto em cartões alternados.

Atalho: flex-flow

O flex-direction tem um parceiro, o flex-wrap (aula Quebrando Linha). Os dois podem ir juntos no atalho flex-flow ("fluxo flex"):

AtalhoÉ o mesmo que
flex-flow: column;flex-direction: column;
flex-flow: row wrap;flex-direction: row; + flex-wrap: wrap;

Escrever as duas propriedades separadas é mais claro para quem está começando; o atalho aparece muito em códigos prontos.

Quando dá errado

Nome inventado: “vertical” is not a “flex-direction” value 
.menu {
  display: flex;
  flex-direction: vertical;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":3.19-3.26: error: CSS: “flex-direction”: “vertical” is not a “flex-direction” value.

O que o leitor vê: o menu continua em linha (o padrão). A declaração foi ignorada e aparece riscada no F12.

Como consertar: os valores são só quatro: row, row-reverse, column e column-reverse. "Vertical" é column.

Sem o display: flex: nada muda 
.menu {
  flex-direction: row;
}

O que o leitor vê: a lista continua em pé, um item por linha.

Por quê: o flex-direction só vale num pai flex. A declaração é válida, então o validador não reclama e o F12 não a risca.

Como consertar: display: flex; no mesmo elemento.

Em coluna, o justify-content: center "não centraliza" 
.painel {
  display: flex;
  flex-direction: column;
  justify-content: center;
}

O que o leitor vê: os itens continuam encostados à esquerda, e esticados na largura toda.

Por quê: em coluna, o justify-content trabalha na vertical (a principal girou, seção 2). E, sem uma altura maior que o conteúdo, não há sobra para dividir em cima e embaixo. Para centralizar na horizontal numa coluna, o certo é o align-items: center.

Referência rápida

Resumo

  • flex-direction vai no pai flex e escolhe a direção principal: row (padrão), row-reverse, column, column-reverse.
  • Numa coluna, as direções giram: justify-content passa a alinhar na vertical, align-items na horizontal, e os itens esticam na largura.
  • A coluna dá aos itens empilhados os poderes do Flexbox (alinhar, gap, crescer) e troca para linha com uma declaração numa media query.
  • O reverse muda só a aparência: o teclado e o leitor de tela seguem o HTML. Para ordens com significado, mude o HTML.
  • Sem display: flex, o flex-direction não faz nada. Valores inventados, como vertical, o validador recusa.
