CSS justify-content

Os itens de um pai flex começam todos encostados à esquerda, e o espaço que sobra fica à direita. Mas e se você quiser os botões no meio? O logo numa ponta e o menu na outra? Os ícones espalhados por igual? Quem decide o que fazer com o espaço que sobra é o justify-content ("justificar o conteúdo", como o "justificado" de um editor de texto). Nesta aula você vai ver os seis valores lado a lado, montar o cabeçalho da lojinha da Ana e a barra de ícones de um celular, e entender quando o justify-content parece não fazer nada.

Você vai aprender
  • A ideia do espaço que sobra na direção principal.
  • Os valores flex-start, flex-end, center, space-between, space-around e space-evenly, lado a lado.
  • O cabeçalho clássico: logo numa ponta, menu na outra.
  • O truque do margin-left: auto para empurrar um item só.
  • O que muda quando o pai está em coluna.
  • Por que, às vezes, nada acontece, e as mensagens reais do validador.

Antes, é bom ter visto Introdução ao Flexbox e Direção (flex-direction). Os resultados são desenhados pelo seu navegador; os números em pixels do texto foram medidos no Chromium. As mensagens do validador saíram do validador W3C (vnu), na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: o espaço que sobra na prateleira

A prateleira tem 1 metro; os três potes, juntos, ocupam 40 centímetros. Sobram 60. A Ana pode deixar os potes juntos num canto e a sobra no outro, juntos no meio com a sobra dividida nas pontas, ou espalhados, com a sobra entre eles. O justify-content é essa decisão: ele não muda o tamanho dos itens, só distribui o espaço que sobra na direção principal (deitada, numa fila em linha).

1. Os valores, lado a lado

Cada caixa tem os mesmos três itens; só muda o justify-content do pai, escrito no alto de cada uma:

  .item { padding: 8px 16px; background-color: firebrick; color: white; border: 1px solid white; }

2. O cabeçalho clássico: logo e menu

Quase todo site tem um cabeçalho com o logo numa ponta e o menu na outra. Com space-between e dois itens, é exatamente isso: o primeiro encosta à esquerda, o último à direita, e o espaço todo fica entre eles.

Missão: no cabeçalho da Lojinha da Ana, deixe o nome à esquerda e o menu à direita, com o espaço que sobra entre os dois.

<link rel="stylesheet" href="style.css">
<header class="topo">
  <strong>Lojinha da Ana</strong>
  <nav>
    <a href="bolos.html">Bolos</a> ·
    <a href="doces.html">Doces</a> ·
    <a href="contato.html">Contato</a>
  </nav>
</header>

.topo {
  display: flex;
  padding: 12px;
  background-color: navy;
  color: white;
}

.topo a {
  color: white;
}

.topo {
  display: flex;
  justify-content: space-between;
  padding: 12px;
  background-color: navy;
  color: white;
}

.topo a {
  color: white;
}

Outra forma: margin-left: auto num item

E se forem três itens (logo, menu e um botão de carrinho), e só o carrinho deve ir para a direita? O space-between espalharia os três. Num item flex, uma margem auto engole todo o espaço que sobra daquele lado. Um margin-left: auto no carrinho o empurra para a ponta direita, e os outros ficam juntos à esquerda:

Experimente: o carrinho foi para a direita sozinho. Mova o margin-left: auto para o .menu e veja o menu e o carrinho irem juntos para a direita.

<link rel="stylesheet" href="style.css">
<header class="topo">
  <strong class="logo">Lojinha da Ana</strong>
  <span class="menu">Bolos · Doces</span>
  <span class="carrinho">Carrinho (2)</span>
</header>

.topo {
  display: flex;
  padding: 12px;
  background-color: navy;
  color: white;
}

.menu {
  margin-left: 24px;
}

.carrinho {
  margin-left: auto;
}

3. Os outros nomes: start, end, left, right

Você vai encontrar também justify-content: start e end. Num Flexbox comum, em linha, eles dão o mesmo resultado que flex-start e flex-end. A diferença aparece com o reverse: o flex-start segue o começo da fila (que, no row-reverse, fica à direita), e o start segue o começo da escrita (à esquerda, em português). Existem ainda left e right. No dia a dia, os flex- são os mais usados em Flexbox, e são os desta aula.

4. Numa coluna, o justify-content é vertical

O justify-content trabalha sempre na direção principal. Com flex-direction: column (aula Direção), a principal é em pé, e ele distribui os itens de cima para baixo. Mas só há sobra para distribuir se o pai for mais alto que os itens: sem uma altura, a coluna fica do tamanho exato do conteúdo, e nada muda.

Experimente: o pai tem 220 px de altura, e o space-between põe o título em cima, o preço embaixo e o texto no meio. Apague o height e veja os três se juntarem em cima: sem sobra, não há o que distribuir.

<link rel="stylesheet" href="style.css">
<article class="cartao">
  <h2>Torta de limão</h2>
  <p>Base crocante e merengue.</p>
  <p class="preco">R$ 60,00</p>
</article>

.cartao {
  display: flex;
  flex-direction: column;
  justify-content: space-between;
  height: 220px;
  width: 220px;
  padding: 0 12px;
  border: 2px solid peru;
  background-color: linen;
}

.preco {
  font-weight: bold;
}

Quando dá errado

Nada muda: não sobra espaço

O que o leitor vê: troca o valor do justify-content, e os itens não se mexem.

Por quê: o justify-content só distribui o espaço que sobra. Se os itens já ocupam a linha toda (porque o texto é longo, ou porque um item tem flex-grow, aula Crescer e Encolher), não há o que distribuir. O mesmo vale para uma coluna sem altura (seção 4).

Como achar: no F12, passe o mouse sobre o pai: o navegador destaca os itens e o espaço livre. Se não houver espaço livre, o problema não é o justify-content.

Esqueceu o display: flex 
.botoes {
  justify-content: center;
}

O que o leitor vê: os botões continuam à esquerda.

Por quê: o justify-content só vale num pai flex (ou grid). A declaração é válida, então o validador não reclama e o F12 não a risca. Para centralizar um texto ou botões em linha sem Flexbox, a propriedade é outra: text-align: center (aula text-align).

Como consertar: display: flex; no mesmo elemento.

Valor escrito errado: “spaced-between” is not a “justify-content” value 
.topo {
  display: flex;
  justify-content: spaced-between;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":3.20-3.33: error: CSS: “justify-content”: “spaced-between” is not a “justify-content” value.

O que o leitor vê: os itens juntos à esquerda (o padrão); a declaração foi ignorada e aparece riscada no F12.

Como consertar: space-between, sem o "d".

“middle” is not a “justify-content” value 
.botoes {
  display: flex;
  justify-content: middle;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":3.20-3.25: error: CSS: “justify-content”: “middle” is not a “justify-content” value.

Como consertar: "meio", em CSS, é center. O middle só existe em outra propriedade, o vertical-align.

Resumo

  • justify-content vai no pai flex e distribui o espaço que sobra na direção principal. Ele não muda o tamanho dos itens.
  • Juntos num lugar: flex-start (padrão), center, flex-end. Espalhados: space-between (pontas encostadas), space-around (meio vão nas pontas), space-evenly (vãos iguais).
  • Logo e menu nas pontas: space-between. Um item só para a direita: margin-left: auto nele.
  • Em coluna, ele distribui de cima para baixo, e só se o pai tiver altura sobrando.
  • Sem display: flex ou sem sobra, nada muda. Valores como spaced-between e middle, o validador recusa.
