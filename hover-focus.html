CSS :hover, :focus e :active

Um botão que muda de cor quando o mouse passa em cima "parece" clicável. Um contorno em volta do link mostra a quem usa o teclado onde ele está. Até agora, cada seletor pegou um elemento sempre do mesmo jeito. Nesta aula você vai estilizar os estados de um elemento: com o mouse em cima, com o foco do teclado, no instante do clique. Tudo isso com as pseudo-classes, a palavra depois dos dois-pontos.

Você vai aprender
  • O que é uma pseudo-classe e como se escreve (a:hover).
  • :hover: o mouse em cima.
  • :focus e :focus-visible: o foco do teclado, e por que ele nunca pode sumir.
  • :active: enquanto o botão está apertado.
  • A ordem das regras e o celular, que não tem mouse.
  • Os erros reais do validador: ::hover, :hoover, espaço depois dos dois-pontos.

Os resultados desta aula são desenhados pelo seu navegador: passe o mouse, clique e use a tecla Tab dentro dos quadros. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: o botão do elevador

O botão do elevador conversa com você. Quando você aproxima o dedo, alguns acendem uma luz fraca. Quando aperta, ele afunda. Depois, fica aceso, mostrando que entendeu. É o mesmo botão, em estados diferentes, e cada estado tem uma aparência.

No CSS, o estado entra no seletor depois de dois-pontos. .botao é "o botão"; .botao:hover é "o botão, enquanto o mouse está em cima dele". Essa palavra depois dos dois-pontos se chama pseudo-classe: funciona como uma classe que o navegador põe e tira sozinho, conforme o que o leitor faz.

1. :hover: o mouse em cima

Experimente: passe o mouse sobre o botão e sobre o link. Depois troque a cor do .botao:hover para crimson.

<link rel="stylesheet" href="style.css">
<p><button class="botao">Comprar bolo</button></p>
<p><a href="#">Ver todas as receitas</a></p>

.botao {
  background-color: #1d4ed8;
  color: white;
  border: none;
  border-radius: 6px;
  padding: 10px 16px;
  font-size: 1rem;
  cursor: pointer;
}

.botao:hover {
  background-color: #1e3a8a;
}

a:hover {
  text-decoration: none;
  background-color: #fef3c7;
}
.botao
O elemento: qualquer seletor serve (classe, elemento, ID).
:
Um só dois-pontos, colado no seletor, sem espaço.
hover
O estado: em inglês, "pairar", o mouse parado em cima.
{ background-color: #1e3a8a; }
Só o que muda no estado. O resto (a cor do texto, o padding) continua vindo da regra .botao.

Com o mouse em cima, o botão passa do azul (#1d4ed8) para um azul mais escuro (#1e3a8a), e o link perde o sublinhado e ganha um fundo amarelo-claro. Tirando o mouse, tudo volta. O cursor: pointer troca a seta pela mãozinha, como num link (aula Cursor e Interação).

Mudança suave

A troca de cor é instantânea. Para ela acontecer devagar, em alguns décimos de segundo, existe o transition (aula Transições).

2. :focus: onde o teclado está

Nem todo mundo usa mouse. Muita gente navega com a tecla Tab, por escolha ou por necessidade (quem não pode usar as mãos com precisão, quem não enxerga e usa leitor de tela, quem só está com pressa). O elemento escolhido pelo Tab está "com o foco", e a pseudo-classe :focus pega esse estado. Links, botões e campos de formulário podem receber o foco.

Sem CSS nenhum, o navegador já desenha um contorno em volta do elemento com foco (o outline, aula Contorno). Com :focus, você troca esse contorno por um que combine com o site:

Experimente: clique no fundo branco do quadro e aperte Tab algumas vezes. O foco passa pelo campo, pelo botão e pelo link, e cada um ganha o contorno laranja.

<link rel="stylesheet" href="style.css">
<p><input type="text" aria-label="Seu nome" placeholder="Seu nome"></p>
<p><button>Enviar</button></p>
<p><a href="#">Ler a receita</a></p>

input:focus,
button:focus,
a:focus {
  outline: 3px solid #f59e0b;
  outline-offset: 2px;
}

O contorno laranja, de 3px, aparece afastado 2px do elemento (o outline-offset), um de cada vez, conforme o Tab avança. O outline é o mais usado para o foco porque não ocupa espaço: o elemento não muda de tamanho nem empurra os vizinhos.

Nunca apague o foco sem pôr outro no lugar

Muita gente acha o contorno do navegador feio e escreve :focus { outline: none; }. Para quem usa mouse, nada muda. Para quem usa teclado, a página fica cega: ele aperta Tab e não sabe mais onde está. É como tirar o cursor do editor de texto. As regras de acessibilidade da web (WCAG) exigem um foco visível. Se não gostou do contorno padrão, troque por outro, como no exemplo acima; nunca por nada.

3. :focus-visible: o foco só para quem precisa

Há um detalhe: em alguns navegadores, clicar num botão com o mouse também dá foco a ele, e o contorno do :focus aparece. Quem clicou com o mouse não precisa do contorno, e muita gente acha que é um defeito. A solução moderna é :focus-visible ("foco visível"): o navegador decide quando o foco precisa aparecer. Em geral:

  • chegou com o Tab: :focus-visible vale, o contorno aparece;
  • clicou num botão ou link com o mouse: :focus vale, mas :focus-visible não, e o contorno não aparece;
  • campo de texto: :focus-visible vale sempre, porque você vai digitar nele.

Experimente: clique no botão com o mouse: não aparece contorno. Agora clique no fundo branco e chegue nele com Tab: o contorno aparece.

<link rel="stylesheet" href="style.css">
<button class="botao">Comprar bolo</button>

.botao {
  background-color: #1d4ed8;
  color: white;
  border: none;
  border-radius: 6px;
  padding: 10px 16px;
  font-size: 1rem;
}

.botao:focus-visible {
  outline: 3px solid #f59e0b;
  outline-offset: 2px;
}
Suporte

:focus-visible funciona em todos os navegadores atuais desde março de 2022 (o Safari foi o último, na versão 15.4), segundo o MDN. Em navegadores mais velhos que isso, a regra inteira é ignorada, e fica o contorno padrão do navegador, que continua visível.

Qual usar

:focusO elemento tem o foco, venha de onde vier (teclado, mouse, toque)Campos de formulário (a borda muda enquanto você digita)
:focus-visibleO elemento tem o foco e o navegador acha que o contorno deve aparecer (em geral, teclado)O contorno de foco de botões e links: a escolha padrão hoje

4. :active: enquanto aperta

:active ("ativo") vale no instante em que o botão do mouse está pressionado sobre o elemento (ou o dedo, na tela de toque). Soltou, acabou. É o "afundar" do botão do elevador:

Experimente: clique no botão e segure: ele escurece mais e desce 2 pixels. Solte e ele volta.

<link rel="stylesheet" href="style.css">
<button class="botao">Comprar bolo</button>

.botao {
  background-color: #1d4ed8;
  color: white;
  border: none;
  border-radius: 6px;
  padding: 10px 16px;
  font-size: 1rem;
  cursor: pointer;
}

.botao:hover {
  background-color: #1e3a8a;
}

.botao:active {
  background-color: #172554;
  transform: translateY(2px);
}

O transform: translateY(2px) empurra o botão 2px para baixo, sem mexer nos vizinhos (aula transform).

A ordem importa

Enquanto você aperta, o mouse também está em cima: :hover e :active valem ao mesmo tempo. As duas regras têm a mesma especificidade (aula Especificidade), e aí vence a que vem depois no código. Por isso, :active vem sempre depois de :hover. Se a ordem for trocada, o :hover cobre o :active e o clique não mostra nada.

Nos links, a ordem completa tem até um apelido em inglês, LVHA ("LoVe HAte", "amor e ódio"): :link (link não visitado), :visited (visitado), :hover, :active. A aula Estilizando Links mostra os quatro.

5. O celular não tem mouse

Na tela de toque, não existe "o dedo parado em cima". Os navegadores de celular costumam aplicar o :hover quando você toca, e ele às vezes fica "grudado" até você tocar em outro lugar. Por isso:

  • use o :hover para enfeitar, nunca para mostrar algo importante (um menu que só abre com o mouse em cima não abre no celular);
  • dê ao :focus-visible um estilo pelo menos tão claro quanto o do :hover: muitas vezes os dois andam juntos (.botao:hover, .botao:focus-visible { … });
  • para aplicar um efeito só em aparelhos com mouse, existe @media (hover: hover) (aula Media Queries).

Quando dá errado

Dois-pontos duplos: Unknown pseudo-element or pseudo-class “::hover” 
.botao::hover {
  background: navy;
}

O que você vê: o botão não muda com o mouse em cima.

Por quê: dois-pontos duplos (::) são para pseudo-elementos, como ::before (aula ::before e ::after). Não existe pseudo-elemento hover, e um seletor inválido faz o navegador ignorar a regra inteira, com tudo o que está dentro das chaves.

$ vnu --css style.css
"file:/home/ana/site/style.css":1.9-1.13: error: CSS: Unknown pseudo-element or pseudo-class “::hover”.

O que significa: "pseudo-elemento ou pseudo-classe desconhecido: ::hover".

Erro de digitação: Unknown pseudo-element or pseudo-class “:hoover” 
$ vnu --css style.css
"file:/home/ana/site/style.css":1.8-1.13: error: CSS: Unknown pseudo-element or pseudo-class “:hoover”

O que significa: a mesma mensagem, para .botao:hoover. A regra inteira é ignorada. Confira a grafia: hover, focus, focus-visible, active.

Espaço depois dos dois-pontos: Parse Error 
.botao: hover {
  background: navy;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":1.9-1.13: error: CSS: Parse Error.

O que significa: "erro de leitura" na coluna 9, onde começa o hover. Os dois-pontos sozinhos, seguidos de espaço, não formam nada que o CSS entenda. A regra inteira é ignorada.

Espaço antes dos dois-pontos: nenhum erro, nenhum efeito 
.botao :hover {
  background: navy;
}

O que você vê: o botão não muda com o mouse em cima.

Por quê: o espaço é o combinador descendente. .botao :hover quer dizer "qualquer elemento dentro do .botao que esteja com o mouse em cima". Um botão só com texto não tem elemento dentro, e a regra não pega ninguém. É um seletor válido, então o validador não reclama.

Como consertar: .botao:hover, tudo junto.

outline: none no foco: a página some para o teclado 
.botao:focus {
  outline: none;
}

O que você vê: com o mouse, nada de diferente. Com o Tab, o foco chega ao botão e não aparece nenhum sinal.

Por quê: a regra é válida, e o validador não reclama. O problema é de acessibilidade: quem navega pelo teclado perde o rumo. A missão final conserta exatamente isso.

Resumo

  • Uma pseudo-classe é um estado que o navegador liga e desliga: seletor:estado, com um dois-pontos colado.
  • :hover: mouse em cima. Use para enfeitar; no celular, não há mouse.
  • :focus: o elemento tem o foco. :focus-visible: o foco que precisa aparecer (teclado), a escolha padrão para o contorno de botões e links.
  • Nunca outline: none no foco sem outro estilo visível no lugar.
  • :active: enquanto aperta. Vem depois do :hover no código (nos links: LVHA).
  • Erros: ::hover e :hoover (Unknown pseudo-element or pseudo-class), : hover (Parse Error): a regra inteira é ignorada. .botao :hover, com espaço, é válido, mas pega os filhos.
