CSS Grid

Com Flexbox, a Ana aprendeu a arrumar itens numa fila: em linha ou em coluna. Mas a galeria de fotos da lojinha pede outra coisa: linhas e colunas ao mesmo tempo, como uma tabela, com as fotos alinhadas de cima a baixo e da esquerda para a direita. Para isso existe o CSS Grid (grid = "grade"): você desenha a grade no pai e os filhos se encaixam nas casas. Esta é a primeira de uma série de aulas sobre Grid.

Você vai aprender
  • O que é uma grade e em que ela é diferente da fila do Flexbox.
  • Como ligar o Grid com display: grid e o que acontece quando você só faz isso.
  • A primeira grade de verdade: três colunas com grid-template-columns.
  • As palavras do Grid: linha, coluna, célula, trilha, linha de grade e área.
  • Como os itens se encaixam sozinhos, casa por casa, e o que acontece quando sobram itens.
  • Grid × Flexbox lado a lado, o Grid no F12 e as mensagens reais do validador W3C.

Antes, é bom ter visto Introdução ao Flexbox e Espaço entre Itens (gap): muita coisa é igual. Os exemplos com resultado são desenhados agora pelo seu navegador. As mensagens do validador saíram do validador W3C (vnu), na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: a forma de gelo

Pense numa forma de gelo, ou numa caixa de ovos. As casas já existem antes de você pôr qualquer coisa: três colunas, quatro linhas. Você despeja a água e ela vai enchendo as casas, uma por uma, na ordem. Se a água acabar, sobram casas vazias. Se sobrar água, ela precisa de mais casas.

O Grid funciona assim. O pai desenha as casas (quantas colunas, de que largura). Os filhos se encaixam nelas, um por casa, da esquerda para a direita e de cima para baixo, como a leitura de um texto. Compare com o Flexbox: lá não existem casas; cada item ocupa o espaço que o seu conteúdo pede, e a fila se ajeita depois. Por isso se diz que o Flexbox é uma dimensão (uma fila) e o Grid é duas (linhas e colunas juntas).

1. Ligando o Grid: display: grid

Como no Flexbox, tudo começa com o display do pai:

.galeria {
  display: grid;
}
.galeria
O pai. Em inglês, grid container, "contêiner da grade". Os filhos diretos viram itens da grade (grid items).
display
A propriedade que diz como o elemento se arruma (aula display).
grid
O valor: "arrume os meus filhos numa grade".

Só com isso, sem dizer quantas colunas, a grade tem uma coluna só, e cada filho ganha uma linha:

<link rel="stylesheet" href="style.css">
<div class="galeria">
  <div class="item">1. Bolo</div>
  <div class="item">2. Torta</div>
  <div class="item">3. Brigadeiro</div>
  <div class="item">4. Pão de mel</div>
</div>

.galeria {
  display: grid;
  gap: 8px;
  border: 2px dashed gray;
}

.item {
  padding: 12px;
  background-color: tomato;
  color: white;
  font-family: sans-serif;
}

Parece igual a quatro div comuns, um embaixo do outro, com a largura toda. A diferença está no gap: ele funciona, porque agora existe uma grade (num bloco comum, ele não faria nada). Para ver o Grid de verdade, falta desenhar as colunas.

2. A primeira grade: três colunas

A propriedade grid-template-columns ("modelo das colunas") desenha as colunas: um valor para cada coluna, separados por espaço.

<link rel="stylesheet" href="style.css">
<div class="galeria">
  <div class="item">1. Bolo</div>
  <div class="item">2. Torta</div>
  <div class="item">3. Brigadeiro</div>
  <div class="item">4. Pão de mel</div>
  <div class="item">5. Cookies</div>
  <div class="item">6. Sonho</div>
  <div class="item">7. Pudim</div>
</div>

.galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 8px;
  border: 2px dashed gray;
}

.item {
  padding: 12px;
  background-color: tomato;
  color: white;
  font-family: sans-serif;
}
grid-template-columns
Desenha as colunas da grade.
1fr 1fr 1fr
Três valores = três colunas. O fr (de fraction, "fração") quer dizer "uma parte do espaço livre". Três colunas de 1fr dividem a largura em três partes iguais. A unidade fr e as outras formas de medir colunas são o assunto da próxima aula, Colunas (grid-template-columns e fr).

Repare no que aconteceu sem você pedir:

  • Os sete itens se encaixaram sozinhos, da esquerda para a direita, três por linha: 1, 2, 3 na primeira; 4, 5, 6 na segunda; 7 na terceira.
  • O navegador criou as linhas que precisava (três), sem você escrever nada sobre linhas. Cada linha tem a altura do seu conteúdo. (Como controlar as linhas é a aula Linhas.)
  • O Pudim, sozinho na última linha, ficou com a mesma largura dos outros, alinhado embaixo do Bolo. As colunas valem para todas as linhas.

Troque o 1fr 1fr 1fr por 1fr 1fr (duas colunas) ou por 1fr 1fr 1fr 1fr (quatro) e veja os itens se reorganizarem.

As próximas aulas usam alguns nomes que vale a pena aprender agora. Todos estão na grade de três colunas da seção 2:

"Linha" quer dizer duas coisas

Em português, "linha" serve para a faixa deitada (row) e para a divisa entre as faixas (grid line). O guia diz "linha" para a faixa e "linha de grade" para a divisa. As linhas de grade são as que você vai usar para dizer "este item vai da linha 1 até a linha 3" (aula Posicionando Itens). Três colunas têm quatro linhas de grade: uma antes de cada coluna e uma depois da última.

4. Grid × Flexbox, lado a lado

Os mesmos cinco itens, com textos de tamanhos diferentes, numa caixa de 320 pixels. Em cima, Flexbox com flex-wrap: wrap; embaixo, Grid com três colunas:

<link rel="stylesheet" href="style.css">
<p>Flexbox (flex-wrap: wrap)</p>
<div class="caixa flex">
  <div class="item">Bolo</div>
  <div class="item">Torta de limão</div>
  <div class="item">Pão</div>
  <div class="item">Brigadeiro</div>
  <div class="item">Sonho</div>
</div>

<p>Grid (3 colunas)</p>
<div class="caixa grade">
  <div class="item">Bolo</div>
  <div class="item">Torta de limão</div>
  <div class="item">Pão</div>
  <div class="item">Brigadeiro</div>
  <div class="item">Sonho</div>
</div>

p {
  font-family: monospace;
}

.caixa {
  width: 320px;
  gap: 8px;
  border: 2px dashed gray;
}

.flex {
  display: flex;
  flex-wrap: wrap;
}

.grade {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}

.item {
  padding: 8px;
  background-color: tomato;
  color: white;
  font-family: sans-serif;
}

No Flexbox, cada item tem a largura do seu texto, e a quebra de linha acontece onde der: os itens da segunda linha não ficam embaixo dos da primeira. No Grid, as colunas mandam: todos os itens têm a mesma largura, e o Brigadeiro fica exatamente embaixo do Bolo. O texto mais comprido ("Torta de limão") quebrou em duas linhas para caber na coluna, e as outras casas da mesma linha ficaram da altura dele.

Use…Quando…Exemplos
FlexboxO conteúdo decide o tamanho; uma direção só (uma fila)Menu, barra de botões, etiquetas, cabeçalho com logo e busca
GridVocê decide as colunas (e as linhas); itens alinhados nas duas direçõesGaleria de fotos, grade de produtos, o layout da página (cabeçalho, lateral, conteúdo, rodapé)
Os dois juntosQuase sempre, num site de verdadeA página é um Grid; dentro do cabeçalho (uma casa do Grid), um Flexbox

A aula Flexbox ou Grid?, no fim desta série, compara os dois com mais calma.

5. O Grid no F12

As linhas de grade não aparecem na página: são invisíveis. Para vê-las, use o F12. No Chrome e no Edge, na aba Elements (Elementos), ao lado de um elemento com display: grid aparece uma etiqueta grid; clicando nela, o navegador desenha por cima da página as linhas de grade, com os números delas. O Firefox tem uma ferramenta parecida, no painel Layout do Inspetor. É o melhor jeito de entender por que um item foi parar numa casa e não em outra.

Quando dá errado

CSS quase nunca mostra mensagem: o navegador ignora em silêncio o que não entende.

As colunas foram parar no item

O que aconteceu: o display: grid e o grid-template-columns foram escritos na regra dos itens (.item), e não na do pai.

O que você vê: os itens continuam um embaixo do outro, com a largura toda. Cada item virou uma grade… do seu próprio conteúdo (o texto), e não há grade nenhuma arrumando os itens.

Como consertar: display: grid e grid-template-columns vão no pai.

Os netos não entram na grade

O que aconteceu: a galeria tem display: grid, mas as fotos estão dentro de um <div class="fotos"> que está dentro da galeria.

O que você vê: uma casa só ocupada (pelo div.fotos), com todas as fotos dentro dela, uma depois da outra. Só os filhos diretos viram itens da grade; os netos, não.

Como consertar: tire o div do meio, ou ponha a grade nele (o .fotos). Existe ainda o subgrid, para grades dentro de grades (aula Subgrid).

error: CSS: “grid-template-column”: Property “grid-template-column” doesn't exist.

O que aconteceu: o nome da propriedade sem o s do fim, ou um nome inventado (grid-columns).

$ vnu --css singular.css
"file:/home/ana/grade/singular.css":3.29-3.31: error: CSS: “grid-template-column”: Property “grid-template-column” doesn't exist.
$ vnu --css gridcolumns.css
"file:/home/ana/grade/gridcolumns.css":3.17-3.17: error: CSS: “grid-columns”: Property “grid-columns” doesn't exist.

"A propriedade não existe." O navegador ignora a linha: a grade fica com uma coluna só. No F12, a declaração aparece riscada, com um ícone de aviso.

Como consertar: grid-template-columns, no plural.

error: CSS: “grid-template-columns”: only “0” can be a “unit”. You must put a unit after your number.

O que aconteceu: a Ana escreveu o número de colunas, grid-template-columns: 3;, como quem diz "quero três".

$ vnu --css tres.css
"file:/home/ana/grade/tres.css":3.26-3.26: error: CSS: “grid-template-columns”: only “0” can be a “unit”. You must put a unit after your number.

"Só o 0 pode ficar sem unidade. Você precisa pôr uma unidade depois do número." O grid-template-columns não recebe "quantas colunas", e sim a largura de cada uma. A declaração é ignorada.

Como consertar: uma largura por coluna: 1fr 1fr 1fr. (Para não repetir, existe o repeat(3, 1fr), aula repeat, minmax e auto-fit.)

error: CSS: “grid-template-columns”: “,” is an incorrect operator.

O que aconteceu: as colunas separadas por vírgula: 1fr, 1fr, 1fr.

$ vnu --css virgula.css
"file:/home/ana/grade/virgula.css":3.36-3.38: error: CSS: “grid-template-columns”: “,” is an incorrect operator.

"A vírgula é um operador incorreto (aqui)." Os valores são separados por espaço. A declaração inteira é ignorada: uma coluna só.

Como consertar: grid-template-columns: 1fr 1fr 1fr;.

error: CSS: “display”: “grids” is not a “display” value. 
$ vnu --css grids.css
"file:/home/ana/grade/grids.css":2.12-2.16: error: CSS: “display”: “grids” is not a “display” value.

Um s a mais, e não existe grade nenhuma: os itens ficam um embaixo do outro, e o grid-template-columns e o gap da mesma regra ficam sem efeito (não dão erro: só não têm o que arrumar).

Como consertar: display: grid;.

Resumo

  • O Grid arruma os filhos em linhas e colunas ao mesmo tempo (duas dimensões); o Flexbox, numa fila (uma dimensão).
  • display: grid no pai; os filhos diretos viram itens. Sem colunas definidas, é uma coluna só.
  • grid-template-columns recebe uma largura por coluna, separadas por espaço: 1fr 1fr 1fr são três colunas iguais.
  • Os itens se encaixam sozinhos, casa por casa; as linhas são criadas conforme a necessidade.
  • As palavras: trilha (linha ou coluna), célula (uma casa), linha de grade (a divisa numerada), área (um retângulo de casas).
  • No F12, a etiqueta grid desenha as linhas de grade por cima da página.
