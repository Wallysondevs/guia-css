CSS ::before e ::after

Toda dica do blog da Ana começa com a palavra "Dica:" em negrito, e todo título tem um risquinho laranja embaixo. Ela pode escrever isso no HTML de cada página, uma por uma. Ou pode deixar o CSS pôr esses enfeites sozinho, em todas as páginas de uma vez. Nesta aula você vai criar conteúdo pelo CSS, antes e depois do conteúdo de um elemento, com os pseudo-elementos ::before e ::after.

Você vai aprender
  • O que é um pseudo-elemento e por que tem dois-pontos duplos.
  • ::before e ::after com a propriedade content, que é obrigatória.
  • Textos, símbolos e o texto de um atributo (attr()) como conteúdo.
  • Enfeites com content: "": um risco, uma bolinha.
  • O que não colocar ali (acessibilidade) e em quais elementos não funciona.
  • Os erros reais do validador: content sem aspas, aspas sem fechar, ::befor.

Os resultados desta aula são desenhados pelo seu navegador. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: o adesivo na caixa

Pense numa caixa de presente. O conteúdo é o presente. Mas você pode colar um adesivo na frente ("Frágil!") e um laço atrás. O adesivo e o laço não são o presente, e quem embrulhou pode trocá-los sem abrir a caixa.

::before ("antes") e ::after ("depois") são esses adesivos. Eles criam um pedacinho novo dentro do elemento, logo antes ou logo depois do conteúdo dele. Esse pedacinho não existe no HTML: só no CSS. Por isso se chama pseudo-elemento, um "elemento de mentira".

Um dois-pontos ou dois?

Pseudo-classe (um estado: :hover, :first-child) tem um dois-pontos. Pseudo-elemento (um pedaço novo: ::before, ::after) tem dois. Sites antigos escrevem :before, com um só, e ainda funciona em todos os navegadores (é a escrita do CSS de antes de 2011). Escreva o novo, com dois.

1. ::before: antes do conteúdo

Experimente: troque o texto do content por "Atenção: ". Depois tente selecionar o "Dica:" com o mouse no resultado.

<link rel="stylesheet" href="style.css">
<p class="dica">Peneire a farinha para o bolo crescer mais.</p>
<p class="dica">Unte a forma com manteiga e farinha.</p>
<p>Asse por 40 minutos.</p>

.dica::before {
  content: "Dica: ";
  font-weight: bold;
  color: #9a3412;
}
.dica
O elemento que recebe o adesivo: os parágrafos com a classe dica.
::before
Dois-pontos duplos, colados. Cria o pedaço antes do conteúdo, ainda dentro do <p>.
content: "Dica: ";
O que vai no pedaço, entre aspas. Sem content, o pseudo-elemento não existe. Repare no espaço depois dos dois-pontos, dentro das aspas: é ele que separa "Dica:" do texto.
font-weight, color
O pedaço aceita CSS como qualquer elemento: negrito, cor, tamanho, fundo, borda.

Os dois parágrafos com class="dica" começam com "Dica:" em negrito e laranja-escuro; o terceiro, sem a classe, não. O "Dica:" não dá para selecionar com o mouse nem copiar: ele não está no texto da página, só no desenho.

No F12, aba de elementos, o pedaço aparece como uma linha ::before dentro do <p>, antes do texto. Clicando nela, você vê as regras dele.

Missão: ponha uma estrela e um espaço ("★ ") antes de cada receita com a classe destaque. Copie a estrela daqui: ★

<link rel="stylesheet" href="style.css">
<ul>
  <li class="destaque">Bolo de cenoura</li>
  <li>Pão de queijo</li>
  <li class="destaque">Pudim de leite</li>
</ul>

.destaque {
  font-weight: bold;
}

.destaque {
  font-weight: bold;
}

.destaque::before {
  content: "★ ";
  color: #ca8a04;
}

2. ::after: depois do conteúdo

::after é igual, do outro lado. Um uso clássico: avisar que um link leva para fora do site.

Experimente: só o link para outro site ganha a seta. Troque a seta por " (outro site)".

<link rel="stylesheet" href="style.css">
<p><a href="receitas.html">Minhas receitas</a></p>
<p><a href="https://example.com" class="externo">Receitas do mundo</a></p>

.externo::after {
  content: " ↗";
}

"Receitas do mundo" termina com uma seta inclinada (↗), que faz parte do link: ela fica sublinhada e é clicável junto com o texto. O link de dentro do site fica sem.

O texto de um atributo: attr()

O content também pode mostrar o valor de um atributo do elemento, com a função attr(). Na versão para imprimir da página, por exemplo, é útil escrever o endereço do link depois dele, já que no papel não dá para clicar (aula CSS para Impressão):

<style>
  a::after {
    content: " (" attr(href) ")";
    color: #555;
  }
</style>
<p>Veja o <a href="https://example.com">site de exemplo</a>.</p>

Depois do texto do link aparece, em cinza, "(https://example.com)", também sublinhado: o pedaço está dentro do <a>, então faz parte do link. O content junta os pedaços em ordem, sem vírgula: o texto " (", o valor do href e o texto ")".

3. Enfeites: content: ""

Com content: "" (aspas vazias), o pseudo-elemento existe, mas sem texto. Dando a ele tamanho e cor, ele vira um enfeite: um risco, uma bolinha, uma faixa. Como ele começa como um elemento em linha, para ter largura e altura ele precisa de display: block (ou inline-block, aula display):

Experimente: mude o width do risco para 100%. Depois apague a linha do display: block: o risco some, porque um pedaço em linha e sem texto não tem largura nem altura.

<link rel="stylesheet" href="style.css">
<h2>Bolo de cenoura</h2>
<p>A receita mais pedida do blog.</p>

h2::after {
  content: "";
  display: block;
  width: 60px;
  height: 4px;
  margin-top: 6px;
  background-color: #ea580c;
}

Embaixo de "Bolo de cenoura" aparece um risco laranja, curto (60px) e grosso (4px), afastado 6px do texto. Ele está dentro do <h2>, depois do texto: por isso fica embaixo do título, e não embaixo do parágrafo.

4. O que pode ir no content

EscritaMostra
content: "Dica: ";Um texto (sempre entre aspas)
content: "★";, content: "→";Um símbolo ou um emoji (o arquivo precisa estar em UTF-8, como todo o guia)
content: "";Nada: o pedaço existe, para ser um enfeite com tamanho e cor
content: attr(href);O valor de um atributo do elemento
content: " (" attr(href) ")";Vários pedaços juntos, separados por espaço
content: "\201C";Um caractere pelo código (aqui, a aspa curva “)
content: counter(passo);Um número que o CSS conta sozinho (os contadores, assunto avançado)

5. Cuidados

Nada importante no content

  • O texto do ::before não pode ser selecionado nem copiado, e não é encontrado pelo Ctrl+F em todos os navegadores.
  • Leitores de tela tratam esse texto de jeitos diferentes: muitos leem, alguns não. Um "★" pode ser lido pelo nome do símbolo, no meio da frase.
  • Se o CSS não carregar, o texto some.

A regra: enfeite no CSS, informação no HTML. "Dica:", uma seta, um risco: ok no CSS. O preço do bolo ou um aviso de "esgotado": no HTML.

Elementos que não têm ::before

O pedaço vai dentro do elemento, antes ou depois do conteúdo. Elementos que não têm conteúdo, como <img>, <input> e <br>, não mostram ::before nem ::after. Para enfeitar uma imagem, ponha o pseudo-elemento num elemento em volta dela (um <figure>, por exemplo).

Quando dá errado

Esqueceu o content: nada aparece 
h2::after {
  display: block;
  width: 60px;
  height: 4px;
  background-color: #ea580c;
}

O que você vê: o título sem o risco.

Por quê: sem content, o ::before e o ::after não são criados, e as outras propriedades não têm onde agir. No F12, o valor calculado do content é none. O validador não reclama: todas as declarações são válidas.

Como consertar: content: ""; sempre, mesmo quando o pedaço não tem texto.

Texto sem aspas: “Dica” is not a “content” value 
.dica::before {
  content: Dica;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":2.12-2.15: error: CSS: “content”: “Dica” is not a “content” value.

O que significa: "Dica não é um valor de content". Sem aspas, o CSS não sabe que é um texto. A declaração é ignorada e nada aparece. O certo é content: "Dica: ";.

Aspas sem fechar: “content”: Parse Error 
.dica::before {
  content: "Dica: ;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":2.20-2.20: error: CSS: “content”: Parse Error.

O que significa: "erro de leitura" no fim da linha 2. A aspa aberta não foi fechada; o ; ficou dentro do texto, e o texto acabou no fim da linha. A declaração é ignorada. Confira se cada " tem o seu par.

Nome errado: Unknown pseudo-element or pseudo-class “::befor” 
$ vnu --css style.css
"file:/home/ana/site/style.css":1.8-1.12: error: CSS: Unknown pseudo-element or pseudo-class “::befor”.

O que significa: "pseudo-elemento ou pseudo-classe desconhecido: ::befor", faltou o e. Com um seletor inválido, a regra inteira é ignorada.

Esqueceu o espaço: "Dica:Peneire"

O que você vê: com content: "Dica:";, o texto aparece grudado: "Dica:Peneire a farinha…".

Por quê: o pseudo-elemento fica colado no conteúdo. O espaço tem de estar dentro das aspas: "Dica: ". (No ::after, o espaço vai no começo: " ↗".)

::before numa imagem

O que você vê: com img::before { content: "Foto: "; }, nada aparece.

Por quê: a imagem não tem "conteúdo de dentro" para o pedaço ficar antes. O validador não reclama: o seletor é válido.

Resumo

  • ::before e ::after criam um pedaço dentro do elemento, antes ou depois do conteúdo. São pseudo-elementos: dois-pontos duplos.
  • content é obrigatório: um texto entre aspas, attr(…), ou "" para um enfeite (que precisa de display: block e tamanho).
  • O pedaço aceita qualquer CSS: cor, negrito, fundo, borda.
  • Enfeite no CSS, informação no HTML: o texto do content não se copia, e os leitores de tela o tratam de jeitos diferentes.
  • img, input e br não têm ::before/::after.
  • Erros: sem content, nada aparece (sem aviso); content sem aspas, aspas sem fechar e ::befor o validador pega.
