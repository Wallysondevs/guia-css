CSS border

A border ("borda") é a linha em volta da caixa: a moldura do quadro. Com ela, a Ana destaca um aviso, separa os itens do cardápio, sublinha um título com uma faixa grossa ou desenha uma caixa tracejada de "recorte este cupom". Nesta aula você vai conhecer as três partes de uma borda, ver todos os estilos lado a lado e entender o erro mais comum de todos: a borda que não aparece porque faltou o estilo.

Você vai aprender
  • As três partes de uma borda: espessura (border-width), estilo (border-style) e cor (border-color).
  • Todos os valores de border-style: solid, dashed, dotted, double e os outros.
  • O atalho border, que junta as três partes numa linha.
  • Bordas num lado só: border-top, border-bottom, border-left, border-right.
  • Como a borda aumenta o tamanho da caixa.
  • Os erros reais: a borda sem estilo (que o validador não acusa), valores demais, número sem unidade, espessura negativa.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a moldura do quadro

Numa loja de molduras, o vendedor pergunta três coisas: qual a largura da moldura (fininha ou larga), qual o modelo (lisa, entalhada, dupla) e qual a cor. Sem escolher o modelo, não há moldura para fazer.

A borda do CSS é igual: tem uma espessura, um estilo e uma cor. E, como na loja, o estilo é obrigatório: sem ele, não há borda.

Na molduraNo CSSValor inicial
A largura da madeiraborder-width (espessura)medium (3px)
O modeloborder-style (estilo)none: nenhuma borda
A corborder-color (cor)a cor do texto do elemento

A borda fica entre o padding (o espaço de dentro) e a margin (o espaço de fora). O desenho completo está na aula O Modelo de Caixa.

1. A primeira borda

<style>
  .aviso {
    border-width: 3px;
    border-style: solid;
    border-color: crimson;
    padding: 12px;
  }
</style>
<p class="aviso">A lojinha fecha no feriado.</p>
border-width: 3px;
A espessura da linha: 3 pixels. Width = "largura".
border-style: solid;
O estilo: uma linha contínua. Solid = "sólido". É esta declaração que faz a borda existir.
border-color: crimson;
A cor da linha, com qualquer cor do CSS (aula Cores).
padding: 12px;
Não é da borda, mas quase sempre anda junto: afasta o texto da linha (aula padding).

Repare: a linha vermelha vai de ponta a ponta da página, porque o <p> é um bloco e ocupa toda a largura disponível. A borda contorna a caixa, não só as palavras.

2. Os estilos: border-style

Cada caixa abaixo usa um valor de border-style, com a mesma espessura (6px) e a mesma cor. O nome do estilo está escrito dentro:

<style>
  .estilo {
    display: inline-block;
    width: 110px;
    padding: 14px 4px;
    margin: 6px;
    text-align: center;
    font-family: monospace;
    border-width: 6px;
    border-color: teal;
    background-color: azure;
  }
</style>
<div class="estilo" style="border-style: none">none</div>
<div class="estilo" style="border-style: hidden">hidden</div>
<div class="estilo" style="border-style: solid">solid</div>
<div class="estilo" style="border-style: dashed">dashed</div>
<div class="estilo" style="border-style: dotted">dotted</div>
<div class="estilo" style="border-style: double">double</div>
<div class="estilo" style="border-style: groove">groove</div>
<div class="estilo" style="border-style: ridge">ridge</div>
<div class="estilo" style="border-style: inset">inset</div>
<div class="estilo" style="border-style: outset">outset</div>

3. A espessura: border-width

A espessura aceita um tamanho (1px, 0.25rem…) ou uma de três palavras:

<style>
  .linha {
    display: inline-block;
    padding: 10px;
    margin: 6px;
    font-family: monospace;
    border-style: solid;
    border-color: darkslateblue;
  }
</style>
<div class="linha" style="border-width: thin">thin</div>
<div class="linha" style="border-width: medium">medium</div>
<div class="linha" style="border-width: thick">thick</div>
<div class="linha" style="border-width: 10px">10px</div>
PalavraTraduçãoCalculado (F12, aba Computed)
thinfina1px
mediummédia (o valor inicial)3px
thickgrossa5px

A especificação do CSS não fixa esses números; os navegadores atuais usam 1, 3 e 5 pixels. Se o tamanho exato importa para o seu desenho, escreva em px.

4. A cor: border-color

Se você não der cor, a borda usa a cor do texto do próprio elemento (o valor currentColor, "a cor atual"). Um elemento de texto azul-marinho ganha borda azul-marinho:

<style>
  .selo {
    display: inline-block;
    color: navy;
    border-style: solid;
    border-width: 2px;
    padding: 4px 10px;
  }
  .verde { color: darkgreen; }
</style>
<span class="selo">Sem glúten</span>
<span class="selo verde">Vegano</span>

Sem nenhum border-color, a primeira borda saiu azul-marinho e a segunda verde, iguais ao texto. Trocar o color troca as duas coisas de uma vez, o que é bem prático em botões e etiquetas.

5. O atalho border

Escrever três propriedades para cada borda cansa. O atalho border junta espessura, estilo e cor numa linha, separados por espaço:

<style>
  .cupom {
    border: 3px dashed darkorange;
    padding: 16px;
    max-width: 300px;
  }
</style>
<div class="cupom">Cupom: 10% de desconto no bolo de cenoura. Recorte aqui.</div>
border:
O atalho das três partes, para os quatro lados.
3px
A espessura.
dashed
O estilo. É a única parte obrigatória.
darkorange
A cor.
  • A ordem é livre: border: dashed darkorange 3px; também funciona. O costume é espessura, estilo e cor, e é assim que o guia escreve.
  • O que falta volta ao valor inicial: border: dashed; dá uma borda tracejada de 3px (medium) na cor do texto.
  • Um valor de cada tipo: o atalho não aceita duas cores nem dois estilos (veja Quando dá errado).
O atalho não aparece no calculado

No F12, na aba Computed, você não acha "border: 3px dashed darkorange". O navegador guarda cada parte de cada lado separada: border-top-width: 3px, border-top-style: dashed, border-top-color: rgb(255, 140, 0), e o mesmo para right, bottom e left. São doze propriedades longas.

Missão: o aviso de encomendas precisa chamar atenção. Dê a ele uma borda de 3px, tracejada (dashed), na cor crimson, usando o atalho border.

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p class="aviso">Encomendas de bolo só até quinta-feira.</p>

.aviso {
  padding: 12px;
}

.aviso {
  padding: 12px;
  border: 3px dashed crimson;
}

Depois de cumprir, experimente trocar dashed por dotted e por double, e a espessura por 8px.

6. Um lado só

Cada lado tem o próprio atalho: border-top (em cima), border-right (à direita), border-bottom (embaixo) e border-left (à esquerda). Eles aceitam as mesmas três partes:

<style>
  h2 {
    border-bottom: 4px solid tomato;
    padding-bottom: 4px;
  }
  .dica {
    border-left: 6px solid seagreen;
    background-color: honeydew;
    padding: 8px 12px;
  }
  .item {
    border-top: 1px dotted gray;
    padding: 6px 0;
    margin: 0;
  }
</style>
<h2>Bolo de cenoura</h2>
<p class="dica">Dica: peneire o açúcar da cobertura.</p>
<p class="item">Bolo de cenoura: R$ 35</p>
<p class="item">Pão de queijo: R$ 2</p>
<p class="item">Brigadeiro: R$ 3</p>

Três usos que você vai ver em muitos sites: o título "sublinhado" por uma faixa (border-bottom), a caixa de dica com uma barra colorida à esquerda (border-left) e a lista com uma linha fina separando os itens (border-top).

Uma parte de um lado

Dá para ir mais fundo e mudar só uma parte de um lado, com as propriedades longas: border-top-color, border-left-width, border-bottom-style… São 12 combinações (4 lados × 3 partes). O jeito mais comum de usá-las é fazer a borda geral e depois ajustar um detalhe:

<style>
  .cartao {
    border: 2px solid lightgray;
    border-top-color: purple;
    border-top-width: 6px;
    padding: 12px;
    max-width: 260px;
  }
</style>
<div class="cartao">Brigadeiro gourmet: R$ 4</div>

Vários valores por lado

border-width, border-style e border-color também aceitam de 1 a 4 valores, na regra do relógio (cima, direita, baixo, esquerda), como o padding:

<style>
  .relogio {
    border-style: solid dashed dotted double;
    border-width: 6px;
    border-color: red green blue orange;
    padding: 16px;
    max-width: 260px;
    font-family: monospace;
  }
</style>
<div class="relogio">cima: red solid · direita: green dashed · baixo: blue dotted · esquerda: orange double</div>

7. A borda aumenta a caixa

Como o padding, a borda é somada por fora da largura (width), no comportamento padrão:

<style>
  .caixa {
    width: 200px;
    background-color: lightcyan;
    margin-bottom: 8px;
    border: 1px solid teal;
  }
  .grossa { border-width: 20px; }
</style>
<div class="caixa">width: 200px, borda 1px</div>
<div class="caixa grossa">width: 200px, borda 20px</div>

A segunda caixa ocupa 240px de largura (200 + 20 + 20), contra 202px da primeira. Isso também explica um tremor clássico: um botão que ganha borda só no :hover cresce e empurra os vizinhos. Os consertos são o box-sizing: border-box (aula box-sizing), deixar uma borda transparent desde o começo e só trocar a cor, ou usar o outline, que não ocupa espaço (aula outline).

8. Formas de escrever e qual usar

EscritaQuando usar
border: 1px solid #ccc;A mesma borda nos quatro lados. É o caso de 9 em cada 10 bordas.
border-bottom: 2px solid tomato;Um lado só: títulos, separadores, abas.
border: 2px solid gray; + border-top-color: purple;Uma borda geral com um detalhe diferente. Escreva o atalho antes do ajuste.
border-color: red green blue orange;Cada lado de um jeito, numa linha (regra do relógio).
border: none; ou border: 0;Tirar a borda (de um <input>, de um <button>). none zera o estilo; 0, a espessura. Os dois somem com a borda.
border: 2px solid transparent;Reservar o espaço de uma borda que só vai aparecer depois (no :hover, por exemplo), sem a caixa mudar de tamanho.

Quando dá errado

Lembre: o CSS não mostra mensagens de erro na página. Uma declaração inválida é ignorada inteira, e o F12 a mostra riscada no painel de estilos (aula DevTools).

Esqueceu o estilo: a borda não aparece (e o validador não reclama) 
<style>
  .aviso {
    border: 2px red;
    padding: 12px;
  }
</style>
<p class="aviso">Cadê a minha borda vermelha?</p>

O que você vê: o texto, sem borda nenhuma.

Por quê: a declaração é válida: o atalho aceita que falte uma parte. Só que a parte que faltou foi o estilo, que volta ao valor inicial, none. Sem estilo, não há borda. No F12, na aba Computed, aparece border-top-style: none e até border-top-width: 0px: com estilo none, o navegador zera a espessura, mesmo você tendo escrito 2px.

$ cat sem-estilo.css
.aviso {
  border: 2px red;
}
$ vnu --css sem-estilo.css
$

O que o validador diz: nada. Para ele, é CSS correto.

Como consertar: sempre ponha o estilo: border: 2px solid red;.

Missão: a Ana quer uma borda de 4px azul-marinho em volta do destaque, mas nada aparece. Conserte a declaração.

<link rel="stylesheet" href="style.css">
<p class="destaque">Receita da semana: torta de limão.</p>

.destaque {
  border: 4px navy;
  padding: 12px;
}

.destaque {
  border: 4px solid navy;
  padding: 12px;
}
Duas cores no atalho: Too many values or values are not recognized 
$ cat duas-cores.css
.aviso {
  border: 2px solid red blue;
}
$ vnu --css duas-cores.css
"file:/home/ana/site/duas-cores.css":2.25-2.28: error: CSS: “border”: Too many values or values are not recognized.

O que você vê: nenhuma borda. O navegador não usa "o que deu para entender": joga fora a declaração inteira.

O que significa: "valores demais ou valores não reconhecidos". O atalho border aceita uma cor, que vale para os quatro lados.

Como consertar: para cores diferentes por lado, use border-color: red blue; depois do atalho.

Número sem unidade: You must put a unit after your number 
$ vnu --css sem-unidade.css
"file:/home/ana/site/sem-unidade.css":2.19-2.21: error: CSS: “border”: only “0” can be a “unit”. You must put a unit after your number.

Em border: 2 solid red;, o 2 está sem unidade: "só o 0 pode ficar sem unidade". A declaração toda é ignorada. Conserto: border: 2px solid red;.

Espessura negativa ou estilo inventado 
$ vnu --css negativa.css
"file:/home/ana/site/negativa.css":2.18-2.20: error: CSS: “border-width”: “-2px” negative values are not allowed.
$ vnu --css estilo-pt.css
"file:/home/ana/site/estilo-pt.css":2.17-2.25: error: CSS: “border-style”: “tracejado” is not a “border-style” value.

"Valores negativos não são permitidos" na espessura; e "tracejado não é um valor de border-style": os valores do CSS são palavras em inglês, sempre (dashed). Nos dois casos, o navegador ignora a declaração.

Resumo

  • Uma borda tem três partes: espessura (border-width), estilo (border-style) e cor (border-color).
  • O estilo é obrigatório: o inicial é none. border: 2px red; não desenha nada, e o validador não avisa.
  • Estilos: solid, dashed, dotted, double são os do dia a dia; groove, ridge, inset, outset fazem relevo; none e hidden escondem.
  • Sem cor, a borda usa a cor do texto (currentColor). Sem espessura, medium (3px).
  • Atalho: border: 3px dashed crimson;. Um lado: border-bottom, border-left… Uma parte de um lado: border-top-color… No F12 (Computed), só aparecem as propriedades longas.
  • A borda soma à largura, como o padding (o conserto é o box-sizing: border-box).
  • Erros: duas cores no atalho, número sem unidade, espessura negativa, estilo em português. Em todos, a declaração inteira é ignorada.
