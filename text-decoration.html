CSS text-decoration

O sublinhado dos links, o preço antigo riscado numa promoção, uma linha ondulada embaixo de um título: tudo isso é text-decoration, "decoração do texto". São linhas que o navegador desenha junto com as letras. Nesta aula você vai ver cada tipo de linha lado a lado, escolher a cor, o estilo e a grossura, tirar o sublinhado de um menu sem deixar os links escondidos e entender por que, às vezes, um none não tira a linha.

Você vai aprender
  • Os quatro tipos de linha: underline, overline, line-through e none.
  • As propriedades longas: text-decoration-line, -color, -style e -thickness, e o atalho text-decoration.
  • Como afastar o sublinhado das letras com text-underline-offset.
  • Quando tirar o sublinhado dos links, e quando não tirar.
  • A diferença entre riscar com CSS e usar o <del> do HTML.
  • Os erros comuns: valor inventado (com a mensagem do validador W3C) e o none num filho que não apaga a linha do pai.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a caneta e a régua

Imagine que você tem um texto impresso, uma caneta e uma régua. Você pode passar uma linha embaixo das palavras (sublinhar), em cima delas ou no meio, riscando. Pode trocar a cor da caneta, fazer a linha mais grossa, pontilhada ou ondulada. Em nenhum caso as letras mudam: a linha é um enfeite por cima delas.

O text-decoration é essa caneta. Ele não muda a fonte, o tamanho nem a cor das letras: só desenha linhas.

1. Os tipos de linha, lado a lado

<style>
  .embaixo { text-decoration: underline; }
  .em-cima { text-decoration: overline; }
  .riscado { text-decoration: line-through; }
  .duas { text-decoration: underline overline; }
</style>
<p class="embaixo">underline: sublinhado</p>
<p class="em-cima">overline: linha em cima</p>
<p class="riscado">line-through: riscado</p>
<p class="duas">underline overline: as duas</p>

text-decoration
A propriedade: "decoração do texto", as linhas desenhadas junto com as letras.
underline
O valor: "sublinhado", a linha under ("embaixo de") as letras.

O valor inicial é none. Quem já nasce com linha são alguns elementos do HTML, por causa do estilo padrão do navegador: o link <a href> e o <ins> (inserido) vêm sublinhados; o <del> (apagado) e o <s> vêm riscados.

2. O estilo da linha: text-decoration-style

A linha pode ser contínua, dupla, pontilhada, tracejada ou ondulada. Para mudar só o estilo, existe uma propriedade própria:

<style>
  p {
    text-decoration-line: underline;
  }
  .solid { text-decoration-style: solid; }
  .double { text-decoration-style: double; }
  .dotted { text-decoration-style: dotted; }
  .dashed { text-decoration-style: dashed; }
  .wavy { text-decoration-style: wavy; }
</style>
<p class="solid">solid: contínua (o padrão)</p>
<p class="double">double: dupla</p>
<p class="dotted">dotted: pontilhada</p>
<p class="dashed">dashed: tracejada</p>
<p class="wavy">wavy: ondulada</p>

Repare que a regra do p usa text-decoration-line: é a propriedade "longa" que escolhe só o tipo de linha. O text-decoration da seção 1 é um atalho que junta várias propriedades longas numa só.

3. Cor, grossura e distância

Mais três propriedades completam a caneta:

PropriedadeO que mudaValor inicial
text-decoration-colorA cor da linhacurrentColor: a mesma cor das letras
text-decoration-thicknessA grossura da linha (2px, 0.1em)auto: o navegador escolhe
text-underline-offsetA distância entre o sublinhado e as letras (só vale para underline)auto
<style>
  .caprichado {
    text-decoration-color: tomato;
    text-decoration-thickness: 3px;
    text-underline-offset: 6px;
  }
</style>
<p><a href="#">Link normal</a></p>
<p><a class="caprichado" href="#">Link caprichado</a></p>

O segundo link continua azul, mas o sublinhado ficou cor de tomate, mais grosso e mais afastado das letras, passando abaixo da "perna" do p. Não foi preciso escrever underline: o link já vem sublinhado do navegador, e as três propriedades só mudam a linha que existe.

O atalho com tudo junto

O atalho text-decoration aceita o tipo, o estilo, a cor e a grossura numa só declaração, em qualquer ordem:

<style>
  h2 {
    text-decoration: underline wavy tomato 2px;
  }
</style>
<h2>Bolo de cenoura</h2>

Na aba Computed (Calculado) do F12, o atalho se desdobra nas propriedades longas: text-decoration-line: underline, text-decoration-style: wavy, text-decoration-color: rgb(255, 99, 71) (o tomato virou números) e text-decoration-thickness: 2px. O text-underline-offset não entra no atalho: ele sempre vai separado.

Suporte nos navegadores

As propriedades longas (text-decoration-line, -style, -color, -thickness) e o text-underline-offset funcionam em todos os navegadores atuais, inclusive no Safari desde a versão 12.1. Já o atalho com estilo, cor e grossura (text-decoration: underline wavy tomato 2px) só chegou ao Safari na versão 26.2, no fim de 2025 (dados do MDN). Num Safari mais velho, prefira as propriedades longas, ou use o atalho só com o tipo de linha.

FormaQuando usar
text-decoration: underline;Só pôr ou tirar a linha. Funciona em qualquer navegador
text-decoration: underline wavy tomato 2px;Tudo de uma vez, em navegadores atuais
As propriedades longas, uma por linhaMudar só um detalhe (a cor, a grossura) de uma linha que já existe, como o sublinhado dos links

4. Tirar o sublinhado dos links: quando pode

O pedido mais comum é a { text-decoration: none; }. Ele funciona, mas cuidado: o sublinhado é o jeito de o leitor saber que aquilo é um link. Só a cor azul não basta, porque muita gente não distingue cores (daltonismo) e a regra de acessibilidade (WCAG) pede que o link não se diferencie do texto só pela cor.

Onde está o linkPode tirar o sublinhado?
No meio de um parágrafoNão. Deixe sublinhado; se quiser, mude a cor, a grossura e a distância da linha
Num menu de navegação, com cara de menuSim: o lugar e o formato já dizem que é clicável
Num link com cara de botão (fundo, borda)Sim: a caixa avisa que é clicável

Um meio-termo muito usado é tirar o sublinhado do menu e devolvê-lo quando o mouse passa por cima, com :hover (aula Estados: :hover, :focus e :active):

Experimente: passe o mouse sobre os itens do menu. Depois troque o text-decoration-style para wavy ou dotted.

<link rel="stylesheet" href="style.css">
<nav>
  <a href="#">Início</a> ·
  <a href="#">Receitas</a> ·
  <a href="#">Contato</a>
</nav>
<p>Veja a <a href="#">receita do bolo de fubá</a>, a favorita da casa.</p>

nav a {
  text-decoration: none;
}

nav a:hover {
  text-decoration-line: underline;
  text-decoration-style: solid;
}

O link do parágrafo continuou sublinhado: a regra só vale para os links dentro do nav.

5. Riscar com CSS ou com <del>?

O HTML tem elementos que já vêm riscados ou sublinhados, e eles dizem algo sobre o texto (aula Formatação do Guia HTML). O CSS só desenha:

<p>De <del>R$ 50,00</del> por <ins>R$ 45,00</ins></p>
<p>Pão de queijo: <s>esgotado</s> chegou fornada nova</p>
UseQuando
<del> / <ins>O texto foi apagado ou inserido (um preço trocado, uma correção). Leitores de tela podem anunciar a mudança
<s>O texto não vale mais, mas continua ali para referência ("esgotado")
text-decoration: line-throughSó aparência, sem significado: um item de lista de tarefas marcado, um enfeite

E o contrário também vale: se o <del> está certo no HTML, mas a Ana não quer o risco, o CSS tira (del { text-decoration: none; }) e o significado continua no código.

Quando dá errado

Um valor que não existe: underlined, wave 
$ cat style.css
a {
  text-decoration: underlined;
}
h2 {
  text-decoration-style: wave;
}
p {
  text-decoration: underline wavy tomato 2px;
}
$ vnu --css style.css
"file:/home/ana/site/style.css":2.20-2.29: error: CSS: “text-decoration”: “underlined” is not a “text-decoration” value.
"file:/home/ana/site/style.css":5.26-5.29: error: CSS: “text-decoration-style”: “wave” is not a “text-decoration-style” value.

O que o leitor vê: nada muda. Os links continuam com o sublinhado padrão, e o título continua com a linha que tinha antes.

Por quê: underlined ("sublinhado", com -ed) e wave ("onda") parecem certos, mas os valores são underline e wavy. O navegador ignora a declaração inteira. No F12, no painel Styles (Estilos), ela aparece riscada, com um ícone de aviso. A linha 8, com o atalho completo, está certa: o validador não reclama dela.

O que o validador diz: "underlined não é um valor de text-decoration" (linha 2, coluna 20) e "wave não é um valor de text-decoration-style" (linha 5, coluna 26).

Como consertar: underline e wavy.

O none no filho não apaga a linha do pai 
<style>
  p {
    text-decoration: underline;
  }
  .destaque {
    text-decoration: none;
    color: green;
  }
</style>
<p>Promoção: <span class="destaque">só hoje</span> bolo pela metade</p>

O que o leitor vê: "só hoje" ficou verde (a regra funcionou), mas continua sublinhado, com a linha preta do parágrafo passando por baixo.

Por quê: quem desenha a linha é o <p>, e ela atravessa tudo o que está dentro dele, inclusive o <span>. O none do span só diz "eu não desenho uma linha minha"; ele não tem como apagar a do pai. Por isso a aba Computed do span mostra text-decoration-line: none, e a linha continua lá. O validador não reclama: tudo é válido.

Como consertar: tire a linha do pai e ponha só onde ela deve aparecer. Se o parágrafo tem de ser sublinhado menos um pedaço, sublinhe os pedaços com spans próprios, deixando o "só hoje" de fora.

Tirou o sublinhado de todos os links

A Ana escreveu a { text-decoration: none; } no começo do CSS e agora os links no meio dos textos parecem palavras azuis comuns. O navegador fez exatamente o que foi pedido, e o validador não tem o que dizer: é um erro de acessibilidade, não de código.

Como consertar: restrinja o seletor aos lugares onde o link já tem cara de clicável (nav a, .botao) e deixe os links do texto sublinhados.

Resumo

  • text-decoration desenha linhas junto com o texto: underline (embaixo), overline (em cima), line-through (riscado) ou none. Dá para juntar tipos: underline overline.
  • As propriedades longas mudam um detalhe por vez: text-decoration-line, -style (solid, double, dotted, dashed, wavy), -color e -thickness. O text-underline-offset afasta o sublinhado.
  • O atalho text-decoration: underline wavy tomato 2px junta tudo; no Safari, só a partir da 26.2.
  • A linha do pai atravessa os filhos: um none no filho não a apaga.
  • Links no meio do texto ficam sublinhados (a cor sozinha não basta). Tire a linha só de menus e de links com cara de botão.
  • <del>, <ins> e <s> têm significado; o line-through do CSS é só aparência.
  • Valor inventado é ignorado; o validador avisa: “underlined” is not a “text-decoration” value.
