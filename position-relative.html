CSS position: relative

O position: relative é o mais tranquilo dos valores de position: o elemento continua na fila, no fluxo normal, mas pode ser empurrado uns pixels para qualquer lado, sem que os vizinhos percebam. Nesta aula você vai ver como ele se diferencia de uma margem, para que ele serve de verdade e por que ele é o "pai" de quase todo absolute.

Você vai aprender
  • Como relative + top/left desloca um elemento a partir do próprio lugar.
  • A diferença entre position: relative; top e margin-top.
  • O que acontece quando top e bottom (ou left e right) brigam.
  • Os usos de verdade: ajuste fino, botão que afunda, referência para absolute.
  • Os erros: relative para montar layout e a página que rola para o lado.

Os resultados são desenhados pelo seu navegador. O panorama dos cinco valores está na aula anterior, position: Como Funciona.

A ideia: o quadro torto na parede

Um quadro pendurado num prego ficou torto, um pouco para baixo. Você não muda o prego de lugar, nem mexe nos outros quadros: só empurra aquele quadro um pouquinho. O prego, o lugar "oficial" do quadro, continua onde estava. É exatamente o relative: o lugar do elemento no fluxo fica guardado, e o que você vê é desenhado um pouco ao lado.

1. Deslocar a partir do próprio lugar

<style>
  .caixa {
    width: 120px;
    height: 36px;
    margin: 4px;
    background-color: #e8ecff;
    border: 2px solid navy;
  }
  .empurrada {
    position: relative;
    top: 20px;
    left: 30px;
    background-color: #fde8e1;
    border-color: tomato;
  }
</style>
<div class="caixa">1</div>
<div class="caixa empurrada">2</div>
<div class="caixa">3</div>
position: relative
"Relativo": os deslocamentos contam a partir do lugar onde a caixa estaria no fluxo normal.
top: 20px
Fique a 20px do topo do seu lugar: a caixa desce 20px.
left: 30px
Fique a 30px da esquerda do seu lugar: a caixa vai 30px para a direita.

Repare: a caixa 2 desceu e foi para a direita, e ficou por cima da caixa 3. A caixa 3 não desceu para dar lugar: para ela, a caixa 2 continua no lugar original. Entre a 1 e a 2 sobrou um espaço vazio, que é a parte do lugar guardado que a caixa 2 deixou à mostra.

2. relative × margin

"Mas a margem também empurra." Sim, mas de um jeito diferente. Compare as duas colunas: na da esquerda, a caixa 2 tem margin-top: 20px; na da direita, position: relative; top: 20px.

    vertical-align: top;

    border: 2px solid navy;
  }
  .margem {
    margin-top: 20px;
    background-color: #fde8e1;
    border-color: tomato;
  }
  .relativa {
    position: relative;
    top: 20px;
    background-color: #fde8e1;
    border-color: tomato;
  }
</style>
<div class="coluna">
  <div class="caixa">1</div>
  <div class="caixa margem">2 margin-top</div>
  <div class="caixa">3</div>
</div>
<div class="coluna">
  <div class="caixa">1</div>
  <div class="caixa relativa">2 relative</div>
  <div class="caixa">3</div>

  • Com margin, a caixa 2 desce e empurra a 3, e a coluna tracejada fica mais alta. A página se rearruma.
  • Com relative, a caixa 2 desce por cima da 3, e a coluna não muda de tamanho. Nada se rearruma: o deslocamento é só visual.

3. Quando dois lados brigam

Com relative, o elemento só pode ir para um lado em cada direção. Se você escreve top e bottom juntos, o top vence, e o bottom é ignorado. Entre left e right, vence o left (em textos da esquerda para a direita, como o português).

.selo {
  position: relative;
  top: 10px;     /* vale: desce 10px */
  bottom: 30px;  /* ignorado */
  left: 10px;    /* vale: vai 10px para a direita */
  right: 30px;   /* ignorado */
}

No F12, a aba Computed mostra os quatro valores, como se todos valessem; o que manda é a regra acima. Na prática, escreva só um de cada par.

4. Para que serve, de verdade

Ajuste fino

Um ícone ou um selo que ficou um pouco alto ou baixo em relação ao texto. Um empurrãozinho de 1 a 3px resolve, sem mexer no resto da linha:

Missão: o selo "Novo!" está alinhado com o pé das letras do título. Suba-o 6px a partir de onde está, sem mudar a altura do título.

<link rel="stylesheet" href="style.css">
<h1>Bolo de fubá <span class="selo">Novo!</span></h1>
<p>Com erva-doce, para o café.</p>

.selo {
  font-size: 0.45em;
  padding: 2px 6px;
  background-color: gold;
}

.selo {
  position: relative;
  top: -6px;
  font-size: 0.45em;
  padding: 2px 6px;
  background-color: gold;
}

O valor negativo inverte o sentido: top: -6px sobe. O mesmo resultado com bottom: 6px.

O botão que afunda

Quando o leitor aperta um botão, ele pode "afundar" 2px, como uma tecla de verdade. O estado de "apertado" é o :active (aula Estados):

Experimente: clique e segure o botão: ele desce 2px enquanto o mouse está apertado, e o texto de baixo não se mexe. Troque o top: 2px por margin-top: 2px e aperte de novo: agora o parágrafo de baixo também pula.

<link rel="stylesheet" href="style.css">
<button class="botao">Encomendar</button>
<p>Entrega em 2 dias.</p>

.botao {
  position: relative;
  padding: 10px 18px;
  background-color: tomato;
  color: white;
  border: none;
  border-radius: 6px;
  box-shadow: 0 4px 0 #a33a22;
}

.botao:active {
  top: 2px;
  box-shadow: 0 2px 0 #a33a22;
}

A referência de um filho absolute

O uso mais comum de todos: position: relative sem nenhum deslocamento. Visualmente, nada muda. Mas o elemento passa a ser posicionado, e um filho com position: absolute passa a contar o top e o left a partir dele:

.cartao {
  position: relative;  /* sem top nem left: só vira a referência */
}

.cartao .selo {
  position: absolute;
  top: 8px;
  right: 8px;
}

Essa dupla é o assunto da próxima aula, position: absolute. Um elemento relative também passa a aceitar z-index, para escolher quem fica por cima (aula Camadas).

Quando dá errado

Montar o layout com relative: buracos e sobreposições 
<style>
  .foto {
    width: 150px;
    height: 80px;
    background-color: #e8ecff;
    border: 2px solid navy;
  }
  .legenda {
    position: relative;
    top: -60px;
    left: 170px;
  }
</style>
<div class="foto">foto</div>
<p class="legenda">Bolo de cenoura, R$ 35,00</p>
<p>Encomendas pelo telefone.</p>

O que você vê: a legenda foi para o lado da foto, como a Ana queria. Mas, embaixo da foto, sobrou um buraco do tamanho da legenda, e o "Encomendas pelo telefone" ficou longe da foto.

Por quê: o relative só desenha a legenda em outro lugar; o lugar original dela continua reservado no fluxo. Numa tela estreita, a legenda ainda pode passar da borda direita.

Como consertar: para pôr coisas lado a lado, use display: flex no pai (aula Flexbox). O relative é para ajustes de poucos pixels.

A página passou a rolar para o lado 
<style>
  .aviso {
    position: relative;
    left: 120px;
    padding: 8px;
    background-color: gold;
  }
</style>
<p class="aviso">Encomendas de Páscoa abertas!</p>

O que você vê: o aviso dourado começa 120px para dentro e passa da borda direita do quadro. O pedaço da direita fica fora da área visível, e o quadro ganha rolagem para o lado.

Por quê: o <p> é um bloco com a largura toda. Empurrado 120px para a direita, ele termina 120px depois da borda: transborda (aula O que Transborda). No celular, é a página inteira que escorrega para o lado.

Como consertar: para afastar da esquerda sem estourar a largura, use margin-left: 120px: a margem diminui a largura do bloco, e ele continua cabendo.

top e bottom juntos: o bottom some

O que acontece: com position: relative; top: 10px; bottom: 10px;, a Ana esperava que um anulasse o outro, mas o elemento desce 10px: o top vence e o bottom é ignorado. O validador não reclama (as duas declarações são válidas), e a aba Computed do F12 mostra as duas.

Como consertar: escreva só um lado de cada direção.

Resumo

  • position: relative mantém o elemento no fluxo, com o lugar guardado, e o desenha deslocado pelo top/bottom/left/right.
  • O deslocamento é só visual: os vizinhos não se mexem, e o elemento pode ficar por cima deles. A margem, ao contrário, rearruma a página.
  • top vence bottom; left vence right. Valores negativos invertem o sentido.
  • Bons usos: ajustes de poucos pixels, o botão que afunda no :active e, sem deslocamento, a referência de um filho absolute.
  • Não monte layout com relative: sobram buracos, e um bloco empurrado para o lado faz a página rolar para o lado.
