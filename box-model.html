CSS O Modelo de Caixa

Esta é uma das aulas mais importantes do curso. Para o navegador, todo elemento é uma caixa retangular: um título, um parágrafo, uma imagem, até uma palavra dentro de um <span>. E toda caixa é feita de quatro camadas, uma por fora da outra: o conteúdo, o padding, a border e a margin. Quem entende essas camadas entende por que uma caixa ficou maior do que devia, por que dois cartões se encostam, por que apareceu uma barra de rolagem. O nome disso em inglês é box model: "modelo de caixa".

Você vai aprender
  • As quatro camadas da caixa, com um desenho, e o que cada uma faz.
  • Como acrescentar uma camada por vez e ver a caixa crescer.
  • A conta da largura total: por que width: 200px dá uma caixa de 250 pixels.
  • Até onde o fundo pinta, e por que a margem é sempre transparente.
  • O box-sizing: border-box, que muda a conta.
  • Como ver o modelo de caixa no F12, e os erros reais do validador W3C.

Esta aula apresenta as quatro camadas juntas. Cada uma tem a sua aula depois: Margem, Espaço Interno, Bordas, Largura e Altura e box-sizing. As medidas foram lidas no Chromium, e as mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana.

A ideia: o quadro na parede

A Ana mandou emoldurar a foto do bolo para pendurar na lojinha. O quadro pronto tem quatro partes, de dentro para fora:

  1. A foto: o que importa. É o conteúdo.
  2. O passe-partout: a margem de papel claro entre a foto e a moldura, para a foto "respirar". É o padding ("preenchimento", o espaço de dentro).
  3. A moldura: a borda de madeira. É a border ("borda").
  4. O espaço na parede até o próximo quadro. Ninguém pinta esse espaço: é a parede que aparece. É a margin ("margem", o espaço de fora).

No CSS é igual. O desenho abaixo mostra uma caixa com width: 200px (a largura do conteúdo), padding: 20px, border: 5px e margin: 30px. As cores são as que o F12 do Chrome usa no desenho do modelo de caixa: laranja para a margem, amarelo para a borda, verde para o padding, azul para o conteúdo. Na largura, o desenho está em escala; na altura, não.

1. Tudo é caixa

Você não vê as caixas porque, sem CSS, elas não têm fundo nem borda. Uma linha de CSS revela todas: outline ("contorno", aula Contorno) desenha uma linha em volta de cada caixa sem mudar o tamanho de nada. O * é o seletor universal (aula Seletor Universal): "todos os elementos".

<link rel="stylesheet" href="style.css">
<h1>Bolo de cenoura</h1>
<p>Leva <strong>três cenouras</strong> e quatro ovos.</p>
<ul>
  <li>Fácil</li>
  <li>50 minutos</li>
</ul>

* {
  outline: 1px solid tomato;
}

Aparecem retângulos vermelhos em volta de tudo: a página inteira, o título, o parágrafo, a lista, cada item e até o <strong>, que é uma caixa pequena só em volta das duas palavras. Repare nos espaços entre os retângulos do título e do parágrafo: são as margens que o navegador já põe nesses elementos. Ninguém escreveu essas margens; elas vêm do estilo padrão do navegador.

Um truque para a vida toda

Quando um layout está estranho e você não entende por quê, acrescente * { outline: 1px solid tomato; } por um minuto. Ver as caixas resolve metade dos mistérios. (Use outline, e não border: a borda aumentaria as caixas, como você vai ver agora.)

2. Uma camada por vez

Agora, a mesma caixa quatro vezes, ganhando uma camada a cada vez. O fundo da página é cinza-claro, e o da caixa, amarelo-claro, para você ver até onde vai cada coisa:

<link rel="stylesheet" href="style.css">
<p class="caixa c1">Bolo de cenoura</p>
<p class="caixa c2">Bolo de cenoura</p>
<p class="caixa c3">Bolo de cenoura</p>
<p class="caixa c4">Bolo de cenoura</p>

body {
  background-color: lightgray;
}

.caixa {
  background-color: lightyellow;
  width: 200px;
}

/* 1: só o conteúdo */

.c2 {
  padding: 20px;
}

.c3 {
  padding: 20px;
  border: 5px solid tomato;
}

.c4 {
  padding: 20px;
  border: 5px solid tomato;
  margin: 30px;
}
  1. Só o conteúdo: uma faixa amarela de 200 pixels de largura e da altura de uma linha (18 pixels, no Chromium). O texto encosta na beirada.
  2. + padding: o texto se afasta 20 pixels da beirada, dos quatro lados, e o amarelo vai junto: o fundo pinta o padding. A caixa amarela agora tem 240 pixels de largura.
  3. + border: uma moldura vermelha de 5 pixels, por fora do padding. A caixa visível tem agora 250 pixels.
  4. + margin: a caixa se afasta 30 pixels das outras coisas e da beirada esquerda da página. O espaço da margem mostra o cinza da página: a margem é transparente. O tamanho da caixa visível não muda (continua 250).

Em nenhum momento o width mudou: o F12 mostra width: 200px nas quatro caixas. O que mudou foi o que está em volta do conteúdo.

3. A conta da largura total

Esta é a conta que todo mundo erra no começo. No CSS, o width é a largura só do conteúdo. O padding e a borda são somados por fora, dos dois lados:

ParteEsquerdaMeioDireitaSoma
Conteúdo (width)200200
+ padding2020240
+ border55250: a caixa que você vê
+ margin3030310: o espaço que ela ocupa na página

Em fórmula:

caixa visível = width + padding-left + padding-right + border-left + border-right
              = 200   + 20           + 20            + 5           + 5            = 250

espaço ocupado = caixa visível + margin-left + margin-right
               = 250           + 30          + 30           = 310

A altura segue a mesma regra, com os lados de cima e de baixo. A caixa 4 da seção 2 tem 18 pixels de conteúdo, mais 20 + 20 de padding, mais 5 + 5 de borda: 68 pixels de altura visível (medido no Chromium).

Missão: o cartão da receita tem de caber num espaço de exatamente 300 pixels de largura visível. Ele já tem padding: 20px e border: 5px. Faça a conta e acerte o width.

<link rel="stylesheet" href="style.css">
<div class="cartao">
  <h2>Bolo de cenoura</h2>
  <p>50 minutos · 12 pedaços</p>
</div>

.cartao {
  background-color: lightyellow;
  width: 300px;
  padding: 20px;
  border: 5px solid tomato;
}

.cartao {
  background-color: lightyellow;
  width: 250px;
  padding: 20px;
  border: 5px solid tomato;
}

300 − 20 − 20 − 5 − 5 = 250. Com width: 300px, o cartão tinha 350 pixels visíveis. Na seção 5 você vai ver um jeito de não precisar fazer essa conta.

4. Os quatro lados

Padding, borda e margem têm quatro lados: top (em cima), right (direita), bottom (embaixo) e left (esquerda). Você pode dar um valor para todos de uma vez ou para cada lado:

EscritaO que faz
padding: 20px;20 nos quatro lados
padding-top: 20px;Só em cima (também -right, -bottom, -left)
padding: 10px 20px;10 em cima e embaixo, 20 nos lados
padding: 10px 20px 30px 40px;Em cima, direita, embaixo, esquerda: no sentido do relógio, a partir do 12

A mesma escrita vale para margin. Os detalhes de cada uma estão nas aulas Margem, Espaço Interno e Bordas. Na conta da largura, cada lado entra com o seu valor: com padding: 10px 20px, a largura ganha 20 + 20.

5. box-sizing: border-box: outra conta

A conta da seção 3 é o comportamento inicial, chamado content-box: o width mede só o conteúdo. Existe outro: com box-sizing: border-box, o width mede a caixa até a borda, e o padding e a borda são tirados de dentro dela.

<link rel="stylesheet" href="style.css">
<p class="caixa conteudo">content-box</p>
<p class="caixa borda">border-box</p>

.caixa {
  background-color: lightyellow;
  width: 200px;
  padding: 20px;
  border: 5px solid tomato;
}

.conteudo {
  box-sizing: content-box;
}

.borda {
  box-sizing: border-box;
}

As duas têm width: 200px, mas a de cima tem 250 pixels de largura visível, e a de baixo, exatamente 200. Na de baixo, o conteúdo ficou com o que sobrou: 200 − 20 − 20 − 5 − 5 = 150 pixels.

content-box (inicial)border-box
O width medesó o conteúdoconteúdo + padding + borda
width: 200px + padding: 20px + border: 5pxcaixa de 250caixa de 200 (conteúdo de 150)
Quando usarquando você quer controlar o tamanho do conteúdo (raro)quase sempre: o tamanho que você escreve é o que você vê

A maioria dos sites de hoje põe box-sizing: border-box em todos os elementos, logo no começo do CSS. A aula box-sizing: border-box mostra como e por quê. A margem fica de fora nos dois casos: ela nunca entra no width.

6. O modelo de caixa no F12

O navegador mostra essas camadas para qualquer elemento. Abra o F12 (aula Inspecionando com o F12), escolha um elemento na aba Elements ("Elementos") e procure a aba Computed ("Calculado"). No alto dela há um desenho de retângulos, um dentro do outro, como o desta aula: margin por fora, depois border, padding e, no centro, o tamanho do conteúdo (por exemplo, 200 × 18). Cada lado mostra o seu número, e um - quando é zero.

Passe o mouse sobre o elemento na aba Elements: a própria página pinta as camadas por cima da caixa, com as mesmas cores (laranja na margem, verde no padding, azul no conteúdo). Com isso você descobre, por exemplo, que o espaço entre dois parágrafos é a margem deles, e não um padding.

(Os nomes exatos das abas mudam um pouco entre o Chrome, o Edge e o Firefox. No Firefox, o desenho fica na aba Layout.)

7. E as caixas em linha?

Tudo acima vale para elementos de bloco (p, div, h1), que ocupam a linha inteira. Os elementos em linha (span, strong, a) também são caixas, mas com um comportamento diferente na vertical:

<link rel="stylesheet" href="style.css">
<p>O bolo leva <span class="destaque">três cenouras</span> e quatro ovos, e fica pronto em cinquenta minutos de forno médio, pré-aquecido.</p>

.destaque {
  background-color: gold;
  padding: 10px;
  margin: 20px;
  border: 2px solid tomato;
}
  • Nos lados, tudo funciona: o padding, a borda e a margem afastam o texto da frase.
  • Em cima e embaixo, o padding e a borda são desenhados, mas não empurram as linhas: a caixa amarela fica mais alta que a linha e avança sobre as linhas vizinhas, sem afastá-las (com a janela estreita, ela cobre parte do texto da linha de cima ou de baixo). E a margem de cima e de baixo não faz nada.

Para uma caixa em linha que respeite as medidas na vertical, existe o display: inline-block, da aula display.

Quando dá errado

Sem mensagem: a caixa maior que a tela

O que aconteceu: a Ana quis uma faixa da largura toda e escreveu width: 100%; com padding: 20px;. Pela conta da seção 3, a faixa ficou com 100% mais 40 pixels: ela passa da beirada direita, e aparece uma barra de rolagem na horizontal.

<link rel="stylesheet" href="style.css">
<div class="faixa">Promoção: bolo de cenoura com 10% de desconto</div>

.faixa {
  background-color: lightblue;
  width: 100%;
  padding: 20px;
}

No Chromium, numa página de 500 pixels, o body tinha 484 de largura (por causa da margem de 8 do navegador), e a faixa ficou com 524: passa 32 pixels da tela.

Como consertar: o mais simples é não escrever width: um elemento de bloco já ocupa a largura toda, e o padding fica dentro. Ou use box-sizing: border-box.

Sem mensagem: a borda que aumentou a caixa

O que aconteceu: dois cartões de 50% cada, lado a lado, e a Ana acrescentou border: 1px solid gray para separá-los. Cada um ficou com 50% + 2 pixels: a soma passa de 100%, e os dois não cabem mais lado a lado. A borda entra na conta, mesmo fininha.

Como consertar: box-sizing: border-box, ou, só para enxergar a caixa enquanto testa, outline, que não entra na conta.

Erro de propósito: cada regra tem um erro, e nenhuma das quatro caixas ganha o tamanho, o espaço ou a borda que devia. Leia os cenários e conserte.

<link rel="stylesheet" href="style.css">
<p class="caixa um">um</p>
<p class="caixa dois">dois</p>
<p class="caixa tres">três</p>
<p class="caixa quatro">quatro</p>

.um {
  width: 200;
}

.dois {
  padding: -10px;
}

.tres {
  margin: 10px 20px 30px 40px 50px;
}

.quatro {
  border: 5px solid tomato
  padding: 20px;
}

.caixa {
  background-color: lightyellow;
}
error: CSS: “width”: only “0” can be a “unit”. You must put a unit after your number.

O que aconteceu: width: 200, sem px. Duzentos o quê? Pixels, centímetros, porcentagem? O navegador não adivinha e ignora a declaração: a caixa continua da largura toda.

$ vnu --css style.css
"file:/home/ana/caixa/style.css":2.10-2.12: error: CSS: “width”: only “0” can be a “unit”. You must put a unit after your number.

Como consertar: width: 200px;. Só o zero dispensa a unidade (margin: 0).

error: CSS: “padding”: “-10px” negative values are not allowed.

O que aconteceu: padding negativo. Não existe "espaço de dentro" menor que nada. A declaração é ignorada.

$ vnu --css style.css
"file:/home/ana/caixa/style.css":6.13-6.16: error: CSS: “padding”: “-10px” negative values are not allowed.

"Valores negativos não são permitidos." A margem aceita valor negativo (puxa a caixa para fora do lugar, aula Margem); o padding e a borda, não.

Como consertar: padding: 0; para tirar o espaço, ou um valor positivo.

error: CSS: “margin”: Too many values or values are not recognized.

O que aconteceu: cinco valores. Uma caixa tem quatro lados: o margin aceita de um a quatro.

$ vnu --css style.css
"file:/home/ana/caixa/style.css":10.31-10.34: error: CSS: “margin”: Too many values or values are not recognized.

Como consertar: no máximo quatro: em cima, direita, embaixo, esquerda.

error: CSS: “border”: Missing a semicolon before the property name “padding”.

O que aconteceu: faltou o ; depois de border: 5px solid tomato. As duas linhas viraram uma declaração só, inválida: a caixa fica sem borda e sem padding.

$ vnu --css style.css
"file:/home/ana/caixa/style.css":15.3-15.9: error: CSS: “border”: Missing a semicolon before the property name “padding”.

Como consertar: border: 5px solid tomato;.

Resumo

  • Todo elemento é uma caixa com quatro camadas, de dentro para fora: conteúdo, padding (espaço de dentro), border (a linha) e margin (espaço de fora).
  • O fundo pinta o conteúdo, o padding e o que fica sob a borda; a margem é sempre transparente.
  • No modo inicial (content-box), o width é só do conteúdo: largura visível = width + padding + borda dos dois lados; espaço ocupado = isso + margens.
  • Com box-sizing: border-box, o width já inclui padding e borda. A margem nunca entra.
  • * { outline: 1px solid tomato; } e a aba Computed do F12 mostram as caixas.
  • Em elementos em linha, padding e borda de cima e de baixo são desenhados, mas não empurram as linhas.
  • Erros comuns: número sem unidade, padding negativo, valores demais, ; esquecido. E, sem mensagem: width: 100% + padding passa da tela.
