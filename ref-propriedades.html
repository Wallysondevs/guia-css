CSS Propriedades

Esta é a "cola" das propriedades do CSS que o guia ensina, separadas por assunto. Em cada linha: um exemplo de uso, o valor que a propriedade tem quando ninguém escreve nada (o inicial), se ela passa de pai para filho (a herança), o que faz e a aula que explica com calma. Use para lembrar um nome, conferir um valor ou achar a aula certa.

Como ler as tabelas
  • Inicial é o valor da especificação, medido no Chromium num elemento sem nenhum estilo. Atenção: o navegador tem a folha de estilos padrão dele, que muda alguns valores em certos elementos (o <h1> já vem em negrito e grande, o <p> já vem com margem, o <div> já é block). Por isso, num <div>, o display é block, embora o inicial seja inline.
  • Herda? "sim" quer dizer que, se você puser a propriedade no pai, os filhos recebem o mesmo valor sem você escrever nada (é por isso que um color no body pinta a página toda). Aula: Herança.
  • Os atalhos (margin, border, font…) aparecem na tabela própria, no fim: no F12 e nas metas, o navegador mostra as propriedades longas (margin-top, border-top-width…).
  • Os assuntos maiores têm referência própria: Flexbox, Grid, Unidades, Nomes de Cores, Funções, Seletores e Pseudo-classes e Pseudo-elementos.

A anatomia, para lembrar

Uma propriedade é a característica que você quer mudar; o valor, como ela fica. Juntas, com : no meio e ; no fim, formam uma declaração:

.cartao {               /* seletor: QUEM recebe o estilo */
  background-color: white;   /* propriedade: valor; */
  padding: 1rem;
}

A aula completa é Regras, Seletores e Declarações. Todas as propriedades aceitam também os valores inherit (copia do pai), initial (volta ao inicial), unset e revert.

Quando dá errado

Uma propriedade que não existe

h1 {
  text-color: navy;
}

p {
  font-color: gray;
  background-colour: white;
}

O que você vê: nada muda: o título continua preto, o parágrafo também. Por quê: o navegador ignora em silêncio a declaração com um nome que ele não conhece. A cor do texto é color (não existe text-color nem font-color), e o CSS usa o inglês americano: color, nunca colour. No F12, a declaração aparece riscada, com um aviso. O validador:

$ vnu --css style.css
"file:/home/ana/ref/style.css":2.15-2.18: error: CSS: “text-color”: Property “text-color” doesn't exist.
"file:/home/ana/ref/style.css":6.15-6.18: error: CSS: “font-color”: Property “font-color” doesn't exist.
"file:/home/ana/ref/style.css":7.22-7.26: error: CSS: “background-colour”: Property “background-colour” doesn't exist.

Um valor que a propriedade não aceita

.preco {
  font-weight: bold;
  font-size: big;
}

O que você vê: o preço fica em negrito, mas no tamanho normal. Por quê: só a declaração inválida é descartada; as outras da mesma regra continuam valendo. big não é um valor de font-size (os nomes são small, medium, large, x-large…; melhor ainda, use rem). A coluna "Exemplo" das tabelas mostra um valor válido de cada propriedade. O validador:

$ vnu --css style.css
"file:/home/ana/ref/style.css":3.14-3.16: error: CSS: “font-size”: “big” is not a “font-size” value.

A propriedade certa no elemento errado

O nome e o valor estão certos, mas nada acontece: justify-content: center num elemento que não é flex nem grid; top: 0 sem position; z-index em caixa não posicionada; width num <span> (em linha); text-overflow: ellipsis sem overflow: hidden. O validador não acusa nada disso: o CSS é válido. A lista completa, com o conserto de cada um, está em "Meu CSS Não Funciona".

Resumo

  • Uma declaração é propriedade: valor;. Nome ou valor errados: o navegador ignora só aquela declaração, em silêncio; o validador aponta.
  • O valor inicial é o da especificação; cada elemento HTML já vem com alguns valores mudados pela folha padrão do navegador.
  • Herdam, em geral, as propriedades de texto (cor, fonte, tamanho, altura de linha, alinhamento, listas, cursor). Não herdam as de caixa (margem, borda, fundo, tamanho, posição, layout).
  • Os atalhos (margin, border, font, background, flex…) resumem várias propriedades e devolvem ao inicial o que você não escrever.
  • Para o detalhe, siga o link da aula em cada linha; Flexbox, Grid, unidades, cores, funções, seletores e pseudo-classes têm referência própria.
