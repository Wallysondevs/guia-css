CSS Botões

O botão padrão do navegador é pequeno, cinza e com cara de 1998. Nesta aula você vai transformar os botões da lojinha da Ana em botões de verdade: cor da marca, tamanho bom para o dedo, cantos arredondados, uma reação ao passar o mouse e ao clicar, um foco visível para quem usa teclado, e um jeito claro de mostrar que um botão está desativado.

Você vai aprender
  • Como é o botão padrão, valor por valor.
  • A receita de um botão: font, padding, border, border-radius, background-color, color, cursor.
  • Os quatro estados: :hover, :active, :focus-visible e :disabled.
  • Variações com classes: principal, secundário e perigo.
  • Link com aparência de botão (e quando usar cada um).
  • Os erros mais comuns e o que o validador W3C diz.

A ideia: o interruptor da parede

Um bom interruptor você reconhece de longe: tem formato de interruptor, fica num lugar previsível, é grande o bastante para o dedo e faz "clique" quando você aperta. Um botão na tela precisa do mesmo: parecer clicável, ter um tamanho confortável e reagir quando você passa o mouse, aperta ou chega nele pelo teclado. O CSS cuida da aparência; o HTML (<button>) já cuida do comportamento: ele funciona com Enter e espaço, recebe o foco do Tab e é anunciado como "botão" pelo leitor de tela.

1. O botão padrão

<button type="button">Encomendar</button>

Pequeno, cinza, com uma borda fina. Os valores que o Chromium calcula para ele (cada navegador tem os seus, parecidos):

PropriedadeValor padrãoO que significa
font-size13.3333pxLetra menor que a da página (16px): o botão não herda a fonte
background-colorrgb(239, 239, 239)Cinza clarinho
border-top-styleoutsetUma borda com efeito de "alto-relevo", de 2px
padding1px 6pxQuase nenhum espaço interno
border-radius0pxCantos retos (o desenho do sistema pode arredondar um pouco)
cursordefaultA setinha normal, e não a mãozinha

2. A receita de um botão

Sete linhas transformam o botão. Uma propriedade de cada vez:

.botao {
  font: inherit;
  padding: 10px 20px;
  border: 2px solid transparent;
  border-radius: 8px;
  background-color: #c2410c;
  color: white;
  cursor: pointer;
}
font: inherit
A letra da página, como nos campos de formulário (aula Formulários).
padding: 10px 20px
Espaço interno: 10 em cima e embaixo, 20 dos lados. É o que faz o botão ficar "gordinho" e fácil de acertar (aula padding).
border: 2px solid transparent
Troca a borda de alto-relevo por uma borda invisível de 2px. Por que não border: none? Porque o botão secundário, mais abaixo, tem uma borda colorida de 2px: com a borda transparente em todos, os botões ficam do mesmo tamanho, lado a lado.
border-radius: 8px
Cantos arredondados (aula border-radius).
background-color: #c2410c
O laranja-escuro da lojinha.
color: white
Texto branco. Branco sobre esse laranja tem contraste suficiente para ler; um laranja claro com texto branco não teria.
cursor: pointer
A "mãozinha" ao passar o mouse (aula Cursor e Interação).

Missão: o botão "Encomendar" está com a cara padrão. Escreva a regra .botao com: a letra da página, espaço interno de 10px 20px, cantos de 8px, fundo #c2410c, texto branco e a mãozinha.

Tamanho para o dedo

No celular, um botão pequeno vira um alvo difícil. As recomendações de acessibilidade pedem uma área de toque de pelo menos 24×24 pixels (o mínimo das regras WCAG 2.2), e o ideal é por volta de 44×44. Com letra de 16px e padding: 10px 20px, o botão desta aula fica com cerca de 43 pixels de altura (conferido no Chromium; o número exato depende da fonte). Para garantir os 44, some um pouco de padding ou use min-height: 44px.

3. Os estados: o botão reage

Um botão de verdade "responde" ao que você faz. Cada estado tem a sua pseudo-classe (aula Estados):

Pseudo-classeQuando valeO que costuma mudar
:hoverO mouse está em cimaFundo um pouco mais escuro
:activeDurante o clique (o botão está sendo apertado)Fundo ainda mais escuro, como se afundasse
:focus-visibleChegou nele pelo teclado (Tab)Um contorno bem visível
:disabledO botão tem o atributo disabledCores apagadas e o cursor de "proibido"
.botao:hover {
  background-color: #9a3412;
}

.botao:active {
  background-color: #7c2d12;
}

.botao:focus-visible {
  outline: 3px solid #1d4ed8;
  outline-offset: 2px;
}

.botao:disabled {
  background-color: #d6d3d1;
  color: #57534e;
  cursor: not-allowed;
}

Com o mouse em cima, o laranja fica mais escuro (rgb(154, 52, 18), conferido no Chromium); com o foco do teclado, aparece um contorno azul grosso em volta, afastado 2 pixels do botão.

Por que o desativado também precisa de :disabled?

Sem a regra .botao:disabled, o botão desativado ficaria com o mesmo laranja dos outros (a classe .botao vale para ele também) e a pessoa clicaria sem entender por que nada acontece. As cores apagadas avisam "não dá". Repare na ordem: a regra do :disabled vem depois da do :hover, e as duas têm a mesma especificidade, então, se o mouse passar por cima de um botão desativado, quem vence é o :disabled (aula A Cascata).

Uma transição deixa a mudança suave

Por padrão, a cor troca de uma vez. Com transition: background-color 0.2s; na regra .botao, a troca leva dois décimos de segundo. É o assunto da aula Transições.

4. Variações: principal, secundário e perigo

Uma página costuma ter um botão principal (a ação mais importante, "Encomendar"), botões secundários (menos destaque, "Ver cardápio") e, às vezes, um de perigo (algo que não tem volta, "Cancelar pedido"). Em vez de repetir tudo, a classe .botao guarda o que é comum e uma segunda classe muda só o que é diferente:

<link rel="stylesheet" href="style.css">
<p>
  <button class="botao" type="button">Encomendar</button>
  <button class="botao botao-secundario" type="button">Ver cardápio</button>
  <button class="botao botao-perigo" type="button">Cancelar pedido</button>
</p>

body {
  font-family: system-ui, sans-serif;
}

.botao {
  font: inherit;
  padding: 10px 20px;
  border: 2px solid transparent;
  border-radius: 8px;
  background-color: #c2410c;
  color: white;
  cursor: pointer;
}

.botao-secundario {
  background-color: white;
  color: #c2410c;
  border-color: #c2410c;
}

.botao-perigo {
  background-color: #b91c1c;
}

Os três ficam da mesma altura, lado a lado: o principal laranja cheio, o secundário branco com borda e texto laranja (o "fantasma" do principal), e o de perigo vermelho. No HTML, o botão secundário tem as duas classes (class="botao botao-secundario", aula Seletor de Classe), e a regra da segunda vem depois no CSS, então ela vence onde as duas falam da mesma propriedade.

A cor não diz tudo

O vermelho do "Cancelar pedido" ajuda, mas o que avisa de verdade é o texto. Escreva o que o botão faz ("Cancelar pedido", e não só "OK"), para quem não distingue as cores e para quem ouve a página num leitor de tela.

5. Link com cara de botão

"Ver cardápio" leva a outra página: é um link (<a href>), mesmo que pareça um botão. A mesma classe serve, com dois acréscimos:

.botao {
  display: inline-block;
  text-decoration: none;
  /* … o resto da receita … */
}
display: inline-block
O <a> é um elemento em linha: o padding de cima e de baixo aparece, mas não empurra as linhas vizinhas, e o fundo invade o texto de cima e de baixo (veja Quando dá errado). Com inline-block, ele vira uma caixa, como o <button> já é (aula display).
text-decoration: none
Tira o sublinhado do link (aula Estilizando Links).
O clique…UseExemplo
Leva a outro lugar (outra página, outro ponto da página)<a href="…" class="botao">"Ver cardápio", "Ler a receita"
Faz algo ali mesmo (enviar, abrir, adicionar)<button class="botao">"Encomendar", "Adicionar ao carrinho"

O CSS deixa os dois iguais por fora, mas por dentro eles continuam diferentes: o link abre com Enter e o leitor de tela diz "link"; o botão funciona também com a barra de espaço e é anunciado como "botão". Escolha pelo que o clique faz, nunca pela aparência.

Quando dá errado

Link com padding, mas sem inline-block: o fundo invade as outras linhas 
<style>
  body {
    font-family: system-ui, sans-serif;
  }
  .botao {
    padding: 10px 20px;
    background-color: #fde68a;
  }
</style>
<p style="width: 320px">Texto antes <a class="botao" href="#">Ver cardápio</a> texto depois, numa linha comprida que quebra para mostrar o problema.</p>

O que você vê: o fundo amarelo do link sobe acima da linha dele e desce por cima da linha de baixo, cobrindo o alto das letras de "depois, numa linha comprida": o espaço interno vertical foi desenhado, mas as linhas não se afastaram para ele.

Por quê: num elemento em linha, o padding de cima e de baixo não ocupa lugar na linha. O validador não acusa nada: o CSS é válido.

Como consertar: display: inline-block; no link.

Só o :hover: no celular e no teclado, nada acontece

O que você vê: no computador, o botão escurece com o mouse. Pelo Tab, se você apagou o contorno, não há sinal nenhum; e no celular não existe "mouse em cima".

Por quê: :hover é só para mouse. O botão precisa ser claramente um botão sem o hover (cor, formato), e o foco precisa de um :focus-visible visível.

Como consertar: nunca dependa só do :hover; mantenha (ou desenhe) o foco.

Erros de digitação: o validador mostra todos 
.botao {
  border-radius: 8 px;
  background-color: #c2410;
  cursor: hand;
}
.botao:hoover {
  background-color: #9a3412;
}

O que você vê: o botão continua com os cantos retos, o fundo cinza, a setinha normal, e não escurece com o mouse. Cada declaração errada foi ignorada; no F12 ela aparece riscada.

$ vnu --css botao.css
"file:/home/ana/site/botao.css":2.20-2.21: error: CSS: “border-radius”: only “0” can be a “unit”. You must put a unit after your number.
"file:/home/ana/site/botao.css":3.21-3.26: error: CSS: “background-color”: “#c2410” is not a “background-color” value.
"file:/home/ana/site/botao.css":4.11-4.14: error: CSS: “cursor”: “hand” is not a “cursor” value.
"file:/home/ana/site/botao.css":6.8-6.13: error: CSS: Unknown pseudo-element or pseudo-class “:hoover”

O que significa:

  • 8 px, com espaço: o validador lê "o número 8" e "a palavra px", e diz que "só o 0 pode ficar sem unidade". O número e a unidade vão grudados: 8px.
  • #c2410 tem 5 dígitos: "não é um valor de background-color". Uma cor hexadecimal tem 3, 4, 6 ou 8.
  • hand não é um cursor: era um valor antigo do Internet Explorer. O certo é pointer.
  • :hoover, com dois "o": "pseudo-classe desconhecida". A regra inteira é descartada.

Resumo

  • O botão padrão tem letra de 13.3333px, fundo cinza, borda outset, quase nenhum espaço e a setinha normal.
  • A receita: font: inherit, padding, border, border-radius, background-color, color com bom contraste, cursor: pointer. Tamanho confortável para o dedo.
  • Estados: :hover (mouse), :active (clique), :focus-visible (teclado, sempre visível) e :disabled (cores apagadas, not-allowed).
  • Uma classe base (.botao) e classes de variação (.botao-secundario, .botao-perigo) que mudam só o necessário.
  • Link com cara de botão: display: inline-block e text-decoration: none. Link leva a um lugar; botão faz uma ação.
  • Erros comuns: 8 px com espaço, hexadecimal com dígitos de menos, cursor: hand, :hoover.
