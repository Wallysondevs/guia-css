CSS align-self e order

Com justify-content e align-items, a Ana arruma todos os itens de uma vez, porque essas propriedades vão no pai. Mas às vezes um item precisa ser diferente: o selo "Promoção" lá em cima, enquanto os outros ficam no meio; o botão "Sair" na outra ponta do menu; o produto em destaque em primeiro lugar, sem mexer no HTML. Esta aula mostra as ferramentas para cuidar de um item só: align-self ("alinhar a si mesmo"), o truque do margin: auto e order ("ordem").

Você vai aprender
  • Como align-self troca, para um item, o alinhamento que o pai deu com align-items.
  • Os valores de align-self, desenhados lado a lado.
  • Por que não existe justify-self no Flexbox, e como o margin-left: auto empurra um item para a outra ponta.
  • Como order muda a posição de um item na tela sem mexer no HTML.
  • Por que o order pode atrapalhar quem navega pelo teclado ou ouve a página.
  • Os erros mais comuns e as mensagens reais do validador W3C.

Antes, é bom ter visto Alinhando na Linha (justify-content) e Alinhando na Coluna (align-items). Os exemplos com resultado são desenhados agora pelo seu navegador. As mensagens do validador saíram do validador W3C (vnu), na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: a foto da turma

Na foto da turma, o fotógrafo dá uma ordem para todo mundo: "todos de pé, alinhados pela cabeça". Isso é o align-items, no pai. Mas a professora fica sentada na frente: ela tem uma exceção só para ela. Isso é o align-self, no item.

E se o aniversariante tiver de ficar em primeiro na fila, sem trocar a lista de chamada? O fotógrafo só diz "você vem antes". Isso é o order: a lista (o HTML) continua igual; só a posição na foto (a tela) muda.

1. align-self: um item com outro alinhamento

Uma fila de 120 pixels de altura com align-items: center: todos os itens no meio. O selo "Promoção" ganhou align-self: flex-start e subiu para o topo, sozinho:

<link rel="stylesheet" href="style.css">
<div class="fila">
  <div class="item">Bolo</div>
  <div class="item selo">Promoção</div>
  <div class="item">Torta</div>
  <div class="item">Pão</div>
</div>

.fila {
  display: flex;
  align-items: center;
  gap: 8px;
  height: 120px;
  border: 2px dashed gray;
}

.item {
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}

.selo {
  align-self: flex-start;
  background-color: darkgreen;
}
.selo
O seletor: um item flex (filho do pai com display: flex).
align-self
"Alinhar a si mesmo": o alinhamento deste item na direção cruzada (de cima para baixo, numa fila em linha). Vence o align-items do pai, só para este item.
flex-start
O valor: no começo da direção cruzada, ou seja, no topo. Os valores são os mesmos do align-items.

Os valores lado a lado

Cinco itens na mesma fila (com align-items: center no pai), cada um com um align-self diferente, escrito dentro dele:

<link rel="stylesheet" href="style.css">
<div class="fila">
  <div class="item auto">auto</div>
  <div class="item inicio">flex-start</div>
  <div class="item fim">flex-end</div>
  <div class="item centro">center</div>
  <div class="item esticar">stretch</div>
</div>

.fila {
  display: flex;
  align-items: center;
  gap: 8px;
  height: 140px;
  border: 2px dashed gray;
}

.item {
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: monospace;
}

.auto {
  align-self: auto;
}

.inicio {
  align-self: flex-start;
}

.fim {
  align-self: flex-end;
}

.centro {
  align-self: center;
}

.esticar {
  align-self: stretch;
}
ValorOnde o item fica (fila em linha)
autoPadrão: obedece o align-items do pai (aqui, center: no meio)
flex-startNo topo
flex-endNo pé
centerNo meio
stretchEsticado do topo ao pé (se o item não tiver height)
baselineAlinhado pela linha de base do texto (a "linha do caderno" em que as letras se apoiam), junto com os vizinhos que também usam baseline

Você também vai ver start e end no lugar de flex-start e flex-end. São os nomes novos, que servem para Flexbox e Grid; numa fila comum, dão o mesmo resultado.

E se a fila for em coluna?

O align-self sempre trabalha na direção cruzada. Numa fila em linha (flex-direction: row), a cruzada é de cima para baixo. Numa fila em coluna (flex-direction: column), ela vira da esquerda para a direita: flex-start passa a ser "à esquerda" e flex-end, "à direita". É o mesmo raciocínio da aula align-items.

2. Um item na outra ponta: margin-left: auto

O align-self mexe na direção cruzada. E para mandar um item só para a outra ponta da linha (o botão "Sair" à direita do menu)? A primeira ideia seria um justify-self, mas no Flexbox ele não existe: o navegador aceita a palavra (ela funciona no Grid), mas num item flex ela não faz nada.

O jeito do Flexbox é uma margem automática. Uma margin-left: auto num item "come" todo o espaço que sobra à esquerda dele, e ele vai parar na ponta direita, levando junto os itens que vêm depois:

<link rel="stylesheet" href="style.css">
<nav class="menu">
  <a href="#">Início</a>
  <a href="#">Receitas</a>
  <a href="#">Contato</a>
  <a href="#" class="sair">Sair</a>
</nav>

.menu {
  display: flex;
  gap: 16px;
  padding: 8px;
  background-color: navy;
  font-family: sans-serif;
}

.menu a {
  color: white;
}

.sair {
  margin-left: auto;
}

"Início", "Receitas" e "Contato" ficam juntos à esquerda; "Sair" foi para a ponta direita. Troque o margin-left: auto por margin-right: auto no "Início" e veja o contrário: o "Início" fica sozinho à esquerda, e os outros três vão juntos para a direita. Com margin: auto (todos os lados), o item fica no meio do espaço livre, nas duas direções: é um dos jeitos de centralizar (aula Centralizando Qualquer Coisa).

3. order: outra posição, o mesmo HTML

Todo item flex tem um número de ordem, que por padrão é 0. O navegador desenha os itens do menor número para o maior; quem tem o mesmo número fica na ordem do HTML. Por isso, para pôr um item em primeiro, basta um número menor que 0; para mandá-lo para o fim, um número maior:

<link rel="stylesheet" href="style.css">
<div class="fila">
  <div class="item">1. Bolo</div>
  <div class="item">2. Torta</div>
  <div class="item destaque">3. Brigadeiro (destaque)</div>
  <div class="item fim">4. Encomendas</div>
  <div class="item">5. Pão</div>
</div>

.fila {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

.item {
  padding: 8px;
  background-color: firebrick;
  color: white;
  font-family: sans-serif;
}

.destaque {
  order: -1;
  background-color: darkgreen;
}

.fim {
  order: 1;
}

Na tela, a ordem ficou: Brigadeiro (que tem -1), depois Bolo, Torta e Pão (os três com 0, na ordem do HTML) e, por último, Encomendas (1). Os números escritos dentro dos itens contam a ordem do HTML, que não mudou.

order
A posição do item na fila, comparada com a dos irmãos.
-1
Um número inteiro (sem vírgula), que pode ser negativo. Não é "a posição 1, 2, 3": é um peso. Dez itens com order: 5 e um com order: 6 funcionam igual a dez com 0 e um com 1.
O order só muda a tela

O leitor de tela (o programa que lê a página em voz alta para quem não enxerga) e a tecla Tab seguem a ordem do HTML. Se o order põe um link em primeiro na tela, mas ele é o quinto no HTML, quem navega pelo teclado vê o foco "pular" de um jeito estranho. Use order para ajustes visuais pequenos (um destaque, uma troca de lugar numa tela estreita); se a ordem importa para entender o conteúdo, mude o HTML. A aula CSS e Acessibilidade volta a esse assunto.

Quando dá errado

CSS quase nunca mostra mensagem: o navegador ignora em silêncio o que não entende ou o que não se aplica.

justify-self num item flex não faz nada

O que aconteceu: a Ana tentou mandar o "Sair" para a direita com .sair { justify-self: flex-end; }.

O que você vê: nada muda; o "Sair" continua junto dos outros. O validador também não reclama: justify-self é uma propriedade válida do CSS (ela funciona no Grid, aula Alinhando no Grid). Só que, num item flex, ela é ignorada: na linha, quem distribui os itens é o justify-content do pai, para todos ao mesmo tempo.

Como consertar: margin-left: auto no item (seção 2).

O align-self foi parar no pai

O que aconteceu: .fila { display: flex; align-self: flex-start; }, esperando subir os itens.

O que você vê: os itens não se mexem. O align-self do .fila vale para a própria .fila dentro do pai dela (e só se esse pai também for flex ou grid).

Como consertar: para todos os itens, align-items no pai; para um só, align-self nesse item.

O align-self: stretch não estica

O que aconteceu: o item tem height: 40px e align-self: stretch.

O que você vê: o item continua com 40 pixels. Esticar só acontece quando a altura do item é auto; uma altura escrita vence.

Como consertar: apague o height (ou troque por min-height, que deixa crescer).

error: CSS: “align-self”: “middle” is not a “align-self” value.

O que aconteceu: palavras que parecem certas, mas não são do CSS: middle ("meio") e top ("topo").

$ vnu --css middle.css
"file:/home/ana/item/middle.css":2.15-2.20: error: CSS: “align-self”: “middle” is not a “align-self” value.
$ vnu --css top.css
"file:/home/ana/item/top.css":2.15-2.17: error: CSS: “align-self”: “top” is not a “align-self” value.

"middle não é um valor de align-self." A declaração é ignorada e o item volta ao alinhamento do pai. (O middle existe, mas em outra propriedade: o vertical-align de tabelas e de elementos em linha.)

Como consertar: center para o meio, flex-start (ou start) para o topo.

error: CSS: “order”: This number should be an integer.

O que aconteceu: a Ana quis pôr um item "entre o 1 e o 2" com order: 1.5;. Ou escreveu uma palavra: order: first;.

$ vnu --css ordem.css
"file:/home/ana/item/ordem.css":2.10-2.12: error: CSS: “order”: This number should be an integer.
$ vnu --css first.css
"file:/home/ana/item/first.css":2.10-2.14: error: CSS: “order”: “first” is not a “order” value.

"Este número deveria ser inteiro." O order só aceita números inteiros (negativos valem: order: -1 passa no validador sem nenhum aviso). A declaração errada é ignorada: o item fica com 0.

Como consertar: use inteiros e deixe "espaço" entre eles se precisar: order: 10, order: 20.

Resumo

  • align-self, no item, troca só para ele o alinhamento cruzado que o pai deu com align-items. auto (padrão) = obedecer o pai.
  • Os valores: flex-start, flex-end, center, stretch, baseline. middle e top não existem aqui.
  • No Flexbox não há justify-self: para empurrar um item para a outra ponta da linha, margin-left: auto.
  • order (inteiro, padrão 0) muda a posição na tela: menor primeiro; empate, ordem do HTML.
  • order não muda o Tab nem o leitor de tela: se a ordem importa, mude o HTML.
