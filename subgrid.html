CSS Subgrid

A Ana pôs três cartões de receita lado a lado com Grid. Ficou quase bonito: como um título tem três linhas e os outros têm uma, as descrições começam em alturas diferentes e os links "Ver receita" ficam desencontrados. Cada cartão monta a sua arrumação sozinho, sem olhar para os vizinhos. O subgrid ("subgrade") faz o contrário: os filhos de cada cartão passam a usar as linhas do grid de fora, e tudo se alinha de um cartão para o outro.

Você vai aprender
  • Por que cartões vizinhos ficam desalinhados, mesmo dentro de um grid.
  • grid-template-rows: subgrid: os cartões usando as linhas do grid pai.
  • O grid-row: span 3, a parte que todo mundo esquece.
  • grid-template-columns: subgrid: colunas alinhadas numa lista (o cardápio da padaria).
  • O gap que vem do pai, e como trocar.
  • Os três jeitos de o subgrid "não funcionar", com as fotos e a mensagem do validador.

Esta aula usa o Grid das aulas Introdução ao Grid, Linhas e Posicionando Itens. Os resultados são desenhados pelo seu navegador; as mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (ana@notebook), na pasta ~/site.

A ideia: a estante com prateleiras corridas

Imagine três caixas de feira lado a lado, cada uma com as suas divisórias. Numa, a divisória está a 10 cm; na outra, a 25 cm, porque o pote de cima é mais alto. Olhando de frente, nada se alinha.

Agora troque as divisórias por prateleiras corridas, que atravessam as três caixas. Se um pote é alto, a prateleira inteira sobe, nas três caixas ao mesmo tempo. O subgrid é isso: o grid pai define as prateleiras (as linhas), e cada cartão, em vez de ter as suas, usa as do pai.

1. O problema: cada cartão por si

Experimente: repare que "Crocante por fora." começa mais embaixo que as outras descrições, e que os três "Ver receita" não estão na mesma altura. Mude o título do pão de queijo para só "Pão de queijo" e veja tudo mudar de novo.

O grid de fora (.cartoes) só cuida de onde fica cada cartão: três colunas, uma linha. O que acontece dentro de cada cartão é outro grid, independente. No primeiro cartão, o título tem uma linha; no segundo, três. Cada um calcula as suas linhas sozinho, e as descrições caem em alturas diferentes.

2. A solução: grid-template-rows: subgrid

São duas mudanças no cartão:

.cartao {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
  padding: 12px;
  border: 2px solid tomato;
}
display: grid
O cartão continua sendo um grid: só um grid pode ter subgrid.
grid-row: span 3
"Ocupe 3 linhas do grid pai." O cartão tem três filhos (título, descrição, link), então precisa de três "prateleiras". Sem isso, ele ocupa uma linha só, e o subgrid tem uma prateleira para três coisas (veja Quando dá errado). O span ("abranger") vem da aula Posicionando Itens.
grid-template-rows: subgrid
"As minhas linhas são as do pai." Em vez de inventar linhas novas, o cartão usa as 3 linhas do .cartoes que ele ocupa. Como os três cartões ocupam as mesmas 3 linhas, a linha do título tem a altura do maior título, e as descrições começam juntas.

O resultado, com o mesmo HTML do exemplo de cima: os três títulos na primeira faixa, as três descrições começando na mesma altura, e os três "Ver receita" lado a lado na última faixa. No Chromium, o estilo calculado do cartão mostra grid-template-rows: subgrid [] [] [] [] (os [] são as 4 divisas das 3 linhas, sem nome) e grid-row-start: span 3.

Missão: alinhe os cartões. No .cartao, faça cada cartão ocupar 3 linhas do grid pai e usar as linhas dele com subgrid. Os três "Ver receita" devem ficar na mesma altura.

3. O gap vem junto

Depois da missão, repare no espaço entre o título e a descrição: ficou bem maior. É o gap: 16px do .cartoes. O subgrid herda do pai as linhas e o espaço entre elas, então os 16 px que separavam os cartões agora separam também o título da descrição.

Para um espaço diferente dentro do cartão, declare o seu próprio row-gap ("espaço entre linhas") no subgrid. Ele vale só dentro do cartão:

.cartao {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
  row-gap: 4px;
}

No Chromium, com o row-gap: 4px, os itens continuam alinhados de um cartão para o outro, mas mais próximos: o título do pão de queijo fica a poucos pixels da descrição, e os cartões continuam separados pelos 16 px do pai.

4. Colunas: grid-template-columns: subgrid

O subgrid funciona nas duas direções. Nas colunas, ele resolve um problema clássico: o cardápio da padaria da Ana é uma lista (<ul>), e cada item tem três partes: o nome, a porção e o preço. Cada <li> é um grid de três colunas, mas cada um calcula a largura das suas colunas sozinho, e os preços ficam em zigue-zague.

Experimente: veja os preços desalinhados. Depois apague o /* e o */ da última linha do li e veja as três colunas se alinharem.

<link rel="stylesheet" href="style.css">
<h2>Padaria da Ana</h2>
<ul class="cardapio">
  <li><span>Pão francês</span> <span>unidade</span> <strong>R$ 0,90</strong></li>
  <li><span>Bolo de cenoura com cobertura</span> <span>fatia</span> <strong>R$ 8,00</strong></li>
  <li><span>Café</span> <span>xícara</span> <strong>R$ 5,50</strong></li>
</ul>

.cardapio {
  display: grid;
  grid-template-columns: auto auto auto;
  gap: 8px 24px;
  padding: 0;
  list-style: none;
}

.cardapio li {
  grid-column: 1 / -1;
  display: grid;
  grid-template-columns: auto auto auto;
  /* grid-template-columns: subgrid; */
}
.cardapio
O pai: um grid de três colunas auto (cada coluna fica da largura do conteúdo). gap: 8px 24px é 8 px entre as linhas e 24 px entre as colunas.
grid-column: 1 / -1
Cada <li> ocupa da primeira à última divisa de coluna do pai, ou seja, as três colunas. O -1 quer dizer "a última divisa" (aula Posicionando Itens). É o mesmo papel do span 3 nos cartões.
grid-template-columns: subgrid
Escrita depois do grid-template-columns: auto auto auto, ela vence (aula Cascata): as colunas do item passam a ser as do pai. A coluna do nome passa a ser uma só para a lista inteira, larga o bastante para o maior nome ("Bolo de cenoura com cobertura"), e as porções e os preços se alinham.

No Chromium, com a linha comentada, os preços de cada item começam numa posição diferente. Com elas, as porções e os preços formam duas colunas retas, como numa tabela. E o HTML continua sendo uma lista de verdade (<ul> e <li>): o alinhamento veio do CSS, sem trocar a lista por uma tabela.

Suporte

O subgrid funciona no Chrome, Edge, Firefox e Safari atuais: o MDN marca Baseline, amplamente disponível, em todos os navegadores principais desde setembro de 2023. Num navegador mais antigo, grid-template-rows: subgrid é ignorado e o cartão volta a ser um grid comum: fica desalinhado como no exemplo 1, mas nada quebra.

Quando dá errado

Esqueceu o span 3: tudo empilhado no mesmo lugar 
.cartao {
  display: grid;
  grid-template-rows: subgrid;
}

O que o leitor vê: o título, a descrição e o link de cada cartão desenhados uns por cima dos outros, numa só faixa: um borrão de letras. Foi o que a foto do Chromium mostrou.

Por quê: sem grid-row: span 3, o cartão ocupa uma linha do pai, e o subgrid tem uma linha só. Um subgrid não cria linhas novas para quem sobra (o MDN explica: sem linhas implícitas na direção do subgrid), então os três filhos vão para a última linha que existe, a única, e se sobrepõem. O estilo calculado mostra grid-template-rows: subgrid [] []: duas divisas, uma linha.

Como consertar: grid-row: span 3, com o número de filhos do cartão.

O cartão não é grid: o subgrid não faz nada 
.cartao {
  grid-row: span 3;
  grid-template-rows: subgrid;
}

O que o leitor vê: os cartões ficam como no exemplo 1, desalinhados. O cartão ocupa as 3 linhas do pai, mas o que está dentro dele não segue as linhas: título, descrição e link ficam um embaixo do outro, cada um com a sua altura.

Por quê: grid-template-rows só vale num elemento com display: grid. Sem ele, o cartão é um bloco comum, e os filhos ficam um embaixo do outro, cada um com a sua altura. A declaração é válida (o validador não reclama e o F12 não a risca): só não tem efeito. O mesmo acontece se o pai não for grid: aí não existem linhas para herdar, e o subgrid vira um grid comum.

Como consertar: display: grid no pai e no cartão.

Escreveu errado: “sub-grid” is not a “grid-template-columns” value 
$ vnu --css estilo.css
"file:/home/ana/site/estilo.css":7.26-7.33: error: CSS: “grid-template-columns”: “sub-grid” is not a “grid-template-columns” value.

O que significa: "sub-grid não é um valor de grid-template-columns". A palavra é subgrid, sem hífen. O navegador joga a declaração fora e o item volta às colunas que tinha; no F12, a linha aparece riscada.

Referência rápida

EscritaO que faz
grid-template-rows: subgridAs linhas do elemento são as linhas do pai que ele ocupa
grid-template-columns: subgridO mesmo, com as colunas
grid-row: span N / grid-column: 1 / -1Quantas linhas ou colunas do pai o subgrid ocupa (obrigatório: sem isso, ele ocupa só uma)
row-gap / column-gap no subgridTroca, só lá dentro, o espaço herdado do pai
RequisitosO pai é display: grid; o subgrid também é display: grid

Resumo

  • Num grid, cada filho que também é grid monta as suas linhas sozinho: cartões vizinhos ficam desalinhados.
  • grid-template-rows: subgrid (ou grid-template-columns: subgrid) faz o elemento usar as linhas (ou colunas) do pai. Como os vizinhos usam as mesmas, tudo se alinha pelo maior conteúdo.
  • O subgrid precisa ocupar várias faixas do pai: grid-row: span 3 ou grid-column: 1 / -1. Sem isso, os filhos se sobrepõem.
  • O pai e o subgrid são display: grid. O gap vem do pai; um row-gap no subgrid troca só lá dentro.
  • Funciona em todos os navegadores atuais desde setembro de 2023. A palavra é subgrid, sem hífen.
