CSS transform

Um selo de "oferta" torto no canto do produto, um botão que cresce um pouquinho quando o mouse passa, uma seta que vira para baixo quando o menu abre. Tudo isso é transform ("transformar"): a propriedade que move, gira, aumenta e inclina um elemento depois que ele já está no lugar, sem empurrar nada em volta.

Você vai aprender
  • A ideia do transform: o elemento muda, mas o lugar dele na página fica reservado.
  • As quatro funções: translate() (mover), rotate() (girar), scale() (escalar) e skew() (inclinar).
  • Como juntar várias, e por que a ordem muda o resultado.
  • O transform-origin: em volta de qual ponto o elemento gira e cresce.
  • As propriedades separadas translate, rotate e scale.
  • O que é aquele matrix(…) que aparece no F12, e os erros mais comuns.

Antes, é bom ter visto O Modelo de Caixa e position: relative. As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana. Os valores calculados foram conferidos no Chromium.

A ideia: o adesivo em cima da página

Imagine a vitrine da lojinha da Ana com etiquetas coladas no vidro. Cada etiqueta tem o seu lugar. Agora a Ana pega uma etiqueta, gira, puxa um pouco para o lado, aumenta com uma lupa. As outras etiquetas não se mexem: o lugar da primeira continua lá, vazio, do jeito que estava.

O transform é assim. Primeiro o navegador monta a página normalmente (a caixa de cada elemento, as margens, o fluxo). Depois, só na hora de pintar, ele mexe no desenho do elemento transformado. Para o resto da página, o elemento continua no lugar original e do tamanho original. Por isso:

  • mover com transform não empurra os vizinhos (diferente de mudar a margin);
  • um elemento aumentado com scale pode ficar por cima dos vizinhos;
  • é ótimo para efeitos e animações: o navegador não precisa recalcular a página inteira a cada passo.

1. translate(): mover

Nos exemplos desta aula, a linha tracejada mostra o lugar original do elemento, e a caixa colorida mostra onde ele foi desenhado.

<style>
  .lugar { display: inline-block; width: 100px; height: 60px; margin: 10px 40px 30px 10px; outline: 2px dashed gray; }
  .caixa { width: 100px; height: 60px; background-color: firebrick; color: white; font: 14px monospace; display: grid; place-items: center; }
  .movida { transform: translate(30px, 20px); }
</style>
<div class="lugar"><div class="caixa">original</div></div>
<div class="lugar"><div class="caixa movida">movida</div></div>
<div class="lugar"><div class="caixa">vizinha</div></div>
transform:
A propriedade. Ela recebe uma ou mais funções de transformação.
translate(
"transladar", deslocar: mover sem girar.
30px,
Quanto andar na horizontal: positivo vai para a direita, negativo para a esquerda.
20px)
Quanto andar na vertical: positivo vai para baixo, negativo para cima. (Na tela, o eixo vertical cresce para baixo.) Os dois números são separados por vírgula.

A caixa do meio foi desenhada 30 px à direita e 20 px abaixo do lugar tracejado, e a vizinha nem percebeu: continua no mesmo lugar.

EscritaO que faz
translate(30px, 20px)30 px para a direita e 20 px para baixo
translate(30px)só na horizontal (o vertical fica 0)
translateX(-10px)só na horizontal: 10 px para a esquerda
translateY(-4px)só na vertical: 4 px para cima (o clássico "botão que sobe")
translate(50%, 0)em porcentagem do próprio elemento: metade da largura dele (e não do pai, como no width)

A porcentagem do próprio tamanho é muito usada para centralizar: translate(-50%, -50%) puxa o elemento metade da largura e metade da altura dele mesmo de volta. Você verá isso na aula position: absolute.

2. rotate(): girar

<style>
  .lugar { display: inline-block; width: 100px; height: 60px; margin: 24px; outline: 2px dashed gray; }
  .caixa { width: 100px; height: 60px; background-color: firebrick; color: white; font: 14px monospace; display: grid; place-items: center; }
</style>
<div class="lugar"><div class="caixa" style="transform: rotate(15deg)">15deg</div></div>
<div class="lugar"><div class="caixa" style="transform: rotate(-15deg)">-15deg</div></div>
<div class="lugar"><div class="caixa" style="transform: rotate(90deg)">90deg</div></div>
<div class="lugar"><div class="caixa" style="transform: rotate(0.5turn)">0.5turn</div></div>
rotate(15deg)
Gira 15 graus (deg, de degrees). Positivo gira no sentido do relógio; negativo, no sentido contrário.
rotate(0.5turn)
turn = "volta": 1turn é a volta inteira (360 graus), 0.5turn é meia volta (180 graus). Repare que a caixa de meia volta ficou de cabeça para baixo, com o texto ao contrário.

A caixa gira em volta do centro dela. A seção 6 mostra como mudar esse ponto.

3. scale(): aumentar e diminuir

<style>
  .lugar { display: inline-block; width: 100px; height: 60px; margin: 24px; outline: 2px dashed gray; }
  .caixa { width: 100px; height: 60px; background-color: firebrick; color: white; font: 14px monospace; display: grid; place-items: center; }
</style>
<div class="lugar"><div class="caixa" style="transform: scale(0.5)">0.5</div></div>
<div class="lugar"><div class="caixa" style="transform: scale(1.3)">1.3</div></div>
<div class="lugar"><div class="caixa" style="transform: scale(1.5, 1)">1.5, 1</div></div>
<div class="lugar"><div class="caixa" style="transform: scale(-1, 1)">-1, 1</div></div>
EscritaO que faz
scale(1)tamanho normal (não muda nada)
scale(0.5)metade do tamanho (é um número, e não porcentagem: 0.5 = 50%)
scale(1.3)30% maior. Repare que ela passa da linha tracejada, por cima do espaço em volta
scale(1.5, 1)largura × 1,5 e altura igual: a caixa "estica" para os lados, e o texto junto
scale(-1, 1)número negativo espelha: o texto aparece ao contrário, como num espelho
scaleX(…) / scaleY(…)só a largura / só a altura
Aumentar com scale não é mudar o width

O scale aumenta o desenho, inclusive o texto, a borda e a sombra, e não muda o espaço que o elemento ocupa. Para um cartão maior "de verdade", que empurra os vizinhos, use width, padding ou font-size. O scale é para efeitos: o botão que cresce um pouquinho no hover, a foto que dá um zoom.

4. skew(): inclinar

<style>
  .lugar { display: inline-block; width: 100px; height: 60px; margin: 24px; outline: 2px dashed gray; }
  .caixa { width: 100px; height: 60px; background-color: firebrick; color: white; font: 14px monospace; display: grid; place-items: center; }
</style>
<div class="lugar"><div class="caixa" style="transform: skew(-15deg)">skew(-15deg)</div></div>
<div class="lugar"><div class="caixa" style="transform: skewY(10deg)">skewY(10deg)</div></div>

skew() ("enviesar") puxa os lados do retângulo em direções opostas, e ele vira um paralelogramo. skew(-15deg) (ou skewX) inclina para os lados, como letra itálica; skewY(10deg) inclina para cima e para baixo. É o menos usado dos quatro: aparece em faixas e etiquetas "dinâmicas".

Experimente: troque a função do .etiqueta por cada uma das quatro (translate(20px, 10px), rotate(-8deg), scale(1.4), skew(-15deg)) e veja que o parágrafo de baixo nunca sai do lugar.

<link rel="stylesheet" href="style.css">
<p><span class="etiqueta">Novidade</span></p>
<p>Pão de queijo recheado com goiabada, só às sextas.</p>

.etiqueta {
  display: inline-block;
  background-color: #2f7d32;
  color: white;
  padding: 4px 12px;
  transform: rotate(-8deg);
}

5. Várias funções juntas, e a ordem

Para fazer mais de uma coisa, escreva as funções uma depois da outra, separadas por espaço:

.selo {
  transform: translate(40px, 0) rotate(45deg);
}

Aqui vem o pulo do gato: a ordem importa. Veja as mesmas duas funções nas duas ordens:

<style>
  .lugar { display: inline-block; width: 100px; height: 60px; margin: 30px 70px 50px 20px; outline: 2px dashed gray; }
  .caixa { width: 100px; height: 60px; background-color: firebrick; color: white; font: 13px monospace; display: grid; place-items: center; }
</style>
<div class="lugar"><div class="caixa" style="transform: translate(40px, 0) rotate(45deg)">move e gira</div></div>
<div class="lugar"><div class="caixa" style="transform: rotate(45deg) translate(40px, 0)">gira e move</div></div>

As duas giraram 45 graus, mas foram parar em lugares diferentes. Na primeira, a caixa andou 40 px para a direita e depois girou no lugar. Na segunda, ela girou primeiro, e o "para a frente" dela passou a apontar na diagonal: os 40 px foram na diagonal, para a direita e para baixo.

Pense em você andando numa sala: "dê dois passos e vire à direita" não termina no mesmo lugar que "vire à direita e dê dois passos". O navegador aplica as funções da esquerda para a direita, cada uma a partir de onde a anterior deixou.

6. transform-origin: o ponto de apoio

Por padrão, o elemento gira e cresce em volta do centro. O transform-origin ("origem da transformação") muda esse ponto, como trocar o lugar do prego que segura um quadro na parede:

<style>
  .lugar { display: inline-block; width: 100px; height: 60px; margin: 30px 50px 50px 30px; outline: 2px dashed gray; }
  .caixa { width: 100px; height: 60px; background-color: firebrick; color: white; font: 13px monospace; display: grid; place-items: center; transform: rotate(20deg); }
</style>
<div class="lugar"><div class="caixa">center</div></div>
<div class="lugar"><div class="caixa" style="transform-origin: top left">top left</div></div>
<div class="lugar"><div class="caixa" style="transform-origin: bottom right">bottom right</div></div>

As três giraram 20 graus. A primeira girou em volta do centro. A segunda ficou "presa" pelo canto de cima à esquerda (top left), que não saiu do lugar. A terceira, pelo canto de baixo à direita (bottom right).

ValorO ponto
center (o padrão)o meio do elemento (é o mesmo que 50% 50%)
top left, bottom right…um canto
left, top…o meio de um lado
20px 10px ou 0% 100%um ponto exato (horizontal, depois vertical)

7. As propriedades separadas: translate, rotate e scale

Há um jeito mais novo de escrever as três transformações mais comuns: cada uma é uma propriedade própria, sem a palavra transform:

.selo {
  translate: 20px 10px;
  rotate: -10deg;
  scale: 1.2;
}
translate: 20px 10px;
O mesmo que translate(20px, 10px). Atenção: aqui os números vão separados por espaço, sem vírgula.
rotate: -10deg;
O mesmo que rotate(-10deg).
scale: 1.2;
O mesmo que scale(1.2). Dois números (scale: 1.5 1;) também vão separados por espaço.

A vantagem é que elas são independentes. Com o transform, se o selo já tem transform: rotate(-10deg) e você escreve, no hover, transform: scale(1.2), o rotate some (o novo valor substitui o antigo inteiro). Com as propriedades separadas, scale: 1.2 no hover não mexe no rotate:

Experimente: passe o mouse no primeiro selo: ele "desentorta", porque o transform do hover substituiu o rotate. No segundo, ele cresce e continua torto. Troque scale: 1.2; por rotate: 0deg; no hover do segundo e veja de novo.

<link rel="stylesheet" href="style.css">
<p><span class="selo antigo">transform</span></p>
<p><span class="selo novo">rotate + scale</span></p>

.selo {
  display: inline-block;
  background-color: #c2410c;
  color: white;
  padding: 6px 12px;
  margin: 12px;
}

.antigo {
  transform: rotate(-10deg);
}

.antigo:hover {
  transform: scale(1.2);
}

.novo {
  rotate: -10deg;
}

.novo:hover {
  scale: 1.2;
}
Suporte

As propriedades translate, rotate e scale funcionam no Chrome e no Edge desde a versão 104, no Firefox desde a 72 e no Safari desde a 14.1 (o último a chegar foi o Chrome, em 2022), segundo o MDN. O transform funciona em todos há muitos anos. Quando as duas formas estão no mesmo elemento, o navegador aplica primeiro translate, depois rotate, depois scale e, por último, o transform.

8. O que o F12 mostra: matrix(…)

Abra o F12 num elemento com transform: rotate(45deg) e olhe a aba Computed (Calculado). Em vez do que você escreveu, aparece algo assim:

transform: matrix(0.707107, 0.707107, -0.707107, 0.707107, 0, 0)

Não se assuste: o navegador junta todas as funções do transform numa conta só, uma matriz de seis números, e é ela que fica guardada como valor calculado. A aba Styles (Estilos) continua mostrando o que você escreveu. Conferido no Chromium:

Você escreveValor calculado
transform: translate(20px, 10px)matrix(1, 0, 0, 1, 20, 10)
transform: translateY(-4px)matrix(1, 0, 0, 1, 0, -4)
transform: scale(1.5)matrix(1.5, 0, 0, 1.5, 0, 0)
transform: scale(-1, 1)matrix(-1, 0, 0, 1, 0, 0)
transform: rotate(45deg)matrix(0.707107, 0.707107, -0.707107, 0.707107, 0, 0)
transform: rotate(45deg) translate(40px, 0)matrix(0.707107, 0.707107, -0.707107, 0.707107, 28.2843, 28.2843)
rotate: -10deg (a propriedade separada)-10deg (e o transform continua none)

Dá para ler os casos simples: os dois últimos números são o deslocamento em px (horizontal e vertical); o primeiro e o quarto são a escala na horizontal e na vertical quando não há giro. Com giro, entram senos e cossenos (0,707107 é o seno e o cosseno de 45 graus), e não vale a pena fazer a conta de cabeça. Repare na última linha da tabela: a rotação seguida de um passo de 40 px virou um deslocamento de 28,28 px para a direita e 28,28 px para baixo, a diagonal da seção 5. E as propriedades separadas mostram o valor do jeito que você escreveu.

Quando dá errado

Nada acontece num <span> (e o validador não reclama)

O que aconteceu: o transform foi posto num elemento em linha, como um <span>, um <a> ou um <strong> no meio do texto:

<style>
  .selo { background-color: #c2410c; color: white; padding: 2px 8px; transform: rotate(-10deg); }
  .bloco { display: inline-block; }
</style>
<p>Hoje: <span class="selo">oferta</span> (span normal)</p>
<p>Hoje: <span class="selo bloco">oferta</span> (com display: inline-block)</p>

O primeiro selo continua reto; o segundo gira. A regra do CSS é que um elemento em linha comum não é "transformável": o navegador simplesmente não aplica o transform. O curioso é que o F12 mostra o valor calculado (matrix(…)) normalmente, sem risco nenhum, e mesmo assim nada gira.

Como consertar: dê display: inline-block (ou block, flex…) ao elemento. Veja a aula display.

A primeira transformação sumiu

O que aconteceu: duas declarações transform na mesma regra (ou em regras diferentes):

.selo {
  transform: rotate(-10deg);
  transform: scale(1.2);
}

O selo fica maior, mas reto. Cada transform é um valor inteiro, e pela cascata o último vence: a primeira linha aparece riscada no F12. O validador não reclama, porque as duas linhas estão certas.

Como consertar: junte numa linha só, separada por espaço (transform: rotate(-10deg) scale(1.2);), ou use as propriedades separadas (rotate: -10deg; scale: 1.2;).

error: CSS: “transform”: only “0” can be a “unit”. You must put a unit after your number.

O que aconteceu: o ângulo ficou sem unidade: transform: rotate(45);.

$ vnu --css semdeg.css
"file:/home/ana/transf/semdeg.css":2.23-2.23: error: CSS: “transform”: only “0” can be a “unit”. You must put a unit after your number.

"Só o 0 pode ficar sem unidade. Você precisa pôr uma unidade depois do número." O navegador ignora a declaração inteira, e nada gira.

Como consertar: rotate(45deg). O mesmo vale para o translate: translate(20px, 10px), com px. Só o scale não tem unidade.

error: CSS: “transform”: “ ” is an incorrect operator.

O que aconteceu: os dois números do translate() ficaram sem vírgula: transform: translate(20px 10px);.

$ vnu --css semvirg.css
"file:/home/ana/transf/semvirg.css":2.33-2.33: error: CSS: “transform”: “ ” is an incorrect operator.

"O espaço é um operador incorreto": dentro da função translate(), os números vão separados por vírgula. É fácil confundir, porque na propriedade translate é o contrário: translate: 20px, 10px; dá a mesma mensagem, só que com a vírgula: “translate”: “,” is an incorrect operator.

Como consertar: função com vírgula, transform: translate(20px, 10px); propriedade com espaço, translate: 20px 10px.

error: CSS: “transform”: “,” is an incorrect operator.

O que aconteceu: vírgula entre as funções: transform: rotate(10deg), scale(1.2);.

$ vnu --css virgulas.css
"file:/home/ana/transf/virgulas.css":2.38-2.38: error: CSS: “transform”: “,” is an incorrect operator.

Entre funções vai só espaço. Com a vírgula, a declaração inteira é ignorada: nem gira, nem aumenta.

Como consertar: transform: rotate(10deg) scale(1.2);.

O elemento aumentado cobre o vizinho

O que aconteceu: um cartão com scale(1.1) ficou por cima do texto ou do cartão ao lado. Não é erro: o transform não muda o espaço reservado (a ideia do adesivo). Se ele cobrir algo importante, dê mais espaço em volta (gap, margin) ou use um scale menor, como 1.05.

Resumo

  • transform mexe no desenho do elemento depois que a página está montada: o lugar original fica reservado e os vizinhos não se mexem.
  • translate(x, y) move, rotate(…deg) gira, scale(n) aumenta ou diminui, skew(…deg) inclina.
  • Várias funções vão separadas por espaço e são aplicadas da esquerda para a direita: a ordem muda o resultado.
  • transform-origin escolhe o ponto de apoio (padrão: o centro).
  • As propriedades translate, rotate e scale fazem o mesmo, sem vírgula e independentes entre si.
  • No F12, o transform calculado vira matrix(…): os dois últimos números são o deslocamento.
  • Erros comuns: transform num elemento em linha, dois transform na mesma regra, ângulo sem deg, vírgula no lugar errado.
