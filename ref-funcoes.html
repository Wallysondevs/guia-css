CSS Funções

Uma função do CSS é um valor que faz alguma coisa antes de ser usado: uma conta (calc(100% - 2rem)), a leitura de uma variável (var(--cor)), uma cor misturada (color-mix(…)), um giro (rotate(45deg)). Esta página lista todas as funções que você vai encontrar, por assunto, com um exemplo, o resultado calculado pelo Chromium e a aula que explica cada uma.

Como usar esta página
  • Procure com Ctrl+F pelo nome da função (clamp, oklch).
  • A coluna "Calculado" mostra o que o Chromium devolveu em getComputedStyle, o mesmo que a aba Computed do F12. Medido num elemento dentro de um pai de 400px, numa janela de 800 × 600, com a letra padrão de 16px. Onde aparece "—", o valor depende da tela ou não foi medido.
  • As funções recentes estão marcadas com novo e têm o suporte numa nota (dados do MDN, outubro de 2026).

Como se escreve

.cartao {
  width: calc(100% - 2rem);
  color: var(--cor-marca, tomato);
}
calc
O nome da função, grudado no parêntese: calc (…), com espaço, não funciona.
( … )
Os argumentos, o que a função recebe para trabalhar.
100% - 2rem
No calc(), o + e o - precisam de espaço dos dois lados: 100%-2rem não funciona.
--cor-marca, tomato
Vários argumentos são separados por vírgula. Aqui, o segundo é a "reserva": a cor usada se a variável não existir.

Uma função pode ir dentro de outra: calc(var(--espaco) * 2), clamp(1rem, 2vw + 1rem, 3rem).

Experimente

Um cartão feito só com funções. Mude o valor da variável --cor-marca, troque a porcentagem do color-mix(), aperte os botões 375 e 768 da barra do quadro para ver o clamp() agir no título:

<link rel="stylesheet" href="style.css">
<div class="cartao">
  <h2>Bolo de cenoura</h2>
  <p>Com cobertura de chocolate.</p>
</div>

:root {
  --cor-marca: tomato;
  --espaco: 1rem;
}

.cartao {
  box-sizing: border-box;
  width: calc(100% - 2 * var(--espaco));
  padding: var(--espaco);
  background-color: color-mix(in srgb, var(--cor-marca) 15%, white);
  border-left: 6px solid var(--cor-marca);
  transform: rotate(-1deg);
}

h2 {
  font-size: clamp(1.25rem, 5vw, 2.5rem);
  color: var(--cor-marca);
  filter: drop-shadow(1px 1px 0 white);
}

Quando dá errado

Espaço que falta, vírgula que falta, -- que falta 
.cartao {
  width: calc(100%-2rem);
  color: var(cor);
}
h1 {
  font-size: clamp(1rem 4vw 2rem);
}

O que a Ana vê: a largura, a cor e o tamanho do título continuam os de antes, como se as três linhas não existissem.

Por quê:

  • calc(100%-2rem): sem espaço em volta do -, o navegador lê "100%" seguido de "-2rem" (um número negativo), sem conta nenhuma. A expressão é inválida. Medido no Chromium: a largura ficou a do bloco inteiro, como se a declaração não existisse.
  • var(cor): o nome da variável sempre começa com --: var(--cor).
  • clamp(1rem 4vw 2rem): faltaram as vírgulas entre os três valores.

O validador W3C responde com o genérico Parse Error ("erro de leitura"), apontando a coluna:

$ vnu --css calc.css
"file:/home/ana/ref/funcoes/calc.css":2.24-2.24: error: CSS: “width”: Parse Error.
$ vnu --css var.css
"file:/home/ana/ref/funcoes/var.css":2.17-2.17: error: CSS: “color”: Parse Error.
$ vnu --css clamp.css
"file:/home/ana/ref/funcoes/clamp.css":2.33-2.33: error: CSS: “font-size”: Parse Error.

Como resolver: espaço dos dois lados do + e do - no calc(); -- no nome da variável; vírgulas entre os argumentos.

A variável que não existe (e o F12 não risca)

Com width: var(--larg) e nenhuma --larg definida, o navegador não tem como saber, ao ler o CSS, que a variável não existe: a declaração parece válida e não aparece riscada no painel Styles. Na hora de calcular, o valor vira o padrão da propriedade (ou o herdado, se ela é herdada). Medido no Chromium: width: var(--larg) deu 400px (a largura automática, a do pai) e color: var(--x) deu rgb(0, 0, 0) (a cor herdada). Use uma reserva, var(--larg, 20rem), e confira o nome da variável na aba Computed.

O validador que reclama do que está certo

O vnu 26.10.12 ainda não conhece algumas funções novas e dá erro em CSS que os navegadores entendem. Conferido:

$ vnu --css t.css
"file:/home/ana/ref/funcoes/t.css":2.53-2.53: error: CSS: “background-image”: “image-set("a.png" 1x,"b.png" 2x)” is not a “background-image” value.

Também deram erro linear(0, 0.5, 1), color(display-p3 1 0 0) e sibling-index(). Já clamp(), min(), color-mix(), oklch(), light-dark(), round(), abs(), hwb(), lab(), env() e a cor relativa rgb(from …) passaram sem mensagem. Quando o erro é numa função nova, confira o suporte no MDN antes de mexer no código.

Missão

Missão: a Ana criou as variáveis, mas esqueceu de usá-las. (1) O título deve usar var(--cor-marca) como cor. (2) O padding do cartão deve ser uma vez e meia o --espaco: use calc() com var(--espaco) (o resultado deve dar 24px).

<link rel="stylesheet" href="style.css">
<div class="cartao">
  <h2>Sonho de creme</h2>
  <p>Recheado na hora.</p>
</div>

:root {
  --cor-marca: tomato;
  --espaco: 1rem;
}

.cartao {
  padding: 10px;
  border: 2px solid gold;
}

h2 {
  color: black;
}

:root {
  --cor-marca: tomato;
  --espaco: 1rem;
}

.cartao {
  padding: calc(var(--espaco) * 1.5);
  border: 2px solid gold;
}

h2 {
  color: var(--cor-marca);
}

Resumo

  • Função = nome grudado no parêntese, argumentos separados por vírgula: clamp(1rem, 4vw, 2rem).
  • Contas: calc() (espaço em volta de + e -), min(), max(), clamp(), round().
  • Variáveis: var(--nome, reserva). Também env(), attr(), url().
  • Cores: rgb(), hsl(), hwb(), oklch(), color-mix(), light-dark(); alfa depois da barra.
  • Degradês, transform, filter, curvas de animação, Grid e clip-path têm as suas funções.
  • Função escrita errada = declaração ignorada (Parse Error no validador). Variável inexistente não é riscada: vira o valor padrão.
  • O vnu ainda dá erro em algumas funções novas (image-set(), linear(), color(display-p3 …)).
