CSS hsl()

Com rgb() e hexadecimal você escolhe a força de três luzes. Funciona, mas responda rápido: qual é a versão mais clara de rgb(199 64 31)? Difícil, porque os três números mudam juntos. A função hsl() descreve a cor do jeito que as pessoas pensam: qual cor, quão viva e quão clara. Para clarear, basta subir um número.

Você vai aprender
  • As três partes de hsl(9 100% 64%): matiz, saturação e luminosidade.
  • A roda de cores: o vermelho no 0, o verde no 120, o azul no 240.
  • A saturação e a luminosidade lado a lado, do cinza ao vivo e do preto ao branco.
  • O grande truque do hsl(): tons mais claros e mais escuros da mesma cor, mudando um número só.
  • Transparência com a barra, a forma antiga com vírgulas e o hsla().
  • Uma limitação: o "50%" do amarelo parece mais claro que o "50%" do azul.
  • Os erros reais do validador (como o % esquecido).

Antes, é bom ter feito rgb(). Os quadros "Resultado" e as caixas "Experimente" são desenhados agora pelo seu navegador. As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: o mostruário da loja de tintas

Numa loja de tintas, o mostruário é organizado assim: primeiro você escolhe a cor (um laranja); depois, numa cartela, escolhe entre o laranja vivo e o laranja acinzentado; e, descendo a cartela, do laranja escuro ao clarinho, quase branco. São três perguntas, e cada uma é um número do hsl():

LetraEm inglêsEm portuguêsA perguntaValores
HhuematizQual cor?0 a 360 (graus na roda de cores)
SsaturationsaturaçãoQuão viva?0% (cinza) a 100% (a cor mais viva)
LlightnessluminosidadeQuão clara?0% (preto) a 100% (branco); 50% é a cor "pura"

1. A anatomia de hsl(9 100% 64%)

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p>Bolo de cenoura com cobertura de chocolate.</p>

h1 {
  color: hsl(9 100% 64%);
}
hsl
O nome da função, colado no parêntese.
9
A matiz: a posição na roda de cores, em graus. O 0 é o vermelho; o 9 é um vermelho que já puxa um pouquinho para o laranja. Sem %.
100%
A saturação: 100% é a cor mais viva possível, sem nada de cinza.
64%
A luminosidade: um pouco acima do meio (50%), então um pouco mais clara que a cor pura.

É, de novo, o tomate: o navegador guarda hsl(9 100% 64%) como rgb(255, 99, 71), igual a tomato e #ff6347. Na caixa acima, mude só o primeiro número (tente 120, 200, 280) e veja a cor dar a volta na roda, com a mesma "força".

2. A matiz: a roda de cores

Imagine as cores do arco-íris dispostas num círculo. A matiz é o ângulo: o vermelho fica no 0, o verde um terço da volta depois (120) e o azul a dois terços (240). No 360, a volta se fecha e estamos no vermelho de novo. As faixas abaixo têm saturação 100% e luminosidade 50%; só a matiz muda:

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px; /* espaço em volta do texto (aula Espaço Interno) */
    font-family: monospace;
  }
  .h0 { background-color: hsl(0 100% 50%); }
  .h30 { background-color: hsl(30 100% 50%); }
  .h60 { background-color: hsl(60 100% 50%); }
  .h120 { background-color: hsl(120 100% 50%); }
  .h180 { background-color: hsl(180 100% 50%); }
  .h240 { background-color: hsl(240 100% 50%); color: white; }
  .h300 { background-color: hsl(300 100% 50%); }
  .h360 { background-color: hsl(360 100% 50%); }
</style>
<p class="h0">hsl(0 100% 50%) vermelho</p>
<p class="h30">hsl(30 100% 50%) laranja</p>
<p class="h60">hsl(60 100% 50%) amarelo</p>
<p class="h120">hsl(120 100% 50%) verde</p>
<p class="h180">hsl(180 100% 50%) ciano</p>
<p class="h240">hsl(240 100% 50%) azul</p>
<p class="h300">hsl(300 100% 50%) magenta</p>
<p class="h360">hsl(360 100% 50%) vermelho de novo</p>

Vale guardar três marcos: 0 vermelho, 120 verde, 240 azul. O resto fica entre eles: o amarelo no meio do vermelho e do verde (60), o ciano no meio do verde e do azul (180).

3. A saturação: do cinza ao vivo

Mesma matiz (0, vermelho), mesma luminosidade (50%); só a saturação muda:

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px;
    font-family: monospace;
    color: white;
  }
  .s0 { background-color: hsl(0 0% 50%); }
  .s25 { background-color: hsl(0 25% 50%); }
  .s50 { background-color: hsl(0 50% 50%); }
  .s75 { background-color: hsl(0 75% 50%); }
  .s100 { background-color: hsl(0 100% 50%); }
</style>
<p class="s0">hsl(0 0% 50%)</p>
<p class="s25">hsl(0 25% 50%)</p>
<p class="s50">hsl(0 50% 50%)</p>
<p class="s75">hsl(0 75% 50%)</p>
<p class="s100">hsl(0 100% 50%)</p>

Com 0%, sobra um cinza médio: não tem cor nenhuma. Subindo, o vermelho vai "acordando": primeiro um vermelho apagado, meio acinzentado, até o vermelho puro em 100%. Saturação baixa dá cores mais sóbrias, boas para fundos; saturação alta chama atenção, boa para um botão ou um aviso.

4. A luminosidade: do preto ao branco

Mesma matiz e saturação; só a luminosidade muda:

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px;
    font-family: monospace;
  }
  .l0 { background-color: hsl(0 100% 0%); color: white; }
  .l25 { background-color: hsl(0 100% 25%); color: white; }
  .l50 { background-color: hsl(0 100% 50%); color: black; }
  .l75 { background-color: hsl(0 100% 75%); }
  .l100 { background-color: hsl(0 100% 100%); }
</style>
<p class="l0">hsl(0 100% 0%) preto</p>
<p class="l25">hsl(0 100% 25%) vermelho escuro</p>
<p class="l50">hsl(0 100% 50%) o vermelho puro</p>
<p class="l75">hsl(0 100% 75%) vermelho claro (rosa)</p>
<p class="l100">hsl(0 100% 100%) branco</p>

Nas pontas, a matiz deixa de importar: 0% é sempre preto e 100% é sempre branco (a última faixa está aí, branca sobre o fundo branco). A cor "de verdade" fica no meio, em 50%.

5. O grande truque: tons da mesma cor

O laranja-tijolo do logo da Ana, #c7401f, em hsl() é hsl(12 73% 45%). Agora, para criar uma versão mais escura (para uma borda) e versões bem claras (para fundos), basta mudar o último número; a matiz e a saturação ficam iguais, e todas combinam:

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px;
    font-family: monospace;
  }
  .t30 { background-color: hsl(12 73% 30%); color: white; }
  .t45 { background-color: hsl(12 73% 45%); color: white; }
  .t60 { background-color: hsl(12 73% 60%); color: black; }
  .t90 { background-color: hsl(12 73% 90%); color: black; }
  .t95 { background-color: hsl(12 73% 95%); color: black; }
</style>
<p class="t30">hsl(12 73% 30%) mais escuro</p>
<p class="t45">hsl(12 73% 45%) a cor do logo</p>
<p class="t60">hsl(12 73% 60%) mais clara</p>
<p class="t90">hsl(12 73% 90%) bem clara</p>
<p class="t95">hsl(12 73% 95%) quase branca</p>

Os cinco são claramente "da mesma família". Em rgb(), os mesmos tons seriam rgb(132 43 21), rgb(199 64 31), rgb(227 108 79), rgb(248 218 211) e rgb(252 237 233): números que não deixam ver parentesco nenhum. É por isso que tanta gente monta a paleta de um site com hsl(). (Na aula Variáveis, você vai guardar a matiz numa variável e trocar a cor do site inteiro de uma vez.)

Missão: o aviso da lojinha está preto no branco. Use a família do logo, hsl(12 73% …): o fundo do .aviso com luminosidade 95% e o texto com luminosidade 30%.

<link rel="stylesheet" href="style.css">
<h1>Lojinha da Ana</h1>
<p class="aviso">Encomendas de bolo até quinta-feira.</p>

h1 {
  color: hsl(12 73% 45%);
}

.aviso {
  padding: 10px;
}

h1 {
  color: hsl(12 73% 45%);
}

.aviso {
  padding: 10px;
  background-color: hsl(12 73% 95%);
  color: hsl(12 73% 30%);
}

6. Cinzas: saturação zero

Com saturação 0%, a matiz não muda nada: hsl(200 0% 20%) e hsl(30 0% 20%) dão o mesmo rgb(51, 51, 51), o #333 da aula de hexadecimal. Um cinza em hsl() é só a luminosidade: hsl(0 0% 20%) é escuro, hsl(0 0% 90%) é bem claro.

Um truque de designer: em vez de cinza puro, use uma saturação baixinha (5% a 15%) com a matiz da cor principal. Fica um cinza "quente" ou "frio", que combina com o resto do site.

7. Uma limitação: o "50%" não é igual para todas as cores

A luminosidade do hsl() é uma conta com as três luzes, e não a claridade que o olho percebe. Veja o amarelo e o azul, os dois com 100% 50%:

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px;
    font-family: monospace;
    color: white;
  }
  .amarelo { background-color: hsl(60 100% 50%); }
  .azul { background-color: hsl(240 100% 50%); }
</style>
<p class="amarelo">hsl(60 100% 50%) texto branco</p>
<p class="azul">hsl(240 100% 50%) texto branco</p>

Mesmo "50%", e o amarelo parece muito mais claro: o texto branco quase some nele, e no azul se lê bem. Então, ao trocar a matiz de uma paleta, confira o contraste de novo. A função oklch(), da aula Cores Modernas, foi criada justamente para resolver isso: nela, a mesma luminosidade parece igual em todas as matizes.

8. Outras formas de escrever

FormaExemploValor calculado
Moderna (espaços)hsl(9 100% 64%)rgb(255, 99, 71)
Com transparência (barra)hsl(9 100% 64% / 50%)rgba(255, 99, 71, 0.5)
Antiga (vírgulas)hsl(9, 100%, 64%)rgb(255, 99, 71)
Antiga com transparênciahsla(9, 100%, 64%, 0.5)rgba(255, 99, 71, 0.5)
Matiz com unidade de ângulohsl(9deg 100% 64%)rgb(255, 99, 71) (deg = graus)
Matiz em voltashsl(0.5turn 100% 50%)rgb(0, 255, 255) (meia volta = 180)

Como no rgb(): não misture vírgulas e espaços, e o hsla() hoje é só outro nome do hsl(). O navegador sempre mostra o valor calculado em rgb()/rgba(), nunca em hsl().

Números fora do intervalo

A matiz é um ângulo, então ela dá a volta: hsl(400 100% 50%) é o mesmo que 40 (400 − 360), um laranja, rgb(255, 170, 0); e hsl(-30 100% 50%) é o mesmo que 330, um rosa, rgb(255, 0, 128). Já a saturação acima de 100% é cortada em 100%.

9. Qual forma de cor usar?

FormaMelhor para
Nome (tomato)Exemplos, testes, white, black, transparent
Hexadecimal (#c7401f)Copiar a cor exata de um logo ou desenho

Quando dá errado

Uma cor inválida é ignorada em silêncio, e o texto fica com a cor de antes. Os quatro títulos abaixo queriam ser tomate:

<style>
  .a { color: hsl(9, 100, 64); }
  .b { color: hsl(9, 100% 64%); }
  .c { color: hsl(9 100%); }
  .d { color: hsl(9 100% 64% 0.5); }
</style>
<h2 class="a">hsl(9, 100, 64)</h2>
<h2 class="b">hsl(9, 100% 64%)</h2>
<h2 class="c">hsl(9 100%)</h2>
<h2 class="d">hsl(9 100% 64% 0.5)</h2>

Os quatro ficaram pretos. O validador:

error: CSS: “color”: “100” is not a valid HSL color.

O que aconteceu: faltou o % na saturação e na luminosidade, na forma com vírgulas: hsl(9, 100, 64).

$ vnu --css sem-porcento.css
"file:/home/ana/hsl/sem-porcento.css":2.24-2.24: error: CSS: “color”: “100” is not a valid HSL color.

"100 não é uma cor HSL válida." Na forma com vírgulas, a saturação e a luminosidade precisam do %. (Na forma com espaços, hsl(9 100 64), os navegadores recentes e o validador aceitam os números sem %; os navegadores mais antigos, não. Escreva sempre o % e você não precisa decorar quando ele é opcional.)

Como consertar: hsl(9 100% 64%).

error: CSS: “color”: Invalid RGB function. (num hsl()!)

O que aconteceu: vírgula e espaço misturados (hsl(9, 100% 64%)), ou faltou um valor (hsl(9 100%)).

$ vnu --css mistura.css
"file:/home/ana/hsl/mistura.css":2.25-2.25: error: CSS: “color”: Invalid RGB function.
$ vnu --css dois.css
"file:/home/ana/hsl/dois.css":2.20-2.20: error: CSS: “color”: Invalid RGB function.

A mensagem diz "função RGB inválida" mesmo sendo um hsl(): o validador usa o mesmo texto para as duas funções. Olhe a posição (linha 2, coluna 25 ou 20) para achar o problema.

Como consertar: três valores, todos separados do mesmo jeito: hsl(9 100% 64%).

error: CSS: “color”: “0.5” is not a valid HSL color.

O que aconteceu: a transparência sem a barra: hsl(9 100% 64% 0.5).

$ vnu --css sem-barra.css
"file:/home/ana/hsl/sem-barra.css":2.28-2.28: error: CSS: “color”: “0.5” is not a valid HSL color.

Como consertar: hsl(9 100% 64% / 0.5).

Missão final: o cartão em outra cor

Missão: o cartão de receita está todo em azul (matiz 200). A Ana quer o mesmo cartão em verde: troque a matiz das três cores para 140, sem mexer na saturação nem na luminosidade.

<link rel="stylesheet" href="style.css">
<div class="cartao">
  <h2>Salada de verão</h2>
  <p>Pronta em 15 minutos.</p>
</div>

.cartao {
  background-color: hsl(200 70% 92%);
  border: 3px solid hsl(200 70% 52%);
  padding: 10px;
}

.cartao h2 {
  color: hsl(200 62% 32%);
}

.cartao {
  background-color: hsl(140 70% 92%);
  border: 3px solid hsl(140 70% 52%);
  padding: 10px;
}

.cartao h2 {
  color: hsl(140 62% 32%);
}

Três números trocados, e o cartão inteiro mudou de cor, com o fundo, a borda e o título ainda combinando entre si. Com rgb() ou hexadecimal, você teria de calcular nove números novos.

Resumo

  • hsl(matiz saturação luminosidade) descreve a cor como as pessoas pensam: qual cor, quão viva, quão clara.
  • Matiz: o ângulo na roda de cores, de 0 a 360 (0 vermelho, 120 verde, 240 azul). Ela dá a volta: 400 = 40.
  • Saturação: 0% é cinza, 100% é a cor mais viva. Luminosidade: 0% preto, 50% a cor pura, 100% branco.
  • O grande truque: mudando só a luminosidade, você cria tons da mesma cor que combinam; mudando só a matiz, a mesma paleta em outra cor.
  • Transparência com a barra: hsl(9 100% 64% / 50%). Formas antigas: vírgulas e hsla(), sempre com %.
  • O navegador guarda tudo como rgb(). E o "50%" do amarelo parece mais claro que o do azul: confira o contraste.
