CSS text-transform

Menus em MAIÚSCULAS, nomes com a Primeira Letra Grande, um aviso todo em minúsculas: dá para conseguir tudo isso sem reescrever uma palavra do HTML. A propriedade text-transform, "transformação do texto", troca só o jeito de mostrar as letras. Nesta aula você vai ver os valores lado a lado, entender por que o texto deve ficar normal no HTML e conhecer a armadilha do capitalize em português.

Você vai aprender
  • Os valores uppercase, lowercase, capitalize e none.
  • Que o texto do HTML não muda: só a aparência.
  • Por que escrever "Receitas" no HTML e deixar o CSS mostrar "RECEITAS".
  • Como ficam os acentos, e por que o capitalize estranha o português.
  • Como um filho volta ao normal com none.
  • Os erros comuns: valor inventado (com a mensagem do validador W3C) e o texto já digitado em maiúsculas.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: o letreiro da padaria

A Ana encomendou um letreiro para a padaria. Ela entregou ao pintor um papel escrito "Padaria da Ana", à mão, normal. O pintor pintou "PADARIA DA ANA", em letras grandes. O nome da padaria não mudou: mudou só o jeito de pintar.

No CSS, o papel é o texto do HTML e o pintor é o text-transform. Ele mostra o texto em maiúsculas ou minúsculas, mas o que está escrito no código continua igual.

1. Os valores, lado a lado

<style>
  .nenhum { text-transform: none; }
  .maiusculas { text-transform: uppercase; }
  .minusculas { text-transform: lowercase; }
  .iniciais { text-transform: capitalize; }
</style>
<p class="nenhum">none: Bolo de fubá com erva-doce da vó Ana</p>
<p class="maiusculas">uppercase: Bolo de fubá com erva-doce da vó Ana</p>
<p class="minusculas">lowercase: Bolo de fubá com erva-doce da vó Ana</p>
<p class="iniciais">capitalize: bolo de fubá com erva-doce da vó ana</p>
.maiusculas
O seletor: os elementos com class="maiusculas".
text-transform
A propriedade: "transformação do texto". Muda como as letras aparecem, maiúsculas ou minúsculas.
uppercase
O valor: "caixa alta", todas as letras maiúsculas. O nome vem das gráficas antigas, que guardavam as letras maiúsculas na caixa de cima (upper case) e as minúsculas na de baixo (lower case).

Repare nos acentos: "fubá" virou "FUBÁ" e "vó" virou "VÓ". O navegador conhece as maiúsculas de cada letra, inclusive acentuadas e com cedilha ("maçã" vira "MAÇÃ"), sobretudo quando a página diz a língua com <html lang="pt-BR">.

2. O texto do HTML não muda

O text-transform só muda o desenho. Quem lê o código (o texto: das missões deste guia, o JavaScript com textContent, os buscadores) continua vendo "Receitas da semana". No F12, na aba Elements (Elementos), o texto aparece como foi escrito; a transformação só aparece na tela e na aba Computed (Calculado), como text-transform: uppercase.

Por que não digitar logo em maiúsculas?

Se o letreiro vai ser em maiúsculas, por que não escrever "RECEITAS" direto no HTML? Três motivos:

  • Mudar de ideia sai barato. Se a Ana enjoar das maiúsculas, ela apaga uma linha do CSS. Com o texto digitado em maiúsculas, teria de reescrever cada menu, botão e título, página por página.
  • O lowercase não conserta tudo. Para ter "Receitas da Ana" de volta a partir de "RECEITAS DA ANA", nenhum valor serve: o capitalize daria "Receitas Da Ana". A informação de quais letras eram maiúsculas se perdeu.
  • Leitores de tela. Uma palavra digitada em maiúsculas pode ser lida como sigla, letra por letra. Escrita normal no HTML, ela é lida como palavra.

3. A herança, e como desligar com none

O text-transform é herdado (aula Herança): um título em maiúsculas transforma também o que está dentro dele. Para uma parte voltar ao normal, dê a ela text-transform: none:

<style>
  h2 {
    text-transform: uppercase;
  }
  h2 span {
    text-transform: none;
  }
</style>
<h2>Receitas <span>da Ana</span></h2>

"Receitas" ficou em maiúsculas, e "da Ana" ficou como foi escrito. Aqui, ao contrário do sublinhado (aula text-decoration), o none do filho funciona: o text-transform é passado por herança, e a regra do filho vence o valor herdado.

4. A armadilha do capitalize em português

O capitalize põe maiúscula na primeira letra de toda palavra. Ele não sabe que, em português, "de", "da", "com" e "e" ficam minúsculas num título:

<style>
  p {
    text-transform: capitalize;
  }
</style>
<p>bolo de fubá com erva-doce da vó ana</p>
<p>bOLO DE FUBÁ</p>

Dois detalhes no resultado:

  • "De", "Com" e "Da" ganharam maiúscula. No Chromium, até o "doce" de "erva-doce" virou "Doce".
  • No segundo parágrafo, nada ficou minúsculo: o capitalize só sobe a primeira letra, nunca abaixa as outras. "bOLO DE FUBÁ" virou "BOLO DE FUBÁ".

Por isso, em português, o capitalize serve bem para nomes curtos ("ana souza" → "Ana Souza"). Para títulos, escreva o texto certo no HTML.

Maiúsculas e o espaço entre as letras

Palavras em maiúsculas ficam com as letras apertadas. Um pouco de letter-spacing (como 0.05em) deixa o menu mais legível (aula Espaçamento). E use maiúsculas só em textos curtos: um parágrafo inteiro em caixa alta é difícil de ler.

Quando dá errado

Um valor que não existe: upper 
$ cat style.css
.chamada {
  text-transform: upper;
}
$ vnu --css style.css
"file:/home/ana/site/style.css":2.19-2.23: error: CSS: “text-transform”: “upper” is not a “text-transform” value.

O que o leitor vê: a chamada continua com as letras como foram escritas.

Por quê: o valor é uppercase, inteiro; upper, caps e capitalized não existem. O navegador ignora a declaração (no F12, no painel Styles, ela aparece riscada, com um ícone de aviso) e o valor calculado continua none.

O que o validador diz: "upper não é um valor de text-transform", na linha 2, coluna 19.

Como consertar: text-transform: uppercase;.

O texto foi digitado em maiúsculas, e o capitalize não resolve 
<style>
  h2 {
    text-transform: capitalize;
  }
</style>
<h2>BOLO DE FUBÁ</h2>

O que o leitor vê: "BOLO DE FUBÁ", igualzinho: o capitalize não abaixa letra nenhuma.

Por quê: o CSS não sabe quais letras deveriam ser minúsculas. O lowercase deixaria tudo minúsculo ("bolo de fubá"), e o capitalize por cima não existe (uma propriedade só tem um valor). O validador não reclama: tudo é válido.

Como consertar: reescreva o texto normal no HTML ("Bolo de fubá") e use o CSS só para a aparência.

O uppercase do pai chegou onde não devia

A Ana pôs nav { text-transform: uppercase; } e o e-mail de contato, dentro do nav, virou "ANA@EXEMPLO.COM". Não é erro do navegador: é a herança. O validador não tem o que dizer.

Como consertar: ponha a regra só nos links do menu (nav a), ou devolva o normal no e-mail com text-transform: none.

Resumo

  • text-transform muda só a aparência das letras: uppercase, lowercase, capitalize ou none (o valor inicial).
  • O texto do HTML não muda: o JavaScript, os buscadores e as missões leem o que foi escrito.
  • Escreva normal no HTML e deixe as maiúsculas para o CSS: fica fácil mudar, e o leitor de tela lê palavras, não siglas.
  • Acentos e cedilha funcionam: "maçã" vira "MAÇÃ".
  • O capitalize sobe a primeira letra de toda palavra ("De", "Da") e nunca abaixa as outras: bom para nomes, ruim para títulos em português.
  • É herdado; text-transform: none no filho desfaz.
  • Valor inventado é ignorado: “upper” is not a “text-transform” value.
