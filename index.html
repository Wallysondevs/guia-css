Tutorial CSS

Aprenda CSS do zero, como numa escola: cores, fontes, espaços, colunas, páginas que se ajeitam no celular e animações. Cada pedacinho de código é explicado, você vê o resultado de verdade logo embaixo e pratica num editor aqui mesmo na página. Os resultados não são imagens: quem desenha cada exemplo é o seu próprio navegador, na hora. Para começar, basta já ter visto um pouco de HTML.

Experimente agora

A caixa abaixo é o editor Experimente do guia. A aba index.html tem o HTML de um cartão da Lojinha da Ana; a aba style.css tem a aparência dele: as cores, os cantos redondos, a sombra. O que aconteceu: o HTML diz o que cada coisa é (um título, um parágrafo, um botão), e o CSS diz como cada coisa aparece. Cada bloco do style.css é uma regra: primeiro o seletor, que escolhe os elementos (.botao = "os elementos com class="botao""), e entre chaves as declarações, cada uma com uma propriedade, dois-pontos, um valor e ponto e vírgula. background-color: seagreen; quer dizer "cor de fundo: verde-mar".

Tente mais: troque 12px do border-radius do cartão por 0 (os cantos ficam retos) ou apague a linha do box-shadow (a sombra some). Se algo der errado, o botão Restaurar volta tudo ao começo.

Uma página que se ajeita na tela

Um site moderno se arruma sozinho: três colunas numa tela larga, uma coluna no celular. Na barra do Resultado abaixo, clique em 375 (a largura de um celular), 768 (um tablet) e cheia, e veja os cartões se rearrumarem. Quem faz isso é uma única linha de CSS, com grid-template-columns, que você vai entender na aula repeat, minmax e auto-fit.

<link rel="stylesheet" href="style.css">
<h1>Doces da semana</h1>
<div class="vitrine">
  <p class="doce">Bolo de cenoura</p>
  <p class="doce">Brigadeiro</p>
  <p class="doce">Pão de mel</p>
  <p class="doce">Cocada</p>
  <p class="doce">Pudim</p>
  <p class="doce">Quindim</p>
</div>

body {
  font-family: system-ui, sans-serif;
}
.vitrine {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 12px;
}
.doce {
  margin: 0;
  padding: 24px 16px;
  border-radius: 8px;
  background-color: wheat;
  text-align: center;
}

O que é este guia

O CSS (Cascading Style Sheets, "folhas de estilo em cascata") é a linguagem que dá a aparência às páginas da Web. O HTML monta a estrutura (título, parágrafo, lista, imagem); o CSS escolhe as cores, as fontes, os tamanhos, os espaços e onde cada coisa fica na tela. É como uma casa: o HTML é a parede e o telhado; o CSS é a tinta, os móveis e a decoração. O CSS foi proposto em 1994, por Håkon Wium Lie, e hoje é mantido pelo W3C, o mesmo consórcio que cuida dos padrões da Web.

Quem aprende CSS consegue:

  • dar cor, fonte e espaço a qualquer página, num arquivo só, que vale para o site inteiro;
  • montar layouts com colunas, menus, cartões e galerias usando Flexbox e Grid;
  • fazer páginas que funcionam bem do celular ao computador (responsivas), com tema escuro;
  • criar botões, efeitos de passar o mouse, transições e animações;
  • usar o CSS moderno, que os navegadores de hoje já entendem: variáveis, clamp(), :has(), aninhamento, @layer, @container e as cores oklch();
  • organizar o CSS de um site grande sem que uma regra brigue com a outra.

O guia é para quem já viu um pouco de HTML (o Guia HTML ensina do zero) e nunca escreveu CSS. Ele começa na primeira regra e vai até layouts completos, animações e boas práticas. O CSS tem uma armadilha: quando você erra, o navegador não avisa. Ele pula a linha errada em silêncio e segue com o resto. Por isso o guia ensina, desde o começo, a achar o erro com o F12 e com o validador do W3C.

Como as aulas funcionam

Nenhum código aparece "seco". Toda aula segue o mesmo caminho:

  1. A ideia primeiro. Antes do código, você entende o problema que ele resolve, com uma comparação do dia a dia.
  2. Anatomia. Cada parte de uma regra nova é separada e explicada: o seletor, a propriedade, o valor, os dois-pontos e o ponto e vírgula.
  3. O resultado real. Logo abaixo de cada exemplo aparece um quadro "Resultado", desenhado pelo seu navegador a partir daquele código. Quando há várias opções (como os tipos de borda), elas aparecem lado a lado.
  4. Experimente. Pelo menos duas caixas por aula para você mudar o código e ver o resultado na hora, muitas com uma missão que confere sozinha se você acertou.
  5. Várias formas de fazer. Quase sempre há mais de um caminho, e uma tabela "qual usar" mostra quando escolher cada um.
  6. Quando dá errado. O código com erro, o que você vê na tela (quase sempre: nada muda), por que aconteceu e a mensagem real do validador W3C, traduzida e explicada.
  7. Exercícios e resumo. Perguntas com correção na hora e uma lista curta do que levar da aula.

Exemplo: a anatomia de uma regra

Veja como as aulas desmontam uma regra de CSS. Primeiro o código, com o resultado embaixo:

<style>
  h1 { color: tomato; }
</style>
<h1>Receitas da Ana</h1>

Agora cada parte da linha h1 { color: tomato; }:

h1
O seletor: escolhe quais elementos a regra pinta. Aqui, todos os <h1> da página (aula Regras, Seletores e Declarações).
{ }
As chaves: guardam as declarações da regra. Tudo entre elas vale para o seletor.
color
A propriedade: o que mudar. color ("cor") é a cor do texto.
:
Os dois-pontos separam a propriedade do valor.
tomato
O valor: como fica. tomato ("tomate") é um dos nomes de cor que o CSS conhece (aula Cores por Nome).
;
O ponto e vírgula fecha a declaração. Esquecer o ; é o erro mais comum de quem começa: a declaração seguinte some junto.

Uma propriedade com o seu valor (color: tomato;) se chama declaração. O seletor com as declarações entre chaves se chama regra.

Exemplo: quando dá errado

Agora a Ana errou uma letra: escreveu colr em vez de color. Veja o que o navegador faz:

<style>
  h1 { colr: tomato; }
</style>
<h1>Receitas da Ana</h1>

Nada. O título fica preto, nenhuma mensagem aparece, e o resto da página segue normal. O navegador não conhece a propriedade colr, então pula a declaração inteira. Para achar esse tipo de erro, as aulas mostram o terminal da máquina fictícia do guia (o computador notebook, da usuária ana) com o validador do W3C, o comando vnu, o mesmo programa do site validator.w3.org:

$ cat style.css
h1 {
  colr: tomato;
}
$ vnu --css style.css
"file:/home/ana/site/style.css":2.9-2.14: error: CSS: “colr”: Property “colr” doesn't exist.
$ echo $?
1                                    « 1: o validador achou erro

A mensagem sai em inglês: "a propriedade colr não existe". O 2.9-2.14 é a posição: linha 2, das colunas 9 a 14 (o validador marca o valor, tomato, mas o problema é o nome da propriedade, na mesma linha). O guia traduz e explica cada mensagem assim, e mostra também como achar o erro no F12, a ferramenta que todo navegador traz (aula Inspecionando com o F12).

Como estudar

CSS se aprende mexendo, como pintar uma parede: você pinta, olha, ajusta. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, a anatomia e o resultado. Não pule a parte "Quando dá errado": no CSS, o erro não avisa, e quem conhece os erros comuns acha o problema em minutos.
  2. Mexa nos exemplos. Em toda caixa Experimente, troque uma cor, um tamanho, apague uma linha de propósito e veja o que acontece. Não tem como estragar nada.
  3. Faça as missões. As caixas com Missão conferem sozinhas se você acertou. Tente de verdade antes de abrir a solução; se abrir, digite a solução você mesmo em vez de só olhar.
  4. Repita no seu computador. Crie a pasta do seu site com o index.html e o style.css, escreva no seu editor e abra no navegador (aula Seu Primeiro Estilo). Lá você usa o F12 à vontade e vê o site num celular de verdade.
A regra de ouro

Ler não basta: digite cada exemplo. Copiar e colar ensina pouco; digitar faz você reparar em cada chave, cada dois-pontos e cada ponto e vírgula. E uma mudança por vez: mude uma linha, olhe o resultado, depois mude a próxima.

O editor do guia

As caixas Experimente não imitam um navegador: o resultado é desenhado pelo seu navegador, num quadro separado do resto da página, a partir do código que está na caixa naquele momento. Cada arquivo tem a sua aba (index.html e style.css), os botões 375 · 768 · cheia mudam a largura do quadro para você ver a página como num celular, e o ◐ liga o tema escuro só no quadro. Tudo isso é explicado na aula O Editor do Guia.

Versão de referência: o CSS dos navegadores atuais

O CSS não tem mais um número de versão único: depois do CSS 2.1, ele virou um conjunto de módulos (Cores, Flexbox, Grid…), cada um atualizado no seu ritmo, e o que as pessoas chamam de "CSS3" é esse conjunto. O guia ensina o CSS que os navegadores de 2025–2026 (Chrome, Edge, Firefox e Safari) entendem; quando um recurso é novo demais e ainda não funciona em todos, a aula avisa. Os resultados foram conferidos no Chromium 155, e as mensagens de erro, com o validador oficial do W3C, o vnu versão 26.10.12, o mesmo do site validator.w3.org.
