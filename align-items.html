CSS align-items

O justify-content cuida do espaço ao longo da fila de itens. Falta a outra direção: numa fila em linha, onde cada item fica na altura? Encostado em cima, embaixo, no meio, esticado? É o trabalho do align-items ("alinhar os itens"). Com ele você resolve um dos problemas mais antigos do CSS, centralizar na vertical, e alinha coisas de tamanhos diferentes: a foto e o nome de um produto, um logo grande e um menu pequeno, preços com letras de tamanhos diferentes.

Você vai aprender
  • Os valores stretch, flex-start, flex-end, center e baseline, lado a lado.
  • Por que os itens de um Flexbox ficam da mesma altura (o stretch), e quando isso para de acontecer.
  • Como centralizar uma foto e um texto na mesma linha.
  • Como alinhar textos de tamanhos diferentes pela linha de base.
  • O que muda numa coluna.
  • As mensagens reais do validador e a diferença para o align-content.

Antes, é bom ter visto Introdução ao Flexbox, Direção e justify-content. Os resultados são desenhados pelo seu navegador; os números em pixels do texto foram medidos no Chromium. As mensagens do validador saíram do validador W3C (vnu), na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: a altura da prateleira

Na prateleira da Ana há um pote alto, um médio e um baixinho. Ela pode encostar todos no fundo da prateleira (o jeito normal), pendurá-los no teto, deixá-los flutuando no meio da altura, ou, se fossem de massinha, esticá-los até preencherem a altura toda. Na prateleira deitada, essa é a direção em pé: a direção cruzada do Flexbox. O align-items decide onde cada item fica nela.

DireçãoNuma fila em linha (row)
justify-contentPrincipalDeitada: esquerda ↔ direita
align-itemsCruzadaEm pé: cima ↕ baixo

1. Os valores, lado a lado

Cada caixa tem um pai com 100 px de altura e três itens de alturas diferentes (o 2 tem duas linhas, o 3 tem letra maior). Só muda o align-items, escrito no alto:

<style>
  .caixa { margin-bottom: 10px; padding: 4px; border: 2px dashed gray; font-family: sans-serif; }
  .caixa p { margin: 0 0 4px; font-weight: bold; }
  .pai { display: flex; height: 100px; background-color: linen; }
  .item { width: 90px; padding: 4px 8px; background-color: tomato; color: white; border: 1px solid white; }
  .grande { font-size: 28px; }
</style>
<div class="caixa"><p>align-items: stretch (o padrão)</p>
  <div class="pai" style="align-items: stretch"><div class="item">1</div><div class="item">2<br>linhas</div><div class="item grande">3</div></div></div>
<div class="caixa"><p>align-items: flex-start</p>
  <div class="pai" style="align-items: flex-start"><div class="item">1</div><div class="item">2<br>linhas</div><div class="item grande">3</div></div></div>
<div class="caixa"><p>align-items: flex-end</p>
  <div class="pai" style="align-items: flex-end"><div class="item">1</div><div class="item">2<br>linhas</div><div class="item grande">3</div></div></div>
<div class="caixa"><p>align-items: center</p>
  <div class="pai" style="align-items: center"><div class="item">1</div><div class="item">2<br>linhas</div><div class="item grande">3</div></div></div>
<div class="caixa"><p>align-items: baseline</p>
  <div class="pai" style="align-items: baseline"><div class="item">1</div><div class="item">2<br>linhas</div><div class="item grande">3</div></div></div>

Neste resultado, o valor de cada caixa está no atributo style só para caber tudo num exemplo; no seu site, use classes num style.css.

2. O stretch: por que os itens têm a mesma altura

Na aula Introdução ao Flexbox, você viu que os cartões de uma vitrine flex ficam da mesma altura. É o stretch, o valor padrão: cada item estica até a altura da linha, que é a altura do item mais alto (ou a do pai, se ele tiver uma). Isso resolve um problema antigo: colunas lado a lado, com fundos de alturas iguais, sem conta nenhuma.

Mas o stretch só estica quem não tem altura definida. Um item com height fica com a altura dele:

Experimente: o cartão do meio tem height: 50px e não esticou. Apague essa linha e veja-o ficar da altura dos outros.

<link rel="stylesheet" href="style.css">
<div class="vitrine">
  <div class="produto">Bolo de cenoura com cobertura de chocolate</div>
  <div class="produto baixo">Pudim</div>
  <div class="produto">Torta de limão</div>
</div>

.vitrine {
  display: flex;
}

.produto {
  width: 120px;
  margin: 4px;
  padding: 8px;
  background-color: seagreen;
  color: white;
}

.baixo {
  height: 50px;
}

3. Centralizar uma foto e um texto

O uso mais comum do align-items: center: uma foto (ou ícone) ao lado de um texto, com o texto no meio da altura da foto, e não grudado no topo.

Missão: em cada produto, o nome está no alto, alinhado com o topo da foto. Centralize o nome na altura da foto.

<link rel="stylesheet" href="style.css">
<div class="produto">
  <img src="assets/midia/bolo-quadrado-400.jpg" alt="" width="64" height="64">
  <p>Bolo de cenoura · R$ 45,00</p>
</div>
<div class="produto">
  <img src="assets/midia/avatar-ana-96.png" alt="" width="64" height="64">
  <p>Encomendas com a Ana</p>

  display: flex;
  margin-bottom: 8px;
  padding: 8px;
  border: 2px solid peru;
  background-color: linen;
}

  margin: 0 0 0 12px;

  display: flex;
  align-items: center;
  margin-bottom: 8px;
  padding: 8px;
  border: 2px solid peru;

No meio do meio: as duas direções

Juntando o justify-content: center (meio na principal) com o align-items: center (meio na cruzada), um item fica bem no centro do pai. É a forma mais usada hoje de centralizar qualquer coisa (aula Centralizando Qualquer Coisa):

<style>
  .palco { display: flex; justify-content: center; align-items: center; height: 160px; background-color: linen; }
  .selo { padding: 12px 20px; background-color: seagreen; color: white; font-family: sans-serif; }
</style>
<div class="palco">
  <p class="selo">Bem no meio</p>
</div>

4. baseline: textos de tamanhos diferentes

Num cartão de preço, o valor é grande e o "por mês" é pequeno. Com center, os dois ficam centralizados, mas as letras não "pisam" na mesma linha, e o olho estranha. Com baseline, as letras de tamanhos diferentes ficam apoiadas na mesma linha, como numa frase:

5. Numa coluna, o align-items é horizontal

O align-items trabalha sempre na direção cruzada. Com flex-direction: column (aula Direção), a cruzada é a deitada: flex-start passa a ser "à esquerda", flex-end "à direita", center "no meio da largura", e o stretch estica na largura.

Experimente: com stretch, os botões da coluna ocupam a largura toda. Troque por center, flex-start e flex-end, e veja-os ficarem do tamanho do texto, no meio, à esquerda e à direita.

<link rel="stylesheet" href="style.css">
<div class="painel">
  <a class="botao" href="bolos.html">Ver os bolos</a>
  <a class="botao" href="doces.html">Ver os doces</a>
  <a class="botao" href="contato.html">Encomendar</a>
</div>

.painel {
  display: flex;
  flex-direction: column;
  align-items: stretch;
  padding: 8px;
  background-color: linen;
}

.botao {
  margin: 4px;
  padding: 8px 16px;
  background-color: seagreen;
  color: white;
}

Os outros nomes, e o align-content

  • start e end também existem e, num Flexbox comum, dão o mesmo que flex-start e flex-end. Há ainda first baseline e last baseline (alinhar pela primeira ou pela última linha de texto); baseline sozinho é o mesmo que first baseline.
  • O align-content parece irmão, mas faz outra coisa: quando os itens quebram em várias linhas (com flex-wrap), ele arruma as linhas dentro do pai. O align-items arruma cada item dentro da sua linha. Detalhes na aula Quebrando Linha.

Quando dá errado

"O center não faz nada": não sobra altura

O que o leitor vê: troca o align-items e nada muda.

Por quê: se todos os itens têm a mesma altura e o pai não tem altura própria, a linha é exatamente da altura deles: não sobra nada para alinhar. O efeito só aparece quando há itens de alturas diferentes (como a foto e o texto da missão) ou um pai mais alto que os itens.

Como consertar: confira no F12 a altura do pai. Para centralizar na tela, o pai precisa de uma altura (por exemplo, min-height; aula Unidades da Tela).

O item não estica

O que o leitor vê: com stretch (o padrão), um cartão continua mais baixo que os vizinhos.

Por quê: ele tem um height (seção 2), ou o pai tem outro align-items, ou o próprio item tem um align-self.

Como consertar: tire o height do item (se precisar de um mínimo, use min-height, que deixa esticar).

align-items: middle: “middle” is not a “align-items” value 
.produto {
  display: flex;
  align-items: middle;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":3.16-3.21: error: CSS: “align-items”: “middle” is not a “align-items” value.

O que o leitor vê: o nome continua no alto (o stretch padrão). A declaração foi ignorada e aparece riscada no F12.

Como consertar: align-items: center;.

“space-between” is not a “align-items” value 
.topo {
  display: flex;
  align-items: space-between;
}

$ vnu --css style.css
"file:/home/ana/site/style.css":3.16-3.28: error: CSS: “align-items”: “space-between” is not a “align-items” value.

Por quê: numa linha só, cada item tem a sua posição na cruzada; não há "espaço entre" itens para distribuir nessa direção. Os valores space-… são do justify-content (e do align-content, para as linhas).

Resumo

  • align-items vai no pai flex e posiciona os itens na direção cruzada (em pé, numa fila em linha).
  • stretch (padrão) estica os itens sem height: por isso os cartões flex têm a mesma altura. flex-start, flex-end e center: em cima, embaixo, no meio. baseline: pela linha das letras.
  • Foto e texto alinhados: align-items: center. Centro do pai: justify-content: center + align-items: center.
  • Em coluna, ele alinha na horizontal, e o stretch estica na largura.
  • Sem altura sobrando, nada muda. middle e space-between não são valores do align-items. Para as linhas de um flex-wrap, o certo é o align-content.
