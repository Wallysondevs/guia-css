CSS Animações

A transição da aula anterior precisa de um empurrão: o mouse entrar, uma classe mudar. E ela só vai de A para B. Uma animação começa sozinha, pode ter várias etapas (A, depois B, depois C) e pode se repetir para sempre. É com ela que se faz o ícone de "carregando" que gira, o selo de "novo" que pulsa, o aviso que treme quando a senha está errada.

Você vai aprender
  • A ideia dos quadros-chave: você desenha alguns momentos, o navegador desenha o resto.
  • A regra @keyframes, com from, to e porcentagens.
  • A propriedade animation: o nome, a duração e o "para sempre" (infinite).
  • Três animações do dia a dia: girar, pulsar e tremer.
  • Quando usar transition e quando usar animation.
  • Os erros que deixam a animação parada.

Antes, veja transform e Transições: os ritmos (ease, linear…) são os mesmos. Os detalhes de controle (atraso, direção, o que acontece no fim) ficam para a próxima aula, Controlando Animações. As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana.

A ideia: o desenho animado

Nos estúdios de desenho animado, o desenhista principal desenha só os quadros-chave: o personagem parado, o personagem no alto do pulo, o personagem no chão de novo. Os assistentes desenham os quadros do meio. Em inglês, quadro-chave é keyframe.

No CSS, você é o desenhista principal e o navegador é o assistente. Você escreve, numa regra @keyframes, como o elemento está em alguns momentos (no começo, no meio, no fim). Depois, liga essa animação num elemento com a propriedade animation, dizendo quanto tempo ela dura. O navegador desenha todos os quadros do meio, como na transição.

1. A primeira animação

Um aviso que surge devagar quando a página abre:

@keyframes surgir {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

.aviso {
  animation: surgir 2s;
}
@keyframes surgir {
Uma regra @ que cria uma animação e dá um nome a ela. O nome é seu: surgir, girar, pulsar… (sem espaço e sem acento, como uma classe).
from { opacity: 0; }
"De": como o elemento está no começo. Dentro das chaves, declarações normais.
to { opacity: 1; }
"Para": como ele está no fim.
.aviso { animation: surgir 2s; }
Liga a animação surgir no .aviso, com a duração de 2 segundos. Sozinho, o @keyframes não faz nada: ele é só a receita. A animation é quem põe a receita no forno.

Experimente: o aviso surge quando o quadro é desenhado. Clique em ↻ (na barra do quadro) para ver de novo. Mude o 2s para 5s e, depois, troque opacity por transform: translateX(-100px) no from e transform: translateX(0) no to.

<link rel="stylesheet" href="style.css">
<p class="aviso">Pedidos de bolo para o fim de semana até quinta-feira!</p>

@keyframes surgir {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

.aviso {
  background-color: #fffaf3;
  border-left: 4px solid #c2410c;
  padding: 12px;
  animation: surgir 2s;
}

2. Mais etapas: porcentagens

from e to são apelidos de 0% e 100%. No meio, você pode pôr quantas etapas quiser, cada uma numa porcentagem do tempo:

@keyframes pular {
  0% {
    transform: translateY(0);
  }
  30% {
    transform: translateY(-30px);
  }
  50% {
    transform: translateY(0);
  }
  65% {
    transform: translateY(-10px);
  }
  80%,
  100% {
    transform: translateY(0);
  }
}

Com animation: pular 1s, o elemento sobe 30 px até os 0,3 s (30% de 1 segundo), cai até os 0,5 s, dá um pulinho menor de 10 px e fica no chão de 0,8 s até o fim. Duas porcentagens com o mesmo estilo podem dividir a mesma regra, separadas por vírgula (80%, 100%).

Seletor do quadro-chaveQuando
from ou 0%no começo
50%na metade do tempo
to ou 100%no fim
25%, 75%dois momentos com o mesmo estilo

Se faltar o 0% ou o 100%, o navegador usa o estilo normal do elemento nesse ponto. Por isso, o pular poderia nem ter o 0%: o elemento já está em translateY(0).

3. Repetir: infinite

Por padrão, a animação acontece uma vez e para. Para repetir, ponha o número de vezes (3) ou infinite ("infinito") na animation:

.icone {
  animation: girar 1s linear infinite;
}
girar
O nome do @keyframes.
1s
A duração de uma volta.
linear
O ritmo, como na transição. Para algo que gira sem parar, linear evita aquela "freada" a cada volta que o ease daria.
infinite
Repete para sempre.

4. Três animações do dia a dia

Girar: o "carregando"

Um círculo com uma borda colorida só em cima, girando:

Experimente: mude a duração para 3s e depois para 0.3s. Troque linear por ease-in-out e repare na freada a cada volta.

<link rel="stylesheet" href="style.css">
<div class="carregando" role="status" aria-label="Carregando"></div>

@keyframes girar {
  to {
    transform: rotate(1turn);
  }
}

.carregando {
  width: 40px;
  height: 40px;
  margin: 20px;
  border: 5px solid #f6d3c2;
  border-top-color: #c2410c;
  border-radius: 50%;
  animation: girar 1s linear infinite;
}

Repare que o @keyframes girar só tem o to: o começo é o estado normal (sem giro). O role="status" e o aria-label são HTML, para quem usa leitor de tela saber o que é aquele círculo.

Pulsar: o selo de "novo"

@keyframes pulsar {
  50% {
    scale: 1.15;
  }
}

.selo {
  animation: pulsar 1.2s ease-in-out infinite;
}

Só uma etapa, no meio: o selo cresce 15% na metade do tempo e volta ao tamanho normal (o 0% e o 100% são o estado normal). A propriedade scale é a separada, da aula transform.

Tremer: o aviso de erro

@keyframes tremer {
  20%,
  60% {
    translate: -6px 0;
  }
  40%,
  80% {
    translate: 6px 0;
  }
}

.erro {
  animation: tremer 0.4s;
}

Esquerda, direita, esquerda, direita, de volta ao lugar, em 0,4 segundo, uma vez. É o "não" que a caixa de senha faz no celular.

Missão: o selo "Novo" está parado. Crie um @keyframes pulsar com uma etapa em 50% que tenha scale: 1.15;, e ligue-o no .selo com duração de 1.2s, ritmo ease-in-out e repetindo para sempre.

<link rel="stylesheet" href="style.css">
<p>Pão de queijo recheado <span class="selo">Novo</span></p>

.selo {
  display: inline-block;
  background-color: #c2410c;
  color: white;
  padding: 2px 8px;
  border-radius: 10px;
  font-size: 0.8rem;
}

@keyframes pulsar {
  50% {
    scale: 1.15;
  }
}

.selo {
  display: inline-block;
  background-color: #c2410c;
  color: white;
  padding: 2px 8px;
  border-radius: 10px;
  font-size: 0.8rem;
  animation: pulsar 1.2s ease-in-out infinite;
}

O display: inline-block não está ali à toa: como o transform, o scale não funciona num elemento em linha comum (aula transform).

5. Duas animações no mesmo elemento

Como na transição, separe com vírgula. Um aviso que surge e treme:

.erro {
  animation: surgir 0.3s, tremer 0.4s;
}

As duas começam juntas. Se elas mexerem na mesma propriedade (as duas no transform, por exemplo), a que vem por último na lista vence. Por isso o surgir usa opacity e o tremer usa translate: cada uma na sua.

Animação demais incomoda

Uma coisa piscando ou pulando sem parar tira a atenção do texto, e para algumas pessoas causa enjoo e tontura de verdade. Use infinite só no que tem motivo (o "carregando"), e respeite quem pede menos movimento no sistema: é a aula Respeitando Quem Prefere Menos Movimento.

O que o F12 mostra

Na aba Computed, a animation aparece separada nas propriedades longas: animation-name: pulsar, animation-duration: 1.2s, animation-iteration-count: infinite, animation-timing-function: ease-in-out (conferido no Chromium). As propriedades que estão sendo animadas (o scale do selo) mudam o tempo todo: cada vez que você olha, mostram um valor do meio do caminho. O Chrome e o Edge têm também um painel Animations (Animações), nas ferramentas extras do F12, que mostra uma linha do tempo e deixa reproduzir a animação mais devagar.

Quando dá errado

A animação não acontece (nome diferente)

O que aconteceu: o nome na animation não é igual ao do @keyframes:

@keyframes pulsar {
  50% {
    scale: 1.15;
  }
}

.selo {
  animation: pulsa 1.2s infinite;
}

O navegador procura um @keyframes pulsa, não acha e não faz nada. O validador também não reclama: pulsa é um nome válido (podia estar em outro arquivo). Maiúsculas contam: Pulsar e pulsar são nomes diferentes.

Como consertar: copie o nome do @keyframes para a animation.

A animação não acontece (sem duração)

O que aconteceu: animation: girar;, sem tempo. A duração padrão é 0s: a animação acontece em tempo zero, e você não vê nada. Na aba Computed: animation-duration: 0s. O validador não reclama, porque a duração é opcional.

Como consertar: sempre um tempo: animation: girar 1s;.

error: CSS: Parse Error. (porcentagem sem %)

O que aconteceu: a porcentagem do quadro-chave ficou sem o %: 50 { scale: 1.15; }.

$ vnu --css semporc.css
"file:/home/ana/anim/semporc.css":4.4-4.4: error: CSS: Parse Error.
"file:/home/ana/anim/semporc.css":5.2-6.1: error: CSS: Parse Error.

"Erro de leitura", duas vezes, apontando para as chaves que fecham (linhas 4 e 5), e não para o 50 da linha 2: o validador se perdeu e só percebeu depois. É comum a mensagem de CSS apontar um pouco depois do erro de verdade. O navegador descarta o quadro-chave 50, que não é um momento válido, e sobra um @keyframes vazio: o selo não pulsa.

Como consertar: 50%, com o sinal.

error: CSS: Unrecognized at-rule “@keyframe”

O que aconteceu: faltou o s: @keyframe pulsar { … }.

$ vnu --css keyframe.css
"file:/home/ana/anim/keyframe.css":1.1-1.9: error: CSS: Unrecognized at-rule “@keyframe”

"Regra @ não reconhecida." O navegador também não conhece @keyframe e ignora o bloco inteiro. A animation procura um @keyframes pulsar, não acha, e nada se mexe.

Como consertar: @keyframes, no plural: são vários quadros.

A animação acontece uma vez e para

O que aconteceu: esqueceu o infinite. Sem ele, a animação roda uma vez quando a página abre e o elemento volta ao normal. Às vezes você nem vê, porque ela terminou antes de você rolar até lá.

Como consertar: animation: pulsar 1.2s infinite;, ou um número de vezes (3).

Resumo

  • Uma animação tem duas partes: a receita (@keyframes nome { … }) e o liga (animation: nome duração;).
  • Os quadros-chave são from/to ou porcentagens; o navegador desenha os quadros do meio. Quadro que falta usa o estilo normal.
  • A animação começa sozinha e acontece uma vez; infinite repete para sempre.
  • Girar (rotate(1turn) com linear infinite), pulsar (scale em 50%) e tremer (translate para os lados) resolvem a maioria dos casos.
  • transition para mudanças de estado; animation para movimentos que começam sozinhos, têm etapas ou se repetem.
  • Erros comuns: nome diferente, sem duração, porcentagem sem %, @keyframe sem s. Os dois primeiros o validador não pega.
