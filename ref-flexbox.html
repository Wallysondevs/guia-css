CSS Flexbox

O Flexbox arruma itens numa linha (ou numa coluna): lado a lado, com espaço entre eles, alinhados no meio, quebrando para a linha de baixo quando não cabem. Esta página é a "cola" de consulta: todas as propriedades, todos os valores, o que cada um faz e a aula que explica. Os valores calculados foram medidos no Chromium.

Como usar esta página
  • As propriedades se dividem em duas turmas: as do contêiner (o pai, que tem display: flex) e as dos itens (os filhos diretos). Pôr uma propriedade na turma errada é o erro número 1.
  • Os nomes falam de dois eixos: o principal (a direção da fila, que o flex-direction escolhe) e o transversal (o outro). justify-… = eixo principal; align-… = eixo transversal.
  • Para aprender do começo, vá à aula Introdução ao Flexbox.

A ideia em uma tela

Pense numa prateleira de padaria. A prateleira é o contêiner: ela decide se os pães ficam em fila (row) ou empilhados (column), se ficam juntos à esquerda ou espalhados, e se passam para a prateleira de baixo quando não cabem. Cada pão é um item: pode pedir para ocupar mais espaço (flex-grow) ou para ficar numa altura diferente (align-self).

.prateleira {          /* o CONTÊINER */
  display: flex;       /* liga o Flexbox: os FILHOS diretos viram itens */
  gap: 1rem;           /* espaço entre os itens */
}

.prateleira .pao {     /* um ITEM */
  flex: 1;             /* cresce para dividir o espaço com os irmãos */
}

justify-content ao vivo

Com flex-direction: column, os eixos trocam de lugar: o justify-content passa a agir na vertical e o align-items, na horizontal. Os exemplos acima usam style="…" só para caber numa tela; no seu site, ponha as regras no style.css.

  <div class="pao">Sonho</div>

Quando dá errado

"O justify-content não faz nada"

O que a Ana vê: escreveu justify-content: center e os itens continuam empilhados à esquerda.

Por quê (as causas mais comuns):

  1. O pai não é flex. justify-content e align-items só funcionam num contêiner com display: flex (ou grid). Num bloco comum, o navegador aceita a declaração, mas ela não muda nada. No F12, o Chrome mostra a propriedade apagada (em cinza) no painel Styles, com um ícone de informação: passe o mouse para ver a explicação.
  2. A propriedade foi para o elemento errado. justify-content vai no pai; align-self e flex, nos filhos. E só nos filhos diretos: um neto não é item flex.
  3. Não sobra espaço. Se os itens têm flex: 1, eles já ocupam tudo: não há espaço para distribuir.
  4. O eixo é o outro. Com flex-direction: column, o justify-content age na vertical, e o contêiner só é tão alto quanto o conteúdo: dê uma altura a ele.

O validador W3C não reclama de nenhum desses casos: o CSS está certo, só não tem efeito. No F12, o Chrome mostra um selo flex ao lado do elemento na aba Elements: se o selo não aparece, o elemento não é um contêiner flex.

O item que não encolhe (e vaza para fora)

Dois itens com flex: 1 num contêiner de 300px, e um deles tem uma palavra enorme. Medido no Chromium: o item com a palavra ficou com 413px de largura, maior que o próprio contêiner, e o outro, com 8px.

Por quê: o valor inicial min-width: auto dos itens flex não deixa um item ficar mais estreito que o seu conteúdo (a palavra, uma imagem, um <pre>).

Como resolver: no item, min-width: 0 (e, para a palavra quebrar, overflow-wrap: anywhere). Medido: os dois itens voltaram a ter 150px cada. Veja a aula Texto que Não Cabe.

display: flexbox não existe (o certo é flex); colum perdeu o "n"; o "meio" é center, não middle; e flex-grow não aceita número negativo (negative values are not allowed = "valores negativos não são permitidos"). Em todos os casos, o navegador ignora a declaração e o layout fica como se ela não existisse.

Resumo

  • Contêiner: display: flex, flex-direction, flex-wrap, justify-content (eixo principal), align-items (eixo transversal), align-content (as linhas), gap.
  • Itens: flex (= flex-grow + flex-shrink + flex-basis), order, align-self, margin: auto.
  • flex: 1 = 1 1 0% (tamanhos iguais); flex: auto = 1 1 auto; flex: none = 0 0 auto.
  • Sem display: flex no pai, as propriedades de alinhamento não fazem nada, e o validador não avisa.
  • Item que vaza: min-width: 0.
  • Linhas e colunas ao mesmo tempo: Grid.
