CSS text-shadow

Uma sombra discreta destaca um título; um brilho colorido chama atenção para uma promoção; uma sombra escura deixa um texto branco legível em cima de uma foto. Tudo isso é text-shadow, "sombra do texto": uma cópia das letras, desenhada atrás delas, deslocada, borrada e colorida do jeito que você pedir. Nesta aula você vai montar sombras peça por peça, empilhar várias e reconhecer os erros que fazem a sombra simplesmente não aparecer.

Você vai aprender
  • As partes da sombra: deslocamento para o lado, para baixo, desfoque e cor.
  • Sombra dura, sombra suave, brilho e sombra para cima e para a esquerda (valores negativos).
  • Várias sombras de uma vez, separadas por vírgula (e o contorno feito com quatro sombras).
  • O uso mais útil: texto legível em cima de uma foto.
  • Como o navegador guarda o valor (o valor calculado).
  • Os erros comuns, com as mensagens do validador W3C: número sem unidade, um valor a mais e a vírgula esquecida.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. Os valores calculados foram conferidos no Chromium; as mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a lanterna atrás das letras

Recorte letras de papelão e ponha uma lanterna na frente delas: a sombra aparece na parede de trás, com o mesmo formato das letras. Mova a lanterna e a sombra vai para o lado ou para baixo. Afaste a parede e a sombra fica borrada, sem contorno nítido.

O text-shadow faz isso com três números e uma cor: quanto a sombra anda para o lado, quanto anda para baixo, quanto ela borra e de que cor ela é.

1. A primeira sombra

<style>
  h1 {
    text-shadow: 2px 2px 4px gray;
  }
</style>
<h1>Receitas da Ana</h1>
text-shadow
A propriedade: "sombra do texto".
2px
O primeiro número: quanto a sombra anda para a direita. Negativo anda para a esquerda.
2px
O segundo: quanto ela anda para baixo. Negativo anda para cima.
4px
O terceiro (opcional): o desfoque, quanto a sombra borra. Sem ele, ou com 0, a sombra fica com a borda dura.
gray
A cor (opcional). Pode vir no começo ou no fim. Sem ela, a sombra usa a cor do próprio texto.
;
Fecha a declaração.

O valor inicial é none: nenhuma sombra. Os números precisam de unidade (px, em); só o 0 pode ficar sem.

2. Os jeitos de sombrear, lado a lado

<style>
  h2 {
    font-family: sans-serif;
  }
  .dura { text-shadow: 2px 2px gray; }
  .suave { text-shadow: 2px 2px 4px gray; }
  .brilho { text-shadow: 0 0 8px tomato; }
  .para-cima { text-shadow: -2px -2px 0 navy; }
  .sem-cor { color: firebrick; text-shadow: 2px 2px 4px; }
</style>
<h2 class="dura">2px 2px gray: dura</h2>
<h2 class="suave">2px 2px 4px gray: suave</h2>
<h2 class="brilho">0 0 8px tomato: brilho</h2>
<h2 class="para-cima">-2px -2px 0 navy: para cima</h2>
<h2 class="sem-cor">2px 2px 4px: sem cor</h2>

O valor calculado

Na aba Computed (Calculado) do F12, o navegador guarda a sombra do jeito dele: a cor vem primeiro, em rgb(), e todos os números ganham unidade. No Chromium:

Você escreveValor calculado
2px 2px grayrgb(128, 128, 128) 2px 2px 0px (o desfoque que faltou vira 0px)
0 0 8px tomatorgb(255, 99, 71) 0px 0px 8px
2px 2px 4px, com color: firebrickrgb(178, 34, 34) 2px 2px 4px (a cor do texto)

3. Várias sombras: separe com vírgula

Uma única declaração pode ter várias sombras, separadas por vírgula. A primeira da lista fica por cima das outras:

<style>
  h2 {
    font-family: sans-serif;
    font-size: 40px;
  }
  .duas {
    text-shadow: 2px 2px 0 gold, 4px 4px 0 tomato;
  }
  .contorno {
    color: white;
    text-shadow:
      -1px -1px 0 black,
       1px -1px 0 black,
      -1px  1px 0 black,
       1px  1px 0 black;
  }
</style>
<h2 class="duas">duas sombras</h2>
<h2 class="contorno">contorno</h2>
  • Duas sombras: uma dourada encostada nas letras e uma cor de tomate mais longe, como camadas.
  • Contorno: letras brancas com quatro sombras pretas, uma para cada diagonal. Juntas, elas desenham uma borda fina em volta de cada letra. Quebrar a lista em várias linhas, como no exemplo, é permitido e ajuda a ler.

4. O uso mais útil: texto legível sobre uma foto

Texto branco em cima de uma foto fica bonito onde a foto é escura e some onde ela é clara. Uma sombra escura e borrada cria um "halo" que separa as letras do fundo. Compare os dois títulos (o fundo com a foto usa background-image, aula Imagem de Fundo):

<style>
  .capa {
    background-image: url("assets/midia/bolo-800.jpg");
    background-size: cover;
    background-position: center;
    padding: 40px 16px;
  }
  .capa h2 {
    color: white;
    font-family: sans-serif;
    font-size: 40px;
    margin: 0;
  }
  .capa .com-sombra {
    text-shadow: 0 2px 6px rgba(0, 0, 0, 0.8);
  }
</style>
<div class="capa">
  <h2>Bolo de cenoura</h2>
  <h2 class="com-sombra">Bolo de cenoura</h2>
</div>

No primeiro título, o "Bolo de", em cima da parte clara da foto, quase desaparece. No segundo, com a sombra preta de 80% (rgba(0, 0, 0, 0.8), aula Transparência), as letras se destacam do começo ao fim. A sombra ajuda, mas não faz milagre: se o fundo for muito claro, escureça a foto também.

Com moderação

Sombras fortes ou muito borradas em texto pequeno embaçam as letras e cansam a leitura. Use text-shadow em títulos e chamadas curtas, não em parágrafos. E a sombra não conta como contraste para quem enxerga pouco: a cor do texto e a do fundo ainda precisam combinar bem.

Quando dá errado

Num erro de sombra, o navegador ignora a declaração inteira: o texto aparece sem nenhuma sombra, e o valor calculado fica none (conferido no Chromium). No F12, no painel Styles (Estilos), a declaração aparece riscada, com um ícone de aviso. Três erros comuns, num só arquivo:

$ cat style.css
h1 {
  text-shadow: 2 2 4 black;
}
h2 {
  text-shadow: 2px 2px 4px 2px black;
}
h3 {
  text-shadow: 2px 2px 4px gray 4px 4px tomato;
}
$ vnu --css style.css
"file:/home/ana/site/style.css":2.22-2.26: error: CSS: “text-shadow”: only “0” can be a “length”. You must put a unit after your number.
"file:/home/ana/site/style.css":5.32-5.36: error: CSS: “text-shadow”: Too many values or values are not recognized.
"file:/home/ana/site/style.css":8.41-8.46: error: CSS: “text-shadow”: Too many values or values are not recognized.
Número sem unidade: only “0” can be a “length”

Por quê: 2 2 4 não diz se são pixels, em ou outra coisa. O validador explica: "só o 0 pode ser um comprimento sem unidade. Você precisa pôr uma unidade depois do número".

Como consertar: text-shadow: 2px 2px 4px black;.

Um número a mais, copiado do box-shadow

Por quê: a sombra da caixa, box-shadow, aceita um quarto número, o "espalhamento" (spread). A sombra do texto não tem esse número. Com 2px 2px 4px 2px, o validador diz "valores demais, ou valores não reconhecidos".

Como consertar: no máximo três números: 2px 2px 4px black.

A vírgula esquecida entre duas sombras 
<style>
  h2 {
    font-family: sans-serif;
    text-shadow: 2px 2px 4px gray 4px 4px tomato;
  }
</style>
<h2>Bolo de fubá</h2>

O que o leitor vê: o título sem sombra nenhuma. Não é que só a segunda sombra falhou: a declaração inteira foi ignorada.

Por quê: sem a vírgula, o navegador lê uma sombra só com cinco números e duas cores, e isso não existe. A mensagem é a mesma: Too many values or values are not recognized, apontando a linha 8, coluna 41 do arquivo acima, onde mora o tomato que sobrou.

Como consertar: text-shadow: 2px 2px 4px gray, 4px 4px tomato;.

Resumo

  • text-shadow: X Y desfoque cor; desenha uma cópia das letras atrás delas: X para a direita, Y para baixo, borrada e colorida. Desfoque e cor são opcionais; sem cor, vale a cor do texto.
  • 0 0 8px cor faz um brilho; números negativos levam a sombra para a esquerda e para cima.
  • Várias sombras vão separadas por vírgula, e a primeira fica por cima. Quatro sombras de 1px fazem um contorno.
  • O uso mais útil: 0 2px 6px rgba(0, 0, 0, 0.8) em texto claro sobre foto.
  • O valor calculado põe a cor primeiro, em rgb(): rgb(128, 128, 128) 2px 2px 4px.
  • Qualquer erro apaga a sombra inteira: número sem unidade (only “0” can be a “length”), o quarto número do box-shadow ou a vírgula esquecida (Too many values or values are not recognized).
