CSS rgb()

Na aula Cores Hexadecimais, você viu que toda cor da tela é uma mistura de três luzes, escrita em pares como ff e 63. A função rgb() escreve a mesma mistura com os números de todo dia: rgb(255 99 71). É também a forma que o navegador usa para mostrar qualquer cor no F12, e a mais fácil para deixar uma cor meio transparente.

Você vai aprender
  • Como escrever rgb(255 99 71), parte por parte.
  • A forma moderna (com espaços) e a antiga (com vírgulas), e o rgba() que você vai ver em códigos mais velhos.
  • Como deixar a cor transparente com a barra: rgb(255 99 71 / 50%).
  • Porcentagens no lugar de 0 a 255, e o que acontece com 300 ou -20.
  • Quando usar rgb() e quando usar hexadecimal.
  • Os erros reais: vírgula misturada, espaço antes do parêntese e o parêntese que não fecha (e apaga a regra seguinte!).

Os quadros "Resultado" e as caixas "Experimente" são desenhados agora pelo seu navegador. As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: três botões de luz

Imagine um palco com três refletores: um vermelho, um verde e um azul, todos apontados para o mesmo ponto. Cada um tem um botão que vai de 0 (apagado) a 255 (no máximo). Com os três apagados, o ponto fica preto; com os três no máximo, branco; mexendo em cada botão, aparece qualquer cor. O rgb() é você dizendo a posição dos três botões, nesta ordem: red (vermelho), green (verde), blue (azul).

1. A anatomia de rgb(255 99 71)

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p>Bolo de cenoura com cobertura de chocolate.</p>

h1 {
  color: rgb(255 99 71);
}
rgb
O nome da função. No CSS, uma função é um nome seguido de parênteses com valores dentro; ela "calcula" um valor, aqui uma cor. Escreva colado no parêntese: rgb(.
255
A luz vermelha, de 0 a 255. 255 é o máximo.
99
A luz verde.
71
A luz azul.
( )
Os parênteses guardam os três números, separados por espaço. O parêntese de fechar é obrigatório (veja "Quando dá errado").

É o mesmo tomate de tomato e de #ff6347: ff = 255, 63 = 99, 47 = 71. Na caixa acima, mude um número de cada vez: suba o verde (99) até 200 e o tomate vira um amarelo-alaranjado; zere o vermelho e sobra um azul-esverdeado escuro.

2. Mexendo em um botão de cada vez

Cada faixa abaixo tem os números escritos dentro e o fundo pintado com eles. Na primeira família, só o vermelho sobe; na segunda, os três sobem juntos:

<style>

    margin: 4px 0;
    padding: 6px 10px; /* espaço em volta do texto (aula Espaço Interno) */

  .v1 { background-color: rgb(64 0 0); color: white; }
  .v2 { background-color: rgb(128 0 0); color: white; }
  .v3 { background-color: rgb(192 0 0); color: white; }
  .v4 { background-color: rgb(255 0 0); color: black; }
  .c1 { background-color: rgb(64 64 64); color: white; }
  .c2 { background-color: rgb(128 128 128); color: black; }
  .c3 { background-color: rgb(192 192 192); color: black; }
  .c4 { background-color: rgb(240 240 240); color: black; }
</style>

<p class="v1">rgb(64 0 0)</p>
<p class="v2">rgb(128 0 0)</p>
<p class="v3">rgb(192 0 0)</p>
<p class="v4">rgb(255 0 0)</p>
<p class="c1">rgb(64 64 64)</p>
<p class="c2">rgb(128 128 128)</p>
<p class="c3">rgb(192 192 192)</p>

Com só o vermelho subindo, a cor sai do preto e chega ao vermelho puro, passando por um vinho escuro (rgb(128 0 0) é o maroon). Com os três números iguais, a cor é sempre um cinza, cada vez mais claro: os três refletores com a mesma força dão luz "sem cor".

Missão: use rgb(). O título deve ficar com o verde-petróleo do logo da Ana, rgb(29 111 106), e o parágrafo com um cinza-escuro: os três números valendo 51.

3. A forma antiga: vírgulas e rgba()

Até uns anos atrás, o rgb() só aceitava os números separados por vírgulas. Você vai encontrar essa forma em quase todo tutorial e site antigo, e no próprio F12:

<style>
  .moderna { color: rgb(255 99 71); }
  .antiga { color: rgb(255, 99, 71); }
</style>
<h2 class="moderna">rgb(255 99 71)</h2>
<h2 class="antiga">rgb(255, 99, 71)</h2>

Mesma cor. As duas formas funcionam e passam no validador; a única regra é não misturar: ou só espaços, ou só vírgulas. O guia usa a forma moderna, com espaços, porque é a mesma das funções de cor mais novas (hsl(), oklch()).

FormaExemploSituação
Moderna (espaços)rgb(255 99 71)A recomendada hoje
Antiga (vírgulas)rgb(255, 99, 71)Funciona; muito comum em código existente
Antiga com transparênciargba(255, 99, 71, 0.5)O a de rgba é de alpha (transparência). Hoje o rgba() é só outro nome do rgb()

E o valor que o navegador guarda (o "calculado", aba Computed do F12) é sempre com vírgulas: rgb(255 99 71) aparece como rgb(255, 99, 71). Não estranhe a diferença: é a mesma cor.

Suporte

A forma com espaços e a barra da transparência (próxima seção) funcionam em todos os navegadores atuais: Chrome 65 e Firefox 52 (de 2018 e 2017), Safari 12.1 (de 2019) e o Edge novo, desde a primeira versão. Só o Internet Explorer exigia as vírgulas.

4. Transparência: a barra /

Um quarto valor, depois de uma barra, diz quanto a cor é opaca: o alfa. Pode ser um número de 0 a 1 (0.5) ou uma porcentagem (50%). Com 0, a cor some; com 1 (ou 100%), fica inteira.

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px;
    font-family: monospace;
  }
  .a100 { background-color: rgb(255 99 71); }
  .a75 { background-color: rgb(255 99 71 / 75%); }
  .a50 { background-color: rgb(255 99 71 / 50%); }
  .a25 { background-color: rgb(255 99 71 / 25%); }
  .a0 { background-color: rgb(255 99 71 / 0); }
</style>
<p class="a100">rgb(255 99 71)</p>
<p class="a75">rgb(255 99 71 / 75%)</p>
<p class="a50">rgb(255 99 71 / 50%)</p>
<p class="a25">rgb(255 99 71 / 25%)</p>
<p class="a0">rgb(255 99 71 / 0)</p>

O tomate vai clareando porque o fundo branco aparece através dele, até sumir de vez com o alfa 0 (a última faixa só tem o texto). O navegador guarda rgb(255 99 71 / 50%) como rgba(255, 99, 71, 0.5). A aula Transparência mostra a diferença entre uma cor transparente e o elemento inteiro transparente.

5. Porcentagens no lugar de 0 a 255

Cada luz também pode ir de 0% a 100%, em vez de 0 a 255:

Você escreveValor calculado
rgb(100% 50% 0%)rgb(255, 128, 0) (um laranja)
rgb(100% 39% 28%)rgb(255, 99, 71) (o tomate, arredondado)

Funciona, mas é raro: quase todo programa de desenho mostra os números de 0 a 255. Prefira os números.

6. Números fora de 0 a 255

O que acontece com rgb(300 0 0)? O navegador não dá erro nem ignora: ele corta no limite. Acima de 255 vira 255; abaixo de 0 vira 0. Números com vírgula decimal também valem e são arredondados:

Você escreveValor calculado
rgb(300 0 0)rgb(255, 0, 0)
rgb(-20 0 0)rgb(0, 0, 0)
rgb(255 99.5 71)rgb(255, 100, 71)
rgb(255 99 71 / 2)rgb(255, 99, 71) (alfa acima de 1 vira 1)

O validador também aceita rgb(300 0 0) sem reclamar. Por isso, se você digitar 2550 no lugar de 255, nada avisa: a cor só fica diferente do que você queria. Confira no F12 o valor calculado.

7. rgb() ou hexadecimal?

Desenham exatamente as mesmas cores. A escolha é de leitura:

SituaçãoMelhor formaPor quê
Copiar a cor de um logo ou de um desenho#c7401fÉ o que os programas entregam; mais curto
Cor meio transparentergb(0 0 0 / 60%)O 60% é fácil de ler; em hexadecimal seria #00000099
Entender ou ajustar a misturargb(199 64 31)Números de 0 a 255 são mais naturais que c7
Criar tons mais claros e mais escuros da mesma corhsl()Aula hsl(): um número só para a claridade

Um uso muito comum de rgb() com alfa: uma faixa escura e transparente por cima de uma foto, para o texto ficar legível. rgb(0 0 0 / 60%) é "60% de preto": escurece sem esconder a imagem.

Quando dá errado

Como toda cor inválida, o navegador ignora a declaração em silêncio, e o texto fica com a cor de antes. Os títulos abaixo queriam ser tomate:

<style>
  .a { color: rgb(255, 99 71); }
  .b { color: rgb (255 99 71); }
  .c { color: rgb(255 99); }
  .d { color: rgb(255 99 71 0.5); }
  .e { color: rgb(255; 99; 71); }
</style>
<h2 class="a">rgb(255, 99 71)</h2>
<h2 class="b">rgb (255 99 71)</h2>
<h2 class="c">rgb(255 99)</h2>
<h2 class="d">rgb(255 99 71 0.5)</h2>
<h2 class="e">rgb(255; 99; 71)</h2>

Os cinco ficaram pretos. O validador explica cada um:

error: CSS: “color”: Invalid RGB function.

O que aconteceu: vírgula e espaço misturados (rgb(255, 99 71)), ou faltou um número (rgb(255 99)).

$ vnu --css mistura.css
"file:/home/ana/rgb/mistura.css":2.24-2.24: error: CSS: “color”: Invalid RGB function.
$ vnu --css dois.css
"file:/home/ana/rgb/dois.css":2.20-2.20: error: CSS: “color”: Invalid RGB function.

"Função RGB inválida." As duas formas existem, mas cada uma inteira: só espaços ou só vírgulas. E são sempre três números (mais o alfa, se quiser).

Como consertar: rgb(255 99 71) ou rgb(255, 99, 71).

error: CSS: “color”: “rgb” is not a “color” value.

O que aconteceu: um espaço entre o nome e o parêntese: rgb (255 99 71).

$ vnu --css espaco.css
"file:/home/ana/rgb/espaco.css":2.13-2.13: error: CSS: “color”: “rgb” is not a “color” value.
"file:/home/ana/rgb/espaco.css":2.26-2.26: error: CSS: Parse Error.
"file:/home/ana/rgb/espaco.css":3.2-4.1: error: CSS: Parse Error.

"rgb não é um valor de cor." Com o espaço, o CSS não vê mais uma função: vê a palavra solta rgb (que não é nome de cor) e, depois, uns parênteses sem dono. Os Parse Error ("erro de leitura") são o validador se perdendo nesse resto.

Como consertar: cole o nome no parêntese: rgb(.

error: CSS: “color”: “0.5” is not a valid LCH color.

O que aconteceu: o alfa foi escrito sem a barra: rgb(255 99 71 0.5).

$ vnu --css sem-barra.css
"file:/home/ana/rgb/sem-barra.css":2.27-2.27: error: CSS: “color”: “0.5” is not a valid LCH color.

A mensagem fala de "LCH", outro tipo de cor, e confunde; o que importa é a posição (coluna 27, o 0.5): o quarto número está no lugar errado. Na forma moderna, o alfa vem depois de uma barra.

Como consertar: rgb(255 99 71 / 0.5).

error: CSS: “color”: Parse Error.

O que aconteceu: ponto e vírgula no lugar das vírgulas: rgb(255; 99; 71).

$ vnu --css pontovirgula.css
"file:/home/ana/rgb/pontovirgula.css":2.14-2.16: error: CSS: “color”: Parse Error.
"file:/home/ana/rgb/pontovirgula.css":2.22-2.22: error: CSS: Parse Error.
"file:/home/ana/rgb/pontovirgula.css":2.27-2.27: error: CSS: Parse Error.
"file:/home/ana/rgb/pontovirgula.css":3.2-4.1: error: CSS: Parse Error.

O ; encerra declarações; dentro do rgb() ele não tem lugar, e o validador se perde em vários "erros de leitura".

Como consertar: espaços (ou vírgulas) entre os números.

error: CSS: “color”: Parse Error. (o parêntese que não fecha)

O que aconteceu: faltou o ) no fim: color: rgb(255 99 71;. Este é o pior, porque o estrago não fica só nessa linha:

Experimente: o parágrafo deveria estar verde, e a regra dele está certinha. Mas os dois estão pretos. Feche o parêntese do h1 e veja os dois ganharem cor.

<link rel="stylesheet" href="style.css">
<h1>Lojinha da Ana</h1>
<p>Bolos e doces por encomenda.</p>

h1 {
  color: rgb(255 99 71;
}

p {
  color: rgb(29 111 106);
}

Enquanto o parêntese está aberto, o navegador considera que tudo o que vem depois (o ;, o }, a regra do p inteira) ainda está dentro do rgb(. A regra do parágrafo é engolida e some junto. O validador acusa o ponto em que se perdeu:

$ vnu --css parenteses.css
"file:/home/ana/rgb/parenteses.css":2.21-2.22: error: CSS: “color”: Parse Error.

Como consertar: feche o parêntese. Quando uma regra certa não funciona, olhe a regra de cima: um ) ou um } esquecido lá costuma ser o culpado.

Os três erros: vírgula misturada com espaço, espaço antes do parêntese, e o alfa sem a barra.

Resumo

  • rgb(vermelho verde azul): três números de 0 a 255, separados por espaço. rgb(255 99 71) é o tomate (#ff6347).
  • Números iguais dão cinza; todos 0, preto; todos 255, branco.
  • A forma antiga usa vírgulas (rgb(255, 99, 71)) e rgba() para a transparência. Funciona, mas não misture vírgulas e espaços.
  • Transparência com a barra: rgb(255 99 71 / 50%). O navegador guarda como rgba(255, 99, 71, 0.5).
  • Números fora de 0 a 255 são cortados no limite, sem aviso.
  • Espaço antes do parêntese, vírgula misturada ou alfa sem barra: a cor é ignorada. Um parêntese sem fechar engole as regras seguintes.
