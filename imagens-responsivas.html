CSS Imagens Responsivas

Uma foto de 800 pixels de largura cabe numa tela de computador, mas não numa tela de celular de 360. Sem CSS, ela passa da borda e a página ganha uma rolagem para o lado. Nesta aula você vai fazer as imagens do site da Ana encolherem junto com a página, sem ficarem achatadas, e vai aprender a encaixar uma foto numa moldura de tamanho fixo, como as miniaturas de uma galeria.

Você vai aprender
  • A dupla max-width: 100% + height: auto, a regra mais usada em imagens.
  • Por que só o max-width achata a foto.
  • A diferença entre width: 100% e max-width: 100%.
  • object-fit: como a foto ocupa uma moldura de tamanho fixo (fill, contain, cover, none, scale-down).
  • object-position: qual pedaço da foto fica à mostra.
  • Os erros mais comuns e o que o validador W3C diz deles.

Os resultados são desenhados pelo seu navegador. Para não depender do tamanho da sua tela, os exemplos colocam a imagem numa coluna de largura fixa (.coluna, 300 pixels, com uma borda tracejada), que faz o papel da "tela pequena". As fotos são da pasta de mídia do guia (assets/midia/).

A ideia: a foto e o porta-retrato

Pense numa foto impressa e num porta-retrato. Se a foto é maior que a moldura, você tem três saídas:

  • Reduzir a foto inteira até caber, mantendo a proporção. É o que max-width: 100% + height: auto faz.
  • Cortar as sobras com uma tesoura, para a foto ocupar a moldura toda. É o object-fit: cover.
  • Esticar a foto até ela ter o formato da moldura. Ninguém faz isso com uma foto de verdade, mas é o que o navegador faz quando você muda a largura e a altura sem cuidado.

Esta aula é sobre escolher a saída certa, e nunca cair na terceira sem querer.

1. O problema: a imagem maior que a coluna

Aqui está a foto do bolo, com 800×600 pixels, dentro da coluna de 300 pixels. Ainda sem nenhuma regra para a imagem:

<link rel="stylesheet" href="style.css">
<div class="coluna">
  <img src="assets/midia/bolo-800.jpg" alt="Bolo de cenoura com cobertura de chocolate" width="800" height="600">
</div>

.coluna {
  width: 300px;
  border: 2px dashed gray;
}

A foto passa da borda tracejada e continua para a direita, até sair do quadro: ela tem 800 pixels e ninguém disse que precisava caber. Num celular, é a página inteira que ganha rolagem para o lado e fica "dançando".

Os atributos width="800" e height="600" do HTML (aula Imagens do Guia HTML) são uma boa prática: eles dizem ao navegador o tamanho da foto antes de ela chegar, e o espaço fica reservado. Mas eles também viram o tamanho desenhado, e é aí que entra o CSS.

2. max-width: 100%: no máximo a largura de quem a contém

max-width é a "largura máxima" (aula Largura e Altura). Com 100%, a imagem pode ter a largura dela, desde que não passe da largura do elemento onde ela está (o "pai", aqui a .coluna):

img {
  max-width: 100%;
}
img
O seletor: vale para todas as imagens da página.
max-width
A largura máxima. A imagem pode ficar menor do que isso, nunca maior.
100%
Cem por cento da largura do pai. Numa coluna de 300 pixels, no máximo 300; numa tela de celular, no máximo a tela.

Só que, sozinha, essa regra deixa um problema. Veja o resultado:

<link rel="stylesheet" href="style.css">
<div class="coluna">
  <img src="assets/midia/bolo-800.jpg" alt="Bolo de cenoura com cobertura de chocolate" width="800" height="600">
</div>

.coluna {
  width: 300px;
  border: 2px dashed gray;
}

img {
  max-width: 100%;
}

A foto cabe na coluna, mas ficou alta e magra: o bolo parece um bolo de festa de três andares. A largura caiu para 300 pixels, mas a altura continuou nos 600 do atributo height="600". A foto, que era mais larga que alta (4 por 3), virou mais alta que larga.

3. height: auto: a altura acompanha a largura

A segunda metade da regra manda o navegador calcular a altura a partir da largura, mantendo a proporção da foto:

<link rel="stylesheet" href="style.css">
<div class="coluna">
  <img src="assets/midia/bolo-800.jpg" alt="Bolo de cenoura com cobertura de chocolate" width="800" height="600">
</div>

.coluna {
  width: 300px;
  border: 2px dashed gray;
}

img {
  max-width: 100%;
  height: auto;
}

Agora o bolo voltou ao normal: 300 pixels de largura e 225 de altura (300 × 600 ÷ 800), conferido no Chromium. A proporção 4 por 3 foi mantida.

height: auto
"Altura automática": o navegador calcula a altura a partir da largura e da proporção da imagem. Ela vence o height="600" do HTML, porque o CSS manda mais que os atributos de tamanho.
Continue pondo width e height no HTML

Com height: auto, o navegador ainda usa os dois atributos para saber a proporção da foto antes de ela baixar. No F12, na aba Computed, a imagem mostra aspect-ratio: auto 800 / 600, vindo dos atributos. O espaço certo fica reservado e o texto de baixo não "pula" quando a foto chega. É por isso que a dupla max-width: 100% + height: auto combina tão bem com os atributos.

Muitos sites começam o CSS com essa regra para todas as imagens (e os vídeos), porque ela não atrapalha as fotos pequenas e salva as grandes:

img,
video {
  max-width: 100%;
  height: auto;
}

4. width: 100% ou max-width: 100%?

As duas parecem iguais com uma foto grande: ela fica com a largura da coluna. A diferença aparece com uma imagem pequena. Aqui, o avatar da Ana, que tem só 96×96 pixels:

<link rel="stylesheet" href="style.css">
<div class="coluna">
  <img class="maxima" src="assets/midia/avatar-ana-96.png" alt="Avatar da Ana" width="96" height="96">
</div>
<div class="coluna">
  <img class="cheia" src="assets/midia/avatar-ana-96.png" alt="Avatar da Ana" width="96" height="96">
</div>

.coluna {
  width: 300px;
  border: 2px dashed gray;
  margin-bottom: 8px;
}

.maxima {
  max-width: 100%;
  height: auto;
}

.cheia {
  width: 100%;
  height: auto;
}
  • Com max-width: 100%, o avatar continua com os seus 96 pixels: ele já cabia, então nada muda.
  • Com width: 100%, ele é esticado até 300×300 e fica borrado: o navegador inventa os pixels que faltam.

Apague o height: auto da regra .cheia e veja o pior caso: o avatar fica com 300 de largura e 96 de altura, achatado.

RegraFoto maior que o paiFoto menor que o paiQuando usar
max-width: 100% + height: autoEncolhe até caberFica do tamanho delaQuase sempre: fotos dentro do texto, receitas, posts
width: 100% + height: autoEncolhe até caberEstica (pode borrar)Quando a imagem tem de ocupar a largura toda (um banner) e você sabe que o arquivo é grande o bastante

5. object-fit: a foto numa moldura de tamanho fixo

Às vezes o tamanho não vem da foto, vem do layout: numa galeria, todas as miniaturas devem ser quadrados de 150×150, mesmo que uma foto seja deitada e a outra em pé. Quando você dá largura e altura a uma imagem, a propriedade object-fit ("encaixe do objeto") decide como a foto ocupa essa moldura.

A foto do bolo tem 400×300 (deitada). Cada quadro abaixo tem 150×150 e um valor diferente, escrito embaixo dele:

<link rel="stylesheet" href="style.css">
<div class="vitrine">
  <figure>
    <img class="fill" src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura">
    <figcaption>fill</figcaption>
  </figure>
  <figure>
    <img class="contain" src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura">
    <figcaption>contain</figcaption>
  </figure>
  <figure>
    <img class="cover" src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura">
    <figcaption>cover</figcaption>
  </figure>
  <figure>
    <img class="none" src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura">
    <figcaption>none</figcaption>
  </figure>
  <figure>
    <img class="scale-down" src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura">
    <figcaption>scale-down</figcaption>
  </figure>
</div>

.vitrine {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

  text-align: center;

  object-fit: fill;
}

.contain {

}

}

}

}
ValorO que fazNo porta-retrato
fillO padrão. Estica a foto até preencher a moldura, sem respeitar a proporção. O bolo deitado ficou espremido num quadrado.Esticar a foto
containReduz a foto até ela caber inteira, mantendo a proporção. Sobram faixas vazias (aqui, em cima e embaixo).Reduzir até caber
coverAumenta ou reduz a foto até ela cobrir a moldura toda, mantendo a proporção, e corta o que sobra (aqui, as laterais).Cortar as sobras
noneNão muda o tamanho da foto: mostra o pedaço do meio, em tamanho natural (400×300), recortado pela moldura.Olhar por uma janelinha
scale-downEscolhe o menor resultado entre none e contain. Aqui a foto é maior que a moldura, então ficou igual ao contain; uma foto pequena ficaria em tamanho natural.Reduzir, mas nunca aumentar

Na prática, cover é o mais usado (miniaturas, avatares, capas), e contain vem em segundo (logotipos e fotos de produto, que não podem ser cortados).

Só funciona com moldura

O object-fit só tem efeito quando a imagem tem largura e altura que não são as dela (por CSS ou pelos atributos). E ele só vale para elementos que mostram um conteúdo de fora, como <img> e <video>. Os dois enganos estão em Quando dá errado.

6. object-position: qual pedaço fica à mostra

Com cover (e none), parte da foto é cortada. Por padrão, o navegador mantém o centro: o valor calculado de object-position é 50% 50%. Para guardar outro pedaço, diga qual:

<link rel="stylesheet" href="style.css">
<p>center (o padrão)</p>
<img class="capa" src="assets/midia/bolo-800.jpg" alt="Bolo de cenoura">
<p>top</p>
<img class="capa topo" src="assets/midia/bolo-800.jpg" alt="Bolo de cenoura">
<p>bottom</p>
<img class="capa base" src="assets/midia/bolo-800.jpg" alt="Bolo de cenoura">

.capa {
  width: 300px;
  height: 120px;
  object-fit: cover;
}

.topo {
  object-position: top;
}

.base {
  object-position: bottom;
}

As três faixas têm 300×120 e mostram pedaços diferentes da mesma foto: a primeira, o corpo do bolo; a do meio (top), a parede da cozinha e só o alto do bolo; a de baixo (bottom), a parte de baixo do bolo, o prato e a mesa. Troque top por left, right ou por porcentagens, como 50% 80% (80% da altura: mais perto de baixo).

Quando dá errado

Só max-width, sem height: auto: a foto fica achatada 
img {
  max-width: 100%;
}

O que você vê: a foto cabe na largura, mas fica deformada (veja o resultado da seção 2): a altura continua a do atributo height do HTML.

Por quê: o max-width só mexe na largura. Quem cuida da altura é o atributo height="600", que continua valendo.

O que o validador diz: nada. As duas coisas são válidas; o problema é a combinação.

Como consertar: ponha height: auto junto. Não tire os atributos width e height do HTML: eles reservam o espaço da foto.

object-fit sem moldura: nada muda 
.foto {
  object-fit: cover;
}

O que você vê: a foto fica exatamente como estava, no tamanho natural (400×300, conferido no Chromium).

Por quê: a imagem não tem uma largura e uma altura diferentes das dela. A moldura é do tamanho da foto, então não há nada para encaixar.

Como consertar: dê os dois tamanhos (width: 150px; e height: 150px;), ou uma largura e um aspect-ratio.

object-fit numa div com imagem de fundo: também nada muda 
.destaque {
  width: 150px;
  height: 150px;
  background-image: url("assets/midia/bolo-400.jpg");
  object-fit: cover;
}

O que você vê: a div mostra só o canto de cima, à esquerda, da foto (a parede da cozinha), em tamanho natural. O object-fit foi ignorado.

Por quê: object-fit vale para o conteúdo de elementos como <img> e <video>. Uma imagem de fundo é outra coisa, com propriedades próprias.

Como consertar: no fundo, o equivalente é background-size: cover; e background-position (aula Tamanho do Fundo).

Valor que não existe: “crop” is not a “object-fit” value 
img {
  object-fit: crop;
}
.foto {
  max-width: 100;
}
.capa {
  object-position: centro;
}

O que você vê: nada muda. O navegador ignora em silêncio cada declaração que não entende; no F12, na aba Elements, o painel de estilos mostra a declaração riscada, com um ícone de aviso.

$ vnu --css estilo.css
"file:/home/ana/site/estilo.css":2.15-2.18: error: CSS: “object-fit”: “crop” is not a “object-fit” value.
"file:/home/ana/site/estilo.css":5.14-5.16: error: CSS: “max-width”: only “0” can be a “unit”. You must put a unit after your number.
"file:/home/ana/site/estilo.css":8.20-8.25: error: CSS: “object-position”: “centro” is not a “object-position” value.

O que significa:

  • "crop não é um valor de object-fit". Cortar é cover.
  • "Só o 0 pode ficar sem unidade. Você precisa pôr uma unidade depois do número": max-width: 100 não é nem 100 pixels nem 100%. Escreva 100%.
  • "centro não é um valor de object-position": os nomes são em inglês, center.

Resumo

  • max-width: 100% + height: auto: a imagem encolhe para caber no pai e mantém a proporção. É a regra para quase toda foto.
  • Sem o height: auto, a altura do atributo height continua valendo e a foto fica achatada. Mantenha os atributos width e height no HTML: eles reservam o espaço.
  • width: 100% estica as imagens pequenas (e borra); use só quando a imagem tem de ocupar a largura toda.
  • object-fit encaixa a foto numa moldura de largura e altura fixas: fill (padrão, estica), contain (inteira), cover (cobre e corta), none, scale-down.
  • object-position escolhe o pedaço que fica à mostra (padrão: o centro).
  • object-fit não faz nada sem moldura, nem em imagem de fundo (lá, é background-size).
