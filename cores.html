CSS Cores por Nome

A primeira coisa que quase todo mundo quer mudar num site é a cor. No CSS, o jeito mais fácil de escolher uma cor é pelo nome, em inglês: red ("vermelho"), navy ("azul-marinho"), tomato ("tomate"). O navegador conhece quase 150 nomes. Nesta aula você vai usar esses nomes, ver as famílias de cores lado a lado e descobrir o que o navegador faz quando o nome está errado.

Você vai aprender
  • Como pintar o texto com a propriedade color e um nome de cor.
  • As famílias de cores (vermelhos, azuis, verdes, cinzas) desenhadas lado a lado.
  • Que Tomato e tomato são a mesma cor, e que gray e grey também.
  • As surpresas dos nomes: darkgray é mais clara que gray.
  • As duas palavras especiais: transparent e currentcolor.
  • Por que o navegador guarda tomato como rgb(255, 99, 71).
  • O que acontece com um nome errado (tomate, light blue, "red") e as mensagens reais do validador W3C.

Antes, é bom ter feito Seu Primeiro Estilo e Regras, Seletores e Declarações. Os quadros "Resultado" e as caixas "Experimente" são desenhados agora pelo seu navegador. As mensagens do validador saíram do validador W3C (vnu, o mesmo do validator.w3.org) na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: a caixa de lápis de cor

Pense numa caixa de lápis de cor. Cada lápis tem o nome escrito: "vermelho", "azul-marinho", "verde-musgo". Você não precisa saber como a fábrica misturou a tinta; basta pedir o lápis pelo nome. Os nomes de cor do CSS são essa caixa: você escreve navy e o navegador sabe exatamente qual azul usar.

A caixa tem um limite: são só os lápis que vieram nela, quase 150. Quando a Ana quiser o laranja exato do logo da lojinha, vai precisar das próximas aulas (hexadecimal, rgb() e hsl()), que deixam escolher qualquer uma de 16 milhões de cores.

1. A primeira cor: color

A propriedade color ("cor") pinta o texto de um elemento. O título da Ana fica cor de tomate assim:

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p>Bolo de cenoura com cobertura de chocolate.</p>

h1 {
  color: tomato;
}
h1
O seletor: a regra vale para todos os <h1> da página.
color
A propriedade: a cor do texto. Escreve-se no inglês dos Estados Unidos, color, e não colour nem cor.
tomato
O valor: um nome de cor, sem aspas, numa palavra só. Tomato é um vermelho alaranjado, cor de tomate maduro.
;
Fecha a declaração. Sempre, até na última.

Só o título mudou: o parágrafo continua preto, porque a regra escolheu só o h1. Na caixa acima, troque tomato por navy, seagreen ou purple e veja a cor mudar enquanto você digita.

Onde mais uma cor entra

O mesmo nome serve em toda propriedade que pede uma cor. As mais comuns, cada uma com a sua aula:

PropriedadeO que ela pintaExemplo
coloro texto (e o que usa a cor do texto)color: navy;
background-coloro fundo do elemento (aula Cor de Fundo)background-color: lightyellow;
border-colora borda (aula Bordas)border-color: crimson;

Nesta aula, o assunto é o nome da cor. Para mostrar as cores lado a lado, alguns exemplos pintam o fundo com background-color: leia como "pinte o fundo desta cor".

2. Os nomes lado a lado

Os nomes vêm em famílias. Cada caixinha abaixo foi pintada com o nome escrito dentro dela:

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px; /* espaço em volta do nome (aula Espaço Interno) */
    font-family: monospace;
  }
  .red { background-color: red; color: white; }
  .crimson { background-color: crimson; color: white; }
  .tomato { background-color: tomato; color: black; }
  .coral { background-color: coral; color: black; }
  .salmon { background-color: salmon; color: black; }
  .navy { background-color: navy; color: white; }
  .royalblue { background-color: royalblue; color: white; }
  .steelblue { background-color: steelblue; color: white; }
  .skyblue { background-color: skyblue; color: black; }
  .darkgreen { background-color: darkgreen; color: white; }
  .seagreen { background-color: seagreen; color: white; }
  .limegreen { background-color: limegreen; color: black; }
</style>
<p class="red">red</p>
<p class="crimson">crimson</p>
<p class="tomato">tomato</p>
<p class="coral">coral</p>
<p class="salmon">salmon</p>
<p class="navy">navy</p>
<p class="royalblue">royalblue</p>
<p class="steelblue">steelblue</p>
<p class="skyblue">skyblue</p>
<p class="darkgreen">darkgreen</p>
<p class="seagreen">seagreen</p>
<p class="limegreen">limegreen</p>

Repare como cada família vai do escuro ao claro: o crimson ("carmim") é um vermelho mais fechado que o red; o salmon ("salmão") quase vira rosa. Nas caixas escuras, o nome está em branco; nas claras, em preto, para dar para ler (veja a seção 6).

Muitos nomes são compostos, sempre numa palavra só, em minúsculas: dark + green = darkgreen ("verde-escuro"), light + blue = lightblue ("azul-claro"), steel + blue = steelblue ("azul-aço"). A lista completa, com cada cor desenhada, está na Referência: Nomes de Cores.

3. Maiúsculas não importam (mas escreva em minúsculas)

Para o navegador, tomato, Tomato e TOMATO são a mesma cor. O validador também aceita as três. Veja os três títulos:

<style>
  .a { color: tomato; }
  .b { color: Tomato; }
  .c { color: TOMATO; }
</style>
<h2 class="a">color: tomato</h2>
<h2 class="b">color: Tomato</h2>
<h2 class="c">color: TOMATO</h2>

Os três ficaram exatamente da mesma cor. Mesmo assim, o costume (e o estilo do guia) é escrever tudo em minúsculas: o código fica uniforme e mais fácil de procurar.

4. As surpresas dos nomes

Os nomes vieram de programas antigos e foram juntados ao longo dos anos, sem muito capricho. Algumas coisas parecem erro, mas são assim mesmo.

darkgray é mais clara que gray

<style>
  p {
    margin: 4px 0;
    padding: 6px 10px;
    font-family: monospace;
  }
  .dimgray { background-color: dimgray; color: white; }
  .gray { background-color: gray; color: white; }
  .darkgray { background-color: darkgray; color: black; }
  .silver { background-color: silver; color: black; }
  .lightgray { background-color: lightgray; color: black; }
</style>
<p class="dimgray">dimgray</p>
<p class="gray">gray</p>
<p class="darkgray">darkgray (o "cinza-escuro"!)</p>
<p class="silver">silver</p>
<p class="lightgray">lightgray</p>

O darkgray ("cinza-escuro") ficou entre o gray e o silver: mais claro que o cinza "normal". É uma herança histórica: o gray veio de uma lista e o darkgray de outra, e ninguém pôde mudar depois sem estragar os sites que já existiam. Se você quer um cinza escuro de verdade, use dimgray.

Nomes repetidos

Estes nomes……são a mesma cor
gray e greyas duas grafias do inglês (EUA e Reino Unido); vale para todos os cinzas: darkgray/darkgrey, lightgray/lightgrey…
aqua e cyano mesmo azul-piscina, bem forte
fuchsia e magentao mesmo rosa-choque

Atenção: só a palavra cor aceita as duas grafias. A propriedade é sempre color; colour não existe (seção "Quando dá errado").

green não é o verde mais forte

O green é um verde médio, meio escuro. O verde mais vivo da tela se chama lime ("lima"). E o rebeccapurple, um roxo, tem uma história: foi acrescentado em 2014 em homenagem a Rebecca, filha de Eric Meyer, um dos pioneiros do CSS. É o único nome de cor com nome de gente.

5. Duas palavras especiais: transparent e currentcolor

Além das cores da caixa, o CSS tem duas palavras que funcionam no lugar de uma cor:

transparent
"Transparente": cor nenhuma, dá para ver o que está atrás. É a cor de fundo que todo elemento já tem quando você não escolhe outra. A aula Transparência mostra as cores "meio transparentes".
currentcolor
"A cor atual": a mesma cor do texto (color) daquele elemento. Útil numa borda que deve acompanhar o texto.
<style>
  .aviso {
    color: crimson;
    border: 3px solid currentcolor; /* borda da cor do texto */
    padding: 8px;
  }
</style>
<p class="aviso">Hoje não tem pão de queijo.</p>

O texto e a borda saíram no mesmo crimson, mas a cor foi escrita uma vez só. Troque crimson por outra cor e os dois mudam juntos. (A propriedade border é da aula Bordas.)

6. Escolha cores que dá para ler

Uma cor bonita sozinha pode ficar ilegível sobre um fundo. O que conta é o contraste: a diferença de claridade entre o texto e o fundo. Compare:

<style>
  .ruim1 { color: yellow; }
  .ruim2 { color: lightgray; }
  .boa1 { color: navy; }
  .boa2 { color: dimgray; }
</style>
<p class="ruim1">yellow no fundo branco: difícil de ler.</p>
<p class="ruim2">lightgray no fundo branco: quase some.</p>
<p class="boa1">navy no fundo branco: fácil de ler.</p>
<p class="boa2">dimgray no fundo branco: fácil de ler.</p>

As duas primeiras linhas mal aparecem sobre o branco. Pense em quem lê no celular, no sol, ou em quem enxerga pouco: com pouco contraste, essa pessoa simplesmente não lê. Regra prática: texto escuro em fundo claro, ou o contrário. A aula CSS e Acessibilidade mostra como medir o contraste com números.

7. O nome vira número: rgb(255, 99, 71)

O nome é só um apelido. Por dentro, toda cor da tela é uma mistura de três luzes: vermelho, verde e azul, cada uma de 0 a 255. Quando lê tomato, o navegador troca pelo número dessa mistura e guarda rgb(255, 99, 71): 255 de vermelho, 99 de verde e 71 de azul.

Você escreveO navegador guarda (valor calculado)
color: tomato;rgb(255, 99, 71)
color: TOMATO;rgb(255, 99, 71)
color: navy;rgb(0, 0, 128)
color: gray; ou greyrgb(128, 128, 128)
color: darkgray;rgb(169, 169, 169) (mais claro que o gray: mais luz)
color: white;rgb(255, 255, 255) (as três luzes no máximo)
color: black;rgb(0, 0, 0) (tudo apagado)
color: transparent;rgba(0, 0, 0, 0) (o último 0 quer dizer "nada opaco")

É esse número que aparece no F12 (aula Inspecionando com o F12): selecione o título no painel de elementos e abra a aba Computed ("Calculado"). Na linha color, aparece rgb(255, 99, 71), e não tomato. Ver uma cor como número vai ficar natural nas aulas Hexadecimal e rgb().

8. Nome, hexadecimal, rgb() ou hsl()?

As quatro formas desenham as mesmas cores; muda o jeito de escrever. O mesmo tomate:

<style>
  .nome { color: tomato; }
  .hex { color: #ff6347; }
  .rgb { color: rgb(255 99 71); }
  .hsl { color: hsl(9 100% 64%); }
</style>
<p class="nome">tomato</p>
<p class="hex">#ff6347</p>
<p class="rgb">rgb(255 99 71)</p>
<p class="hsl">hsl(9 100% 64%)</p>

As quatro linhas saíram iguais. Não se preocupe ainda com os números: cada forma tem a sua aula.

FormaQuando usar
Nome (tomato)Exemplos, testes rápidos, white, black e transparent. Fácil de ler, mas só quase 150 opções.
Hexadecimal (#ff6347)A cor exata de um logo ou de um programa de desenho, que quase sempre entrega o código #. É a forma mais comum nos sites.
rgb()Quando você pensa na mistura de luzes ou precisa de transparência.
hsl()Para criar variações (mais clara, mais escura) da mesma cor.

Quando dá errado

Um nome de cor errado não mostra mensagem nenhuma na página. O navegador lê a declaração, não entende, joga fora e segue em frente: o texto fica com a cor que já tinha (no exemplo, o preto padrão). Todos os casos abaixo estão desenhados de verdade no Resultado:

<style>
  .a { color: tomate; }
  .b { color: light blue; }
  .c { color: "red"; }
  .d { colour: tomato; }
  .e {
    color: tomato
    background-color: lightyellow;
  }
</style>
<p class="a">color: tomate</p>
<p class="b">color: light blue</p>
<p class="c">color: "red"</p>
<p class="d">colour: tomato</p>
<p class="e">faltou o ; depois de tomato</p>

As cinco linhas ficaram pretas, sem fundo. Nenhuma das cores pegou. No F12, no painel de estilos (Styles), a declaração inválida aparece riscada, com um ícone de aviso ao lado: é o jeito do navegador dizer "li, mas não entendi". Para saber o motivo, use o validador:

error: CSS: “color”: “tomate” is not a “color” value.

O que aconteceu: o nome foi escrito em português (ou com uma letra trocada): color: tomate;.

$ vnu --css nome-errado.css
"file:/home/ana/cores/nome-errado.css":2.10-2.15: error: CSS: “color”: “tomate” is not a “color” value.

"tomate não é um valor de cor." O 2.10-2.15 é a linha 2, das colunas 10 a 15: a palavra exata. O texto fica com a cor de antes.

Como consertar: os nomes são em inglês: tomato. Na dúvida, confira na lista de nomes.

error: CSS: “color”: Too many values or values are not recognized.

O que aconteceu: o nome composto foi escrito separado: color: light blue;.

$ vnu --css espaco.css
"file:/home/ana/cores/espaco.css":2.16-2.19: error: CSS: “color”: Too many values or values are not recognized.

"Valores demais ou valores não reconhecidos": o color espera uma cor, e recebeu duas palavras.

Como consertar: junte as palavras: lightblue.

error: CSS: “color”: “"red"” is not a “color” value.

O que aconteceu: o nome está entre aspas: color: "red";. No HTML os valores de atributo têm aspas, e o costume vem junto.

$ vnu --css aspas.css
"file:/home/ana/cores/aspas.css":2.10-2.14: error: CSS: “color”: “"red"” is not a “color” value.

Com aspas, "red" vira um texto, e não o nome de uma cor.

Como consertar: tire as aspas: color: red;.

error: CSS: “colour”: Property “colour” doesn't exist.

O que aconteceu: a propriedade foi escrita no inglês britânico: colour: tomato;.

$ vnu --css colour.css
"file:/home/ana/cores/colour.css":2.11-2.16: error: CSS: “colour”: Property “colour” doesn't exist.

"A propriedade colour não existe." Aqui o erro está no nome da propriedade, e não no valor.

Como consertar: color, sem o u.

error: CSS: “color”: Missing a semicolon before the property name “background-color”.

O que aconteceu: faltou o ; no fim de color: tomato, e a linha de baixo era outra declaração.

$ vnu --css ponto.css
"file:/home/ana/cores/ponto.css":3.3-3.18: error: CSS: “color”: Missing a semicolon before the property name “background-color”.

"Falta um ponto e vírgula antes do nome da propriedade background-color." Sem o ;, o navegador lê as duas linhas como uma declaração só (color: tomato background-color: lightyellow), que não faz sentido. Ele joga fora as duas: por isso a última linha do Resultado ficou sem a cor e sem o fundo.

Como consertar: ponha o ; no fim de toda declaração, até da última.

Resumo

  • color pinta o texto. O valor pode ser um nome de cor em inglês: tomato, navy, seagreen. São quase 150 nomes.
  • Nomes compostos são uma palavra só (darkgreen, lightblue), sem aspas. Maiúsculas não importam, mas escreva em minúsculas.
  • Surpresas: gray = grey; aqua = cyan; darkgray é mais clara que gray; o verde vivo é lime.
  • transparent é cor nenhuma; currentcolor é a cor do texto do elemento.
  • Texto escuro em fundo claro (ou o contrário): contraste baixo deixa o texto ilegível.
  • O navegador guarda o nome como rgb(…): é o que aparece no F12, na aba Computed.
  • Nome errado, aspas, espaço no meio, colour ou falta de ;: o navegador ignora em silêncio, e o validador W3C mostra o motivo.
