CSS Flexbox ou Grid?

Você já conhece as duas ferramentas de layout do CSS moderno: o Flexbox e o Grid. Muita coisa dá para fazer com qualquer uma delas, e é aí que surge a dúvida: qual usar? Nesta aula você vai ver o mesmo conteúdo feito dos dois jeitos, entender a diferença de verdade entre eles e aprender a regra prática que resolve quase todos os casos. Spoiler: numa página de verdade, você usa os dois.

Você vai aprender
  • A diferença principal: uma dimensão (Flexbox) × duas dimensões (Grid).
  • Quem manda no tamanho: o conteúdo (Flexbox) ou o layout (Grid).
  • Quatro casos comuns, cada um com a ferramenta que combina melhor: etiquetas, menu, galeria e o esqueleto da página.
  • Como usar os dois juntos, um dentro do outro.
  • O que acontece quando você mistura as propriedades de um no outro.

Os resultados desta aula são desenhados pelo seu navegador. Algumas caixas têm uma largura fixa, para todo mundo ver as mesmas quebras de linha; os botões 375, 768 e cheia, na barra de cada quadro, mudam a largura.

A ideia: a fila e o tabuleiro

Pense numa fila de pessoas no banco. Cada pessoa ocupa o espaço que precisa, uma depois da outra. Se a fila não cabe no corredor, ela faz a curva e continua, mas a segunda parte da fila não tem nada a ver com a primeira: ninguém se alinha com quem está "em cima". Isso é o Flexbox: uma direção só, e cada item com o seu tamanho.

Agora pense num tabuleiro de xadrez, ou numa planilha. As casas já estão desenhadas antes das peças chegarem: colunas e fileiras alinhadas, nas duas direções. A peça entra na casa. Isso é o Grid: duas direções, e o desenho da grade manda no tamanho.

FlexboxGrid
DireçõesUma por vez: a linha ou a colunaDuas ao mesmo tempo: linhas e colunas
Quem manda no tamanhoO conteúdo: o item tem o tamanho dele, e o resto se ajustaO layout: você desenha as colunas, e o item entra na célula
Quando quebra a linhaCada linha é independente: os itens não se alinham com os de cimaOs itens continuam alinhados nas colunas
Onde se escreve a maior parteNos itens (flex-grow, flex-basis)No pai (grid-template-columns, grid-template-areas)

No Flexbox, cada etiqueta tem o tamanho do seu texto: "Doce" é curtinha, "Para festas" é comprida. Elas formam uma fila que quebra quando chega na borda, e as linhas não se alinham entre si. No Grid, as etiquetas formam colunas de mesma largura, todas alinhadas, e as curtas ganham espaço sobrando.

Nenhum dos dois está errado: para etiquetas, o jeito do Flexbox costuma ser o desejado (o tamanho segue o texto). Para cartões de uma galeria, o do Grid.

2. Um menu: Flexbox

Um menu é uma fileira só, com itens de tamanhos diferentes: o logo de um lado, os links do outro. Uma dimensão, e o conteúdo manda. É o caso típico do Flexbox:

<style>
  .topo {
    display: flex;
    justify-content: space-between;
    align-items: center;
    background: #ede9fe;
    padding: 8px 12px;
  }
  .topo nav {
    display: flex;
    gap: 16px;
  }
  .logo { font-weight: bold; }
</style>
<header class="topo">
  <span class="logo">Receitas da Ana</span>
  <nav>
    <a href="#">Início</a>
    <a href="#">Receitas</a>
    <a href="#">Sobre</a>
  </nav>
</header>

O logo fica à esquerda, os três links juntos à direita, tudo centralizado na altura da faixa. Com Grid daria para fazer, mas você teria de pensar em colunas que ninguém precisa.

3. Uma galeria de cartões: Grid

Cartões de receita em várias fileiras precisam ficar alinhados nas duas direções. É o caso típico do Grid. O Flexbox até parece funcionar, até chegar a última fileira:

Missão: a galeria usa Flexbox, e o quarto cartão, sozinho na última fileira, esticou até ocupar a largura toda. Troque o .galeria por uma grade com repeat(auto-fill, minmax(140px, 1fr)): o último cartão fica do tamanho dos outros, alinhado na primeira coluna. Pode apagar a regra do .galeria div que tem o flex.

<link rel="stylesheet" href="style.css">
<div class="galeria">
  <div class="cartao">Bolo</div>
  <div class="cartao">Pudim</div>
  <div class="cartao">Torta</div>
  <div class="cartao">Quindim</div>
</div>

.galeria {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

.galeria div {
  flex: 1 1 120px;
}

.cartao {
  background: #ede9fe;
  border: 2px solid #6d28d9;
  padding: 24px 12px;
}

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(140px, 1fr));
  gap: 8px;
}

.cartao {
  background: #ede9fe;
  border: 2px solid #6d28d9;
  padding: 24px 12px;
}

Por que o Flexbox estica o último: o flex: 1 1 120px diz a cada item "comece com 120px de conteúdo e cresça para ocupar a sobra da sua linha". Na última linha, o "Quindim" está sozinho, então a sobra toda é dele. O Flexbox não sabe que existem colunas, porque ele não tem colunas. O Grid tem.

4. O esqueleto da página: Grid

Topo, menu lateral, conteúdo e rodapé: duas dimensões, e você quer desenhar o layout antes do conteúdo chegar. É o terreno do Grid com áreas (aula Áreas com Nome). Com Flexbox, você precisaria de uma caixa flex dentro de outra (uma coluna com o topo, uma linha no meio, o rodapé), e mudar o layout no celular seria mexer no HTML.

5. Os dois juntos

A pergunta "Flexbox ou Grid?" é sobre cada caixa, e não sobre o site. O normal é o Grid organizar o esqueleto e o Flexbox arrumar o que vai dentro de cada parte. Um item de grade pode ser uma caixa flex, e vice-versa:

<style>
  .galeria {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(160px, 1fr));
    gap: 8px;
  }
  .cartao {
    display: flex;
    flex-direction: column;
    background: #ede9fe;
    border: 2px solid #6d28d9;
    padding: 12px;
  }
  .cartao h3 { margin: 0 0 4px; }
  .cartao p { margin: 0 0 8px; }
  .cartao a { margin-top: auto; }
</style>
<div class="galeria">
  <div class="cartao">
    <h3>Bolo</h3>
    <p>Fofinho, de cenoura com cobertura de chocolate.</p>
    <a href="#">Ver receita</a>
  </div>
  <div class="cartao">
    <h3>Pudim</h3>
    <p>De leite.</p>
    <a href="#">Ver receita</a>
  </div>
  <div class="cartao">
    <h3>Torta</h3>
    <p>De limão.</p>
    <a href="#">Ver receita</a>
  </div>
</div>
.galeria { display: grid }
O Grid põe os cartões em colunas alinhadas, todos com a mesma altura na fileira (o stretch da aula Alinhando no Grid).
.cartao { display: flex; flex-direction: column }
Dentro de cada cartão, o Flexbox empilha o título, o texto e o link.
.cartao a { margin-top: auto }
A margem automática empurra o link para o fundo do cartão. Assim, os três "Ver receita" ficam na mesma altura, mesmo com textos de tamanhos diferentes.

No resultado, os três cartões têm a mesma altura (a do cartão do bolo, que tem o texto mais longo) e os três links "Ver receita" ficam alinhados lá embaixo.

6. Qual usar: a regra prática

SituaçãoUsePor quê
Itens numa linha só (menu, barra de botões, ícone + texto)FlexboxUma dimensão; cada item do tamanho do conteúdo
Etiquetas, palavras, botões que quebram a linhaFlexboxCada linha independente é o desejado
Empilhar coisas dentro de um cartão e empurrar uma para o fimFlexboxflex-direction: column + margin-top: auto
Cartões, fotos, produtos em fileiras e colunasGridDuas dimensões; colunas alinhadas, a última fileira não estica
O esqueleto da página (topo, lateral, conteúdo, rodapé)GridVocê desenha o layout; grid-template-areas muda tudo sem mexer no HTML
Formulário com rótulos à esquerda e campos alinhados à direitaGridDuas colunas que precisam ficar alinhadas de cima a baixo
Centralizar uma coisa sóQualquer umplace-items: center (Grid) ou justify-content + align-items (Flexbox): aula Centralizando

Resumo da regra: se você pensa em "linha" ou em "fila", Flexbox; se pensa em "tabela" ou em "colunas alinhadas", Grid. E quando estiver na dúvida, comece com o que você acha mais simples de ler: os dois funcionam em todos os navegadores atuais.

Quando dá errado

O erro mais comum é usar uma propriedade de um no outro. Como as declarações são válidas, o validador W3C não reclama, e o F12 não as risca: elas só não fazem nada naquele elemento.

grid-template-columns numa caixa flex 
.galeria {
  display: flex;
  grid-template-columns: 1fr 1fr 1fr;
}

O que você vê: os itens ficam lado a lado, cada um do tamanho do conteúdo, como em qualquer caixa flex. Nada de três colunas iguais.

Por quê: grid-template-columns só vale com display: grid. O display é que decide qual das duas ferramentas a caixa usa.

flex-wrap e flex-grow numa grade

O que você vê: com display: grid, um flex-wrap: wrap no pai ou um flex: 1 nos itens não mudam nada.

Por quê: numa grade, quem quebra a linha é o número de colunas, e quem decide a largura dos itens é a coluna. Para "quantas couberem", use repeat(auto-fill, …) (aula repeat, minmax e auto-fit).

O que vale nos dois

Algumas propriedades funcionam nas duas ferramentas, com o mesmo sentido: gap, justify-content, align-items, align-self, align-content e order. Já justify-items e justify-self são só do Grid: numa caixa flex, são ignoradas.

Forçar colunas com Flexbox

O que você vê: para ter três colunas com Flexbox, a Ana escreveu width: 33.33% em cada item, com flex-wrap: wrap e gap: 8px. O terceiro item caiu para a linha de baixo.

Por quê: três vezes 33,33% já dá a largura toda, e os dois gap de 8px não cabem. Com Flexbox, colunas exigem contas (calc((100% - 16px) / 3)); com Grid, é repeat(3, 1fr), e o gap é descontado sozinho. Se a conta está ficando difícil, provavelmente o caso é de Grid.

Resumo

  • Flexbox: uma direção por vez; o conteúdo manda no tamanho; cada linha quebrada é independente. Bom para menus, barras, etiquetas e para arrumar o que vai dentro de um cartão.
  • Grid: linhas e colunas ao mesmo tempo; o layout manda; os itens ficam alinhados nas colunas. Bom para galerias, formulários alinhados e o esqueleto da página.
  • A escolha é por caixa: o normal é Grid no esqueleto e Flexbox dentro das partes, um dentro do outro.
  • Propriedade de um no outro (grid-template-columns em flex, flex-wrap em grid, justify-items em flex) não dá erro: só não faz nada. Quem decide é o display.
  • gap, justify-content, align-items e align-self valem nos dois.
