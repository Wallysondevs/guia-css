CSS Cursor e Interação

A setinha do mouse conversa com quem usa o site: vira mãozinha em cima de um link, vira um "I" em cima de um texto, vira uma mão aberta num mapa que dá para arrastar. Nesta aula você vai escolher o cursor certo para cada coisa na lojinha da Ana e conhecer duas propriedades vizinhas: pointer-events, que deixa o clique "atravessar" um elemento, e user-select, que controla o que dá para selecionar com o mouse.

Você vai aprender
  • cursor e os valores mais usados, lado a lado.
  • Quando usar cada cursor (e quando não mudar o cursor).
  • Cursor com imagem própria: url() e o valor reserva obrigatório.
  • pointer-events: none: o clique passa para o que está embaixo.
  • user-select: impedir a seleção ou selecionar tudo de uma vez.
  • Os erros comuns e as mensagens do validador W3C.

Esta aula é feita para o mouse: no celular não há cursor. Se estiver num, os exemplos de cursor não vão mostrar diferença; o resto (pointer-events e user-select) funciona com o dedo também.

A ideia: as placas da loja

Numa loja física, pequenos sinais dizem o que dá para fazer: "empurre" na porta, "não toque" na vitrine, uma setinha apontando para o caixa. O cursor é a placa do mouse: ele muda de forma para dizer "isto é clicável", "aqui dá para escrever", "isto dá para arrastar", "isto não está disponível". Placas certas ajudam; placas erradas (um "empurre" numa porta de puxar) confundem.

1. A propriedade cursor

.mapa {
  cursor: grab;
}
cursor
"Cursor": a forma da seta do mouse quando ela passa em cima do elemento.
grab
"Agarrar": uma mão aberta, o sinal de "dá para arrastar".

Passe o mouse em cada caixa abaixo. Cada uma tem um valor de cursor, escrito dentro dela. O desenho exato de cada cursor muda de sistema para sistema (Windows, macOS, Linux), mas a ideia é a mesma em todos:

<link rel="stylesheet" href="style.css">
<div class="vitrine">
  <div style="cursor: auto">auto</div>
  <div style="cursor: default">default</div>
  <div style="cursor: pointer">pointer</div>
  <div style="cursor: text">text</div>
  <div style="cursor: help">help</div>
  <div style="cursor: wait">wait</div>
  <div style="cursor: progress">progress</div>
  <div style="cursor: not-allowed">not-allowed</div>
  <div style="cursor: grab">grab</div>
  <div style="cursor: grabbing">grabbing</div>
  <div style="cursor: move">move</div>
  <div style="cursor: crosshair">crosshair</div>
  <div style="cursor: zoom-in">zoom-in</div>
  <div style="cursor: zoom-out">zoom-out</div>
  <div style="cursor: col-resize">col-resize</div>
  <div style="cursor: none">none</div>
</div>

Aqui o style="…" no HTML (aula Três Jeitos de Usar CSS) serve só para cada caixa mostrar o próprio valor de um jeito compacto. No site de verdade, use classes no style.css.

Não mude o cursor à toa

A mãozinha diz "isto é clicável". Se você puser cursor: pointer num texto comum, a pessoa vai clicar e nada vai acontecer. E se tirar a mãozinha de um link (cursor: default), ela não vai saber que pode clicar. O cursor tem de dizer a verdade sobre o elemento.

Missão: ponha o cursor certo em cada parte da página: grab no mapa (dá para arrastar), help na abreviação "CEP" (mostra uma explicação) e not-allowed no botão desativado.

<link rel="stylesheet" href="style.css">

<p>Entregamos no seu <abbr class="ajuda" title="Código de Endereçamento Postal">CEP</abbr>.</p>
<button class="esgotado" type="button" disabled>Bolo de fubá: esgotado</button>

.mapa {
  max-width: 100%;
  height: auto;
}

.mapa {
  max-width: 100%;
  height: auto;
  cursor: grab;
}

.ajuda {
  cursor: help;
}

.esgotado {
  cursor: not-allowed;
}

2. Cursor com imagem: url()

Dá para usar uma imagem pequena como cursor. A regra tem três partes:

.bolo-surpresa {
  cursor: url("assets/midia/favicon-32.png") 16 16, pointer;
}
url("…")
O endereço da imagem. Use uma imagem pequena: 32×32 pixels é o tamanho seguro (o ícone de bolo da pasta de mídia tem exatamente isso).
16 16
Opcional: o "ponto quente", onde fica a ponta do cursor, contado a partir do canto de cima, à esquerda da imagem. 16 16 é o meio de uma imagem de 32. Sem ele, a ponta é o canto 0 0.
, pointer
Obrigatório: depois da vírgula, um cursor comum de reserva, usado se a imagem não carregar. Sem ele, a declaração inteira é inválida (veja Quando dá errado).

Experimente: passe o mouse sobre a caixa. Depois troque o 16 16 por 0 0 e veja onde fica a "ponta" do cursor.

<link rel="stylesheet" href="style.css">
<p class="bolo-surpresa">Passe o mouse aqui: hoje tem bolo surpresa!</p>

.bolo-surpresa {
  padding: 40px 16px;
  background-color: oldlace;
  cursor: url("assets/midia/favicon-32.png") 16 16, pointer;
}

Use com moderação: cursores enfeitados ficam engraçados num jogo ou numa página de festa, mas atrapalham num site de uso diário.

3. pointer-events: none: o clique atravessa

Às vezes um elemento decorativo fica por cima de outro, e "rouba" o clique. A lojinha tem um selo "Novo!" posicionado em cima do botão "Ver cardápio" (com position: absolute). Clique em cima do selo:

<link rel="stylesheet" href="style.css">
<div class="destaque">
  <a class="botao" href="cardapio.html">Ver cardápio</a>
  <span class="selo">Novo!</span>
</div>

<h1>Cardápio</h1>
<p>Você chegou! O clique passou pelo selo.</p>
<p><a href="index.html">Voltar</a></p>

.destaque {
  position: relative;
  display: inline-block;
  margin: 24px;
  font-family: sans-serif;
}

.botao {
  display: inline-block;
  padding: 16px 32px;
  background-color: #c2410c;
  color: white;
  text-decoration: none;
  border-radius: 8px;
}

.selo {
  position: absolute;
  top: -8px;
  right: 8px;
  padding: 8px 12px;
  background-color: gold;
  border-radius: 999px;
  /* pointer-events: none; */
}

Clicando no meio do selo amarelo, que cobre um pedaço do texto do botão, nada acontece: quem recebe o clique é o selo, que não é um link. Agora apague o /* e o */ da última linha do CSS (aula Comentários) e clique de novo no meio do selo: o clique atravessa o selo e chega ao link, e o quadro abre a página do cardápio (o botão ↻ volta).

pointer-events
"Eventos do ponteiro": se o elemento pode ser o alvo do mouse (clique, :hover, cursor) e do toque.
none
"Nenhum": o elemento fica "transparente" para o mouse. O clique e o :hover vão para o que está embaixo dele.
auto
O padrão: o elemento recebe o mouse normalmente.
pointer-events: none não desativa nada de verdade

Ele só vale para o mouse e o toque. Um link com pointer-events: none não responde ao clique, mas continua recebendo o foco do Tab, e o Enter abre o link normalmente (conferido no Chromium). O leitor de tela também continua anunciando o link. Para desativar um botão, use o atributo disabled do HTML; para um link que não deve funcionar, tire o href. E lembre que pointer-events é herdado: com none num pai, os filhos também deixam de receber cliques (a não ser que você ponha pointer-events: auto neles).

4. user-select: o que dá para selecionar

Normalmente, você arrasta o mouse sobre um texto e ele fica selecionado, pronto para copiar. user-select muda isso:

ValorO que fazQuando usar
autoO padrão: o texto se seleciona normalmenteQuase sempre
noneO texto não pode ser selecionadoRótulos de controles que a pessoa clica muitas vezes seguidas (as setas de um carrossel), para não selecionar o texto sem querer
allUm clique seleciona o elemento inteiroCoisas que a pessoa vai copiar inteiras: um código de cupom, uma chave Pix, um comando
textPode selecionar, mesmo que o pai tenha noneLiberar um pedaço dentro de uma área com none

Experimente: dê um clique no código do cupom: ele é selecionado inteiro, pronto para o Ctrl+C. Depois tente selecionar o texto "Toque para ver o próximo bolo": não dá.

<link rel="stylesheet" href="style.css">
<p>Use o cupom <code class="cupom">BOLO10</code> e ganhe 10% de desconto.</p>
<p class="controle">Toque para ver o próximo bolo ›</p>

.cupom {
  padding: 4px 8px;
  background-color: lightyellow;
  border: 1px dashed orange;
  -webkit-user-select: all;
  user-select: all;
}

.controle {
  -webkit-user-select: none;
  user-select: none;
}
Suporte: o Safari ainda pede o prefixo

O MDN marca user-select como "disponibilidade limitada": o Chrome, o Edge e o Firefox entendem a propriedade normal, mas o Safari (no Mac e no iPhone) precisa da versão com prefixo, -webkit-user-select. Por isso os exemplos escrevem as duas, primeiro a com prefixo. É um dos poucos casos em que o prefixo -webkit- ainda é necessário hoje.

Não bloqueie a seleção do conteúdo

user-select: none num texto de verdade (uma receita, um artigo) só atrapalha: quem quer copiar um ingrediente, traduzir uma palavra ou usar uma ferramenta de leitura não consegue. E não protege nada: o texto continua no código da página (F12) e o leitor pode desligar o CSS.

Quando dá errado

Cursor com imagem, sem a reserva: a declaração inteira some 
.bolo-surpresa {
  cursor: url("assets/midia/favicon-32.png");
}

O que você vê: o cursor continua o normal. O valor calculado de cursor fica auto (conferido no Chromium): a declaração foi ignorada.

Por quê: depois do url(), um cursor comum de reserva é obrigatório. Sem ele, o valor é inválido. O validador mostra a mesma coisa (linha 14 do arquivo abaixo).

Como consertar: cursor: url("assets/midia/favicon-32.png"), pointer;

Valores que não existem 
.cupom {
  user-select: all;
}

  pointer-events: none;
}

O que significa: as linhas de 1 a 12 estão certas e não aparecem. Cada erro diz "X não é um valor de propriedade":

  • Linha 14: o url() sem a reserva, o caso acima.
  • Linha 15: hand era um valor do antigo Internet Explorer; o certo é pointer.
  • Linha 16: os valores são em inglês, sempre: mao não existe.
  • Linha 17: para desligar, é none, e não off.
  • Linha 18: o mesmo, none, e não nenhum.

No navegador, cada uma dessas declarações é ignorada em silêncio; no F12, ela aparece riscada.

pointer-events: none no pai: nada lá dentro funciona 
.cartao {
  pointer-events: none;
}

O que você vê: o link e o botão dentro do cartão não respondem ao clique nem ao :hover.

Por quê: pointer-events é herdado: os filhos ficam com none também (conferido no Chromium, o link dentro do pai calcula none).

Como consertar: ponha o none só no elemento decorativo, ou devolva pointer-events: auto aos filhos que precisam do clique.

Resumo

  • cursor muda a forma da seta em cima do elemento: pointer (clicável), text, not-allowed, grab/grabbing, help, wait, zoom-in… O desenho exato depende do sistema.
  • O cursor tem de dizer a verdade: mãozinha só no que é clicável.
  • Cursor com imagem: url("…") x y, reserva. Sem a reserva, a declaração é ignorada.
  • pointer-events: none deixa o mouse atravessar o elemento (bom para enfeites). Não desativa o teclado e é herdado.
  • user-select: none impede a seleção; all seleciona tudo com um clique. O Safari pede -webkit-user-select. Não bloqueie a seleção do conteúdo.
  • Valores em português (mao, nenhum) ou antigos (hand) são ignorados; o validador diz "is not a … value".
