CSS Transparência (opacity e alfa)

Uma foto apagadinha para um produto esgotado, uma faixa escura por cima de uma imagem, um botão desativado: tudo isso é transparência. O CSS tem dois jeitos de fazer, e eles parecem iguais até você pôr texto dentro. A propriedade opacity deixa o elemento inteiro transparente; o alfa de uma cor (rgb(0 0 0 / 60%)) deixa transparente só aquela cor. Nesta aula você vê os dois lado a lado e aprende quando usar cada um.

Você vai aprender
  • A propriedade opacity, de 0 (invisível) a 1 (normal).
  • A diferença entre opacity e o alfa de uma cor, desenhada lado a lado.
  • Que um elemento com opacity: 0 continua lá: ocupa espaço e pode ser clicado.
  • Por que um filho não consegue ser "menos transparente" que o pai.
  • As quatro formas de escrever uma cor com alfa.
  • Os erros, inclusive dois que nem o validador pega: 0,5 com vírgula e 50 sem %.

Antes, é bom ter feito rgb(). Os quadros "Resultado" e as caixas "Experimente" são desenhados agora pelo seu navegador, com as imagens de exemplo do guia. As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: o vidro e a película

Pense numa vitrine. A opacity é como trocar o vidro inteiro por um vidro fosco: tudo o que está atrás dele e tudo o que está pintado nele (o nome da loja, os adesivos) fica igualmente apagado. O alfa de uma cor é como colar uma película escura só no fundo do vidro: o fundo fica transparente, mas as letras pintadas por cima continuam firmes.

1. opacity: o elemento inteiro

A propriedade opacity ("opacidade", o contrário de transparência) recebe um número de 0 a 1:

opacity
A propriedade. Vale para o elemento inteiro: o fundo, a borda, o texto, as imagens e tudo o que estiver dentro dele.
1
Totalmente opaco: o normal, o valor que todo elemento já tem.
0.5
Meio transparente: metade do que está atrás aparece. Escreva com ponto, como no inglês. .5 (sem o zero) também vale.
0
Totalmente transparente: invisível (mas continua lá, veja a seção 3).

As quatro fotos abaixo são o mesmo arquivo. Da esquerda para a direita: opacity 1, 0.75, 0.5 e 0.25:

<style>
  .o100 { opacity: 1; }
  .o75 { opacity: 0.75; }
  .o50 { opacity: 0.5; }
  .o25 { opacity: 0.25; }
</style>
<img class="o100" src="assets/midia/bolo-400.jpg" alt="Bolo, opacity 1" width="128" height="96">
<img class="o75" src="assets/midia/bolo-400.jpg" alt="Bolo, opacity 0.75" width="128" height="96">
<img class="o50" src="assets/midia/bolo-400.jpg" alt="Bolo, opacity 0.5" width="128" height="96">
<img class="o25" src="assets/midia/bolo-400.jpg" alt="Bolo, opacity 0.25" width="128" height="96">

Quanto menor o número, mais a foto "desbota": o fundo branco da página aparece através dela. Com 0.25, o bolo vira quase uma marca-d'água.

Também em porcentagem

opacity: 50% é o mesmo que opacity: 0.5. Nos dois casos, o navegador guarda o número 0.5 (é o que aparece no F12, aba Computed).

Suporte

A opacity com número funciona em qualquer navegador. Com porcentagem, desde o Chrome e o Edge 78, o Firefox 70 e o Safari 13.1 (2019–2020): todos os atuais. O guia usa o número, que é o mais comum.

Missão: a torta de limão esgotou. Deixe a foto dela (classe esgotado) com opacity de 0.4, para o cliente perceber de longe.

  color: hsl(12 73% 45%);
}

h1 {

}

.esgotado {
  opacity: 0.4;
}

2. opacity × alfa da cor: lado a lado

Agora a diferença que importa. As duas caixas brancas abaixo estão sobre um fundo laranja e querem ser "meio transparentes". A de cima usa opacity: 0.5; a de baixo usa só um fundo com alfa, rgb(255 255 255 / 50%):

<style>
  .cartaz {
    background-color: hsl(12 73% 45%);
    padding: 12px;
  }
  .caixa {
    padding: 10px;
    margin: 8px 0;
  }
  .com-opacity {
    background-color: white;
    opacity: 0.5;
  }
  .com-alfa {
    background-color: rgb(255 255 255 / 50%);
  }
</style>
<div class="cartaz">
  <p class="caixa com-opacity"><strong>opacity: 0.5</strong>: o fundo e o texto ficaram transparentes.</p>
  <p class="caixa com-alfa"><strong>rgb(255 255 255 / 50%)</strong>: só o fundo; o texto continua firme.</p>
</div>

Os dois fundos ficaram iguais, um branco meio laranja. Mas compare o texto: na primeira caixa, ele também desbotou: o preto virou um marrom-avermelhado, misturado com o laranja que está atrás. Na segunda, continua preto e nítido. A regra:

Você quer…UseExemplo
Apagar o elemento inteiro (foto esgotada, botão desativado, um efeito de aparecer/sumir)opacityopacity: 0.4;
Um fundo transparente com o texto nítido (faixa sobre foto, cartão sobre fundo colorido)alfa na cor do fundobackground-color: rgb(0 0 0 / 60%);
Só o texto mais suavealfa na cor do texto (com cuidado com o contraste)color: rgb(0 0 0 / 70%);
Só a borda transparentealfa na cor da bordaborder-color: rgb(0 0 0 / 20%);

As quatro dão o mesmo valor calculado, rgba(0, 0, 0, 0.6). E a palavra transparent (aula Cores por Nome) é a cor com alfa zero: rgba(0, 0, 0, 0).

3. opacity: 0 não é "sumir"

Um elemento com opacity: 0 fica invisível, mas continua na página: ocupa o lugar dele e pode até receber cliques. Veja o buraco no meio da lista:

<style>
  .invisivel { opacity: 0; }
</style>
<p>1. Bolo de cenoura</p>
<p class="invisivel">2. Torta de limão</p>
<p>3. Pudim</p>

O item 2 não aparece, mas o espaço dele ficou ali, entre o 1 e o 3. E o texto continua no HTML: se você selecionar as linhas com o mouse, ele vem junto. Para tirar um elemento de verdade, há outras propriedades (display: none), na aula Escondendo. A opacity: 0 é útil quando o elemento vai aparecer aos poucos (aula Transições).

4. O filho não escapa da transparência do pai

A opacity do pai é aplicada ao grupo inteiro, já desenhado: o filho pode pedir opacity: 1, mas continua dentro do "vidro fosco" do pai.

<style>
  .cartao {
    opacity: 0.4;
    border: 2px solid navy;
    padding: 8px;
  }
  .cartao strong {
    opacity: 1; /* não adianta */
    color: crimson;
  }
</style>
<div class="cartao">
  <p>Cartão meio apagado com um <strong>aviso importante</strong> dentro.</p>
</div>

O "aviso importante" saiu tão apagado quanto o resto do cartão. Se o fundo do cartão deve ser transparente e o conteúdo, não, a resposta é a mesma da seção 2: use alfa na cor do fundo, e não opacity.

E os números se multiplicam: um filho com opacity: 0.5 dentro de um pai com 0.5 aparece com um quarto da força (0,5 × 0,5 = 0,25).

5. Transparência e contraste

Toda transparência deixa o fundo "vazar", e isso reduz o contraste. Um texto preto com opacity: 0.3 vira, na prática, um cinza-claro sobre o branco: bonito no "design", ilegível para muita gente. Use opacity baixa só em coisas que não precisam ser lidas (uma foto de fundo, um produto esgotado que também tem a palavra "esgotado" escrita). A aula CSS e Acessibilidade mostra como medir.

Experimente: mude o 0.5 da opacity e o 50% do alfa. Repare que, no primeiro parágrafo, o texto desbota junto; no segundo, não.

<link rel="stylesheet" href="style.css">
<div class="cartaz">
  <p class="um">Com opacity</p>
  <p class="dois">Com alfa no fundo</p>
</div>

.cartaz {
  background-color: navy;
  padding: 10px;
}

.um {
  background-color: white;
  opacity: 0.5;
}

.dois {
  background-color: rgb(255 255 255 / 50%);
}

Quando dá errado

Aqui o "quando dá errado" tem uma pegadinha: dois dos erros mais comuns passam no validador. As quatro fotos abaixo queriam ficar meio transparentes (0.5):

<style>
  .a { opacity: 0,5; }
  .b { opacity: 50; }
  .c { opacity: 50 %; }
  .d { opacity: transparent; }
</style>
<img class="a" src="assets/midia/bolo-400.jpg" alt="opacity: 0,5" width="128" height="96">
<img class="b" src="assets/midia/bolo-400.jpg" alt="opacity: 50" width="128" height="96">
<img class="c" src="assets/midia/bolo-400.jpg" alt="opacity: 50 %" width="128" height="96">
<img class="d" src="assets/midia/bolo-400.jpg" alt="opacity: transparent" width="128" height="96">

As quatro fotos ficaram totalmente opacas: nenhuma transparência funcionou.

Nenhuma mensagem: opacity: 0,5; (vírgula no lugar do ponto)

O que aconteceu: no Brasil escrevemos "zero vírgula cinco"; no CSS, como no inglês, o decimal é com ponto. O navegador não entende 0,5 como número e ignora a declaração. E o validador, desta vez, não acusa nada:

$ vnu --css virgula.css
$

Nenhuma linha de resposta: para o validador, o arquivo está certo. É um bom lembrete de que o validador não pega tudo. Quando algo não funciona, abra o F12: no painel de estilos, a declaração aparece riscada.

Como consertar: opacity: 0.5;, com ponto.

Nenhuma mensagem: opacity: 50; (pensando em porcentagem)

O que aconteceu: a Ana queria 50% e escreveu só 50. Para o CSS, 50 é um número válido, mas acima de 1; o navegador o corta em 1: totalmente opaco. Não é erro, então nem o navegador nem o validador reclamam:

$ cat certos.css
.a { opacity: 0.5; }
.b { opacity: .5; }
.c { opacity: 50%; }
.d { opacity: 1.5; }
.e { opacity: 50; }
$ vnu --css certos.css
$

As cinco linhas passam. No F12, aba Computed, a última aparece como opacity: 1, e esse é o jeito de descobrir.

Como consertar: opacity: 0.5; ou opacity: 50%;, com o %.

error: CSS: Parse Error.

O que aconteceu: um espaço entre o número e o %: opacity: 50 %;.

$ vnu --css espaco.css
"file:/home/ana/opacity/espaco.css":2.17-2.17: error: CSS: Parse Error.
"file:/home/ana/opacity/espaco.css":3.2-4.1: error: CSS: Parse Error.

"Erro de leitura" na coluna 17, o % solto. Número e unidade (%, px, rem) andam sempre colados.

Como consertar: opacity: 50%;.

error: CSS: “opacity”: “transparent” is not a “opacity” value.

O que aconteceu: opacity: transparent;. O transparent é uma cor; a opacity quer um número.

$ vnu --css palavra.css
"file:/home/ana/opacity/palavra.css":2.12-2.22: error: CSS: “opacity”: “transparent” is not a “opacity” value.

Como consertar: opacity: 0; para invisível, ou background-color: transparent; se a ideia era um fundo transparente.

Código antigo: filter: alpha(opacity=50);

O que aconteceu: você copiou de um tutorial muito velho. Esse era o jeito do Internet Explorer 8 e anteriores, antes de ele entender opacity. Os navegadores atuais ignoram essa linha (e o validador, curiosamente, não reclama).

Como consertar: apague a linha e use opacity: 0.5;.

Resumo

  • opacity vai de 0 (invisível) a 1 (normal) e vale para o elemento inteiro: fundo, borda, texto e filhos. Decimal com ponto; 50% também vale.
  • O alfa de uma cor (rgb(0 0 0 / 60%), hsl(… / 60%), #00000099) deixa transparente só aquela cor: é o certo para um fundo transparente com texto nítido.
  • opacity: 0 esconde, mas o elemento ocupa espaço e recebe cliques.
  • O filho não escapa da opacity do pai; as opacidades se multiplicam.
  • Transparência reduz o contraste: cuidado com texto.
  • 0,5 com vírgula e 50 sem % passam no validador, mas não funcionam como você queria. 50 % e transparent o validador acusa.
