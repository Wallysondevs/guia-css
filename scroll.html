CSS Rolagem Suave e scroll-snap

Quando o leitor clica em "Modo de preparo" no sumário da receita, a página pula de uma vez para o título, e ele perde a noção de onde está. Num carrossel de fotos, a rolagem para no meio de uma foto, cortada ao meio. O CSS resolve as duas coisas sem nenhuma linha de JavaScript: a rolagem pode deslizar até o destino, e um contêiner pode encaixar cada item no lugar certo, como as fotos de um álbum. Nesta aula você vai fazer as duas coisas no site da Ana.

Você vai aprender
  • scroll-behavior: smooth: a rolagem que desliza até a âncora, e onde ele precisa ficar (no html, não no body).
  • Como respeitar quem pediu menos movimento, com prefers-reduced-motion.
  • scroll-margin-top e scroll-padding-top: o cabeçalho fixo que não cobre mais o título.
  • scroll-snap-type e scroll-snap-align: um carrossel que para certinho em cada foto.
  • mandatory × proximity, e scroll-snap-stop.
  • Por que um scroll-snap "não faz nada", e as mensagens reais do validador W3C.

Os resultados desta aula são desenhados pelo seu navegador: clique nos links e role os carrosséis com o mouse, o dedo ou as setas do teclado. As mensagens de erro são do validador W3C (vnu) rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: o elevador e a gaveta com trava

Duas comparações do dia a dia:

  • Rolagem suave é a diferença entre um teletransporte e um elevador com porta de vidro. Os dois levam você ao 8º andar, mas no elevador você vê os andares passando e sabe que subiu. Na página, o leitor vê o texto passar e entende que desceu até o "Modo de preparo".
  • scroll-snap ("encaixe da rolagem") é a gaveta com trava: você empurra de qualquer jeito e ela para fechada ou aberta, nunca pela metade. O carrossel para sempre com uma foto inteira à mostra.

1. Rolagem suave: scroll-behavior: smooth

A receita da Ana tem um sumário no topo com links para as partes da própria página (as âncoras do Guia HTML, Âncoras na Mesma Página). Sem CSS, o clique faz a página pular. Uma declaração no html faz ela deslizar:

html {
  scroll-behavior: smooth;
}
html
O seletor. Quem rola a página inteira é a janela, e o CSS fala com ela pelo elemento raiz, o html. Não serve o body (veja Quando dá errado).
scroll-behavior
"Comportamento da rolagem". Vale para a rolagem que o site provoca: o clique num link #ingredientes, ou um JavaScript que manda rolar. A rodinha do mouse, o dedo e a barra de rolagem continuam como o leitor está acostumado.
smooth
"Suave": o navegador anima a rolagem até o destino, em uma fração de segundo. O valor padrão é auto, o pulo imediato.

Experimente: clique em "Modo de preparo" e em "Voltar ao topo": a página desliza. Agora troque smooth por auto na aba style.css e clique de novo: ela pula.

<link rel="stylesheet" href="style.css">
<h1 id="topo">Bolo de cenoura</h1>
<nav>
  <a href="#ingredientes">Ingredientes</a> ·
  <a href="#preparo">Modo de preparo</a>
</nav>
<section id="ingredientes">
  <h2>Ingredientes</h2>
  <p>3 cenouras, 3 ovos, 1 xícara de óleo, 2 xícaras de açúcar, 2 xícaras de farinha.</p>
</section>
<section id="preparo">
  <h2>Modo de preparo</h2>
  <p>Bata no liquidificador as cenouras, os ovos e o óleo. Misture o açúcar e a farinha e asse por 40 minutos.</p>
  <p><a href="#topo">Voltar ao topo</a></p>

html {
  scroll-behavior: smooth;
}

section {
  min-height: 400px;
  border-top: 2px solid tomato;
}

O min-height: 400px nas seções só existe para a página ficar comprida e ter o que rolar. Numa receita de verdade, o próprio texto faz isso.

Quem pediu menos movimento

Para algumas pessoas (com labirintite, enxaqueca, alguns tipos de epilepsia), a tela deslizando sozinha causa enjoo de verdade. Os sistemas operacionais têm uma opção "reduzir movimento", e o CSS consegue lê-la com a consulta prefers-reduced-motion (aula Respeitando Quem Prefere Menos Movimento). O jeito recomendado de ligar a rolagem suave é só para quem não pediu menos movimento:

@media (prefers-reduced-motion: no-preference) {
  html {
    scroll-behavior: smooth;
  }
}
@media (…)
Uma media query: as regras de dentro só valem quando a condição é verdadeira (aula Media Queries).
prefers-reduced-motion
"Prefere movimento reduzido": a opção de acessibilidade do sistema.
no-preference
"Sem preferência": a pessoa não ligou a opção. Só nesse caso a rolagem desliza; para quem ligou, ela continua pulando, sem animação.

No Chromium, com a opção desligada, o html fica com scroll-behavior: smooth. Com a opção ligada (simulada no F12, na aba Rendering), fica auto. Os dois valores foram conferidos com o estilo calculado.

Missão: a lista de compras da Ana é comprida e o link "Laticínios" pula de uma vez. Faça a página deslizar, mas só para quem não pediu menos movimento (use @media (prefers-reduced-motion: no-preference)). Teste clicando no link.

2. O cabeçalho que cobre o título: scroll-margin-top

Muitos sites têm um cabeçalho que fica grudado no topo enquanto a página rola (position: sticky, aula position: sticky). O problema: quando o link leva ao título, o navegador põe o título colado no topo da janela, exatamente atrás do cabeçalho. O leitor chega e não vê o título.

Experimente: clique em "Modo de preparo". O título "Modo de preparo" fica escondido atrás da faixa azul. Depois, apague o /* e o */ em volta da regra do h2 e clique de novo.

<link rel="stylesheet" href="style.css">
<header class="topo">
  Receitas da Ana ·
  <a href="#ingredientes">Ingredientes</a> ·
  <a href="#preparo">Modo de preparo</a>
</header>
<h2 id="ingredientes">Ingredientes</h2>
<p class="longo">3 cenouras, 3 ovos, 1 xícara de óleo.</p>
<h2 id="preparo">Modo de preparo</h2>
<p class="longo">Bata tudo e asse por 40 minutos.</p>

.topo {
  position: sticky;
  top: 0;
  padding: 16px;
  background-color: navy;
  color: white;
}

.topo a {
  color: white;
}

.longo {
  min-height: 500px;
}

/*
h2 {
  scroll-margin-top: 4rem;
}
*/
h2
O seletor aponta para os destinos dos links: os títulos com id.
scroll-margin-top
"Margem de rolagem em cima": quando o navegador rolar até este elemento, ele para essa distância antes. Não muda nada no desenho da página (não é uma margin de verdade); só muda onde a rolagem para.
4rem
64 px com a fonte padrão: um pouco mais que a altura do cabeçalho (16 px de preenchimento em cima e embaixo, mais a linha de texto). Use um valor que sobre um pouco, para o título não ficar encostado na faixa.

No Chromium, sem a regra, depois do clique o topo do título fica em 0 px do topo da janela, atrás do cabeçalho de 50 px. Com scroll-margin-top: 4rem, fica a 64 px, logo abaixo da faixa azul.

A outra forma: scroll-padding-top no html

Em vez de dar margem a cada destino, dá para dizer ao elemento que rola que o topo dele está "ocupado":

html {
  scroll-padding-top: 4rem;
}

O efeito é o mesmo: toda rolagem até uma âncora para 4rem abaixo do topo da janela. A diferença é onde a regra mora:

FormaVai emQuando usar
scroll-padding-topquem rola (html)O cabeçalho fixo vale para a página inteira: uma regra resolve todas as âncoras. É a escolha mais comum.
scroll-margin-topo destino (h2, [id]…)Só alguns destinos precisam de folga, ou cada um precisa de uma folga diferente (um título grande, uma figura).
Dica: use uma variável

Se a altura do cabeçalho aparece em dois lugares (no cabeçalho e no scroll-padding-top), guarde-a numa variável, como --altura-topo: 4rem (aula Variáveis). Mudou o cabeçalho, muda um número só.

3. O carrossel que encaixa: scroll-snap

A Ana quer mostrar as fotos dos bolos numa faixa que rola para o lado. Primeiro, a faixa sem encaixe: um contêiner com display: flex e overflow-x: auto (aula overflow).

Experimente: role a faixa para o lado (rodinha com Shift, arrastar a barra, deslizar o dedo ou as setas do teclado depois de clicar nela). Ela para em qualquer lugar, com fotos cortadas.

<link rel="stylesheet" href="style.css">
<div class="carrossel">
  <img src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura inteiro" width="400" height="300">
  <img src="assets/midia/bolo-quadrado-400.jpg" alt="Fatia quadrada do bolo" width="400" height="400">
  <img src="assets/midia/bolo-400.jpg" alt="Bolo de cenoura na mesa" width="400" height="300">
  <img src="assets/midia/bolo-quadrado-400.jpg" alt="Outra fatia do bolo" width="400" height="400">
</div>

.carrossel {
  display: flex;
  gap: 12px;
  overflow-x: auto;
}

.carrossel img {
  width: 80%;
  height: 200px;
  flex-shrink: 0;
  object-fit: cover;
}

Agora o encaixe. São duas declarações, uma no pai e uma nos filhos:

.carrossel {
  scroll-snap-type: x mandatory;
}

.carrossel img {
  scroll-snap-align: start;
}
scroll-snap-type
"Tipo de encaixe", no contêiner que rola. Liga o encaixe e diz em que direção e com que força.
x
A direção: x é a horizontal (para o lado), y a vertical, both as duas.
mandatory
"Obrigatório": quando o leitor solta, a rolagem sempre termina num ponto de encaixe. A outra opção é proximity ("proximidade"), que só encaixa se a rolagem parou perto de um ponto. Sem a palavra, vale proximity.
scroll-snap-align
"Alinhamento do encaixe", em cada filho: diz qual parte do filho encosta no contêiner.
start
O começo da foto (a borda esquerda) para encostado no começo do carrossel. Os outros valores são center (meio com meio) e end (fim com fim).

Os três valores de scroll-snap-align, lado a lado. Role cada faixa e repare onde cada item numerado para:

<style>
  .faixa {
    display: flex;
    gap: 12px;
    overflow-x: auto;
    scroll-snap-type: x mandatory;
    margin-bottom: 16px;
    border: 2px dashed #888;
  }
  .faixa div {
    flex: 0 0 60%;
    height: 70px;
    padding: 8px;
    background-color: #ffe0d6;
    font-family: sans-serif;
  }
  .start div { scroll-snap-align: start; }
  .center div { scroll-snap-align: center; }
  .end div { scroll-snap-align: end; }
</style>
<p>start: o item encosta à esquerda</p>
<div class="faixa start"><div>1</div><div>2</div><div>3</div><div>4</div></div>
<p>center: o item fica no meio, com um pedaço dos vizinhos</p>
<div class="faixa center"><div>1</div><div>2</div><div>3</div><div>4</div></div>
<p>end: o item encosta à direita</p>
<div class="faixa end"><div>1</div><div>2</div><div>3</div><div>4</div></div>

Repare que o center é o que mais "parece carrossel": o pedaço da próxima foto aparecendo na borda é um convite para rolar. O start é o mais comum em listas de cartões.

mandatory × proximity

ValorO que fazQuando usar
x mandatorySempre termina num encaixe.Carrossel de fotos, galeria em que cada item ocupa quase toda a largura.
x proximity (ou só x)Encaixa só quando a rolagem para perto de um ponto; longe, para onde o leitor deixou.Listas longas, em que o leitor precisa poder parar entre dois itens.
y mandatoryO mesmo, na vertical.Páginas em "telas", uma seção por vez. Cuidado: se uma seção for mais alta que a janela, o leitor pode ter dificuldade de ler o meio dela.

scroll-snap-stop: always: uma foto por vez

Com um movimento rápido (um "peteleco" no celular), a rolagem pode passar por cima de várias fotos e encaixar lá na frente. Para obrigar a parada em cada foto:

.carrossel img {
  scroll-snap-align: start;
  scroll-snap-stop: always;
}

O padrão é normal (pode pular). Use always quando cada item precisa ser visto, como os passos de uma receita. Funciona em todos os navegadores atuais desde 2022 (MDN: Baseline, amplamente disponível).

Suporte

scroll-behavior e o scroll-snap funcionam no Chrome, Edge, Firefox e Safari atuais (o MDN marca Baseline, amplamente disponível: o scroll-behavior desde março de 2022). O MDN lembra que o navegador pode ignorar o scroll-behavior, por exemplo quando o sistema pede menos movimento. Num navegador antigo, nada quebra: a rolagem só pula e para em qualquer lugar.

Quando dá errado

scroll-behavior: smooth no body: a página continua pulando 
body {
  scroll-behavior: smooth;
}

O que o leitor vê: nada muda; o clique no link pula de uma vez. No Chromium, medindo a rolagem logo depois do clique, a página já estava no destino na primeira medida (sem passos intermediários). Com a mesma regra no html, a rolagem passou por várias posições no caminho.

Por quê: quem rola a página é a janela, e ela só obedece ao scroll-behavior do html. O MDN avisa: no body, ele não passa para a janela. No F12, o body mostra scroll-behavior: smooth na aba Computed, sem nada riscado: a declaração é válida, só está no elemento errado. O validador também não reclama.

Como consertar: html { scroll-behavior: smooth; }.

O encaixe "não faz nada": as propriedades trocadas de lugar 
.carrossel {
  display: flex;
  overflow-x: auto;
  scroll-snap-align: start;
}

.carrossel img {
  scroll-snap-type: x mandatory;
}

O que o leitor vê: a faixa rola, mas para em qualquer lugar, como se não houvesse encaixe.

Por quê: o scroll-snap-type só tem efeito no elemento que rola (o pai, com overflow-x: auto), e o scroll-snap-align só tem efeito nos filhos dele. Trocados, as duas declarações são válidas e nenhuma faz nada. O validador fica em silêncio.

Como consertar: scroll-snap-type no pai, scroll-snap-align nos filhos. A mesma coisa acontece se o pai não rolar: sem overflow-x: auto (ou com fotos que cabem todas na largura), não há rolagem, e não há o que encaixar.

Valor fora de ordem ou inventado: a declaração inteira é ignorada 
.carrossel {
  overflow-x: auto;
  scroll-snap-type: mandatory x;
}
.foto {
  scroll-snap-align: left;
}
html {
  scroll-behavior: suave;
}

$ vnu --css estilo.css
"file:/home/ana/site/estilo.css":3.31-3.31: error: CSS: “scroll-snap-type”: “mandatory” is not a “scroll-snap-type” value.
"file:/home/ana/site/estilo.css":6.22-6.25: error: CSS: “scroll-snap-align”: “left” is not a “scroll-snap-align” value.
"file:/home/ana/site/estilo.css":9.20-9.24: error: CSS: “scroll-behavior”: “suave” is not a “scroll-behavior” value.

O que significa: "mandatory não é um valor de scroll-snap-type" (a ordem é direção primeiro: x mandatory); "left não é um valor de scroll-snap-align" (são start, center, end, que também funcionam em sites escritos da direita para a esquerda); "suave não é um valor de scroll-behavior" (os valores do CSS são sempre em inglês).

O que o leitor vê: nada de encaixe nem de rolagem suave. O navegador joga fora cada declaração inválida: no Chromium, o estilo calculado ficou scroll-snap-type: none, scroll-snap-align: none e scroll-behavior: auto, os valores padrão. No F12, as três linhas aparecem riscadas, com um ícone de aviso.

Resumo

  • html { scroll-behavior: smooth; } faz os links da mesma página deslizarem em vez de pular. No body não funciona. Ponha dentro de @media (prefers-reduced-motion: no-preference).
  • O cabeçalho fixo cobre o título? scroll-padding-top no html (vale para todas as âncoras) ou scroll-margin-top no destino.
  • Carrossel que encaixa: scroll-snap-type: x mandatory no contêiner que rola, scroll-snap-align: start | center | end em cada filho.
  • mandatory sempre encaixa; proximity (o padrão) só quando para perto. scroll-snap-stop: always para em cada item.
  • Quando "não faz nada": a propriedade está no elemento errado (o validador não avisa), o pai não rola, ou o valor é inválido (mandatory x, left, suave), e aí o validador avisa e o F12 risca a linha.
