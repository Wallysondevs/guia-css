CSS Seletor de Classe (.)

O seletor de elemento (p, h1) pinta todos os parágrafos, todos os títulos. Mas quase sempre você quer escolher: só este parágrafo em destaque, só estes dois cartões em promoção. Para isso existe a classe: um nome que você cola nos elementos, no HTML, e depois chama no CSS com um ponto na frente. É o seletor que você mais vai usar na vida.

Você vai aprender
  • O atributo class no HTML e o seletor .nome no CSS: como um encontra o outro.
  • A mesma classe em vários elementos, e várias classes no mesmo elemento.
  • A diferença entre .destaque, p.destaque, .cartao.promocao e .cartao .promocao.
  • Como dar bons nomes às classes.
  • Os erros mais comuns: esquecer o ponto, pôr o ponto no HTML, maiúscula trocada, número no começo, vírgula no class.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: etiquetas coloridas

Pense numa estante de potes de tempero. A Ana quer marcar os potes que estão acabando. Ela não escreve "o terceiro pote da segunda prateleira": ela cola uma etiqueta vermelha em cada pote que está no fim. Depois, para fazer a lista de compras, basta procurar as etiquetas vermelhas.

A classe é essa etiqueta:

Na estanteNa página
Colar a etiqueta "acabando" no poteEscrever class="acabando" no elemento, no HTML
Uma etiqueta igual em vários potesA mesma classe em vários elementos
Um pote com duas etiquetas ("acabando" e "picante")Um elemento com duas classes: class="acabando picante"
"Procure todos os potes com a etiqueta vermelha"O seletor .acabando, no CSS

1. A primeira classe

São dois passos, um em cada arquivo. No HTML, você dá a classe ao elemento; no CSS, você escreve o nome da classe com um ponto na frente.

Experimente: só o parágrafo com class="destaque" ganhou o fundo amarelo e as letras vermelho-escuras. Os outros dois continuam normais. Troque o class="destaque" de lugar, para o primeiro parágrafo, e veja o destaque mudar junto.

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p>Bolo de cenoura com cobertura de chocolate.</p>
<p class="destaque">Receita nova toda sexta-feira!</p>
<p>Pão de queijo mineiro.</p>

.destaque {
  background-color: lightyellow;
  color: darkred;
  font-weight: bold;
}
class="destaque"
No HTML: o atributo class ("classe") cola a etiqueta destaque no parágrafo. Aqui o nome vai sem ponto. O atributo class não muda nada na aparência sozinho: ele só dá um nome.
.
No CSS: o ponto quer dizer "classe". Sem ele, o navegador procuraria um elemento <destaque>, que não existe.
destaque
O nome da classe, escrito igualzinho ao do HTML, letra por letra.
{ … }
As declarações, como em qualquer regra (aula Regras, Seletores e Declarações). Valem para todo elemento que tiver essa classe.

O nome é você quem inventa. O navegador não conhece nenhuma classe de antemão: destaque, aviso, cartao-receita, tanto faz. O que importa é que o nome no HTML e o nome no CSS sejam iguais.

2. A mesma classe em vários elementos

A grande vantagem da classe: você escreve o estilo uma vez e usa em quantos elementos quiser, até de tipos diferentes. Aqui, um título, um parágrafo e um item de lista usam a mesma classe:

<style>
  .destaque {
    background-color: lightyellow;
    color: darkred;
  }
</style>
<h2 class="destaque">Novidades da semana</h2>
<p>Esta semana tem <span class="destaque">bolo de fubá</span> e pão de mel.</p>
<ul>
  <li>Brigadeiro</li>
  <li class="destaque">Cocada (nova!)</li>
  <li>Quindim</li>
</ul>

Os três elementos com class="destaque" ficaram com fundo amarelo e letras vermelho-escuras. Repare que o fundo segue a forma de cada um: no <h2> e no <li>, que são blocos, o fundo ocupa a largura toda; no <span>, que fica em linha, só atrás das palavras "bolo de fubá" (aula display). O <span> é o elemento "sem significado" do HTML, feito justamente para receber uma classe no meio de uma frase.

Quer mudar o destaque do site inteiro? Troque lightyellow por outra cor uma vez, no CSS, e todos os elementos mudam juntos. Esse é o motivo de existir CSS separado.

3. Várias classes no mesmo elemento

Um elemento pode ter várias classes, separadas por espaço dentro do mesmo class. Cada classe traz o seu pedaço do estilo, e o elemento recebe tudo junto:

Experimente: os três cartões têm a classe cartao (borda e espaço interno). O do meio tem também promocao (fundo amarelo e borda vermelha). Acrescente promocao no terceiro cartão: class="cartao promocao".

<link rel="stylesheet" href="style.css">
<div class="cartao">Bolo de fubá</div>
<div class="cartao promocao">Bolo de cenoura</div>
<div class="cartao">Pão de mel</div>

.cartao {
  border: 2px solid gray;
  padding: 8px;
  margin-bottom: 8px;
}

.promocao {
  background-color: lightyellow;
  border-color: crimson;
}
class="cartao promocao"
Duas classes, separadas por um espaço. O elemento entra na regra .cartao e na regra .promocao.
a ordem no HTML
Não importa: class="promocao cartao" dá o mesmo resultado.
border-color: crimson
As duas regras falam da borda: .cartao diz cinza e .promocao diz vermelho. Ganha a que vem depois no CSS, e não a que vem depois no class. Esse "quem ganha" tem aula própria: A Cascata.

Esse é o jeito de montar variações sem repetir código: uma classe com a base (cartao) e outras pequenas com o que muda (promocao, esgotado, grande).

Missão: o CSS já tem a classe esgotado (letra cinza e riscada). O pão de queijo acabou: dê a classe esgotado ao item "Pão de queijo", e só a ele.

4. Elemento + classe: p.destaque

Você pode juntar um nome de elemento e uma classe, sem espaço: p.destaque quer dizer "um <p> que tenha a classe destaque". Um <h2 class="destaque"> não entra.

<style>
  .destaque {
    color: darkred;
  }
  p.destaque {
    background-color: lightyellow;
  }
</style>
<h2 class="destaque">Novidades</h2>
<p class="destaque">Receita nova toda sexta-feira!</p>

Os dois ficaram com letra vermelho-escura (regra .destaque), mas só o parágrafo ganhou o fundo amarelo (regra p.destaque). Na prática, use p.destaque pouco: se a classe só serve para parágrafos, .destaque já basta, e um seletor mais comprido fica mais difícil de vencer depois (aula Especificidade).

5. .cartao.promocao × .cartao .promocao

Um espaço muda tudo:

SeletorQuer dizer
.cartao.promocao (sem espaço)Um elemento que tem as duas classes ao mesmo tempo
.cartao .promocao (com espaço)Um elemento com a classe promocao que está dentro de outro, com a classe cartao

Experimente: o primeiro cartão tem as duas classes e ganhou o fundo amarelo (.cartao.promocao). No segundo, só a palavra "Promoção", que está dentro do cartão, ficou vermelha (.cartao .promocao). Tire o espaço do segundo seletor e veja a palavra perder a cor.

<link rel="stylesheet" href="style.css">
<div class="cartao promocao">Cartão com as duas classes</div>
<div class="cartao"><span class="promocao">Promoção</span> dentro de um cartão</div>

.cartao {
  border: 2px solid gray;
  padding: 8px;
  margin-bottom: 8px;
}

.cartao.promocao {
  background-color: lightyellow;
}

.cartao .promocao {
  color: crimson;
  font-weight: bold;
}

O seletor com espaço é um combinador, assunto da aula Descendente, Filho e Irmãos. Por enquanto, guarde: sem espaço = o mesmo elemento.

6. Como dar nome a uma classe

O CSS aceita quase qualquer nome, mas alguns ajudam e outros atrapalham:

RegraBomEvite
Diga o que é, e não a aparênciaaviso, preco, esgotadovermelho, letra-grande (e quando o aviso virar laranja?)
Letras minúsculas, palavras com hífencartao-receitaCartaoReceita, cartao_receita (funcionam, mas o guia usa o hífen)
Sem acento e sem espaçopreco, promocaopreço (funciona, mas é fácil digitar diferente); com espaço, vira duas classes
Comece com letracoluna-11coluna: o CSS não aceita (veja Quando dá errado)

E lembre: maiúscula e minúscula são diferentes. Destaque e destaque são duas classes.

Quando dá errado

No CSS, um seletor que não acha ninguém não dá erro: a regra simplesmente não pega em nada. O sintoma é sempre o mesmo, nada muda. Na aula Inspecionando com o F12 você aprende a clicar no elemento e ver quais regras chegaram nele: se a sua regra não aparece na lista, o seletor não casou.

Esqueceu o ponto no CSS 
<style>
  destaque {
    background-color: lightyellow;
  }
</style>
<p class="destaque">Receita nova toda sexta-feira!</p>

O que você vê: o parágrafo continua sem fundo.

Por quê: sem o ponto, destaque é um seletor de elemento: "todos os <destaque> da página". Não há nenhum.

O que o validador diz: nada. vnu --css aceita o arquivo sem nenhuma mensagem, porque o seletor é válido: ele só não acha ninguém.

Como consertar: .destaque.

Pôs o ponto no HTML 
<style>
  .destaque {
    background-color: lightyellow;
  }
</style>
<p class=".destaque">Receita nova toda sexta-feira!</p>

O que você vê: nada muda.

Por quê: o ponto é só do CSS. Com class=".destaque", o nome da classe passou a ser .destaque, com ponto e tudo, e o seletor .destaque procura a classe destaque, sem ponto. O validador de HTML também não reclama: qualquer texto vale como nome de classe.

Como consertar: no HTML, o nome puro: class="destaque".

Maiúscula trocada 
<style>
  .destaque {
    background-color: lightyellow;
  }
</style>
<p class="Destaque">Receita nova toda sexta-feira!</p>

O que você vê: nada muda.

Por quê: nomes de classe diferenciam maiúsculas de minúsculas. Destaque e destaque são etiquetas diferentes. Por isso a regra do guia: tudo minúsculo.

Classe começando com número 
<style>
  .1coluna {
    background-color: lightyellow;
  }
</style>
<p class="1coluna">Receita nova toda sexta-feira!</p>

O que você vê: nada muda, mesmo com o nome igual nos dois lados.

Por quê: no HTML, class="1coluna" é permitido. Mas no CSS um nome depois do ponto não pode começar com algarismo: o navegador lê .1coluna como um número com uma unidade estranha, o seletor fica inválido e a regra inteira é jogada fora. O validador avisa:

$ vnu --css numero.css
"file:/home/ana/site/numero.css":1.1-1.8: error: CSS: In CSS1, a class name could start with a digit (".55ft"), unless it was a dimension (".55in"). In CSS2, such classes are parsed as unknown dimensions (to allow for future additions of new units) To make “1coluna” a valid class, CSS2 requires the first digit to be escaped: “.\31 coluna”.

O que significa: "no CSS1, um nome de classe podia começar com algarismo; no CSS2, essas classes são lidas como dimensões desconhecidas (um número com unidade, como 1em). Para tornar 1coluna uma classe válida, o CSS2 exige que o primeiro algarismo seja escapado: .\31 coluna". O escape funciona, mas ninguém quer escrever isso.

Como consertar: comece o nome com letra: coluna-1, nos dois arquivos.

Espaço depois do ponto: Parse Error 
$ cat espaco.css
. destaque {
  color: red;
}
$ vnu --css espaco.css
"file:/home/ana/site/espaco.css":1.3-1.10: error: CSS: Parse Error.

O que significa: "erro de leitura" na linha 1, colunas 3 a 10 (a palavra destaque). O ponto e o nome têm de vir colados. Com o espaço, o seletor fica inválido e o navegador ignora a regra inteira, em silêncio.

Como consertar: .destaque, sem espaço.

Vírgula entre as classes no HTML 
<style>
  .cartao {
    border: 2px solid gray;
    padding: 8px;
  }
  .promocao {
    background-color: lightyellow;
  }
</style>
<div class="cartao, promocao">Bolo de cenoura</div>

O que você vê: o fundo amarelo apareceu, mas a borda cinza, não.

Por quê: no class, quem separa as classes é o espaço. Com a vírgula, as classes do elemento viraram cartao, (com a vírgula grudada) e promocao. A regra .cartao procura cartao, sem vírgula, e não acha. O validador de HTML não reclama.

Como consertar: class="cartao promocao", só com espaço. A vírgula é usada no CSS, para juntar seletores (aula Agrupando Seletores).

Resumo

  • A classe é uma etiqueta: no HTML, class="destaque" (sem ponto); no CSS, .destaque (com ponto). Os nomes têm de ser idênticos, maiúsculas incluídas.
  • A mesma classe serve para quantos elementos você quiser, de qualquer tipo. Um elemento pode ter várias classes, separadas por espaço.
  • p.destaque: só parágrafos com a classe. .cartao.promocao: as duas classes no mesmo elemento. .cartao .promocao: uma dentro da outra.
  • Nomes que dizem o que a coisa é (aviso, preco), em minúsculas, com hífen, começando com letra.
  • Quando dá errado, nada muda: falta de ponto no CSS, ponto no HTML, maiúscula trocada e vírgula no class passam em silêncio; número no começo e espaço depois do ponto o validador acusa.
  • Para estilo, a classe é a escolha padrão. O ID fica para a próxima aula.
