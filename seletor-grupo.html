CSS Agrupando Seletores (,)

A Ana quer os títulos <h1>, <h2> e <h3> do site com a mesma cor e a mesma fonte. Ela pode escrever três regras iguais, uma para cada título. Ou pode escrever uma regra só, com os três seletores separados por vírgula. Isso é um grupo de seletores: menos código repetido e um lugar só para mudar.

Você vai aprender
  • A vírgula no seletor: h1, h2, h3 { … }.
  • Misturar tipos de seletor no mesmo grupo: h1, .aviso, #topo.
  • O padrão "grupo com o que é comum, regra própria com o que muda".
  • A diferença entre vírgula, espaço e nada: h1, p × h1 p × p.destaque.
  • O perigo: um seletor inválido no grupo derruba a regra inteira.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: um recado para vários

A Ana manda no grupo da família: "Pedro, Júlia e Rafa: almoço às 13h". Um recado, três destinatários. Ela não precisa escrever três mensagens iguais. A vírgula no CSS é isso: "h1, h2 e h3: cor azul-ardósia".

1. Antes e depois

Sem agrupar, o CSS repete as mesmas declarações:

h1 {
  color: darkslateblue;
  font-family: Georgia, serif;
}

h2 {
  color: darkslateblue;
  font-family: Georgia, serif;
}

h3 {
  color: darkslateblue;
  font-family: Georgia, serif;
}

Agrupando, fica uma regra só, com o mesmo resultado:

Experimente: os três títulos ficaram azul-ardósia, e com a fonte Georgia, se o seu computador a tiver (fontes têm aula própria: font-family). O parágrafo não está no grupo e não mudou. Acrescente p ao grupo (h1, h2, h3, p) e veja o parágrafo entrar.

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<h2>Bolos</h2>
<h3>Bolo de fubá</h3>
<p>Fofinho, com erva-doce.</p>

h1, h2, h3 {
  color: darkslateblue;
  font-family: Georgia, serif;
}
h1, h2, h3

{ … }
As declarações valem para cada um dos seletores, como se você tivesse escrito uma regra para cada.

Para mudar a cor de todos os títulos do site, agora basta trocar um valor.

Missão: o CSS tem duas regras com a mesma declaração. Junte as duas numa regra só, com o grupo h2, .aviso, e mude a cor para darkred.

<link rel="stylesheet" href="style.css">

<p class="aviso">Pedidos até quinta-feira.</p>

}

h2,

  color: darkred;
}

2. Qualquer seletor entra no grupo

O grupo aceita seletores de tipos diferentes: elemento, classe, ID, *, combinações. Cada um continua com o seu sentido:

<style>
  #topo,
  .aviso,
  footer p {
    background-color: lightyellow;
  }
</style>
<header id="topo">Padaria da Ana</header>
<p class="aviso">Fechado no feriado.</p>
<p>Pão quentinho às 7 da manhã.</p>
<footer>
  <p>Rua das Flores, 120</p>
</footer>

Ganharam o fundo amarelo: o cabeçalho (#topo), o aviso (.aviso) e o parágrafo do rodapé (footer p, um <p> dentro de um <footer>). O parágrafo do meio não está em nenhum dos três e ficou sem fundo.

Um seletor por linha

Com dois ou três seletores curtos, uma linha só (h1, h2, h3) fica bem. Com seletores maiores, escreva um por linha, como no exemplo acima: fica fácil de ler, de acrescentar e de apagar um seletor sem mexer nos outros.

3. O que é comum no grupo, o que muda na regra própria

Os três títulos têm a mesma cor e a mesma fonte, mas tamanhos diferentes. O padrão é: o comum vai no grupo, e cada um ganha uma regra própria só com o que é dele.

Experimente: o h3 tem uma regra própria que o deixa em itálico. Ele continua com a cor e a fonte do grupo. Dê uma regra própria ao h2 com text-transform: uppercase; (tudo maiúsculo).

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<h2>Bolos</h2>
<h3>Bolo de fubá</h3>

h1, h2, h3 {
  color: darkslateblue;
  font-family: Georgia, serif;
}

h3 {
  font-style: italic;
}

Um elemento pode receber declarações de várias regras: o <h3> pega a cor e a fonte do grupo, e o itálico da regra dele. Se as duas regras falassem da mesma propriedade, uma teria de ganhar: é a cascata, próxima aula.

4. Vírgula, espaço ou nada

Três seletores que parecem quase iguais e fazem coisas bem diferentes:

SeletorO que separaPega
h2, pVírgulaTodos os <h2> e também todos os <p>
div pEspaçoOs <p> que estão dentro de um <div> (combinador)
p.destaqueNadaOs <p> que também têm a classe destaque (aula de classe)

Experimente: com h2, p, o título e os dois parágrafos ficaram vermelhos. Apague a vírgula (h2 p): nada fica vermelho, porque não há nenhum <p> dentro de um <h2>. Agora tente div p.

<link rel="stylesheet" href="style.css">
<h2>Encomendas</h2>
<p>Pedidos até quinta-feira.</p>
<div>
  <p>Entregamos no bairro.</p>
</div>

h2, p {
  color: crimson;
}

Quando dá errado

Um seletor inválido derruba o grupo inteiro 
<style>
  h1,
  h2:hovr {
    color: crimson;
  }
</style>
<h1>Receitas da Ana</h1>
<h2>Bolos</h2>

O que você vê: nada fica vermelho, nem o <h1>, que está escrito certinho.

Por quê: :hovr é um erro de digitação de :hover (aula Estados). Pela regra do CSS, se um seletor da lista é inválido, a regra inteira é ignorada, com todos os seletores. É a pegadinha mais traiçoeira do grupo: um erro num seletor "quebra" outro que não tem nada a ver.

$ vnu --css hovr.css
"file:/home/ana/site/hovr.css":2.4-2.7: error: CSS: Unknown pseudo-element or pseudo-class “:hovr”

O que significa: "pseudo-elemento ou pseudo-classe desconhecido: :hovr", na linha 2, colunas 4 a 7.

Como consertar: corrija o seletor (h2:hover). E, quando um seletor do grupo é novo demais e talvez não funcione em todos os navegadores, deixe-o numa regra separada: assim, se ele falhar, só ele falha. (Os seletores :is() e :where() são "tolerantes" e não têm esse problema: aula :not(), :is() e :where().)

Vírgula sobrando no fim: Parse Error 
<style>
  h1, h2, h3, {
    color: darkslateblue;
  }
</style>
<h1>Receitas da Ana</h1>
<h2>Bolos</h2>

O que você vê: nenhum título muda de cor.

Por quê: depois da última vírgula, o navegador espera mais um seletor e encontra o {. Um seletor vazio é inválido, e, como no caso anterior, a regra inteira cai.

$ vnu --css sobra.css
"file:/home/ana/site/sobra.css":1.11-1.11: error: CSS: Parse Error.

O que significa: "erro de leitura" na linha 1, coluna 11: a vírgula que sobrou. Acontece muito quando se apaga o último seletor de uma lista escrita um por linha.

Como consertar: h1, h2, h3 {, sem vírgula antes da chave.

Esqueceu a vírgula

O que você vê: com h1 h2 { color: crimson; }, nada muda.

Por quê: sem a vírgula, o espaço vira um combinador: "um <h2> dentro de um <h1>". Não há nenhum. O validador não reclama, porque o seletor é válido: vnu --css termina sem nenhuma mensagem.

Como consertar: h1, h2.

Resumo

  • A vírgula junta seletores numa regra só: h1, h2, h3 { … }. As declarações valem para cada um.
  • Qualquer seletor entra no grupo: elemento, classe, ID, combinações. Com seletores longos, um por linha.
  • O comum vai no grupo; o que muda vai na regra própria de cada um.
  • Vírgula = "e também"; espaço = "dentro de"; nada = "que também é".
  • Um seletor inválido no grupo derruba a regra inteira, e a vírgula sobrando antes do { também. Esquecer a vírgula não dá erro: vira outro seletor.
