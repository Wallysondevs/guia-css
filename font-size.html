CSS Tamanho da Letra (font-size)

Letra pequena demais cansa; letra grande demais vira cartaz. A propriedade font-size ("tamanho da fonte") decide o tamanho do texto. O difícil não é a propriedade: é escolher a unidade. Você pode escrever 24px, 1.5rem, 1.5em ou 150%, e as quatro podem dar o mesmo tamanho hoje e tamanhos diferentes amanhã. Nesta aula você vê cada uma desenhada e descobre por que o guia usa rem.

Você vai aprender
  • O tamanho padrão do texto (16px) e os tamanhos lado a lado.
  • As unidades px, rem, em e %, e o valor calculado em px que o navegador guarda.
  • Por que o em "cresce sozinho" dentro de listas, e o rem não.
  • Por que rem respeita quem aumentou a letra no navegador, e px não.
  • Os tamanhos padrão dos títulos h1 a h6 e as palavras small, large…
  • Os erros: número sem unidade, espaço antes do px, vírgula no decimal.

Os quadros "Resultado" e as caixas "Experimente" são desenhados agora pelo seu navegador. As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana (usuária ana, computador notebook).

A ideia: a régua e a receita

Numa receita, "200 gramas de farinha" é uma medida fixa. Já "meia xícara a mais do que a receita base" depende da receita base: se a base dobrar, a meia xícara a mais também muda. No CSS, o px é a medida fixa; o rem, o em e o % são medidas relativas: "uma vez e meia o tamanho de referência". O segredo é saber qual é a referência de cada uma.

1. O tamanho padrão e os primeiros tamanhos

Sem nenhum CSS, o texto normal dos navegadores tem 16 pixels de altura (o px, "pixel", é a unidade de medida da tela). A partir daí:

<style>
  .p12 { font-size: 12px; }
  .p16 { font-size: 16px; }
  .p20 { font-size: 20px; }
  .p24 { font-size: 24px; }
  .p32 { font-size: 32px; }
</style>
<p class="p12">12px: letra miúda, de rodapé</p>
<p class="p16">16px: o tamanho padrão do texto</p>
<p class="p20">20px: texto grande</p>
<p class="p24">24px: subtítulo</p>
<p class="p32">32px: o tamanho padrão de um h1</p>
font-size
A propriedade: o tamanho da letra.
20
O número.
px
A unidade, colada no número (sem espaço). Sem unidade, a declaração não vale (veja "Quando dá errado").

Repare que a linha de 12px já cansa os olhos. Para o texto principal de um site, 16px é o mínimo recomendado; muitos sites usam 17 ou 18px.

2. rem: relativo à raiz

rem quer dizer root em, "o em da raiz". A raiz é o elemento <html>, cujo tamanho padrão é 16px. Então 1rem = 16px, 1.5rem = 24px, 2rem = 32px:

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p class="destaque">Bolo de cenoura: pronto em 50 minutos.</p>
<p>Texto normal, sem regra própria.</p>

h1 {
  font-size: 2.5rem;
}

.destaque {
  font-size: 1.25rem;
}
Você escreveContaValor calculado

O valor calculado (o que aparece no F12, aba Computed) é sempre em px: o navegador faz a conta e guarda o resultado. Escreva o decimal com ponto: 1.25rem.

Por que rem e não px: a escolha do leitor

Muita gente, principalmente quem enxerga pouco, aumenta o tamanho da letra nas configurações do navegador (no Chrome: Configurações › Aparência › Tamanho da fonte; descrição ilustrativa, o caminho muda entre versões). Essa escolha muda o tamanho da raiz: de 16px para 20px, por exemplo. Aí:

  • um texto com 1.25rem passa de 20px para 25px: acompanha a escolha do leitor;
  • um texto com 20px continua com 20px: ignora a escolha.

Por isso, para tamanhos de letra, o guia usa rem. (O zoom do navegador, Ctrl e +, aumenta tudo, com px ou sem; a configuração de fonte, não.)

Missão: usando rem, deixe o título com 2.5rem (40px) e os parágrafos com 1.125rem (18px).

<link rel="stylesheet" href="style.css">
<h1>Padaria da Ana</h1>
<p>Pão francês quentinho às 7h e às 17h.</p>
<p>Encomendas pelo telefone.</p>

h1 {
  color: hsl(12 73% 45%);
}

h1 {
  color: hsl(12 73% 45%);
  font-size: 2.5rem;
}

p {
  font-size: 1.125rem;
}

3. em e %: relativos ao pai

O em e o % também multiplicam, mas a referência é o tamanho da letra do pai (o elemento de fora). 1.5em = 150% = uma vez e meia a letra do pai.

<style>
  .cartao {
    font-size: 20px;
  }
  .cartao .nota {
    font-size: 0.8em; /* 0,8 × 20px */
  }
</style>
<div class="cartao">
  <p>Texto do cartão: 20px.</p>
  <p class="nota">Nota: 0.8em do cartão = 16px.</p>
</div>
<p class="nota">Fora do cartão, sem regra: 16px.</p>

Isso parece prático, e às vezes é: aumente o .cartao e a nota aumenta junto, na proporção. O problema aparece quando um elemento fica dentro de outro igual.

O em que cresce sozinho

<style>
  li {
    font-size: 1.2em;
  }
</style>
<ul>
  <li>Bolos
    <ul>
      <li>Bolos de frutas
        <ul>
          <li>Bolo de banana</li>
        </ul>
      </li>
    </ul>
  </li>
</ul>

A intenção era "itens de lista um pouco maiores". Mas cada li é 1,2 vez o li de fora: 19.2px, depois 23.04px, depois 27.648px. Quanto mais fundo, maior a letra. Com 1.2rem, os três teriam 19.2px, porque a referência é sempre a raiz. Use em só quando você quer acompanhar o pai (como um ícone do tamanho do texto em volta).

4. Os tamanhos padrão dos títulos

Os títulos já vêm com tamanhos do navegador, todos em em (relativos ao pai):

<h1>h1: 2em (32px)</h1>
<h2>h2: 1.5em (24px)</h2>
<h3>h3: 1.17em (18.72px)</h3>
<h4>h4: 1em (16px)</h4>
<h5>h5: 0.83em (13.28px)</h5>
<h6>h6: 0.67em (10.72px)</h6>
<p>p: 16px</p>

Repare que o h5 e o h6 ficam menores que o texto normal. Se o tamanho não combina com o seu site, troque com font-size, mas nunca escolha h4 ou h5 "porque o tamanho é bom": o nível do título diz a estrutura da página (aula de títulos do Guia HTML), e o tamanho é com o CSS.

5. As palavras: small, large…

O font-size também aceita palavras, que valem tamanhos fixos (relativos ao padrão do leitor):

PalavraValor calculado (com o padrão de 16px)
xx-small9px
x-small10px
small13px
medium16px (o padrão)
large18px
x-large24px
xx-large32px
smaller / largerUm degrau menor / maior que o pai

Funcionam, mas os saltos são grandes e o número exato muda de navegador para navegador. Para controle, use rem.

6. Herança: escolha no body

O font-size é herdado, como a font-family. Um tamanho no body vale para todo o texto que não tem regra própria. E os títulos, que usam em, crescem junto:

<style>
  body {
    font-size: 1.125rem; /* 18px */
  }
</style>
<h1>Título: 2em do body = 36px</h1>
<p>Parágrafo: herdou 18px.</p>
Um tamanho que se adapta à tela

Títulos grandes no computador ficam enormes no celular. A função clamp() escolhe um tamanho entre um mínimo e um máximo conforme a largura da tela: font-size: clamp(1.75rem, 5vw, 3rem);. É assunto da aula min(), max() e clamp().

Quando dá errado

Um tamanho inválido é ignorado em silêncio, e o texto fica com o tamanho de antes. As quatro linhas abaixo queriam 24px:

<style>
  .a { font-size: 24; }
  .b { font-size: 24 px; }
  .c { font-size: 1,5rem; }
  .d { font-size: grande; }
</style>
<p class="a">font-size: 24</p>
<p class="b">font-size: 24 px</p>
<p class="c">font-size: 1,5rem</p>
<p class="d">font-size: grande</p>

As quatro ficaram com os 16px do padrão.

error: CSS: “font-size”: only “0” can be a “unit”. You must put a unit after your number.

O que aconteceu: o número ficou sem unidade: font-size: 24;.

$ vnu --css sem-unidade.css
"file:/home/ana/tamanho/sem-unidade.css":2.14-2.15: error: CSS: “font-size”: only “0” can be a “unit”. You must put a unit after your number.

"Só o 0 pode ficar sem unidade. Você precisa pôr uma unidade depois do número." 24 o quê? Pixels, rem, em? O navegador não adivinha.

Como consertar: font-size: 1.5rem; (ou 24px).

error: CSS: “font-size”: Too many values or values are not recognized.

O que aconteceu: um espaço entre o número e a unidade (24 px), ou vírgula no decimal (1,5rem).

$ vnu --css espaco.css
"file:/home/ana/tamanho/espaco.css":2.17-2.18: error: CSS: “font-size”: Too many values or values are not recognized.
$ vnu --css virgula.css
"file:/home/ana/tamanho/virgula.css":2.16-2.19: error: CSS: “font-size”: Too many values or values are not recognized.

"Valores demais ou não reconhecidos." Com o espaço, 24 e px viram dois valores separados. Com a vírgula, o CSS lê 1 e 5rem, dois valores (a vírgula separa itens de uma lista, como na font-family).

Como consertar: número e unidade colados, decimal com ponto: 24px, 1.5rem.

error: CSS: “font-size”: “grande” is not a “font-size” value.

O que aconteceu: uma palavra que não existe: font-size: grande;.

$ vnu --css palavra.css
"file:/home/ana/tamanho/palavra.css":2.14-2.19: error: CSS: “font-size”: “grande” is not a “font-size” value.

Como consertar: as palavras são em inglês (large), mas o melhor é um número: 1.5rem.

error: CSS: “font-size”: “-2rem” negative values are not allowed.

O que aconteceu: font-size: -2rem;. Não existe letra de tamanho negativo; o navegador ignora e mantém os 16px.

$ vnu --css negativo.css
"file:/home/ana/tamanho/negativo.css":2.15-2.18: error: CSS: “font-size”: “-2rem” negative values are not allowed.

Como consertar: para diminuir a letra, use um número menor que 1: 0.875rem.

Resumo

  • font-size é o tamanho da letra. O padrão é 16px; para texto, não use menos que isso.
  • rem multiplica a letra da raiz (16px): 1.5rem = 24px. É a unidade recomendada, porque acompanha a configuração de letra do leitor.
  • px é fixo e ignora essa configuração. em e % multiplicam a letra do pai e acumulam em elementos dentro de elementos.
  • O valor calculado é sempre em px. Títulos vêm em em: h1 = 2em = 32px.
  • Número sem unidade, espaço antes da unidade, vírgula no decimal ou palavra inventada: o tamanho é ignorado.
