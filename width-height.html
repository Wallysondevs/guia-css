CSS width e height

Toda caixa da página tem uma largura e uma altura. Quase sempre o navegador as escolhe sozinho, e escolhe bem. Mas às vezes você quer um cartão com 300px de largura, um texto que não passe de 600px para ser fácil de ler, ou uma faixa com pelo menos 200px de altura. Para isso servem o width ("largura") e o height ("altura"), e os primos max-width e min-height. Nesta aula você também vai ver por que fixar a altura costuma dar problema.

Você vai aprender
  • O tamanho automático (auto): como o navegador decide a largura e a altura sozinho.
  • width e height em px, % e rem, lado a lado.
  • max-width e min-width, max-height e min-height: os limites, que são o jeito moderno de dar tamanho.
  • O que acontece quando o conteúdo não cabe na altura que você deu.
  • Por que height: 50% muitas vezes não faz nada.
  • Por que width não funciona num <span> ou num <a>.
  • Os erros reais do validador W3C.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a água e o copo

Despeje água numa mesa: ela se espalha até onde der. Despeje num copo: ela fica do tamanho do copo, e se você puser água demais, ela transborda.

Uma caixa de bloco sem tamanho é a água na mesa: ocupa toda a largura disponível e fica tão alta quanto o conteúdo. O width e o height são o copo: o tamanho passa a ser o seu. E, como o copo, uma altura fixa pode ser pequena demais para o que vai dentro.

1. O tamanho automático

Sem width nem height, os dois valem auto ("automático"). Para um elemento de bloco, como <div>, <p> e <h1>:

<style>
  .caixa {
    background-color: lightblue;
    border: 2px solid steelblue;
    margin-bottom: 8px;
  }
</style>
<div class="caixa">Uma linha.</div>
<div class="caixa">Três linhas:<br>pão de queijo<br>brigadeiro</div>
  • Largura automática: as duas caixas vão de ponta a ponta, mesmo com pouco texto. O bloco ocupa toda a largura do pai.
  • Altura automática: a primeira tem a altura de uma linha; a segunda, de três. O bloco cresce com o conteúdo.

Isso é quase sempre o que você quer. Guarde esta regra: só dê tamanho quando precisar, e dê preferência aos limites (seção 4).

2. A primeira largura e altura

<style>
  .cartao {
    width: 250px;
    height: 100px;
    background-color: lavender;
    border: 2px solid slateblue;
  }
</style>
<div class="cartao">Bolo de cenoura: R$ 35</div>
width: 250px;
A largura da caixa: 250 pixels, mesmo que a tela seja maior. Width = "largura".
height: 100px;
A altura: 100 pixels, mesmo que o texto ocupe só uma linha. Height = "altura".

Repare: a caixa parou nos 250px e sobrou espaço branco à direita; e ela ficou bem mais alta que o texto. A borda é desenhada por fora desses números: a caixa ocupa 254 × 104px (os 2px de borda de cada lado). Mais sobre isso na seção 7.

<div class="pai">
  <div class="barra">auto</div>
  <div class="barra" style="width: 200px">200px</div>
  <div class="barra" style="width: 50%">50%</div>

No F12, na aba Computed (Calculado), a largura aparece sempre em pixels, mesmo que você tenha escrito 50% ou 10rem: o navegador mostra o tamanho que de fato desenhou. A barra de 50% mostra width: 200px.

4. Os limites: max-width e min-height

Uma largura fixa tem um problema: width: 600px num celular de 360px de largura faz a caixa passar da tela, e aparece a rolagem para o lado. Quase sempre, o que você quer dizer é "no máximo 600px". Para isso existem os limites:

PropriedadeQuer dizerUso típico
max-widthlargura máxima: encolhe à vontade, cresce até alitextos (linhas curtas são mais fáceis de ler), cartões, imagens
min-widthlargura mínima: cresce à vontade, encolhe até alibotões que não podem ficar estreitos demais
max-heightaltura máximacaixas com rolagem (com overflow)
min-heightaltura mínima: cresce com o conteúdo se precisarfaixas e cartões que precisam de uma altura mínima
<style>
  .texto {
    max-width: 30ch;
    background-color: honeydew;
    border-left: 4px solid seagreen;
    padding: 8px;
  }
  .foto {
    max-width: 100%;
    height: auto;
  }
</style>
<p class="texto">Bata a manteiga com o açúcar, junte os ovos um a um e, por fim, a farinha peneirada com o fermento.</p>
<img class="foto" src="assets/midia/bolo-1200.jpg" alt="Bolo de cenoura com cobertura de chocolate" width="1200" height="900">
.texto { max-width: 30ch; }
O parágrafo não passa de uns 30 caracteres de largura, mesmo com espaço sobrando. Num quadro estreito, ele encolhe junto. Em textos de verdade, algo entre 60ch e 75ch é o mais confortável de ler.
.foto { max-width: 100%; }
A foto tem 1200px de verdade, mas nunca passa da largura do pai: aqui ela encolheu para caber no quadro. É a regra mais famosa do CSS responsivo (aula Imagens que se Adaptam).
height: auto;
Recalcula a altura para a foto não ficar achatada quando a largura encolhe. Sem ela, o height="900" do HTML seria mantido, e a foto ficaria deformada.

Missão: a receita deve ter no máximo 600px de largura, mas encolher se a tela for menor. Troque a largura fixa pelo limite certo. Depois, use os botões 375, 768 e cheia da barra do quadro para ver o texto se ajustar.

<link rel="stylesheet" href="style.css">
<article class="receita">
  <h2>Bolo de cenoura</h2>
  <p>Bata no liquidificador as cenouras, os ovos e o óleo. Despeje numa tigela, junte o açúcar e a farinha e misture bem. Por último, o fermento. Asse em forno médio por 40 minutos.</p>
</article>

.receita {
  width: 600px;
  background-color: oldlace;
  padding: 16px;
}

.receita {
  max-width: 600px;
  background-color: oldlace;
  padding: 16px;
}

5. Quando o conteúdo não cabe na altura

A altura fixa é o copo cheio demais. As duas caixas abaixo têm o mesmo texto, que precisa de quatro ou cinco linhas:

<style>
  .caixa {
    display: inline-block;
    vertical-align: top;
    width: 200px;
    margin: 0 8px 8px 0;
    background-color: mistyrose;
    border: 2px solid crimson;
  }
  .fixa   { height: 60px; }
  .minima { min-height: 60px; }
</style>
<div class="caixa fixa">height: 60px. Bolo de cenoura com cobertura de chocolate, fofinho, fácil de fazer e perfeito para o café da tarde.</div>
<div class="caixa minima">min-height: 60px. Bolo de cenoura com cobertura de chocolate, fofinho, fácil de fazer e perfeito para o café da tarde.</div>
  • height: 60px: a caixa para nos 60px, e o texto vaza por baixo da borda. Se houvesse algo embaixo, o texto passaria por cima.
  • min-height: 60px: a caixa tem pelo menos 60px e cresce o quanto for preciso.

O texto muda de tamanho quando o leitor aumenta a fonte, traduz a página ou abre num celular. Por isso, para caixas com texto, prefira min-height. O height fixo combina com coisas de tamanho conhecido: imagens, ícones, faixas decorativas. Para escolher o que fazer com o conteúdo que sobra (esconder, rolar), existe o overflow (aula O que Transborda).

6. width não funciona em elementos em linha

Elementos em linha, como <span>, <a>, <strong> e <em>, ficam no meio do texto e têm o tamanho das próprias letras. Neles, o navegador ignora width e height:

<style>
  .etiqueta {
    width: 150px;
    height: 40px;
    background-color: gold;
  }
  .bloco-em-linha {
    display: inline-block;
  }
</style>
<p>Em linha: <span class="etiqueta">Promoção</span> (ignorou o tamanho)</p>
<p>inline-block: <span class="etiqueta bloco-em-linha">Promoção</span> (150 × 40px)</p>

O primeiro span tem só o tamanho da palavra; o segundo, com display: inline-block, aceitou os 150 × 40px e continuou na mesma linha do texto. A propriedade display tem aula própria: display: block, inline e inline-block. Imagens (<img>) são a exceção: ficam em linha e mesmo assim aceitam width e height.

7. O tamanho que você dá × o tamanho que a caixa ocupa

Por padrão, width e height medem só o conteúdo. O padding e a borda são somados por fora:

<style>
  .caixa {
    width: 200px;
    background-color: lightcyan;
    border: 2px solid teal;
    margin-bottom: 8px;
  }
  .recheada {
    padding: 20px;
    border-width: 10px;
  }
</style>
<div class="caixa">width: 200px</div>
<div class="caixa recheada">width: 200px, padding 20px, borda 10px</div>

As duas dizem width: 200px, mas a segunda ocupa 260px: 200 + 20 + 20 de padding + 10 + 10 de borda. Por isso a regra box-sizing: border-box, que faz o width já incluir padding e borda, aparece no começo de quase todo CSS moderno. Ela é a próxima aula: box-sizing.

8. Formas de dar tamanho e qual usar

EscritaQuando usar
Nada (auto)A maioria das caixas. Deixe o navegador decidir.
max-width: 65ch;Colunas de texto: linhas confortáveis de ler.
max-width: 1100px; + margin: 0 auto;O "miolo" do site, centralizado nas telas grandes (aula Margem).
max-width: 100%; + height: auto;Imagens que não podem passar do pai.

Largura e altura "lógicas"

Você também vai encontrar inline-size (a largura, no sentido em que o texto corre) e block-size (a altura), com max-inline-size e companhia. Em português, valem o mesmo que width e height; mudam em idiomas escritos na vertical. Aula Propriedades Lógicas.

Quando dá errado

Lembre: o navegador ignora a declaração inválida, em silêncio. A caixa volta ao tamanho automático, e o F12 mostra a linha riscada no painel de estilos (aula DevTools). Dois dos problemas abaixo nem são erros: o CSS é válido, só não faz o que você esperava.

Número sem unidade: You must put a unit after your number 
<style>
  .cartao {
    width: 300;
    background-color: lavender;
  }
</style>
<div class="cartao">Era para ter 300px de largura.</div>

O que você vê: a caixa lavanda ocupando a largura toda: o width foi ignorado.

$ vnu --css largura-semunidade.css
"file:/home/ana/site/largura-semunidade.css":2.10-2.12: error: CSS: “width”: only “0” can be a “unit”. You must put a unit after your number.

O que significa: "só o 0 pode ficar sem unidade". O atributo width="300" do HTML, nas imagens, é sem unidade; no CSS, não. Conserto: width: 300px;.

Valor negativo, dois valores ou nome errado 
$ vnu --css largura-neg.css
"file:/home/ana/site/largura-neg.css":2.11-2.15: error: CSS: “width”: “-100px” negative values are not allowed.
$ vnu --css dois.css
"file:/home/ana/site/dois.css":2.16-2.20: error: CSS: “width”: Too many values or values are not recognized.
$ vnu --css largura-nome.css
"file:/home/ana/site/largura-nome.css":2.10-2.14: error: CSS: “widht”: Property “widht” doesn't exist.

"Valores negativos não são permitidos" (não existe caixa com largura menor que zero). Em width: 300px 200px;, "valores demais": o width não é atalho de largura e altura, são duas propriedades. E widht, com o h e o t trocados, "não existe". Nos três casos, a caixa fica no tamanho automático.

height: 50% não faz nada (e o validador não reclama) 
<style>
  .pai {
    border: 2px dashed gray;
  }
  .filho {
    height: 50%;
    background-color: gold;
  }
</style>
<div class="pai">
  <div class="filho">Era para ter metade da altura do pai.</div>
</div>

O que você vê: a faixa dourada com a altura de uma linha, como se o height nem existisse.

Por quê: a altura do pai é auto, ou seja, depende da altura do filho. "Metade de algo que depende de mim" não tem resposta, e a regra do CSS manda tratar esse % como auto. O vnu --css não acusa nada: o CSS é válido.

Como consertar: dê uma altura de verdade ao pai (height: 300px, por exemplo), ou use outra unidade no filho (min-height: 50vh, metade da altura da janela). Para dividir o espaço entre caixas, Flexbox e Grid resolvem melhor.

Missão: o texto da faixa vaza para fora dela (o fim dele, branco, some no fundo branco da página). Troque a altura fixa por uma altura mínima de 120px, para a faixa crescer com o texto.

<link rel="stylesheet" href="style.css">
<section class="faixa">
  <h2>Encomendas de Natal</h2>
  <p>Panetone caseiro, bolo de frutas e cookies decorados. Faça o pedido até o dia 15 de dezembro pelo telefone da lojinha.</p>
</section>
<p>Próxima seção do site.</p>

.faixa {
  max-width: 260px;
  height: 120px;
  background-color: darkred;
  color: white;
  padding: 8px 16px;
}

.faixa {
  max-width: 260px;
  min-height: 120px;
  background-color: darkred;
  color: white;
  padding: 8px 16px;
}
width num <a> ou <span>: nada muda

O que você vê: o link continua do tamanho do texto (seção 6). Também não é erro, e o validador fica calado.

Como consertar: display: inline-block; (ou block) no elemento, e o tamanho passa a valer.

Resumo

  • Sem tamanho (auto), um bloco ocupa toda a largura do pai e tem a altura do conteúdo. Quase sempre é o melhor.
  • width e height fixam o tamanho do conteúdo, em px, % (do pai), rem, ch, vw…
  • Prefira os limites: max-width para textos, cartões e imagens (max-width: 100%); min-height no lugar de height em caixas com texto.
  • Uma altura fixa pequena faz o texto vazar. height: 50% só funciona se o pai tiver altura definida.
  • Em elementos em linha (span, a), width e height são ignorados; use inline-block.
  • Padding e borda são somados ao width (até a próxima aula, box-sizing).
  • Erros: número sem unidade, negativo, dois valores, widht. Em todos, o navegador ignora a declaração.
