CSS Listas

Lista de ingredientes, passo a passo do modo de preparo, menu do site: listas estão em todo lugar. O navegador já as desenha com bolinhas (<ul>) ou números (<ol>) e um recuo à esquerda. Nesta aula você vai trocar esses marcadores por quadradinhos, letras, algarismos romanos ou um símbolo qualquer, pintar o marcador de outra cor e, no fim, tirar tudo para transformar uma lista num menu.

Você vai aprender
  • O que é o marcador de uma lista e de onde vem o recuo.
  • list-style-type: bolinha, quadrado, letras, romanos ou um texto seu.
  • list-style-position: o marcador dentro ou fora do texto.
  • O atalho list-style e o list-style-image.
  • ::marker: mudar a cor e o tamanho só do marcador.
  • Como tirar marcadores e recuo para fazer um menu.
  • Os erros: o nome de marcador que vira número, o marcador que sai da tela e o que o validador W3C diz.

Os resultados são desenhados pelo seu navegador, logo abaixo de cada código. As listas em HTML (<ul>, <ol> e <li>) foram assunto do Guia HTML; aqui o assunto é só a aparência delas.

A ideia: a etiqueta e o recuo

Pense numa lista de compras escrita à mão. Cada item começa com um tracinho, uma bolinha ou um número: é a etiqueta que diz "aqui começa um item". E a lista inteira fica um pouco para dentro, para a etiqueta ter onde ficar.

No CSS é igual. A etiqueta se chama marcador (marker, em inglês), e o recuo é um espaço interno (padding, "preenchimento") que o navegador põe à esquerda da lista. Veja os dois no resultado:

<style>
  ul {
    border: 2px dashed tomato;
  }
</style>
<ul>
  <li>Farinha</li>
  <li>Ovos</li>
  <li>Cenoura</li>
</ul>

A borda tracejada mostra a caixa do <ul>. Repare:

  • As bolinhas ficam dentro da borda, mas num espaço vazio à esquerda do texto. Esse espaço é o padding-left da lista: 40px no Chrome, no Edge e no Firefox (é o que o F12 mostra na aba Computed).
  • A lista tem uma margem em cima e embaixo (margin-top e margin-bottom de 16px, o tamanho de uma linha de texto).
  • Cada <li> tem display: list-item: é esse valor que faz o navegador desenhar um marcador. Ele volta no Quando dá errado.

1. Trocar o marcador: list-style-type

A propriedade list-style-type ("tipo do estilo da lista") escolhe o desenho do marcador:

Experimente: troque square por circle e veja os marcadores mudarem.

<link rel="stylesheet" href="style.css">
<h2>Ingredientes</h2>
<ul class="ingredientes">
  <li>2 xícaras de farinha</li>
  <li>3 ovos</li>
  <li>3 cenouras</li>
</ul>

.ingredientes {
  list-style-type: square;
}
.ingredientes
O seletor: a lista com class="ingredientes".
list-style-type
A propriedade do desenho do marcador.
square
O valor: "quadrado".
Na lista ou no item?

O list-style-type é herdado: posto no <ul>, ele passa para todos os <li> de dentro (aula Herança). Por isso o costume é escrever na lista. Escrever num <li> só muda aquele item.

Os valores, lado a lado

Cada lista abaixo usa um valor, escrito no próprio item:

<style>
  .disc   { list-style-type: disc; }
  .circle { list-style-type: circle; }
  .square { list-style-type: square; }
  .none   { list-style-type: none; }
</style>
<ul class="disc"><li>disc (o padrão do ul)</li></ul>
<ul class="circle"><li>circle</li></ul>
<ul class="square"><li>square</li></ul>
<ul class="none"><li>none (sem marcador)</li></ul>

Repare no none: o marcador some, mas o texto continua recuado. O recuo é o padding da lista, e não o marcador; a seção 5 tira os dois.

Para listas numeradas, há vários tipos de número:

<style>
  .decimal { list-style-type: decimal; }
  .zero    { list-style-type: decimal-leading-zero; }
  .alpha   { list-style-type: lower-alpha; }
  .ALPHA   { list-style-type: upper-alpha; }
  .roman   { list-style-type: lower-roman; }
  .ROMAN   { list-style-type: upper-roman; }
</style>
<ol class="decimal"><li>decimal (o padrão do ol)</li><li>dois</li></ol>
<ol class="zero"><li>decimal-leading-zero</li><li>dois</li></ol>
<ol class="alpha"><li>lower-alpha</li><li>dois</li></ol>
<ol class="ALPHA"><li>upper-alpha</li><li>dois</li></ol>
<ol class="roman"><li>lower-roman</li><li>dois</li></ol>

Marcador é aparência; ordem é HTML

Trocar o marcador não muda o significado. Uma lista em que a ordem importa (os passos da receita) continua sendo <ol>, mesmo que você mostre letras ou romanos. E um <ul> com decimal mostra números, mas para o leitor de tela continua sendo uma lista sem ordem.

Um texto qualquer como marcador

Entre aspas, o valor vira o próprio marcador. Deixe um espaço no fim do texto, senão ele gruda no item:

<style>
  .seta    { list-style-type: "→ "; }
  .colado  { list-style-type: "→"; }
  .estrela { list-style-type: "★ "; }
</style>
<ul class="seta"><li>com espaço depois da seta</li></ul>
<ul class="colado"><li>sem espaço: a seta gruda</li></ul>
<ul class="estrela"><li>estrela</li></ul>

O texto como marcador funciona no Chrome e no Edge desde a versão 79, no Firefox desde a 39 e no Safari desde a 14.1: todos os navegadores atuais.

2. Dentro ou fora: list-style-position

O marcador pode ficar fora do texto (outside, o padrão), pendurado no recuo, ou dentro (inside), como se fosse a primeira letra do item. A diferença aparece quando o item ocupa mais de uma linha:

<style>
  ul {
    border: 2px dashed tomato;
    max-width: 300px;
  }
  .fora   { list-style-position: outside; }
  .dentro { list-style-position: inside; }
</style>
<ul class="fora">
  <li>outside: a segunda linha do item fica alinhada com a primeira</li>
</ul>
<ul class="dentro">
  <li>inside: o marcador entra no texto, e a segunda linha volta para baixo dele</li>
</ul>
  • Com outside, o marcador fica à esquerda e o texto forma um bloco alinhado. É o mais fácil de ler.
  • Com inside, o marcador anda para a direita, para dentro do item, e a segunda linha começa embaixo dele.

Use inside quando o item tem fundo ou borda e você quer o marcador dentro dessa caixa. No resto, fique com o padrão.

3. O atalho list-style e o list-style-image

Como em várias propriedades do CSS, existe um atalho que junta as três de uma vez: o tipo, a posição e a imagem, em qualquer ordem.

.ingredientes {
  list-style: square inside;
}

.menu {
  list-style: none;
}
list-style
O atalho de list-style-type, list-style-position e list-style-image.
square inside
Tipo square e posição inside. O que você não escreve volta ao padrão: aqui, sem imagem.
none
O jeito mais comum de usar o atalho: "nenhum marcador".

O list-style-image ("imagem do estilo da lista") troca o marcador por uma imagem: list-style-image: url(seta.svg);. Ele quase não é usado hoje, porque não dá para controlar o tamanho nem a posição da imagem: ela entra do tamanho que tiver. Para um marcador sob medida, a aula ::before e ::after mostra o jeito moderno.

ParaEscrevaQuando usar
Trocar só o desenholist-style-type: square;O mais claro: quem lê sabe o que mudou
Tirar os marcadoreslist-style: none;Menus; é o jeito que você vai ver em todo site
Desenho e posição juntoslist-style: square inside;Quando muda mais de uma coisa

4. Pintar só o marcador: ::marker

E se a Ana quiser os números do modo de preparo em laranja, mas o texto em preto? Um color no <li> pinta os dois. Para mexer só no marcador, existe o pseudo-elemento ::marker:

Experimente: mude o font-size para 2em e a cor para navy.

<link rel="stylesheet" href="style.css">
<h2>Modo de preparo</h2>
<ol class="preparo">
  <li>Bata as cenouras com os ovos.</li>
  <li>Misture a farinha.</li>
  <li>Asse por 40 minutos.</li>
</ol>

.preparo li::marker {
  color: tomato;
  font-size: 1.5em;
  font-weight: bold;
}
.preparo li
Os itens da lista do modo de preparo.
::marker
Os dois-pontos duplos indicam um pseudo-elemento: uma parte do elemento que não existe no HTML, mas o CSS consegue estilizar. Aqui, o marcador de cada <li>.
color, font-size, font-weight
Só valem para o número; o texto do item não muda.

O ::marker aceita poucas propriedades: color, as de fonte (font-size, font-weight, font-family…), content (para trocar o texto do marcador), white-space, animações e transições. Um background, um padding ou uma border no ::marker são ignorados.

Suporte

O ::marker funciona no Chrome e no Edge desde a versão 86 e no Firefox desde a 68. No Safari, só color e font-size funcionam: um font-weight ou um content são ignorados lá. Para cor e tamanho, pode usar sem medo.

Missão: deixe os passos com letras minúsculas (a, b, c) e pinte só as letras de tomato, com ::marker.

  <li>Bata as cenouras com os ovos.</li>

}

  list-style-type: lower-alpha;
}

5. Sem marcador e sem recuo: a lista vira menu

Quase todo menu de site é uma lista de links: são vários itens do mesmo tipo, e o leitor de tela anuncia "lista, 4 itens", o que ajuda quem não enxerga. Mas ninguém quer bolinhas no menu. São três coisas a tirar: o marcador, o recuo (padding) e a margem de cima e de baixo.

Experimente: apague uma linha de cada vez (o list-style, depois o padding, depois o margin) e veja o que cada uma tirava.

<link rel="stylesheet" href="style.css">
<nav>
  <ul class="menu">
    <li><a href="index.html">Início</a></li>
    <li><a href="receitas.html">Receitas</a></li>
    <li><a href="sobre.html">Sobre</a></li>
  </ul>
</nav>

.menu {
  list-style: none;
  padding: 0;
  margin: 0;
  border: 2px dashed tomato;
}

Com as três linhas, os links ficam encostados na borda tracejada, um embaixo do outro. Para pôr os itens lado a lado, o caminho moderno é display: flex no <ul>, assunto da aula Introdução ao Flexbox. O visual dos links (cor, sublinhado) está na aula Estilizando Links.

Safari e o leitor de tela

O Safari, com o leitor de tela VoiceOver, pode deixar de anunciar como lista uma lista com list-style: none. Dentro de um <nav> isso não costuma acontecer. Numa lista sem marcador fora do <nav>, em que o "lista, 4 itens" importa, acrescente role="list" no <ul>.

Quando dá errado

Nome de marcador errado: aparecem números numa lista com bolinhas 
<style>
  .ingredientes {
    list-style-type: squared;
  }
</style>
<ul class="ingredientes">
  <li>Farinha</li>
  <li>Ovos</li>
</ul>

O que você vê: a lista ganha números, 1. e 2., em vez dos quadradinhos (e em vez das bolinhas).

Por quê: o list-style-type aceita, além dos nomes prontos, o nome de um estilo de contador que você mesmo pode criar (com @counter-style). Por isso squared é um valor permitido: o navegador procura um estilo com esse nome, não acha e, pela regra do CSS, usa decimal, os números. É um dos raros casos em que o erro não é ignorado: ele muda o resultado.

O que o validador diz: nada. vnu --css style.css não mostra nenhum erro, pelo mesmo motivo: squared poderia ser um estilo seu.

Como consertar: o nome certo é square. Se aparecerem números onde não devia, confira a grafia do valor.

Valor errado na posição: a declaração é ignorada 
.ingredientes {
  list-style-position: dentro;
}

O que você vê: nada muda; o marcador continua do lado de fora. No F12, no painel Styles (Estilos), a declaração aparece riscada, com um ícone de aviso.

$ vnu --css style.css
"file:/home/ana/site/style.css":2.24-2.29: error: CSS: “list-style-position”: “dentro” is not a “list-style-position” value.

O que significa: "dentro não é um valor de list-style-position". Os valores do CSS são em inglês: inside e outside. Um nome de propriedade errado dá outra mensagem: com list-styl-type, o validador diz Property “list-styl-type” doesn't exist, "a propriedade não existe".

Tirou o recuo e o marcador sumiu da tela 
<style>
  .ingredientes {
    padding: 0;
    border: 2px dashed tomato;
  }
</style>
<ul class="ingredientes">
  <li>Farinha</li>
  <li>Ovos</li>
</ul>

O que você vê: o texto encosta na borda e as bolinhas desaparecem.

Por quê: com outside, o marcador fica pendurado à esquerda do texto, no espaço do padding. Sem esse espaço, ele é desenhado fora da caixa da lista, à esquerda, e aqui sai da área visível. Num site, ele pode aparecer por cima de outra coisa ou ser cortado.

Como consertar: se quer o marcador, deixe um recuo (padding-left: 1.5em, por exemplo) ou use list-style-position: inside. Se não quer, tire de propósito, com list-style: none.

O item virou flex e perdeu o marcador 
<style>
  .ingredientes li {
    display: flex;
  }
</style>
<ul class="ingredientes">
  <li>Farinha</li>
  <li>Ovos</li>
</ul>

O que você vê: os itens continuam recuados, mas sem bolinha.

Por quê: só um elemento com display: list-item ganha marcador. O <li> tem esse valor por padrão; ao trocá-lo por flex (ou block, grid…), o marcador vai junto. O validador não reclama: tudo ali é CSS válido. A aula display explica os valores.

Como consertar: ponha o display: flex num elemento de dentro do item, ou desenhe o marcador com ::before.

Resumo

  • Toda lista tem um marcador por item e um recuo à esquerda, que é o padding-left de 40px da lista, além de margens de 16px em cima e embaixo.
  • list-style-type troca o desenho: disc, circle, square, decimal, lower-alpha, upper-roman, none ou um texto entre aspas. É herdado: escreva na lista.
  • list-style-position: outside (padrão, texto alinhado) ou inside (marcador dentro do texto).
  • list-style é o atalho; list-style: none é o mais usado.
  • li::marker estiliza só o marcador (no Safari, só color e font-size).
  • Para um menu: list-style: none, padding: 0 e margin: 0.
  • Erros: um nome de marcador inexistente (squared) vira números, sem aviso do validador; padding: 0 joga o marcador para fora da caixa; um <li> com outro display perde o marcador.
