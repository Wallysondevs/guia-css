CSS Variáveis

O laranja da lojinha da Ana aparece no título, nos botões, nas bordas dos cartões, nos links: #c2410c escrito vinte vezes no CSS. No dia em que ela quiser um laranja um pouco diferente, vai ter de achar e trocar todos, e torcer para não esquecer nenhum. As variáveis do CSS resolvem isso: você dá um nome ao valor, escreve o valor uma vez e usa o nome em todo lugar.

Você vai aprender
  • Declarar uma variável (--cor-principal: #c2410c;) e usá-la com var().
  • Por que as variáveis "globais" ficam no :root.
  • O valor reserva: var(--cor, tomato).
  • Escopo e herança: a variável vale para o elemento e para tudo dentro dele.
  • Variações (tema escuro, cartão de destaque) trocando só as variáveis.
  • Variáveis com calc() e com media queries.
  • Os erros silenciosos: nome errado, unidade colada, valor que não serve.

O nome oficial é custom properties, "propriedades personalizadas": para o navegador, uma variável é uma propriedade que você inventa. Todo mundo chama de "variável do CSS". Elas funcionam em todos os navegadores atuais há anos (o MDN as marca como "Baseline: amplamente disponível").

A ideia: o pote com etiqueta

Na cozinha da Ana, o açúcar fica num pote com a etiqueta "AÇÚCAR". As receitas dizem "uma xícara do pote AÇÚCAR", e não "uma xícara do saco azul da marca tal comprado no dia 3". Se um dia ela trocar por açúcar mascavo, só troca o que está dentro do pote: todas as receitas passam a usar o mascavo, sem mudar uma linha.

O pote com a etiqueta "AÇÚCAR"A variável: --cor-principal
O que está dentro do poteO valor: #c2410c
"Use o pote AÇÚCAR"var(--cor-principal)

1. Declarar e usar

São duas partes: declarar a variável (encher o pote) e usar (pegar do pote):

:root {
  --cor-principal: #c2410c;
}

h1 {
  color: var(--cor-principal);
}
:root
Um seletor que escolhe a raiz da página, o elemento <html>. Como todos os elementos estão dentro dele, uma variável declarada ali vale para a página inteira (veja a seção 3).
--cor-principal
O nome da variável. Começa sempre com dois hífens, --. Depois, o nome que você quiser: letras, números, hífens. Diferencia maiúsculas de minúsculas: --Cor e --cor são duas variáveis diferentes.
: #c2410c;
O valor, como numa propriedade comum. Pode ser uma cor, um tamanho (16px), uma lista de fontes, qualquer coisa.
var(
A função que lê a variável: "use aqui o valor de…".
--cor-principal)
O nome, com os dois hífens, exatamente como foi declarado.

Experimente: o título, o botão e a borda do cartão usam a mesma variável. Troque #c2410c por teal, ou por #7c3aed, na primeira regra: os três mudam juntos.

<link rel="stylesheet" href="style.css">
<h1>Lojinha da Ana</h1>
<div class="cartao">
  <p>Bolo de cenoura com cobertura de chocolate.</p>
  <button class="botao" type="button">Encomendar</button>
</div>

:root {
  --cor-principal: #c2410c;
}

body {
  font-family: system-ui, sans-serif;
}

h1 {
  color: var(--cor-principal);
}

.cartao {
  padding: 16px;
  border: 3px solid var(--cor-principal);
  border-radius: 8px;
}

.botao {
  font: inherit;
  padding: 8px 16px;
  border: none;
  border-radius: 6px;
  background-color: var(--cor-principal);
  color: white;
}

O valor calculado do título é rgb(194, 65, 12), conferido no Chromium: na hora de desenhar, o navegador troca o var(--cor-principal) pelo valor da variável, e daí em diante é uma cor comum. No F12, a aba Computed mostra a cor final, e a aba de estilos mostra a regra como você escreveu, com o var(…).

2. O valor reserva: var(--x, padrão)

O var() aceita um segundo valor, depois da vírgula: o que usar se a variável não existir.

.selo {
  background-color: var(--cor-destaque, gold);
}
--cor-destaque
A variável que o var() procura primeiro.
, gold
A reserva: se ninguém declarou --cor-destaque, o fundo fica gold.

A reserva é útil em peças que você reaproveita em vários sites (um "componente"): ele funciona sozinho, com a cor padrão, e quem quiser muda a cor declarando a variável. Tudo depois da primeira vírgula é a reserva, então ela pode ter vírgulas também: var(--fonte, Georgia, serif). E pode ser outra variável: var(--cor-destaque, var(--cor-principal)).

Experimente: o selo usa a reserva gold, porque --cor-destaque não existe. Apague o /* e o */ da primeira regra: a variável passa a existir e vence a reserva.

<link rel="stylesheet" href="style.css">
<p><span class="selo">Novidade</span> Bolo de fubá com goiabada</p>

/* :root {
  --cor-destaque: lightgreen;
} */

.selo {
  padding: 4px 10px;
  border-radius: 999px;
  background-color: var(--cor-destaque, gold);
}

3. Escopo e herança: onde a variável vale

Uma variável vale para o elemento onde foi declarada e para tudo que está dentro dele: ela é herdada, como a cor do texto (aula Herança). Por isso o :root é o lugar das variáveis "globais": tudo está dentro do <html>.

Mas você também pode declarar uma variável num elemento qualquer. Aí ela só existe ali dentro:

<link rel="stylesheet" href="style.css">
<div class="cartao">
  <p class="etiqueta">Dentro do cartão</p>
</div>
<p class="etiqueta">Fora do cartão</p>

.cartao {
  --fundo: lightyellow;
  padding: 8px;
  border: 1px solid tan;
}

.etiqueta {
  padding: 8px;
  background-color: var(--fundo, white);
}

As duas etiquetas têm a mesma regra, background-color: var(--fundo, white). A de dentro do cartão herda --fundo e fica amarelo-clara (rgb(255, 255, 224)). A de fora não tem --fundo nenhum (o valor calculado de --fundo nela é vazio) e usa a reserva, branco (valores conferidos no Chromium).

4. Variações: troque só as variáveis

Aqui as variáveis mostram a sua força. O cartão usa duas variáveis, --fundo e --texto. Para fazer um cartão escuro, você não reescreve as regras do cartão: só redefine as variáveis numa segunda classe.

:root {
  --fundo: white;
  --texto: #222;
}

.cartao {
  background-color: var(--fundo);
  color: var(--texto);
}

.cartao-escuro {
  --fundo: #333;
  --texto: white;
}

Um elemento com class="cartao cartao-escuro" tem as duas classes: a regra .cartao manda usar var(--fundo), e a .cartao-escuro diz que, ali, --fundo vale #333. A redefinição vale para o elemento e para os filhos dele. É assim que se faz um tema escuro para o site inteiro: as mesmas regras, outras variáveis.

Variáveis que mudam com a tela

Uma media query também pode redefinir variáveis. Todas as regras que usam a variável acompanham:

:root {
  --espaco: 12px;
}

@media (min-width: 768px) {
  :root {
    --espaco: 24px;
  }
}

.cartao {
  padding: var(--espaco);
  margin-bottom: var(--espaco);
}

5. Variáveis e calc()

Uma variável guarda um valor, e você pode fazer conta com ele usando calc():

:root {
  --espaco: 16px;
}

.secao {
  padding: var(--espaco);
  margin-bottom: calc(var(--espaco) * 2);
}

O margin-bottom calculado fica 32px. Mude --espaco e os dois espaços mudam, sempre na mesma proporção.

A variável não "cola" com uma unidade

Se a variável guarda só um número (--colunas: 3), para virar um tamanho multiplique pela unidade: calc(var(--n) * 1px). Escrever var(--espaco)px não funciona: o navegador não junta os pedaços num valor só (veja Quando dá errado).

6. Variável ou valor direto?

SituaçãoUse
Um valor que se repete (a cor da marca, a fonte, o espaçamento padrão)Variável no :root
Um componente com variações (cartão claro, escuro, de destaque)Variáveis no componente, redefinidas na classe da variação
Tema escuro, espaços maiores em telas largasRedefinir as variáveis numa media query
Um valor que aparece uma vez sóO valor direto: uma variável ali só deixa o código mais longo
Dê nomes pelo papel, e não pela aparência

--cor-principal continua fazendo sentido se a Ana trocar o laranja por verde; --laranja vira uma mentira (--laranja: green). Bons nomes: --cor-principal, --cor-texto, --fundo, --espaco, --raio.

Quando dá errado

As variáveis têm uma armadilha que as outras propriedades não têm. Numa declaração comum com erro, o navegador ignora a linha e fica com a declaração anterior. Com var(), o navegador só descobre o problema depois, na hora de calcular o valor, e aí já é tarde para voltar atrás: a propriedade fica como se nunca tivesse sido escrita, com o valor herdado do pai (nas propriedades que herdam, como color) ou com o valor inicial (nas outras, como background-color, que fica transparente).

Nome errado: nem a cor de antes sobra 
:root {
  --cor-principal: #c2410c;
}

body {
  color: darkgreen;
}

.aviso {
  color: red;
  color: var(--cor-principa);
}

O que você vê: o aviso fica verde-escuro, a cor do body. Nem laranja (a variável) nem vermelho (a linha de cima). O valor calculado é rgb(0, 100, 0), conferido no Chromium.

Por quê: falta o "l" de --cor-principal. A variável --cor-principa não existe e não há reserva, então o color do aviso é tratado como se não existisse, e a cor é herdada do pai. O red já tinha sido descartado, porque a declaração seguinte venceu a cascata.

O que o validador diz: nada. Para ele, var(--cor-principa) está escrito certo; ele não confere se a variável existe.

Como consertar: confira o nome letra por letra (inclusive maiúsculas: --Cor não é --cor). No F12, a aba Computed mostra o valor final: se ele não for o esperado, procure o nome da variável na aba de estilos e compare com a declaração.

Unidade colada: var(--espaco)px 
:root {
  --espaco: 16px;
}

p {
  margin-top: var(--espaco)px;
}

O que você vê: o parágrafo perde até a margem de cima que o navegador dá a todo <p>. O margin-top calculado fica 0px (o valor inicial), e não 16.

Por quê: o resultado seria 16px px, dois pedaços separados, e não um tamanho. Como margin-top não é herdado, ele cai no valor inicial, zero.

Como consertar: guarde a unidade dentro da variável (--espaco: 16px; e margin-top: var(--espaco);), ou, com um número puro, calc(var(--n) * 1px).

Um valor que não serve para a propriedade 
:root {
  --tamanho: 20;
}

p {
  font-size: var(--tamanho);
}

O que você vê: a letra continua com 16 pixels, herdada do pai.

Por quê: a variável aceita qualquer coisa, então --tamanho: 20 é válido. Mas font-size: 20, sem unidade, não é um tamanho. O problema só aparece na hora de usar.

Como consertar: --tamanho: 1.25rem;

Esqueceu os dois hífens no var(): o validador pega 
:root {
  --cor-principal: #c2410c;
  --espaco: 16px;
}
h1 {
  color: var(--cor-principal);
  margin: var(--espaco)px;
}
p {
  color: var(cor-principal);
  padding: calc(var(--espaco) * 2);
}

$ vnu --css v.css
"file:/home/ana/site/v.css":10.27-10.27: error: CSS: “color”: Parse Error.

O que significa: "erro de leitura" na linha 10: var(cor-principal), sem os --, não é uma forma válida de var(). Repare no que o validador não acusa: o var(--espaco)px da linha 7. Ele não sabe o que a variável vai conter, então os erros das seções acima só aparecem no navegador.

Resumo

  • Variável (custom property): --nome: valor;, sempre com dois hífens; diferencia maiúsculas de minúsculas.
  • Use com var(--nome). Com reserva: var(--nome, padrão).
  • As variáveis são herdadas: no :root, valem para a página toda; numa classe, valem ali dentro.
  • Para variações (cartão escuro, tema escuro, telas largas), redefina as variáveis, e não as regras.
  • Contas com calc(var(--x) * 2); número puro vira tamanho com calc(var(--n) * 1px), nunca var(--n)px.
  • Nome errado ou valor que não serve: a propriedade fica com o valor herdado ou o inicial, e não com a declaração anterior. O validador não percebe; o F12, sim.
