CSS box-sizing

Nas aulas de padding, borda e largura, uma coisa se repetiu: você escreve width: 200px, põe um padding, e a caixa fica maior que 200px. Isso confunde todo mundo que começa, e atrapalha até quem já sabe. O box-sizing ("dimensionamento da caixa") muda essa conta, e uma única regra, que você vai copiar no começo de todo CSS, resolve o problema de vez.

Você vai aprender
  • Os dois valores: content-box (o padrão) e border-box, lado a lado.
  • A conta de cada um: quanto a caixa ocupa de verdade.
  • O caso clássico: duas colunas de 50% que não cabem lado a lado.
  • A regra universal com *, ::before e ::after, e por que quase todo site a usa.
  • Onde ver o box-sizing no F12.
  • Os erros reais do validador W3C.

Os resultados desta aula são desenhados pelo seu navegador, logo abaixo de cada código. As mensagens de erro são do validador W3C (vnu), rodado na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/site.

A ideia: a mala de mão

A companhia aérea diz: "a mala de mão pode ter no máximo 55 cm". Você compra uma mala cujo espaço interno tem 55 cm, chega no aeroporto e ela não passa no medidor: com as rodinhas, as alças e o forro, ela tem 62 cm por fora.

A companhia mede por fora. A loja mediu por dentro. As duas estão "certas"; só usam regras diferentes.

ValorNa malaO width mede…
content-box (o padrão)Por dentro: só o espaço para as roupasSó o conteúdo. Padding e borda são somados por fora.
border-boxPor fora: a mala inteira, com rodinhas e alçasConteúdo + padding + borda. O que você escreve é o que a caixa ocupa.

Nos dois casos, a margin fica de fora da conta: ela é o espaço entre as malas na esteira, não faz parte de nenhuma.

1. Os dois valores lado a lado

As duas caixas têm exatamente as mesmas medidas escritas. Só o box-sizing muda:

<style>
  .caixa {
    width: 200px;
    padding: 20px;
    border: 5px solid darkcyan;
    background-color: lightcyan;
    margin-bottom: 10px;
    font-family: monospace;
  }
  .content { box-sizing: content-box; }
  .border  { box-sizing: border-box; }
</style>
<div class="caixa content">content-box</div>
<div class="caixa border">border-box</div>

A primeira caixa ficou visivelmente mais larga que a segunda. As contas:

content-boxborder-box
O que você escreveuwidth: 200px; padding: 20px; border: 5px
Largura do conteúdo200px200 − 20 − 20 − 5 − 5 = 150px
Largura que a caixa ocupa200 + 20 + 20 + 5 + 5 = 250px200px, o que você escreveu
box-sizing
A propriedade: diz o que o width e o height medem. Box sizing = "dimensionamento da caixa".
content-box
"Caixa do conteúdo": width e height medem só o conteúdo. É o valor inicial, por razões históricas.
border-box
"Caixa da borda": width e height medem até a borda, por fora. O conteúdo encolhe para dar lugar ao padding e à borda.

Com border-box, você pode mudar o padding ou a borda à vontade, e a caixa não muda de tamanho na página: só o espaço de dentro muda. Isso deixa o layout previsível.

2. O caso clássico: as colunas que não cabem

A Ana quer duas colunas lado a lado, cada uma com metade da largura (50%) e um padding para o texto não encostar. Parece simples:

<style>
  .coluna {
    display: inline-block;
    vertical-align: top;
    width: 50%;
    padding: 12px;
    background-color: lavender;
    border: 1px solid slateblue;
  }
</style>
<div class="coluna">Doces: bolo, brigadeiro, pudim.</div><div class="coluna">Salgados: coxinha, pão de queijo, empada.</div>

A segunda coluna caiu para a linha de baixo. Cada coluna ocupa 50% + 24px de padding + 2px de borda, e duas delas passam de 100%. (As duas div estão coladas no código, sem espaço entre elas, de propósito: com inline-block, um espaço vira um espacinho na tela e atrapalharia a conta.)

Missão: faça as duas colunas caberem lado a lado, sem tirar o padding nem a borda: acrescente uma declaração ao .coluna.

<link rel="stylesheet" href="style.css">
<div class="coluna">Doces: bolo, brigadeiro, pudim.</div><div class="coluna">Salgados: coxinha, pão de queijo, empada.</div>

.coluna {
  display: inline-block;
  vertical-align: top;
  width: 50%;
  padding: 12px;
  background-color: lavender;
  border: 1px solid slateblue;
}

.coluna {
  display: inline-block;
  vertical-align: top;
  width: 50%;
  padding: 12px;
  background-color: lavender;
  border: 1px solid slateblue;
  box-sizing: border-box;
}

Com border-box, cada coluna ocupa exatamente 50%, padding e borda incluídos. Hoje, colunas se fazem com Flexbox e Grid, mas o mesmo problema aparece neles e em qualquer caixa com largura em % e padding: um campo de formulário com width: 100% e padding, por exemplo, passa da borda do formulário.

3. A regra universal

Como border-box é mais fácil de pensar, quase todo site moderno o liga para todos os elementos, logo no começo do style.css:

*,
*::before,
*::after {
  box-sizing: border-box;
}
*
O seletor universal: casa com todos os elementos da página (aula Seletor Universal).
*::before, *::after
Os pseudo-elementos, "caixas de mentira" que o CSS pode criar antes e depois do conteúdo de um elemento (aula ::before e ::after). O * sozinho não os alcança, por isso entram na lista.
,
A vírgula junta os três seletores numa regra só (aula Agrupando Seletores).
box-sizing: border-box;
A partir daqui, todo width e height do site mede por fora.

Ela é tão comum que faz parte dos "resets", os trechos de CSS que zeram as diferenças entre navegadores (aula Reset e Normalize). O seletor * tem especificidade zero, então qualquer regra sua com classe passa por cima dela, se um dia você precisar de content-box numa caixa específica.

A variação com inherit

Você também vai encontrar esta versão:

html {
  box-sizing: border-box;
}

*,
*::before,
*::after {
  box-sizing: inherit;
}

Aqui, o <html> ganha border-box e todo o resto herda o valor do pai (inherit = "herdar", aula Herança). O resultado é o mesmo; a vantagem é que, se um componente inteiro precisar de content-box, basta pôr no elemento de fora, e os de dentro o seguem. As duas versões funcionam em todos os navegadores; escolha uma e use sempre.

Os campos de formulário já vêm diferentes

No Chromium que o guia usa para conferir, botões, <input>, <select> e <textarea> já vêm com box-sizing: border-box do próprio navegador, enquanto <div>, <p> e os outros vêm com content-box. Os padrões dos campos variam de navegador para navegador, e essa mistura é mais um motivo para a regra universal: com ela, todo mundo segue a mesma conta.

4. O box-sizing no F12

No F12 (aula DevTools), escolha um elemento na aba Elements (Elementos) e abra a aba Computed (Calculado). Lá estão:

  • a propriedade box-sizing, com o valor que está valendo;
  • o desenho do modelo de caixa: retângulos um dentro do outro (margem, borda, padding e conteúdo), com os números de cada um. Com border-box, o número do meio, o do conteúdo, fica menor que o width que você escreveu;
  • o width, que o Chrome mostra como o tamanho que você deu à caixa (os 200px do exemplo, nos dois casos).

(Os nomes das abas mudam um pouco entre o Chrome, o Edge e o Firefox, e entre as versões em inglês e em português.)

5. O que o border-box não faz

  • Não inclui a margem. Uma caixa de width: 50% com margin: 10px continua passando de 50%. Para espaço entre colunas, use o gap do Flexbox e do Grid (aula gap).
  • Não faz mágica com padding grande demais. Se padding + borda passarem da largura (width: 30px; padding: 20px, 40px de padding numa caixa de 30), o conteúdo vai a zero e a caixa cresce mesmo assim.
  • Vale também para a altura. Com height: 100px e padding: 20px, sobram só 60px para o conteúdo. Se o texto não couber, ele vaza (aula Largura e Altura).
  • Não muda nada em caixas sem width nem height. Uma caixa automática já ocupa o espaço que tem, com padding e tudo. O box-sizing só entra na conta quando você dá um tamanho.

6. Qual usar

EscritaQuando usar
*, *::before, *::after { box-sizing: border-box; }No começo de todo projeto novo. É a recomendação do guia.
html { box-sizing: border-box; } + * { box-sizing: inherit; }A mesma ideia, com herança. Útil se você usa componentes de terceiros que esperam content-box.
.caixa { box-sizing: border-box; }Só numa caixa: para consertar um caso isolado num site antigo, sem mexer no resto.
box-sizing: content-box;Raro: quando o tamanho do conteúdo tem de ser exato (uma imagem de 300px com moldura em volta, por exemplo).

Quando dá errado

A declaração inválida é ignorada, em silêncio, e a caixa continua em content-box. No F12, ela aparece riscada no painel de estilos.

Valor errado: is not a “box-sizing” value 
$ cat bs1.css
.caixa {
  box-sizing: border;
}
$ vnu --css bs1.css
"file:/home/ana/site/bs1.css":2.15-2.20: error: CSS: “box-sizing”: “border” is not a “box-sizing” value.
$ vnu --css bs2.css
"file:/home/ana/site/bs2.css":2.15-2.23: error: CSS: “box-sizing”: “borderbox” is not a “box-sizing” value.

O que você vê: a caixa continua somando padding e borda, como se a linha não existisse.

O que significa: "border não é um valor de box-sizing" (e borderbox, sem o hífen, também não). Os únicos valores são content-box e border-box, com hífen.

Como consertar: box-sizing: border-box;.

Missão: o campo deveria caber no formulário (width: 100% com padding), mas passa da borda à direita. A Ana até escreveu o box-sizing, mas o navegador o ignorou. Conserte.

<link rel="stylesheet" href="style.css">
<form class="formulario">
  <div class="campo">Seu nome</div>
</form>

.formulario {
  max-width: 300px;
  border: 2px solid teal;
  padding: 10px;
}

.campo {
  width: 100%;
  padding: 10px;
  border: 2px solid gray;
  box-sizing: borderbox;
}

.formulario {
  max-width: 300px;
  border: 2px solid teal;
  padding: 10px;
}

.campo {
  width: 100%;
  padding: 10px;
  border: 2px solid gray;
  box-sizing: border-box;
}

(O "campo" aqui é um <div> desenhado como campo, para o exemplo funcionar igual em todos os navegadores: os campos de verdade, <input>, já vêm com regras próprias, como você viu na nota da seção 3.)

Pus o border-box e as colunas ainda não cabem

O que você vê: duas caixas de width: 50% com box-sizing: border-box, mas a segunda continua caindo para a linha de baixo.

Por quê: confira três coisas. (1) Uma margin: ela nunca entra no border-box. (2) Um espaço no HTML entre duas caixas inline-block, que vira um espacinho na tela. (3) A regra foi escrita num seletor que não casa com as caixas (um erro de digitação na classe), e o F12, na aba Computed, mostra box-sizing: content-box.

O que o validador diz: nada. Nos três casos, o CSS é válido.

Resumo

  • box-sizing diz o que o width e o height medem.
  • content-box (o padrão): só o conteúdo; padding e borda são somados por fora. border-box: até a borda; o que você escreve é o que a caixa ocupa.
  • O caso clássico: colunas de 50% com padding não cabem lado a lado em content-box.
  • Comece todo CSS com *, *::before, *::after { box-sizing: border-box; } (ou a versão com inherit).
  • A margem nunca entra na conta.
  • Erros: border ou borderbox no lugar de border-box; o navegador ignora e a caixa continua somando.
