CSS Degradês (linear-gradient)

Um degradê (em inglês, gradient) é a passagem suave de uma cor para outra: o céu do pôr do sol, do laranja ao amarelo. No CSS, ele é feito pela função linear-gradient() ("degradê linear", em linha reta), e não precisa de nenhum arquivo de imagem: o próprio navegador desenha. Nesta aula você vai fazer o botão da lojinha com um leve degradê, listras de toalha de piquenique e escurecer a foto do bolo para o título ficar legível.

Você vai aprender
  • Por que o degradê é uma imagem, e vai no background-image (e não no background-color).
  • Como escolher a direção: to right, to bottom right e os graus (45deg).
  • Como usar várias cores e dizer onde cada uma começa (as paradas).
  • Como fazer listras, com corte seco e com repeating-linear-gradient().
  • Como pôr um degradê transparente por cima de uma foto.
  • O degradê que vira faixas no body, e os erros reais do validador W3C.

Antes, veja Imagem de Fundo e Tamanho do Fundo. As mensagens do validador saíram do validador W3C (vnu) na máquina fictícia da Ana.

A ideia: uma imagem que o navegador pinta

Imagine a Ana pintando uma parede com rolo: ela começa com tinta vermelha numa ponta, vai misturando amarelo aos poucos e termina com amarelo puro na outra ponta. No meio, as cores se misturam sozinhas. Ela só decide as cores e a direção. O linear-gradient() é isso.

O detalhe importante: para o CSS, o degradê é uma imagem, igual a um .jpg, só que gerada na hora. Por isso ele entra no background-image, no lugar do url(), e obedece a tudo o que você viu nas aulas de imagem de fundo (tamanho, posição, repetição, várias imagens).

1. O primeiro degradê

<link rel="stylesheet" href="style.css">
<div class="faixa">Promoção da semana</div>

.faixa {
  background-image: linear-gradient(tomato, gold);
  height: 120px;
}
background-image
A propriedade da imagem de fundo. O degradê é uma imagem.
linear-gradient(
A função do degradê em linha reta. Como no url(, o nome vem colado no parêntese.
tomato, gold
As cores, separadas por vírgula, na ordem em que aparecem. São pelo menos duas. Qualquer forma de cor serve: nome, hex, rgb(), hsl().
)
Fecha a função.

Sem dizer a direção, o degradê vai de cima para baixo: tomate no alto, amarelo-ouro embaixo, e todos os tons de laranja no meio. Ele ocupa a caixa inteira: de 120 pixels de altura, as cores se espalham pelos 120.

2. A direção

A direção vem antes das cores, separada delas por vírgula. Há duas formas de escrever: com palavras (to + o lado) e com graus. As caixas abaixo têm as mesmas duas cores; só muda a direção, escrita dentro de cada uma:

<link rel="stylesheet" href="style.css">
<div class="caixa d1"><code>(nada) = to bottom</code></div>
<div class="caixa d2"><code>to right</code></div>
<div class="caixa d3"><code>to top</code></div>
<div class="caixa d4"><code>to bottom right</code></div>
<div class="caixa d5"><code>45deg</code></div>
<div class="caixa d6"><code>90deg</code></div>

.caixa {
  width: 200px;
  height: 100px;
  border: 1px solid gray;
  margin-bottom: 8px;
}

.caixa code {
  background-color: white;
}

.d1 {
  background-image: linear-gradient(tomato, gold);
}

.d2 {
  background-image: linear-gradient(to right, tomato, gold);
}

.d3 {
  background-image: linear-gradient(to top, tomato, gold);
}

.d4 {
  background-image: linear-gradient(to bottom right, tomato, gold);
}

.d5 {
  background-image: linear-gradient(45deg, tomato, gold);
}

.d6 {
  background-image: linear-gradient(90deg, tomato, gold);
}
DireçãoO degradê vai…
(nenhuma) ou to bottomde cima para baixo: a primeira cor em cima
to rightda esquerda para a direita
to topde baixo para cima: o tomate fica embaixo
to leftda direita para a esquerda
to bottom rightna diagonal, do canto de cima, à esquerda, para o canto de baixo, à direita
0degpara cima (igual a to top)
90degpara a direita (igual a to right)
180degpara baixo (igual a to bottom)
45degna diagonal, para cima e para a direita: o tomate no canto de baixo, à esquerda

Os graus são como os ponteiros de um relógio: 0deg aponta para o 12 (para cima), e o número cresce no sentido horário: 90deg é o 3, 180deg é o 6, 270deg é o 9. O deg vem de degree, "grau", e é obrigatório (seção "Quando dá errado").

FormaQuando usar
Palavras (to right)Na maioria das vezes: lê-se como português. E to bottom right acerta o canto da caixa, qualquer que seja o formato dela.
Graus (135deg)Quando você quer um ângulo exato, que não é para um lado nem para um canto.

O navegador guarda o degradê com as cores em rgb(): linear-gradient(to right, tomato, gold) vira linear-gradient(to right, rgb(255, 99, 71), rgb(255, 215, 0)). Como to bottom é a direção inicial, ele some do valor calculado: to bottom e 180deg são guardados sem direção nenhuma (lido no Chromium).

Missão: a faixa de promoção está com fundo liso. Troque por um degradê de tomato a gold, da esquerda para a direita, escrito com to right.

<link rel="stylesheet" href="style.css">
<div class="faixa">Promoção: bolo de cenoura com 10% de desconto</div>

.faixa {
  background-color: tomato;
  padding: 16px;
}

.faixa {
  background-color: tomato;
  background-image: linear-gradient(to right, tomato, gold);
  padding: 16px;
}

Repare que a solução mantém o background-color: tomato. O degradê fica por cima da cor (é uma imagem), então ela não aparece; mas, se algum navegador antigo não entender o degradê, a faixa continua tomate, e o texto continua legível.

3. Várias cores e as paradas

Você pode pôr quantas cores quiser. Sem dizer onde cada uma fica, o navegador as espalha por igual: com três cores, a do meio fica a 50%. Para escolher o lugar, escreva uma parada (color stop) depois da cor: uma porcentagem ou um tamanho.

<link rel="stylesheet" href="style.css">
<div class="caixa a"><code>tomato, gold, seagreen</code></div>
<div class="caixa b"><code>tomato 30%, gold 70%</code></div>
<div class="caixa c"><code>tomato 50%, gold 50%</code></div>
<div class="caixa d"><code>três faixas</code></div>

.caixa {
  height: 80px;
  border: 1px solid gray;
  margin-bottom: 8px;
}

.caixa code {
  background-color: white;
}

.a {
  background-image: linear-gradient(to right, tomato, gold, seagreen);
}

.b {
  background-image: linear-gradient(to right, tomato 30%, gold 70%);
}

.c {
  background-image: linear-gradient(to right, tomato 50%, gold 50%);
}

.d {
  background-image: linear-gradient(to right, seagreen 33%, white 33% 66%, tomato 66%);
}
  • a: três cores espalhadas por igual: tomate na esquerda, ouro no meio, verde na direita.
  • b: o tomate é puro até 30% da largura, a mistura acontece entre 30% e 70%, e dali em diante é ouro puro. As paradas dizem onde cada cor está inteira.
  • c: as duas cores param no mesmo lugar (50%): não sobra espaço para misturar, e a passagem vira um corte seco. Metade tomate, metade ouro.
  • d: com cortes secos, três faixas: verde, branco e tomate. O white 33% 66% é uma cor com duas paradas: branco puro de 33% a 66%.

O degradê com corte seco é um jeito de desenhar faixas e bandeiras sem imagem nenhuma.

4. Listras: repeating-linear-gradient()

A irmã repeating-linear-gradient() ("degradê linear que se repete") repete as paradas até o fim da caixa. Com cortes secos, ela faz listras, como numa toalha de piquenique ou na fita de "em obras":

<link rel="stylesheet" href="style.css">
<div class="toalha"></div>

.toalha {
  background-image: repeating-linear-gradient(45deg, tomato 0 10px, gold 10px 20px);
  height: 120px;
}

As paradas dizem: tomate de 0 a 10 pixels, ouro de 10 a 20 pixels. Depois dos 20, o padrão recomeça, e assim até cobrir a caixa: listras diagonais de 10 pixels, alternando tomate e ouro. Mude o 45deg para 90deg (listras em pé) e os tamanhos para 0 20px e 20px 40px (listras mais largas).

5. Degradê transparente por cima de uma foto

Na aula Imagem de Fundo, o título em cima da foto precisava de ajuda para ter contraste. O degradê é essa ajuda. Como ele é uma imagem, entra numa lista de imagens, em primeiro lugar (por cima da foto), com cores que vão de um preto meio transparente ao transparent:

<link rel="stylesheet" href="style.css">
<div class="capa">
  <h1>Bolo de cenoura</h1>
</div>

.capa {
  background-color: saddlebrown;
  background-image:
    linear-gradient(rgb(0 0 0 / 70%), transparent),
    url("assets/midia/bolo-800.jpg");
  background-size: cover;
  background-position: center;
  color: white;
  height: 250px;
}

A parte de cima da foto fica escurecida, e a escuridão vai sumindo em direção ao bolo. O título branco, no alto, ganha um fundo escuro por trás e fica fácil de ler, e o bolo continua bonito. Apague a linha do linear-gradient (e a vírgula depois dele) para comparar: as letras brancas quase somem sobre a parede clara.

O background-size: cover e o background-position: center valem para as duas imagens da lista. O degradê não liga: ele sempre se estica para a caixa inteira.

6. O degradê em faixas no body

Um degradê de fundo na página inteira parece fácil: body { background-image: linear-gradient(lightyellow, tomato); }. Mas, numa página curta, o resultado é estranho:

Experimente: aqui, o quadro tem 300px de altura fixa, mais alto que o conteúdo, como uma janela de verdade. Veja as faixas. Depois, apague o /* e o */ da primeira regra. (O botão ↗ abre o resultado numa aba nova, com a altura da sua janela.)

<link rel="stylesheet" href="style.css">
<h1>Receitas da Ana</h1>
<p>Bolo de cenoura.</p>

/* html {
  min-height: 100%;
} */

body {
  background-image: linear-gradient(lightyellow, tomato);
}

Sem o conserto, o degradê aparece em faixas: do amarelo ao tomate na altura do título e do parágrafo, e de novo, e de novo, até o fim da janela. Por quê? O fundo do body pinta a janela inteira (aula Cor de Fundo), mas o tamanho da imagem é medido pela página, que tem só a altura do conteúdo, uns 114 pixels. O degradê tem 114 pixels de altura e se repete, como toda imagem de fundo.

Com html { min-height: 100%; }, a página passa a ter no mínimo a altura da janela, e o degradê vai de cima a baixo uma vez só. Outra saída é background-repeat: no-repeat com background-color: tomato: depois do fim do degradê, a cor continua.

Quando dá errado

Erro de propósito: as cinco caixas deviam ter degradês. Todas ficaram sem fundo, só com a borda cinza. Leia os cenários e conserte.

<link rel="stylesheet" href="style.css">
<div class="caixa um">um</div>
<div class="caixa dois">dois</div>
<div class="caixa tres">três</div>
<div class="caixa quatro">quatro</div>
<div class="caixa cinco">cinco</div>

.caixa {
  height: 80px;
  border: 1px solid gray;
}

.um {
  background-color: linear-gradient(tomato, gold);
}

.dois {
  background-image: linear-gradient(to right tomato, gold);
}

.tres {
  background-image: linear-gradient(to rigth, tomato, gold);
}

.quatro {
  background-image: linear-gradient(90, tomato, gold);
}

.cinco {
  background-image: linear-gradient(right, tomato, gold);
}
error: CSS: “background-color”: “linear-gradient(tomato, gold)” is not a “background-color” value.

O que aconteceu: o degradê foi para o background-color. Parece lógico ("é uma cor de fundo"), mas o degradê é uma imagem, e o background-color só aceita uma cor. A declaração é ignorada.

$ vnu --css style.css
"file:/home/ana/degrade/style.css":7.49-7.49: error: CSS: “background-color”: “linear-gradient(tomato, gold)” is not a “background-color” value.

Como consertar: background-image: linear-gradient(tomato, gold);, ou o atalho background: linear-gradient(tomato, gold);, que entende as duas coisas.

error: CSS: “background-image”: “tomato” is not a “linear-gradient” value.

O que aconteceu: faltou a vírgula entre a direção e a primeira cor: to right tomato. O navegador leu tudo como uma direção só e não entendeu.

$ vnu --css style.css
"file:/home/ana/degrade/style.css":11.58-11.58: error: CSS: “background-image”: “tomato” is not a “linear-gradient” value.

Como consertar: linear-gradient(to right, tomato, gold): vírgula depois da direção e entre as cores. Dentro de uma parada não há vírgula (tomato 30%).

error: CSS: “background-image”: “rigth” is not a “linear-gradient” value.

O que aconteceu: rigth, com as letras trocadas.

$ vnu --css style.css
"file:/home/ana/degrade/style.css":15.59-15.59: error: CSS: “background-image”: “rigth” is not a “linear-gradient” value.

Como consertar: right: r-i-g-h-t.

error: CSS: “background-image”: only “0” can be a “90”. You must put a unit after your number.

O que aconteceu: o ângulo sem a unidade: 90 no lugar de 90deg.

$ vnu --css style.css
"file:/home/ana/degrade/style.css":19.53-19.53: error: CSS: “background-image”: only “0” can be a “90”. You must put a unit after your number.

"Você precisa pôr uma unidade depois do número." (A primeira parte da frase, "só 0 pode ser um 90", é torta; ela quer dizer que só o zero pode ficar sem unidade.) No CSS, um número que é um tamanho ou um ângulo sempre leva a unidade.

Como consertar: 90deg, colado.

error: CSS: “background-image”: The first argument to the “linear-gradient” function should be “to right”, not “right”.

O que aconteceu: linear-gradient(right, …), sem o to. É a escrita antiga, dos degradês com prefixo (-webkit-linear-gradient(right, …)), que você ainda encontra em tutoriais velhos. Hoje, sem o to, o degradê é ignorado.

$ vnu --css style.css
"file:/home/ana/degrade/style.css":23.56-23.56: error: CSS: “background-image”: The first argument to the “linear-gradient” function should be “to right”, not “right”.

"O primeiro argumento da função linear-gradient deveria ser to right, e não right." Repare: na escrita antiga, right dizia de onde o degradê saía; com o to, diz para onde ele vai.

Como consertar: to right. E nada de prefixo -webkit-: todos os navegadores de hoje entendem o linear-gradient() sem ele.

Resumo

  • O degradê é uma imagem desenhada pelo navegador: vai no background-image (ou no atalho background), nunca no background-color.
  • linear-gradient(direção, cor1, cor2, …). Sem direção, vai para baixo. Direção com palavras (to right, to bottom right) ou graus (90deg, com a unidade).
  • Paradas dizem onde cada cor está pura; duas cores na mesma parada fazem um corte seco. repeating-linear-gradient() repete o padrão: listras.
  • Um degradê transparente na frente de um url() escurece a foto e dá contraste ao texto.
  • No body de uma página curta, o degradê se repete em faixas: html { min-height: 100%; } resolve.
  • Erros comuns: degradê no background-color, vírgula esquecida, rigth, ângulo sem deg e a escrita antiga sem to. O navegador ignora; o validador aponta.
